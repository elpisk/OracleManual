================================================================================
 제11장 실습 03 — 사용자와 프로젝트 할당량
 대상   : ol7a
 목표   : uquota·gquota·pquota 마운트 옵션으로 할당량을 켜고, xfs_quota -x 의
          limit·report·state 로 사용자·그룹·프로젝트 한도를 건다. /etc/projects 와
          /etc/projid 로 디렉터리 트리에 프로젝트 할당량을 건다. 루트 파일 시스템은
          remount 로 켤 수 없어 부트 파라미터 rootflags 가 필요함을 재부팅으로 확인한다
 배경   : XFS 할당량은 별도 파일(aquota.user)이 아니라 파일 시스템 메타데이터로
          관리된다. 켜는 시점은 마운트할 때 하나뿐이다. 사용자·그룹 할당량은
          소유자 기준이고, 프로젝트 할당량은 소유자와 무관하게 디렉터리 트리 기준이다.
          quotacheck·quotaon 같은 Ext 용 절차가 없다 (본문 11.6)
 소요   : 약 30분 (재부팅 2회 포함)
 선행   : storage-clean 스냅샷. student 계정(기준 상태에 있음)
 계정   : root, student
 주의   : [12] 에서 부트 파라미터를 바꾸고 재부팅한다. 끝에서 원래대로 돌리고
          한 번 더 재부팅한다. sda(VG ol)는 건드리지 않는다
 되돌림 : /etc/fstab·/etc/projects·/etc/projid 원복, 마운트 해제, wipefs,
          grubby 로 rootflags 제거 후 재부팅. /proc/cmdline 에 rootflags 가 없으면 끝

 [2] remount 로 켜 보기
--------------------------------------------------------------------------------

-- Ext4 는 remount 로 usrquota 를 붙일 수 있다. XFS 에서 같은 방법을 써 본다.
[root@ol7a ~]# mount -o remount,uquota /xfsq; echo "rc=$?"; grep xfsq /proc/mounts; dmesg | tail -2
rc=0
/dev/sdb /xfsq xfs rw,seclabel,relatime,attr2,inode64,logbufs=8,logbsize=32k,noquota 0 0
[   12.052627] XFS (sdb): Ending clean mount
[   12.052644] xfs filesystem being mounted at /xfsq supports timestamps until (%ptR?) (0x7fffffff)
-- rc=0 이지만 옵션은 여전히 noquota
-- 오류 없이 무시됐다. rc 만 믿으면 속는다
-- 2038 년 줄은 v4 형식의 시각 한계 알림

-- 언마운트했다가 옵션을 주고 다시 마운트한다.
--   uquota  사용자 할당량 계정과 강제(usrquota·quota 와 같은 뜻)
--   gquota  그룹 할당량(grpquota)
--   pquota  프로젝트 할당량(prjquota)
--   uqnoenforce 처럼 noenforce 가 붙으면 사용량만 세고 막지는 않는다
[root@ol7a ~]# umount /xfsq; mount -o uquota,gquota,pquota /dev/sdb /xfsq; grep xfsq /proc/mounts; dmesg | tail -3
mount: wrong fs type, bad option, bad superblock on /dev/sdb,
       missing codepage or helper program, or other error

       In some cases useful info is found in syslog - try
       dmesg | tail or so.
[   12.052644] xfs filesystem being mounted at /xfsq supports timestamps until (%ptR?) (0x7fffffff)
[   12.284914] XFS (sdb): Unmounting Filesystem
[   12.289987] XFS (sdb): Super block does not support project and group quota together
-- 증상   : mount 일반 문구 + dmesg 의 Super block does not support
--          project and group quota together
-- 원인   : 이 장치는 v4 형식이다([3] 의 V4)
--          v4 는 그룹·프로젝트가 inode 하나를 나눠 쓴다
-- 조치   : -m crc=1 로 v5 를 만들어 다시 마운트
-- 재확인 : /proc/mounts 의 usrquota,prjquota,grpquota

--------------------------------------------------------------------------------
 [3] v4 형식의 제약과 v5 로 다시 만들기
--------------------------------------------------------------------------------

-- 이 시스템의 mkfs.xfs 기본값이 어느 형식인지 슈퍼블록으로 본다.
[root@ol7a ~]# xfs_db -r -c version /dev/sdb
versionnum [0xb4a4+0x28a] = V4,NLINK,DIRV2,ALIGN,LOGV2,EXTFLG,MOREBITS,ATTR2,LAZYSBCOUNT,PROJID32BIT,FTYPE
-- 첫 항목 V4. CRC·FINOBT 가 없다
-- mkfs.xfs 5.4 기본값이 v4 다

-- -m crc=1  v5 형식(메타데이터 체크섬)으로 만든다. 그룹·프로젝트 할당량을 함께 쓸 수 있다.
[root@ol7a ~]# mkfs.xfs -f -q -m crc=1 -L xfsq /dev/sdb; xfs_db -r -c version /dev/sdb
versionnum [0xb4a5+0x18a] = V5,NLINK,DIRV2,ALIGN,LOGV2,EXTFLG,MOREBITS,ATTR2,LAZYSBCOUNT,PROJID32BIT,CRC,FTYPE,FINOBT,SPARSE_INODES
-- V5 로 바뀌고 CRC·FINOBT·SPARSE_INODES 가 붙었다
[root@ol7a ~]# mount -o uquota,gquota,pquota /dev/sdb /xfsq; echo "rc=$?"; grep xfsq /proc/mounts
rc=0
/dev/sdb /xfsq xfs rw,seclabel,relatime,attr2,inode64,logbufs=8,logbsize=32k,usrquota,prjquota,grpquota 0 0
-- uquota 는 usrquota 로 바뀌어 표시된다
-- 세 종류가 모두 켜졌다
