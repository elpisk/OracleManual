 제2장 실습 03 — 설치 결과 확인
 대상   : ol7a (os-installed 스냅샷 — 설치 직후, 업데이트 전)
 목표   : 설치가 남긴 기록(/root/anaconda-ks.cfg, /var/log/anaconda/)을 읽고,
          디스크 배치·패키지·커널·서비스·네트워크·계정이 설치 화면의 선택과
          맞는지 확인한다. 설치 로그에서 경고를 찾고, 켜지지 않은 NIC 를 진단한다
 배경   : Anaconda 는 설치 중 /tmp 에 로그를 쓰고, 성공하면 /var/log/anaconda/ 로
          옮긴다. 고른 설정은 kickstart 형식으로 /root/anaconda-ks.cfg 에 남는다.
          설치 직후 시스템은 저장소 설정만 있고 업데이트는 하지 않은 상태다.
          설치 후 첫 점검 목록이 곧 운영 서버 인수 점검 목록이 된다(본문 2.6·2.7절).
 소요   : 약 25분
 선행   : ol7a 를 os-installed 스냅샷으로 되돌림
 계정   : root
 주의   : [10] 에서 ens33 을 잠시 올렸다 내린다. 그 밖에는 조회만 한다
 되돌림 : ifdown ens33 후 ip -br addr show ens33 에 IPv4 주소가 없으면 시작 상태와 같다

-- 파일 전체 내용은 실습 02 [변형] 에서 본다. 여기서는 크기와 뼈대만 확인한다.

[root@ol7a ~]# wc -l < /root/anaconda-ks.cfg; grep -c '^#' /root/anaconda-ks.cfg; grep -c -v -E '^#|^$' /root/anaconda-ks.cfg
55
13
35
-- 55줄 중 주석 13줄, 지시어 35줄, 나머지 7줄은 빈 줄이다.
-- 구역 경계(% 로 시작하는 줄)만 줄 번호와 함께. 구역마다 %end 로 닫혔는지 본다.
[root@ol7a ~]# grep -n '^%' /root/anaconda-ks.cfg
36:%packages
45:%end
47:%addon com_redhat_kdump --enable --reserve-mb='auto'
49:%end
51:%anaconda
55:%end
-- 구역 셋(%packages, %addon, %anaconda)이
-- 모두 %end 로 닫혔다. %pre·%post 는 없다.
-- 해시가 든 두 줄은 앞부분만. $6$ 는 SHA-512 해시라는 표시다.
[root@ol7a ~]# grep -n -E '^(rootpw|user) ' /root/anaconda-ks.cfg | cut -c1-50
24:rootpw --iscrypted $6$5Cdlp2/WVWJJT7nO$FPGiuZ0X
29:user --groups=wheel --name=student --password=$
-- rootpw --iscrypted 는 해시를 그대로
-- 적었다는 뜻이다. $6$ 뒤 두 번째 $ 까지가 솔트다.
-- 이 파일은 암호 해시를 담으므로 600 을
-- 유지하고, 공유할 때는 이 두 줄을 지운다.

Maybe run: yum groups mark convert (see man yum)
rc=0

 [10] 켜지지 않은 NIC 진단 — ens33
--------------------------------------------------------------------------------

[root@ol7a ~]# nmcli -f DEVICE,TYPE,STATE,CONNECTION device
DEVICE  TYPE      STATE         CONNECTION 
ens32   ethernet  connected     ens32      
ens33   ethernet  disconnected  --         
lo      loopback  unmanaged     --         
-- ens33 은 장치는 있지만 연결(CONNECTION)이
-- 붙지 않은 disconnected 다.
[root@ol7a ~]# cat /etc/sysconfig/network-scripts/ifcfg-ens33
TYPE=Ethernet
PROXY_METHOD=none
BROWSER_ONLY=no
BOOTPROTO=dhcp
DEFROUTE=yes
IPV4_FAILURE_FATAL=no
IPV6INIT=yes
IPV6_AUTOCONF=yes
IPV6_DEFROUTE=yes
IPV6_FAILURE_FATAL=no
IPV6_ADDR_GEN_MODE=stable-privacy
NAME=ens33
UUID=09e33476-a93c-4005-a933-74479920bb5b
DEVICE=ens33
ONBOOT=no
-- 주소를 DHCP 로 받게 돼 있지만
-- ONBOOT=no 라 부팅 때 올리지 않는다.
-- NAME·UUID·IPV6_* 키는
-- NetworkManager 가 만든 ifcfg 의 특징이다.
[root@ol7a ~]# ifup ens33
Connection successfully activated (D-Bus active path: /org/freedesktop/NetworkManager/ActiveConnection/2)
-- 7 의 ifup 은 NetworkManager 와
-- network-scripts 를 함께 쓴다.
-- [OL8/9] ifup 은 nmcli 래퍼다.
-- ifup 은 NetworkManager 에게 ens33
-- 연결을 켜라고 요청한다(D-Bus 경로가 그 흔적).
[root@ol7a ~]# ip -br addr show ens33; ip route
ens33            UP             172.16.225.132/24 fe80::f0a:d06b:8d7b:c663/64 
default via 172.16.225.2 dev ens32 proto static metric 100 
default via 172.16.225.2 dev ens33 proto dhcp metric 101 
172.16.225.0/24 dev ens32 proto kernel scope link src 172.16.225.61 metric 100 
172.16.225.0/24 dev ens33 proto kernel scope link src 172.16.225.132 metric 101 
-- ens33 이 DHCP 로 172.16.225.132
-- 를 받았다. 장치와 DHCP 는 정상이다.
-- 기본 경로가 둘이 됐다. metric 100(ens32)이
-- 101(ens33)보다 작아 ens32 쪽이 먼저 쓰인다.
[root@ol7a ~]# ifdown ens33; ip -br addr show ens33
Device 'ens33' successfully disconnected.
ens33            UP             
-- 증상   : ens33 에 주소가 없다(nmcli disconnected, ip 에 IPv4 없음)
-- 원인   : 설치 화면에서 켜지 않아 ifcfg-ens33 이 ONBOOT=no 로 만들어졌다
-- 조치   : 지금은 ifup ens33. 부팅 때마다 올리려면 ONBOOT=yes 로 바꾼다(13장)
-- 재확인 : ifup 뒤 172.16.225.132/24 와 dhcp 경로. ifdown 으로 되돌리면 다시 주소가 없다
-- ifup 은 ifcfg 파일을 바꾸지 않는다. 재부팅하면 다시 주소가 없다.

[root@ol7a ~]# id student; getent group wheel
uid=1000(student) gid=1000(student) groups=1000(student),10(wheel)
wheel:x:10:student
-- 사용자·그룹은 8장에서 다룬다.
-- student 는 wheel 그룹 구성원이다.
-- wheel 은 sudo 를 쓸 수 있는 관리자 그룹이다.
[root@ol7a ~]# awk -F: '$1=="root"||$1=="student"{print $1, substr($2,1,3), $3, $5}' /etc/shadow
root $6$  99999
student $6$  99999
-- 열: 이름, 해시 앞 세 글자, 마지막 변경일,
-- 최대 사용일. $6$ 는 SHA-512.
-- 셋째 열(마지막 변경일)이 비어 있다. 설치 프로그램이 날짜를 적지 않았다.
[root@ol7a ~]# chage -l student | head -4
Last password change                                    : never
Password expires                                        : never
Password inactive                                       : never
Account expires                                         : never
-- 그래서 Last password change
-- 가 never 다. 암호 만료도 없다.
[root@ol7a ~]# grep -E '^(ENCRYPT_METHOD|PASS_MAX_DAYS|PASS_MIN_LEN|UID_MIN)' /etc/login.defs
PASS_MAX_DAYS   99999
PASS_MIN_LEN    5
UID_MIN                  1000
ENCRYPT_METHOD SHA512
-- PASS_MIN_LEN 5 는 PAM(pwquality)을 쓰는
-- 7 의 passwd 길이 검사에는 쓰이지 않는다.
-- 새 계정의 기본값. 이후 useradd 는 UID 1000 부터,
-- SHA512 해시, 만료 99999일(사실상 없음)로 만든다.
