================================================================================
 제2장 실습 02 — Anaconda 그래픽 설치 과정
 대상   : ol7a (설치 화면은 VNC 캡처, 설치 결과는 os-installed 스냅샷에서 확인)
 목표   : 설치 화면을 순서대로 따라가며 각 선택이 무엇을 정하는지 기록하고,
          그 선택이 설치된 시스템의 어느 파일·설정으로 남았는지 바로 대조한다
 배경   : Anaconda 는 허브(INSTALLATION SUMMARY)와 스포크(각 설정 화면) 구조다.
          경고 아이콘이 붙은 스포크를 모두 채워야 Begin Installation 이 켜진다.
          디스크는 Begin Installation 을 누르기 전까지 건드리지 않는다. 설치가 끝나면
          고른 값이 /root/anaconda-ks.cfg 에 kickstart 형식으로 남는다(본문 2.2절).
 소요   : 설치 약 15분(19:43 Begin → 19:57 Complete), 확인 약 15분
 선행   : 빈 VM ol7a(디스크 5개, NIC 2개)에 OEL7V9.iso 연결. 확인 단계는 os-installed
 계정   : 설치 화면에서 root/oracle, student/student 생성. 확인은 root
 주의   : 설치는 선택한 디스크(sda)를 지운다. 이 기록은 2026-11-11 19:40~19:58 의
          실제 설치 화면을 순서대로 옮긴 것이다. 화면 파일은 img/02/ 에 있다
 되돌림 : 확인 단계에서 켠 chronyd 를 [12] 에서 끈다. timedatectl 의 NTP enabled: no

[root@ol7a ~]# lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINT

-- root 는 35.12GiB LV, df 는 36G 로 반올림해 보인다. /home 은 없다(디스크 50GiB 미만).
-- DB 서버라면 설치 뒤 /u01 용 LV 를 만들 생각을 하게 된다. 자동 분할이 VG 를 얼마나
-- 남겼는지 보고, 10GB LV 를 만들어 본다. 만들어지면 바로 지운다.
[root@ol7a ~]# vgs -o vg_name,vg_size,vg_free ol

  ol <39.00g 4.00m
[root@ol7a ~]# lvcreate -L 10G -n u01 ol; echo "rc=$?"

rc=5
-- 증상   : "Volume group "ol" has insufficient free space (1 extents): 2560 required.", rc=5
-- 원인   : 자동 분할이 VG 를 거의 다 썼다. VFree 4.00m 는 4MiB 익스텐트 하나다
-- 조치   : 설치 때 수동 분할로 /u01 을 정하거나, 설치 뒤에는 디스크를 더해 VG 를 늘린다(10장)
-- 재확인 : vgs 의 VFree 가 10G 이상이 된 뒤 같은 lvcreate 가 성공한다
-- 설계한 오류는 "자동 분할로 /home 이 커짐" 이었으나 40GiB 디스크에서는 /home 이 생기지 않아 바꿨다.

-- 화면 : a26_config.png
--   문구 : "CONFIGURATION", ROOT PASSWORD "Root password is not set", USER CREATION
--          "No user will be created", 아래 "Starting package installation process"
--   선택 : Begin Installation 을 누르는 순간 디스크 작업과 패키지 설치가 시작되고,
--          계정 설정은 그동안 한다
-- 화면 : a27_rootpw.png
--   문구 : 강도 막대 "Weak", 아래 띠 "The password you have provided is weak: The
--          password fails the dictionary check - it is based on a dictionary word You
--          will have to press Done twice to confirm it.."
--   선택 : root 암호 oracle 입력 후 Done 한 번
-- 화면 : a28_rootpw_weak.png
--   문구 : 띠가 "... it is based on a dictionary word. Press Done again to use anyway."
--          로 바뀌었다
--   선택 : Done 을 한 번 더 눌러 받아들였다
[root@ol7a ~]# sed -n '/^%anaconda/,/^%end/p' /root/anaconda-ks.cfg
%anaconda
pwpolicy root --minlen=6 --minquality=1 --notstrict --nochanges --notempty
pwpolicy user --minlen=6 --minquality=1 --notstrict --nochanges --emptyok
pwpolicy luks --minlen=6 --minquality=1 --notstrict --nochanges --notempty
-- root·user·luks 각각 최소 6자, 품질 1, --notstrict(약해도 Done 두 번이면 허용).
%end
[root@ol7a ~]# grep -E '^(rootpw|auth)' /root/anaconda-ks.cfg | cut -c1-40
auth --enableshadow --passalgo=sha512
rootpw --iscrypted $6$5Cdlp2/WVWJJT7nO$F
-- 설치 화면의 강도 검사는 libpwquality 가 한다. 같은 라이브러리의 pwscore 로 재현한다.
[root@ol7a ~]# echo oracle | pwscore; echo "rc=$?"
Password quality check failed:
 The password is shorter than 8 characters
rc=1
-- 설치 화면은 "dictionary word" 였는데 여기서는 "shorter than 8 characters" 다.
[root@ol7a ~]# echo 'Ol7-Adm1n#Lab' | pwscore; echo "rc=$?"
95
rc=0
-- pwscore 는 /etc/security/pwquality.conf 를 읽는다. 설치 화면은 pwpolicy 의 --minlen=6 을 썼다.
-- 설정 파일에 무엇이 켜져 있는지 본다(주석·빈 줄 제외, 아무것도 없으면 grep rc=1).
[root@ol7a ~]# grep -v -E '^#|^$' /etc/security/pwquality.conf; echo "rc=$?"
rc=1
-- 설정 파일에 켜진 항목이 없다. 기본값의 최소 길이 규칙에 6자 oracle 이 걸렸다.
-- 설치 화면과 같은 조건(minlen 6)을 잠시 넣고 다시 검사한다. 원본은 백업해 둔다.
[root@ol7a ~]# cp -p /etc/security/pwquality.conf /root/pwquality.conf.bak; echo 'minlen = 6' >> /etc/security/pwquality.conf
[root@ol7a ~]# echo oracle | pwscore; echo "rc=$?"
Password quality check failed:
 The password fails the dictionary check - it is based on a dictionary word
rc=1
-- 증상   : 같은 암호 oracle 이 설치 화면과 pwscore 에서 다른 이유로 거부됨
-- 원인   : pwscore 는 pwquality.conf 기본값을, 설치 화면은 pwpolicy 의 --minlen=6 을 썼다
-- 조치   : 설치 화면과 같은 minlen = 6 을 넣고 다시 검사했다
-- 재확인 : "fails the dictionary check - it is based on a dictionary word" 로 화면과 같아졌다
-- 두 번째 인자는 사용자 이름이다. 사용자 이름이 든 암호를 검사한다.
[root@ol7a ~]# echo student | pwscore student; echo "rc=$?"
Password quality check failed:
 The password contains the user name in some form
rc=1
-- student 계정의 경고 "contains the user name in some form" 도 같은 라이브러리에서 나온다.
[root@ol7a ~]# cp -p /root/pwquality.conf.bak /etc/security/pwquality.conf; rm -f /root/pwquality.conf.bak; grep -c '^minlen' /etc/security/pwquality.conf
0
-- 되돌렸다. minlen 줄 0개.
