 제18장 실습 07 — sosreport 만들기와 OSWatcher 설치·보관 파일
 대상   : ol7a
 목표   : sosreport 를 만들고(--batch, --case-id, --label, -o) 묶음을 풀어
          구조를 확인한다. 대화형 확인과 임시 공간 부족을 겪어 본다.
          OSWatcher 를 ol7_addons 저장소에서 설치해 서비스로 돌리고,
          보관 파일의 형식과 수집 간격·보관 시간 설정을 바꿔 본다

          tar.xz 로 묶는다. 모으는 동안 /var/tmp 아래에 풀린 사본을 먼저 만든다.
          OSWatcher 는 vmstat·iostat·top·ps 등을 정해진 간격으로 돌려 시간별
          파일로 남기는 셸 스크립트 묶음이다. 공식 문서는 MOS 문서 301137.1 의
          tar 를 안내하지만 OL7 은 ol7_addons 에 RPM 도 있다(본문 18.8, 18.9)
 소요   : 약 30분
 선행   : ol7-base 스냅샷. 인터넷(yum.oracle.com)
 계정   : root
 주의   : sos 는 기준 상태에 이미 있다(지우지 않는다). oswatcher 는 설치했다가
          끝에서 지운다. 작은 tmpfs 를 잠깐 마운트한다
 되돌림 : sosreport·풀린 디렉터리 삭제, tmpfs 해제, oswatcher 제거와 데이터 삭제.

-- 증상   : sosreport 가 Press ENTER to continue, or CTRL-C to
--          quit. 다음에
--          EOF when reading a line 을 찍고 exit 1. 묶음은 만들어지지 않았다(마지막 0)
-- 원인   : --batch 가 없으면 시작 전에 확인을 받는다. 입력이
--          /dev/null 이라 읽을 줄이 없었다

-- 조치   : 자동화·원격 실행에서는 늘 --batch 를 붙인다

 [9] 설정 파일과 서비스

[root@ol7a ~]# cat /etc/sysconfig/oswatcher
# The directory where oswatcher logs should be kept
DATADIR=/var/log/oswatcher
# The interval (in seconds) between runs runs of statistics collections
INTERVAL=30
# The maximum age (in hours) of the various log files
MAXAGE=48
# An optional program used to compress the log files
ZIP=gzip
-- DATADIR 보관 위치, INTERVAL 수집 간격(초), MAXAGE 보관
-- 시간(시간), ZIP 압축 도구
-- 30초·48시간은 tar 판 startOSWbb.sh 의 기본값과 같다
[root@ol7a ~]# systemctl cat oswatcher | grep -E '^(Type|EnvironmentFile|ExecStart|Restart)'
Type=simple
EnvironmentFile=/etc/sysconfig/oswatcher
Restart=on-abort
ExecStart=/usr/sbin/OSWatcher $INTERVAL $MAXAGE $ZIP $DATADIR
-- EnvironmentFile 로 위 네 변수를 읽어 ExecStart 의 인자로
-- 넘긴다. 상주하는 셸 스크립트라 Type=simple
[root@ol7a ~]# systemctl is-enabled oswatcher; systemctl is-active oswatcher
