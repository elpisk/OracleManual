================================================================================
 제5장 실습 03 — 설치와 이력 되돌리기
 대상   : ol7a
 목표   : yum 으로 패키지를 설치하면서 의존성 해석 결과를 읽고, yum history 로
          트랜잭션을 확인한 뒤 undo·rollback 으로 되돌린다. 의존성으로 함께
          들어온 패키지까지 되돌아가는지, 뒤 트랜잭션이 같은 패키지를 건드렸을
          때 undo 가 어떻게 되는지 본다
 배경   : yum 은 설치·업데이트·제거를 트랜잭션 단위로 /var/lib/yum/history 의
          SQLite 데이터베이스에 남긴다. undo 는 트랜잭션 하나의 반대 동작,
          rollback 은 지정한 시점 이후 전부의 반대 동작이다.
          rpm 으로 직접 설치한 것은 이 이력에 남지 않는다 (본문 5.4)
 소요   : 약 25분
 선행   : ol7-base 스냅샷, 인터넷 접속
 계정   : root
 주의   : httpd 와 mod_ssl 을 설치했다 지운다
 되돌림 : rpm -qa | wc -l 이 [0] 의 값(565)으로 돌아오면 끝
================================================================================

 [6] undo — 의존성까지 되돌아가는가
--------------------------------------------------------------------------------

-- undo 는 last 를 받는다. info 와 다르다.
-- -y 를 붙여 확인 질문을 건너뛴다.
-- undo N : N 번의 반대 동작. 설치였으니 제거.
[root@ol7a ~]# yum history undo -y last 2>&1 | sed -n '/^Removed/,$p'
Removed:
  apr.x86_64 0:1.4.8-7.el7            apr-util.x86_64 0:1.5.2-6.0.1.el7_9.1    
  httpd.x86_64 0:2.4.6-99.0.5.el7_9.1 httpd-tools.x86_64 0:2.4.6-99.0.5.el7_9.1
  mailcap.noarch 0:2.1.41-2.el7      

Complete!
-- 확인 질문 없이 바로 지웠다.
-- 의존성 넷까지 다섯 개 모두 Removed.

-- tail -2 로 각 설치의 마지막 두 줄만 남겼다.

     7 | root <root>              | 2026-11-13 09:23 | Erase          |    5
