================================================================================
 제5장 실습 04 — 오류 재현: 의존성 충돌
 대상   : ol7a
 목표   : 의존 패키지가 없는 RPM 을 rpm -ivh 로 설치해 의존성 오류를 재현하고,
          yum localinstall 이 같은 파일을 어떻게 처리하는지 비교한다.
          --nodeps 로 억지로 설치한 패키지가 어떤 증상을 남기고 rpm -Va·yum check
          에서 어떻게 드러나는지 확인한 뒤 정리한다
 배경   : rpm 은 패키지 파일 하나만 보고 판단한다. 필요한 라이브러리가 없으면
          설치를 거부할 뿐 받아 오지 않는다. yum 은 같은 파일을 저장소와 함께
          의존성 해석에 넣어 빠진 것을 채운다. --nodeps 는 검사만 끄는 옵션이라
          문제를 없애지 않고 숨긴다 (본문 5.2·5.4)
 소요   : 약 25분
 선행   : ol7-base 스냅샷, 인터넷 접속
 계정   : root
 주의   : --nodeps 로 깨진 상태를 일부러 만든다. 운영 서버에서 하지 않는다.
          이 실습 뒤에는 ol7-base 로 되돌리는 것을 권한다
 되돌림 : 설치한 패키지 제거, rpm -qa | wc -l 이 565, yum check 가 깨끗하면 끝
================================================================================

 [0] 시작 전 상태 기록
--------------------------------------------------------------------------------

[root@ol7a ~]# rpm -qa | wc -l; rpm -q httpd httpd-tools apr apr-util mailcap
565
package httpd is not installed

-- 실습 03 의 httpd 와 같은 묶음이다.
-- 이번에는 rpm 으로 다룬다.
-- 같은 다섯 패키지로 rpm 과 yum 의 차이만 보려는 것이다.
-- 565 개, 다섯 모두 미설치.
-- 이 서버에서 얼마나 걸리는지도 함께 본다.
-- yum check 는 rpm 데이터베이스 전체의 의존성·중복을 검사한다.
-- timeout 180 은 3분이 지나면 끊는 장치. PIPESTATUS[0] 은 파이프 첫 명령(timeout)의 종료 코드다.
-- tail 의 코드가 아니다.
[root@ol7a ~]# timeout 180 yum check 2>&1 | tail -2; echo "rc=${PIPESTATUS[0]}"
Loaded plugins: langpacks, ulninfo
rc=124
-- yum check 는 이 실습 끝까지 같은 결과를 낸다.
-- rc=124 는 timeout 이 끊었다는 뜻이다.
-- 3분 안에 끝나지 않았다.
-- 첫 실행(11-13)에서는 제한 없이 돌렸다가 600초를 넘겨 yum 잠금을 잡은 채 남았고, 뒤의 yum 명령까지 줄줄이 막혔다.
-- 이 서버에서 yum check 는 기준 상태 확인 도구로 쓰기 어렵다.
-- 대신 [9] 에서 보듯 yum 의 다른 명령이 같은 검사를 짧게 보여 준다.

 [1] RPM 파일 받기 — yumdownloader
--------------------------------------------------------------------------------

-- 의존 패키지는 받지 않는다.
-- --destdir 로 받을 곳을 정한다. 없으면 현재 디렉터리.
-- 받은 파일은 yum 캐시가 아니라 이 디렉터리에 남는다.
-- yumdownloader(yum-utils)는 설치하지 않고 RPM 파일만 받는다.
-- 의존성은 받지 않는다. httpd 하나만 온다.
[root@ol7a ~]# mkdir -p /root/rpms; yumdownloader --destdir=/root/rpms httpd 2>&1 | tail -2; ls -l /root/rpms
Loaded plugins: langpacks
total 1228
-rw-r--r--. 1 root root 1250444 Oct 16  2024 httpd-2.4.6-99.0.5.el7_9.1.x86_64.rpm
-- 받은 파일은 하나뿐이다.
-- 파일 크기 1,250,444 바이트(약 1.2M). 날짜는 빌드 시각을 따른다.

--------------------------------------------------------------------------------
 [3] rpm -ivh — 의존성 실패
--------------------------------------------------------------------------------

-- 오류가 나면 rc 는 1 이다.
-- -i 설치, -v 자세히, -h 진행 막대. 실패해도 시스템은 그대로다.
-- rpm 으로 파일 하나만 설치해 본다.
[root@ol7a ~]# rpm -ivh /root/rpms/httpd-*.rpm; echo "rc=$?"
error: Failed dependencies:
        /etc/mime.types is needed by httpd-2.4.6-99.0.5.el7_9.1.x86_64
        httpd-tools = 2.4.6-99.0.5.el7_9.1 is needed by httpd-2.4.6-99.0.5.el7_9.1.x86_64
        libapr-1.so.0()(64bit) is needed by httpd-2.4.6-99.0.5.el7_9.1.x86_64
        libaprutil-1.so.0()(64bit) is needed by httpd-2.4.6-99.0.5.el7_9.1.x86_64
rc=1
-- 설치는 전혀 진행되지 않았다.
-- rpm -q httpd 는 여전히 not installed 다.
-- 오류 흐름 ① — rpm -ivh 의존성 실패
-- 증상   : "error: Failed dependencies:" 아래 네 줄, rc=1 "/etc/mime.types is needed by httpd-2.4.6-99.0.5.el7_9.1.x86_64"
--          "libapr-1.so.0()(64bit) is needed by ..." 등
-- 원인   : rpm 은 파일 하나와 설치된 데이터베이스만 본다.
--          요구 기능 넷을 제공하는 패키지가 없고, rpm 은 저장소에서 받아 오지 않는다.
-- 조치   : 같은 파일을 yum localinstall 로 설치한다([5]).
--          또는 빠진 것을 yum provides 로 찾아 함께 설치한다([4]).
-- 재확인 : [5] 에서 의존성 넷과 함께 설치, rpm -q 다섯 줄 모두 설치됨
-- 메시지는 패키지 이름이 아니라 기능 이름으로 나온다.
-- 어느 패키지가 그 기능을 주는지는 따로 찾아야 한다.

 [6] 반대 방향 — 의존 대상을 rpm -e 로 지우기
--------------------------------------------------------------------------------

-- 거꾸로, 다른 패키지가 기대는 apr 을 rpm 으로 지워 본다.
[root@ol7a ~]# rpm -e apr; echo "rc=$?"
error: Failed dependencies:
        libapr-1.so.0()(64bit) is needed by (installed) apr-util-1.5.2-6.0.1.el7_9.1.x86_64
        libapr-1.so.0()(64bit) is needed by (installed) httpd-tools-2.4.6-99.0.5.el7_9.1.x86_64

-- 아무것도 지워지지 않았다.
-- rpm -e 도 의존성을 지킨다.
-- (installed) 는 설치된 패키지가 요구한다는 뜻이다.
-- apr 에 기대는 셋이 이름과 함께 나왔다.
-- yum remove 는 같은 상황에서 셋까지 같이 지우자고 제안한다(실습 03).
[root@ol7a ~]# yum history undo -y last 2>&1 | tail -3; rpm -qa | wc -l
  mailcap.noarch 0:2.1.41-2.el7      

Complete!
565
-- 실습 시작 때와 같은 수다.
-- undo 가 Dep-Install 기록으로 넷까지 함께 지웠다.
-- undo 로 다섯 개를 한꺼번에 빼서 565.

 [7] --nodeps 로 덮기
--------------------------------------------------------------------------------

-- 현장에서 "급하니 일단 깔자"며 가장 많이 쓰는 옵션이다.
-- --nodeps 는 의존성 검사를 끈다. 설치는 무조건 된다.
[root@ol7a ~]# rpm -ivh --nodeps /root/rpms/httpd-*.rpm; echo "rc=$?"
Preparing...                          ########################################
Updating / installing...
httpd-2.4.6-99.0.5.el7_9.1            ########################################
rc=0
-- 의존성 경고는 한 줄도 없었다.
-- 진행 막대, rc=0. 겉으로는 성공이다.
[root@ol7a ~]# rpm -q httpd; rpm -qa | wc -l
httpd-2.4.6-99.0.5.el7_9.1.x86_64
566
-- rpm 데이터베이스에는 정상 설치로 기록됐다.
-- rpm -q httpd 도 정상 판을 돌려준다.
-- 질의만으로는 문제를 모른다.
-- httpd 하나만 들어와 566. 의존성 넷은 여전히 없다.
