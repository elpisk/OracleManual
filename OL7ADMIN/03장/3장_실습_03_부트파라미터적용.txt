================================================================================
 제3장 실습 03 — 부트 파라미터 적용
 대상   : ol7a (원격 SSH 세션 + 직렬 콘솔 ttyS0 의 GRUB 메뉴)
 목표   : 커널 부트 파라미터를 세 가지 방법으로 넣고 각각이 어디까지 유지되는지
          비교한다. ① GRUB 편집 화면에서 한 번만, ② grubby --update-kernel 로
          특정 항목에, ③ /etc/default/grub + 재생성
          (세 범위 비교)
 배경   : 커널은 GRUB 이 넘겨 준 문자열(/proc/cmdline)만 안다. GRUB 편집 화면의
          변경은 메모리에만 있다가 사라진다. grubby 는 grub.cfg 의 해당 항목을
          직접 고친다. /etc/default/grub 은 재생성할 때 모든 항목에 들어가는
          원본이다. 실습 값은 THP 끄기(transparent_hugepage=never),
          DB 서버 권고값(17장) (본문 3.4)
 소요   : 약 40분 (부팅 여섯 번)
 선행   : pre-break 스냅샷(= ol7-base). GRUB 은 직렬 콘솔에도 나옴
 계정   : root
 주의   : GRUB 편집 화면에서 linux16 줄 말고 다른 줄을 지우면 부팅하지 못한다.
          그때는 Esc 로 편집을 버리고 메뉴로 돌아간다
 되돌림 : 모든 항목의 부트 파라미터가 [0] 과 같고, UEK 로 부팅해 THP 가 always.
          확인은 cat /proc/cmdline; grubby --info=DEFAULT | grep args

-- 비교 기준을 남긴다.
-- 마지막 [되돌림] 에서 같은 명령을 다시 친다.
-- 지금 부팅에 쓰인 파라미터와 THP 설정값을 남긴다.
-- 대괄호 안 값이 현재 선택이다.
-- 커널.
[root@ol7a ~]# uname -r
5.4.17-2136.338.4.2.el7uek.x86_64
-- 이번 부팅의 인자.
[root@ol7a ~]# cat /proc/cmdline
BOOT_IMAGE=/vmlinuz-5.4.17-2136.338.4.2.el7uek.x86_64 root=/dev/mapper/ol-root ro crashkernel=auto rd.lvm.lv=ol/root rd.lvm.lv=ol/swap rhgb quiet console=tty0 console=ttyS0,115200 scsi_mod.scan=sync
[root@ol7a ~]# cat /sys/kernel/mm/transparent_hugepage/enabled
[always] madvise never
-- THP 는 always.
-- 대괄호가 지금 값이다.
-- 원본 설정.
[root@ol7a ~]# grep '^GRUB_CMDLINE_LINUX' /etc/default/grub
GRUB_CMDLINE_LINUX="crashkernel=auto rd.lvm.lv=ol/root rd.lvm.lv=ol/swap rhgb quiet console=tty0 console=ttyS0,115200 scsi_mod.scan=sync"

-- grub.cfg 의 항목별 파라미터를 grubby 로 본다.
-- 기본 항목의 전체 정보.
[root@ol7a ~]# grubby --info=DEFAULT
index=0
kernel=/boot/vmlinuz-5.4.17-2136.338.4.2.el7uek.x86_64
args="ro crashkernel=auto rd.lvm.lv=ol/root rd.lvm.lv=ol/swap rhgb quiet console=tty0 console=ttyS0,115200 scsi_mod.scan=sync "
root=/dev/mapper/ol-root
initrd=/boot/initramfs-5.4.17-2136.338.4.2.el7uek.x86_64.img
title=Oracle Linux Server 7.9, with Unbreakable Enterprise Kernel 5.4.17-2136.338.4.2.el7uek.x86_64
-- index : 메뉴 번호
-- kernel·initrd : 파일
-- args : 커널 인자
-- root : 루트 장치
-- title : 메뉴 제목
-- args 끝에 공백이 있다.
-- grub2-mkconfig 가 남긴 것.
-- 항목 다섯 개에 transparent_hugepage 가 몇 번 들어 있는지 센다.
-- 이 실습 내내 같은 반복문으로 비교한다.
[root@ol7a ~]# for i in 0 1 2 3 4; do echo "index=$i THP=$(grubby --info=$i | grep -c transparent_hugepage)"; done
index=0 THP=0
index=1 THP=0
index=2 THP=0
index=3 THP=0
index=4 THP=0
-- 다섯 항목 모두 0.
-- 비교용 사본.
[root@ol7a ~]# cp /boot/grub2/grub.cfg /tmp/grub.cfg.0; cp /etc/default/grub /tmp/default-grub.0

 [11] 방법별 지속 범위 — grub2-mkconfig 를 한 번 더 돌리면
--------------------------------------------------------------------------------

-- 원본에 없는 값은 재생성에서 살아남지 못한다.

-- 끝 공백도 다시 생겼다.

--------------------------------------------------------------------------------
 [12] grubby 로 빼기 — --remove-args
--------------------------------------------------------------------------------

-- 시험이 끝나면 이렇게 뺀다.
-- 넣고 뺀다.
-- [11] 에서 이미 빠졌지만, grubby 로 넣었다가 빼는 정식 방법을 확인한다.
[root@ol7a ~]# grubby --update-kernel=DEFAULT --args="transparent_hugepage=never"; grubby --info=DEFAULT | grep args
args="ro crashkernel=auto rd.lvm.lv=ol/root rd.lvm.lv=ol/swap rhgb quiet console=tty0 console=ttyS0,115200 scsi_mod.scan=sync transparent_hugepage=never"
-- 넣으면 args 끝에 붙는다.
[root@ol7a ~]# grubby --update-kernel=DEFAULT --remove-args="transparent_hugepage"; grubby --info=DEFAULT | grep args
args="ro crashkernel=auto rd.lvm.lv=ol/root rd.lvm.lv=ol/swap rhgb quiet console=tty0 console=ttyS0,115200 scsi_mod.scan=sync"
-- 이름만 줘도 빠진다.
-- 끝 공백은 없다.
