 실습 06 정리
--------------------------------------------------------------------------------
 · USER_DEPENDENCIES 로 어떤 객체가 무엇을 참조하는지 확인해
   스키마 변경의 영향 범위를 사전에 계산한다.
 · 참조 테이블의 자료형이 바뀌면 의존 객체가 INVALID 가 되며,
   간접 의존 객체까지 연쇄적으로 무효화된다.
 · INVALID 객체는 호출 시 자동 재컴파일되지만, 실패하면 PLS-00905 가 나고
   성공해도 첫 호출자가 컴파일 비용을 부담한다.
   따라서 배포 절차에 ALTER ... COMPILE 을 명시적으로 넣는다.
 · 'Procedure altered' 는 컴파일 시도를 뜻할 뿐이므로 STATUS 를 재검증한다.
 · 삭제된 객체를 PL/SQL 에서 호출하면 PLS-00201, SQL 에서 참조하면
   ORA-00904, 존재하지 않는 객체를 DROP 하면 ORA-04043 이 발생한다.
 · DROP 후 CREATE 는 부여된 EXECUTE 권한을 모두 잃는다.
   운영 환경에서는 반드시 CREATE OR REPLACE 를 사용한다.
