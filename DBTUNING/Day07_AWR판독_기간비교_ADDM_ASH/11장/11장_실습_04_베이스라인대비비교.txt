================================================================================
 11장 실습 04 — 베이스라인 대비 비교 수행
 목표: 평시 구간을 CREATE_BASELINE 으로 고정해 이름 붙여 보존하고, 이후 구간을
       그 베이스라인과 대조한다. 고정 베이스라인과 이동 윈도우 베이스라인
       (SYSTEM_MOVING_WINDOW)을 확인하고, 베이스라인이 기간 비교의 한쪽 구간으로
       그대로 쓰인다는 것을 익힌다.
 환경: non-CDB=orcl 19.3 (SYS AS SYSDBA로 수행)
 부하: WL_06_mixed.sql 로 만든 구간A(303→304, 가벼운 평시)를 베이스라인으로,
       구간B(305→306, 무거운 부하)를 비교 대상으로 사용.
 주의: 개인 실습 환경 전용. 🔒 베이스라인·DBA_HIST_* 는 Diagnostics Pack 필요.
================================================================================

$ sqlplus / as sysdba

SYS@orcl> SET LINESIZE 200

--------------------------------------------------------------------------------
-- [1] (조치 전 상태) 지금 존재하는 베이스라인을 먼저 확인한다.
--------------------------------------------------------------------------------
SYS@orcl> SELECT baseline_name, start_snap_id, end_snap_id, baseline_type
  2       FROM  dba_hist_baseline
  3       ORDER BY baseline_id;

BASELINE_NAME           START_SNAP_ID END_SNAP_ID BASELINE_TYPE
----------------------- ------------- ----------- -------------
SYSTEM_MOVING_WINDOW              <환경값>    <환경값> MOVING_WINDOW

-- 해석: 기본으로 SYSTEM_MOVING_WINDOW(이동 윈도우) 하나가 존재한다. 크기는
--   AWR 보존 기간과 같다. 아직 사람이 만든 고정 베이스라인은 없다.

--------------------------------------------------------------------------------
-- [2] (조치) 평시 구간(303→304)을 고정 베이스라인으로 만든다.
--------------------------------------------------------------------------------
SYS@orcl> BEGIN
  2         DBMS_WORKLOAD_REPOSITORY.CREATE_BASELINE(
  3            start_snap_id => 303,
  4            end_snap_id   => 304,
  5            baseline_name => 'NORMAL_MORNING_PEAK');
  6       END;
  7     /
PL/SQL procedure successfully completed.

SYS@orcl> SELECT baseline_name, start_snap_id, end_snap_id, baseline_type
  2       FROM  dba_hist_baseline WHERE baseline_name='NORMAL_MORNING_PEAK';

BASELINE_NAME           START_SNAP_ID END_SNAP_ID BASELINE_TYPE
----------------------- ------------- ----------- -------------
NORMAL_MORNING_PEAK               303         304 STATIC

-- 해석: 303→304 가 STATIC(고정) 베이스라인으로 이름 붙여 보존됐다. 이제 이
--   스냅들은 AWR 보존 기간(기본 8일)이 지나도 삭제되지 않는다 — 이것이 핵심 가치.

--------------------------------------------------------------------------------
-- [3] (조회) 베이스라인 구간을 Compare Periods 의 한쪽으로 넣어 대조한다.
--     즉 '평시(303→304) 대 오늘(305→306)' 차이 보고서를 만든다.
--------------------------------------------------------------------------------
SYS@orcl> @?/rdbms/admin/awrddrpt.sql
Enter value for report_type: text
Enter value for begin_snap: 303      -- 베이스라인(평시) 구간
Enter value for end_snap: 304
Enter value for begin_snap2: 305      -- 비교 대상(오늘) 구간
Enter value for end_snap2: 306
...
Report written to awrdiff_baseline_vs_today.txt

-- 해석: 베이스라인은 스냅 범위에 붙인 '이름표'일 뿐이므로, 기간 비교와 별개
--   기능이 아니다. 같은 비교 위에 '기준을 저장한다'는 한 겹을 더한 것이다.
--   보고서 DB time: 평시 81.8초 vs 오늘 302.0초 → 실습 05에서 판정한다.

--------------------------------------------------------------------------------
-- [4] (이상 징후 → 원인 → 조치 → 재확인)
--     이상 징후: 실수로 잘못된 구간을 베이스라인으로 만들어 지우려 한다.
--------------------------------------------------------------------------------
SYS@orcl> BEGIN
  2         DBMS_WORKLOAD_REPOSITORY.DROP_BASELINE(
  3            baseline_name => 'NORMAL_MORNING_PEAK', cascade => FALSE);
  4       END;
  5     /
BEGIN ... END;
*
ERROR at line 1:
ORA-13541: system moving window baseline ... (또는 스냅 보존 관련 제약)

SYS@orcl> -- 원인 파악: cascade=FALSE 는 베이스라인 정의만 지우고 스냅은 남긴다.
SYS@orcl> --   또 SYSTEM_MOVING_WINDOW 는 삭제 대상이 아니다. 대상 이름을 정확히 준다.
-- 조치: 사용자 고정 베이스라인만 정확한 이름으로 지운다.
SYS@orcl> EXEC DBMS_WORKLOAD_REPOSITORY.DROP_BASELINE('NORMAL_MORNING_PEAK', FALSE);
PL/SQL procedure successfully completed.
-- 재확인: DBA_HIST_BASELINE 에서 NORMAL_MORNING_PEAK 가 사라지고
--   SYSTEM_MOVING_WINDOW 는 그대로 남아 있는지 확인한다.
--   (본 실습에서는 이후 판정에 쓰기 위해 다시 [2]로 베이스라인을 만들어 둔다.)

--------------------------------------------------------------------------------
-- [5] (라이선스 대안)
--------------------------------------------------------------------------------
-- 베이스라인은 🔒 Diagnostics Pack 기능이다. 없으면 Statspack 스냅을 지우지
--   않고 별도 표에 '이 스냅은 평시 기준'이라고 관리하거나, 평시 V$ 캡처 결과를
--   파일/표로 저장해 기준선으로 삼는다. 자동 보존은 안 되므로 수동 관리가 필요하다.

--------------------------------------------------------------------------------
-- [정리]
--------------------------------------------------------------------------------
-- 1) CREATE_BASELINE 으로 평시 구간(303→304)을 STATIC 베이스라인으로 보존.
-- 2) 베이스라인 스냅은 보존 기간이 지나도 삭제되지 않는다.
-- 3) 고정=사람이 고른 사진(전후 비교), 이동 윈도우=자동 평시 분포(적응형 임계값·12장).
-- 4) 베이스라인은 awrddrpt.sql 의 한쪽 구간으로 그대로 지정해 대조한다.
-- ※ 🔒 베이스라인·DBA_HIST_* 는 Diagnostics Pack 필요. 없으면 Statspack·수동 관리.

SYS@orcl> EXIT
