================================================================================
 5장 실습 04 — STATISTICS_LEVEL 수준별로 수집되는 통계 차이 확인
 목표: STATISTICS_LEVEL의 세 값(BASIC/TYPICAL/ALL)과 TIMED_STATISTICS의 관계를
       확인한다. BASIC으로 바꾸면 자동 통계·시간 모델 수집이 빈약해지는 이상
       징후를 재현하고 TYPICAL로 원복해 교정한다.
 환경: non-CDB=orcl 19.3 (SYS AS SYSDBA로 수행)
 주의: 개인 실습 환경 전용. STATISTICS_LEVEL 변경은 인스턴스 전체에 영향을 준다.
       실습 끝에서 반드시 TYPICAL(기본값)로 원복한다. 공유 DB에서는 금지.
================================================================================

$ sqlplus / as sysdba

SYS@orcl> SET LINESIZE 200

SYS@orcl> SET PAGESIZE 100

--------------------------------------------------------------------------------
-- [1] (조치 전 상태) 현재 STATISTICS_LEVEL과 TIMED_STATISTICS를 확인한다.
--------------------------------------------------------------------------------
SYS@orcl> COLUMN name  FORMAT A20

SYS@orcl> COLUMN value FORMAT A10

SYS@orcl> SELECT name, value FROM v$parameter
  2       WHERE name IN ('statistics_level','timed_statistics')
  3       ORDER BY name;

NAME                 VALUE
-------------------- ----------
statistics_level     TYPICAL
timed_statistics     TRUE

-- 해석: 기본값 TYPICAL이며, 이때 TIMED_STATISTICS는 파생으로 TRUE(대기 시간 수집).
--   세 값의 의미:
--     BASIC   : 자동 통계·AWR 스냅샷·시간 모델 상당수를 끈다(비권장).
--     TYPICAL : 기본값·권장. 주요 통계를 대부분 수집, TIMED_STATISTICS 자동 ON.
--     ALL     : TYPICAL + OS 통계·계획 통계(오버헤드 큼, 상시 사용 지양).

--------------------------------------------------------------------------------
-- [2] (조치 전 상태) TYPICAL에서 시간 모델이 정상 수집되는지 확인.
--------------------------------------------------------------------------------
SYS@orcl> SELECT COUNT(*) time_model_rows,
  2         SUM(CASE WHEN value > 0 THEN 1 ELSE 0 END) nonzero
  3       FROM v$sys_time_model;

TIME_MODEL_ROWS    NONZERO
--------------- ----------
             31         17

-- 해석: TYPICAL이라 시간 모델 통계가 정상적으로 값(누적)을 쌓고 있다.

--------------------------------------------------------------------------------
-- [3] (이상 징후 재현) STATISTICS_LEVEL을 BASIC으로 바꾸면 무엇이 달라지나?
--     ★ 개인 실습 환경 전용 ★
--------------------------------------------------------------------------------
SYS@orcl> ALTER SYSTEM SET statistics_level = BASIC;

ALTER SYSTEM SET statistics_level = BASIC
*
ERROR at line 1:
ORA-32017: failure in updating SPFILE
ORA-00830: cannot set statistics_level to BASIC with auto-tune SGA enabled

SYS@orcl> -- 이상 징후: BASIC 으로 내리는 것 자체가 거부됐다(ORA-00830).
SYS@orcl> -- 원인: 이 인스턴스는 SGA_TARGET 이 켜진 자동 SGA 관리(ASMM)다. ASMM 은 메모리 어드바이저
SYS@orcl> --   통계를 먹고 사는데, BASIC 은 그 통계 수집까지 끄는 수준이라 Oracle 이 막는다.
SYS@orcl> --   즉 BASIC 은 '자동 관리가 돌아갈 수 없는 상태'다 — 얼마나 많이 끄는지 아래에서 본다.
SYS@orcl> COLUMN statistics_name FORMAT A34

SYS@orcl> COLUMN activation_level FORMAT A10

SYS@orcl> COLUMN system_status FORMAT A8

SYS@orcl> SELECT statistics_name, activation_level, system_status
  2       FROM   v$statistics_level ORDER BY activation_level DESC, statistics_name;

-- 해석: ACTIVATION_LEVEL=TYPICAL 인 항목(시간 통계·시간 모델·ASH·AWR 스냅샷·세그먼트 통계·

--------------------------------------------------------------------------------
-- [4] (원인 → 조치 → 재확인)
--------------------------------------------------------------------------------
SYS@orcl> -- 원인: BASIC 은 측정 자체를 켜는 스위치를 내린 것이다. 진단하려고 열어 둔
SYS@orcl> --   창을 스스로 닫는 셈이라, 이후의 어떤 분석 도구도 빈손이 된다. ASMM 이 켜진 이 랩에서는
SYS@orcl> --   Oracle 이 먼저 막아 주었지만, 수동 메모리 관리(SGA_TARGET=0) 환경이면 실제로 내려간다.
SYS@orcl> -- 조치: 기본값이자 권장값인 TYPICAL 을 유지한다(거부됐으므로 바뀐 것은 없다).
SYS@orcl> -- 재확인: 파라미터가 그대로인지, 파생값 TIMED_STATISTICS 가 TRUE 인지 확인한다.
SYS@orcl> SELECT name, value FROM v$parameter
  2       WHERE name IN ('statistics_level','timed_statistics')
  3       ORDER BY name;

NAME                 VALUE
-------------------- ----------
statistics_level     TYPICAL
timed_statistics     TRUE

-- 재확인 완료: TYPICAL 그대로, TIMED_STATISTICS 도 TRUE. 대기 시간 수집·시간 모델·AWR 수집이
--   모두 정상 동작한다.
-- 참고: TIMED_STATISTICS 를 ALTER SYSTEM 으로 명시 설정하면 파생값을 덮어쓴다.
--   그러나 BASIC 은 다른 기능도 함께 끄므로 그런 우회는 권장되지 않는다.
-- 참고: 세션 단위로 ALL 을 켜 특정 SQL 의 행 소스 통계만 볼 수 있다(SQL 부문 Ch14 의 GATHER_PLAN_STATISTICS 와 같은 효과).
SYS@orcl> ALTER SESSION SET statistics_level = ALL;

Session altered.

SYS@orcl> ALTER SESSION SET statistics_level = TYPICAL;

Session altered.

--------------------------------------------------------------------------------
-- [정리]
--------------------------------------------------------------------------------
-- 1) STATISTICS_LEVEL: BASIC(비권장) / TYPICAL(기본·권장) / ALL(오버헤드 큼).
-- 2) TYPICAL·ALL이면 TIMED_STATISTICS가 자동 ON → 대기 시간이 수집된다.
-- 3) BASIC은 자동 통계·AWR·시간 모델 상당수를 함께 꺼 측정 창을 닫는다.
-- 4) ASMM(SGA_TARGET>0) 인스턴스에서는 BASIC 이 ORA-00830 으로 거부된다 — 자동 관리도 통계가 필요하다.
-- 5) 변경 후에는 반드시 기본값 TYPICAL로 원복하고 파생값을 재확인한다.
-- ※ 이 실습의 조회는 라이선스가 필요 없다. AWR 수집부터 🔒 Diagnostics Pack.

SYS@orcl> EXIT
