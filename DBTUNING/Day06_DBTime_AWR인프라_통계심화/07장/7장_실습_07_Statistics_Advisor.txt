================================================================================
 7장 실습 07 — Optimizer Statistics Advisor 실행과 권고 해석 (ADMIN 33장 심화)
 목표: 통계 운영을 룰로 점검하는 Statistics Advisor 태스크를 만들어 실행하고,
       권고 보고서를 해석해 통계 부재·과다 오차를 근거 있게 해소한다.
 환경: non-CDB=orcl 19.3 (SYS로 수행)
 주의: ★개인 실습 환경 전용★. Statistics Advisor는 무료 기본 기능이며
       Tuning Pack이 아니다. 진단 목적으로 특정 테이블 통계를 지웠다가
       실습 끝에 재수집으로 원복하고, 생성한 어드바이저 태스크도 제거한다.
================================================================================

$ sqlplus / as sysdba

SYS@orcl> SET LINESIZE 200

SYS@orcl> SET PAGESIZE 100

SYS@orcl> SET LONG 200000

SYS@orcl> SET LONGCHUNKSIZE 200000

--     (Advisor가 '통계 없는 객체'를 잡아내는지 보기 위함. 실습용 의도적 조작)
--------------------------------------------------------------------------------
SYS@orcl> SELECT table_name, num_rows,

--------------------------------------------------------------------------------
-- [2] (조치) Advisor 태스크를 만들고 실행한다.
--------------------------------------------------------------------------------
SYS@orcl> DECLARE
  2    v_task VARCHAR2(64);
  3  BEGIN
  4    v_task := DBMS_STATS.CREATE_ADVISOR_TASK('STAT_ADV_CH7');
  5    v_task := DBMS_STATS.EXECUTE_ADVISOR_TASK('STAT_ADV_CH7');
  6  END;
  7  /

PL/SQL procedure successfully completed.

SYS@orcl> -- 재확인: 태스크가 완료됐는지 상태를 본다.

  2       FROM dba_advisor_tasks
  3       WHERE task_name='STAT_ADV_CH7';

-- 해석: Advisor 는 룰별로 Finding/Recommendation/Rationale 을 제시한다. 방금 통계를 지운
--   DRUG_MASTER 가 '통계 없는 객체' 권고의 대상 객체에 잡혔다. 보고서 함수가 실패해도 뷰로 같은
--   내용을 읽을 수 있다 — 도구는 뷰 위의 서식이다.

--------------------------------------------------------------------------------
-- [4] (이상 징후 → 원인 → 조치 → 재확인)
--     이상 징후: 권고를 '전부 자동 적용(IMPLEMENT)'하려다, 통계가 의도적으로
--       잠긴 객체까지 건드릴 위험을 발견한다. 잠금 여부를 먼저 확인한다.
--------------------------------------------------------------------------------
SYS@orcl> SELECT table_name, stattype_locked
  2       FROM dba_tab_statistics
  3       WHERE owner='SQLT' AND stattype_locked IS NOT NULL;

no rows selected

-- 이상 징후: 만약 잠긴 통계가 있었다면 IMPLEMENT가 이를 건드릴 수 있다.
-- 원인: 권고는 결론이 아니라 가설이다. 잠금이 의도된 것(휘발성 테이블의
--   대표 통계 고정 등)이면 자동 적용이 오히려 해가 된다.
-- 조치: 이 환경엔 잠긴 통계가 없음을 확인했으므로, 권고 중 'DRUG_MASTER
--   통계 수집'만 근거를 확인하고 국소적으로 채택한다(전체 자동 적용 아님).
SYS@orcl> EXEC DBMS_STATS.GATHER_TABLE_STATS('SQLT','DRUG_MASTER');

PL/SQL procedure successfully completed.

--------------------------------------------------------------------------------
-- [5] (조치) 실습 원복 — 생성한 Advisor 태스크를 제거한다.
--------------------------------------------------------------------------------
SYS@orcl> EXEC DBMS_STATS.DROP_ADVISOR_TASK('STAT_ADV_CH7');

PL/SQL procedure successfully completed.

SYS@orcl> SELECT COUNT(*) task_cnt FROM dba_advisor_tasks
  2       WHERE task_name='STAT_ADV_CH7';

  TASK_CNT
----------
         0

-- 재확인: 태스크가 제거됐다. 실습 흔적 없음.

--------------------------------------------------------------------------------
-- [정리]
--------------------------------------------------------------------------------
-- 1) Statistics Advisor는 통계 운영을 룰로 점검(무료, Tuning Pack 아님).
-- 2) CREATE → EXECUTE → REPORT 순으로 실행, Finding/Recommendation/Rationale 해석.
-- 3) 의도적으로 지운 DRUG_MASTER 통계를 '통계 없는 객체'로 정확히 지목.
-- 4) 권고는 가설 — 전체 자동 적용 대신 근거·맥락(잠금 등) 확인 후 국소 채택.
-- ※ 원복 완료: DRUG_MASTER 통계 재수집 + Advisor 태스크 제거.

SYS@orcl> EXIT
