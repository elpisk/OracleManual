================================================================================
 제5장 실습 05 — 링크 세션 관리와 원복
 대상    : oel7v9 orcl, sales
 목표    : 세션이 열어 둔 링크 연결을 V$DBLINK 로 보고 닫으며(ORA-02080),
          이 장에서 만든 계정·링크·디렉터리·파일을 모두 철거한다
 소요    : 약 15분
 변경    : 이 장에서 만든 것 전부 철거
================================================================================

--------------------------------------------------------------------------------
 [1] 열린 링크 보기
--------------------------------------------------------------------------------

SQL> CONNECT / AS SYSDBA
Connected.
SYS@orcl> GRANT SELECT ON v_$dblink TO sec05_own;

Grant succeeded.

SYS@orcl> CONNECT sec05_own/sec05_own
Connected.
SEC05_OWN@orcl> SELECT COUNT(*) FROM emp@sales_lnk;

  COUNT(*)
----------
         9

1 row selected.

SEC05_OWN@orcl> SELECT COUNT(*) FROM dual@sales_cu;

  COUNT(*)
----------
         1

1 row selected.

SEC05_OWN@orcl> COL db_link FOR a12
SEC05_OWN@orcl> SELECT db_link, logged_on, open_cursors, in_transaction FROM v$dblink;

DB_LINK      LOG OPEN_CURSORS IN_
------------ --- ------------ ---
SALES_LNK    YES            0 YES
SALES_CU     YES            0 YES

2 rows selected.

-- ★ 링크를 한 번 쓰면 세션이 끝날 때까지 원격 연결이 열려 있다. OPEN_LINKS(기본 4) 가 세션당 상한이다.
--    SELECT 만 했는데도 IN_TRANSACTION 이 YES 다. 원격 조회도 분산 트랜잭션 상태를 연다.

--------------------------------------------------------------------------------
 [2] 오류 재현 — 트랜잭션 중에 링크 닫기
--------------------------------------------------------------------------------

SQL> CONNECT sec05_own/sec05_own
Connected.
SEC05_OWN@orcl> UPDATE emp@sales_lnk SET sal = sal WHERE empno = 201;

1 row updated.

SEC05_OWN@orcl> COL db_link FOR a12
SEC05_OWN@orcl> SELECT db_link, in_transaction, update_sent FROM v$dblink;

DB_LINK      IN_ UPD
------------ --- ---
SALES_LNK    YES YES

1 row selected.

SEC05_OWN@orcl> ALTER SESSION CLOSE DATABASE LINK sales_lnk;
ERROR:
ORA-02080: database link is in use


SEC05_OWN@orcl> ROLLBACK;

Rollback complete.

SEC05_OWN@orcl> ALTER SESSION CLOSE DATABASE LINK sales_lnk;

Session altered.

SEC05_OWN@orcl> SELECT db_link, logged_on FROM v$dblink;

no rows selected

-- ★ 원격 UPDATE 후에는 UPDATE_SENT 가 YES. 이 상태에서 링크를 닫으면 ORA-02080: database link is in use.
--    ROLLBACK(또는 COMMIT)으로 트랜잭션을 끝내야 ALTER SESSION CLOSE DATABASE LINK 가 된다.
--    연결 풀처럼 세션이 오래 사는 환경에서 원격 연결을 쌓아 두지 않으려면 사용 후 닫는다.

================================================================================
 정리
================================================================================

-- - V$DBLINK 는 현재 세션의 링크 연결만 보여 준다. 트랜잭션 중에는 링크를 닫을 수 없다(ORA-02080).
-- - 철거 확인: orcl·sales 의 SEC05% 계정 0, 링크 목록 기준과 동일, 디렉터리·덤프 파일 없음.
