================================================================================
 제5장 실습 04 — Data Pump NETWORK_LINK
 대상    : oel7v9 sales(작업 수행) ← orcl(원본)
 목표    : 링크를 통해 원격 테이블을 내보내고 가져오며, 양쪽 계정의 권한 수준이 맞아야 한다는 것(ORA-39149)과
          덤프 파일 암호화 비밀번호(ORA-39174)를 확인한다
 소요    : 약 25분
 변경    : orcl: sec05_src / sales: sec05_dp, 디렉터리 sec05_dir, /home/oracle/sec05_dp (05 에서 철거)
================================================================================

--------------------------------------------------------------------------------
 [1] 원본(orcl) 쪽 링크 대상 계정
--------------------------------------------------------------------------------

SQL> CONNECT / AS SYSDBA
Connected.
SYS@orcl> CREATE USER sec05_src IDENTIFIED BY sec05_src;

User created.

SYS@orcl> GRANT CREATE SESSION TO sec05_src;

Grant succeeded.

SYS@orcl> GRANT SELECT ON scott.salgrade TO sec05_src;

Grant succeeded.

SYS@orcl> GRANT SELECT ON scott.dept TO sec05_src;

Grant succeeded.

-- ★ 원본 실습의 linkuser 역할이다. SCOTT 테이블 두 개의 조회 권한만 줬다.

--------------------------------------------------------------------------------
 [2] 덤프 디렉터리
--------------------------------------------------------------------------------

[oracle@oel7v9 ~]$ mkdir -p /home/oracle/sec05_dp
[oracle@oel7v9 ~]$ ls -ld /home/oracle/sec05_dp
drwxr-xr-x. 2 oracle dba 6 Oct 27 20:06 /home/oracle/sec05_dp

-- ★ 덤프 파일은 작업을 수행하는 DB(sales) 서버에 생긴다. 같은 VM 이라 경로 하나로 충분하다.

--------------------------------------------------------------------------------
 [3] 대상(sales) 쪽 계정·디렉터리·링크
--------------------------------------------------------------------------------

SQL> CONNECT system/oracle_4U@SALES
Connected.
SYSTEM@SALES> CREATE USER sec05_dp IDENTIFIED BY sec05_dp QUOTA 10M ON users;

User created.

SYSTEM@SALES> GRANT CREATE SESSION, CREATE TABLE, CREATE DATABASE LINK TO sec05_dp;

Grant succeeded.

SYSTEM@SALES> GRANT DATAPUMP_EXP_FULL_DATABASE, DATAPUMP_IMP_FULL_DATABASE TO sec05_dp;

Grant succeeded.

SYSTEM@SALES> CREATE DIRECTORY sec05_dir AS '/home/oracle/sec05_dp';

Directory created.

SYSTEM@SALES> GRANT READ, WRITE ON DIRECTORY sec05_dir TO sec05_dp;

Grant succeeded.

SYSTEM@SALES> CONNECT sec05_dp/sec05_dp@SALES
Connected.
SEC05_DP@SALES> CREATE DATABASE LINK orcl_lnk CONNECT TO sec05_src IDENTIFIED BY sec05_src USING 'ORCL';

Database link created.

SEC05_DP@SALES> SELECT COUNT(*) FROM scott.salgrade@orcl_lnk;

  COUNT(*)
----------
         5

1 row selected.

-- ★ 원본 실습의 ruser 역할이다. 남의 스키마 테이블을 내보내야 하므로 DATAPUMP_EXP_FULL_DATABASE 를 받았다.
--    링크로 원격 SALGRADE 5건이 보인다.

--------------------------------------------------------------------------------

-- ★ ORA-31631 + ORA-39149: cannot link privileged user to non-privileged user.
--    로컬 작업 계정은 FULL 권한을 가졌는데 링크가 접속하는 원격 계정에는 없다.
--    권한이 낮은 원격 계정을 통해 권한이 높은 작업을 하는 것을 Data Pump 가 막는다.

Grant succeeded.

-- ★ 원격 계정 sec05_src 에도 DATAPUMP_EXP_FULL_DATABASE 를 줬다.

================================================================================
 정리
================================================================================

-- - NETWORK_LINK 작업에서 덤프 파일은 작업을 수행하는 쪽 DB 서버에 생긴다.
-- - 로컬 계정이 FULL 권한을 쓰면 링크의 원격 계정도 같은 수준이어야 한다(ORA-39149).
-- - 덤프 암호화 비밀번호가 없으면 가져올 수 없다(ORA-39174).
-- - impdp NETWORK_LINK 는 덤프 파일 없이 원격 데이터를 직접 옮긴다.
