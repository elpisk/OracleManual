================================================================================
 제12장 실습 05 — 정책 관리와 철거
 대상    : oel7v9 orcl
 목표    : DISABLE/ENABLE/DROP 으로 정책을 관리하고,
          정책 소유자를 지우면 정책이 함께 사라지는 것을 확인한 뒤 원복한다
 소요    : 약 15분
 변경    : 이 장에서 만든 사용자·정책·디렉터리·파일 철거
================================================================================

--------------------------------------------------------------------------------
 [1] 현재 정책
--------------------------------------------------------------------------------

SQL> CONNECT / AS SYSDBA
Connected.
SYS@orcl> COL policy_name FOR a12
SYS@orcl> COL policy_text FOR a14
SYS@orcl> COL pf_function FOR a10
SYS@orcl> SELECT policy_name, policy_text, pf_schema, pf_function, enabled FROM dba_audit_policies WHERE object_schema = 'HR';

POLICY_NAME  POLICY_TEXT
------------ --------------
PF_SCHEMA
------------------------------------------------------------------------------------------------------------------------
PF_FUNCTIO ENA
---------- ---
EMP_HIGH_SAL SALARY > 9999
SECADM
RT_ALERT   YES


1 row selected.

SYS@orcl> SELECT COUNT(*) FROM dba_fga_audit_trail WHERE policy_name = 'EMP_HIGH_SAL';

  COUNT(*)
----------
         6

1 row selected.

-- ★ 조건 SALARY > 9999 와 핸들러 SECADM.RT_ALERT 가 정책 정의에 함께 남아 있다. 기록은 6건이다.

--------------------------------------------------------------------------------
 [2] 끄고 조회, 켜고 조회
--------------------------------------------------------------------------------

SQL> CONNECT secadm/oracle
Connected.
SECADM@orcl> EXEC DBMS_FGA.DISABLE_POLICY('HR', 'EMPLOYEES', 'EMP_HIGH_SAL')

PL/SQL procedure successfully completed.

SECADM@orcl> CONNECT hr/hr
Connected.
HR@orcl> SELECT salary FROM employees WHERE employee_id = 100;

    SALARY
----------
     24000

1 row selected.

HR@orcl> CONNECT / AS SYSDBA
Connected.
SYS@orcl> SELECT enabled FROM dba_audit_policies WHERE policy_name = 'EMP_HIGH_SAL';

ENA
---
NO

1 row selected.

SYS@orcl> SELECT COUNT(*) FROM dba_fga_audit_trail WHERE policy_name = 'EMP_HIGH_SAL';

  COUNT(*)
----------
         6

1 row selected.

SYS@orcl> CONNECT secadm/oracle
Connected.
SECADM@orcl> EXEC DBMS_FGA.ENABLE_POLICY('HR', 'EMPLOYEES', 'EMP_HIGH_SAL')

PL/SQL procedure successfully completed.

SECADM@orcl> CONNECT hr/hr
Connected.
HR@orcl> SELECT salary FROM employees WHERE employee_id = 100;

    SALARY
----------
     24000

1 row selected.

HR@orcl> CONNECT / AS SYSDBA
Connected.
SYS@orcl> SELECT COUNT(*) FROM dba_fga_audit_trail WHERE policy_name = 'EMP_HIGH_SAL';

  COUNT(*)
----------
         7

1 row selected.

-- ★ DISABLE 상태(ENABLED = NO)에서 조건을 만족하는 조회를 해도 기록 건수는 6 그대로다.
--    ENABLE 후 같은 조회를 하자 7건이 됐다. 끈 동안의 접근은 흔적이 없다.
--    정책을 끄고 켠 행위 자체를 남기려면 통합 감사 정책으로 DBMS_FGA 실행을 감사해야 한다.

--------------------------------------------------------------------------------
 [3] 오류 재현 — 없는 정책 이름
--------------------------------------------------------------------------------

SQL> CONNECT secadm/oracle
Connected.
SECADM@orcl> EXEC DBMS_FGA.DROP_POLICY('HR', 'EMPLOYEES', 'EMP_HIGH_SALARY')
BEGIN DBMS_FGA.DROP_POLICY('HR', 'EMPLOYEES', 'EMP_HIGH_SALARY'); END;

*
ERROR at line 1:
ORA-28102: policy does not exist
ORA-06512: at "SYS.DBMS_FGA", line 60
ORA-06512: at line 1

-- ★ 이름을 틀리면 ORA-28102: policy does not exist. 다음 단계에서 정책은 다른 방법으로 사라진다.

--------------------------------------------------------------------------------
 [4] 감사 관리 계정을 지우면
--------------------------------------------------------------------------------

SQL> CONNECT / AS SYSDBA
Connected.
SYS@orcl> DROP USER secadm CASCADE;

User dropped.

SYS@orcl> SELECT COUNT(*) FROM dba_audit_policies WHERE object_schema = 'HR';

  COUNT(*)
----------
         0

1 row selected.

SYS@orcl> DROP DIRECTORY fga_alert_dir;

Directory dropped.

-- ★ DROP USER secadm CASCADE 만으로 HR 의 FGA 정책 수가 0 이 됐다.
--    정책을 만든 사용자를 지우면 그 사용자의 FGA 정책도 함께 삭제된다(매뉴얼 명시).
--    계정 정리 전에 DBA_AUDIT_POLICIES 를 확인하지 않으면 감사가 조용히 꺼진다.

================================================================================
 정리
================================================================================

-- - DISABLE 중의 접근은 기록되지 않는다. 정책 관리 행위는 별도 감사 대상이다.
-- - DROP_POLICY 이름 오류는 ORA-28102.
-- - 정책 소유자나 대상 객체를 지우면 정책도 사라지고, 쌓인 기록은 남는다.
-- - 이 장의 secadm·정책·디렉터리·OS 파일을 모두 지웠다. 기존 EMP_FGA 정책은 그대로다.
