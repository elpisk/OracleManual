================================================================================
 제10장 실습 02 — 키스토어 생성과 마스터 키
 대상    : oel7v9 tdedb
 목표    : ADMINISTER KEY MANAGEMENT 로 키스토어를 만들고 열고 마스터 키를 설정한다.
          원본 자료 문법, 마스터 키 없는 암호화, WITH BACKUP 누락의 오류를 차례로 본다
 소요    : 약 15분
 변경    : 키스토어 파일, 마스터 키
================================================================================

--------------------------------------------------------------------------------
 [1] 오류 재현 — 원본 문법: 경로를 적은 CREATE KEYSTORE
--------------------------------------------------------------------------------

SQL> CONNECT / AS SYSDBA
Connected.
SYS@tdedb> ADMINISTER KEY MANAGEMENT CREATE KEYSTORE '/u01/app/oracle/admin/tdedb/wallet/tde' IDENTIFIED BY "Tde#2026orcl";
ADMINISTER KEY MANAGEMENT CREATE KEYSTORE '/u01/app/oracle/admin/tdedb/wallet/tde' IDENTIFIED BY "Tde#2026orcl"
*
ERROR at line 1:
ORA-46633: creation of a password-based keystore failed

-- ★ ORA-46633: creation of a password-based keystore failed.
--    원본 자료는 WALLET_ROOT 를 설정한 뒤에도 키스토어 경로를 직접 적는다. 19.3 에서 이 조합은 실패했다.

--------------------------------------------------------------------------------
 [2] 조치 — 19c 문법 (경로 없이)
--------------------------------------------------------------------------------

SQL> CONNECT / AS SYSDBA
Connected.
SYS@tdedb> ADMINISTER KEY MANAGEMENT CREATE KEYSTORE IDENTIFIED BY "Tde#2026orcl";

keystore altered.

SYS@tdedb> HOST ls -l /u01/app/oracle/admin/tdedb/wallet /u01/app/oracle/admin/tdedb/wallet/tde
/u01/app/oracle/admin/tdedb/wallet:

SYS@tdedb> COL wallet_type FOR a16
SYS@tdedb> SELECT wrl_parameter, status, wallet_type, fully_backed_up FROM v$encryption_wallet;

WRL_PARAMETER                            STATUS               WALLET_TYPE      FULLY_BAC
---------------------------------------- -------------------- ---------------- ---------
/u01/app/oracle/admin/tdedb/wallet/tde/  CLOSED               UNKNOWN          UNDEFINED

1 row selected.

-- ★ WALLET_ROOT 아래 tde 디렉터리가 자동으로 만들어지고 ewallet.p12 가 생겼다. 상태는 CLOSED.
--    디렉터리 권한은 750, 파일은 600 이다.

--------------------------------------------------------------------------------
 [3] 키스토어 열기
--------------------------------------------------------------------------------

SQL> CONNECT / AS SYSDBA
Connected.
SYS@tdedb> ADMINISTER KEY MANAGEMENT SET KEYSTORE OPEN IDENTIFIED BY "Tde#2026orcl";

keystore altered.

SYS@tdedb> COL wrl_parameter FOR a40
SYS@tdedb> COL status FOR a20
SYS@tdedb> COL wallet_type FOR a16
SYS@tdedb> SELECT wrl_parameter, status, wallet_type, fully_backed_up FROM v$encryption_wallet;

WRL_PARAMETER                            STATUS               WALLET_TYPE      FULLY_BAC
---------------------------------------- -------------------- ---------------- ---------
/u01/app/oracle/admin/tdedb/wallet/tde/  OPEN_NO_MASTER_KEY   PASSWORD         UNDEFINED

1 row selected.

SYS@tdedb> SELECT COUNT(*) FROM v$encryption_keys;

  COUNT(*)
----------
         0

1 row selected.

-- ★ OPEN_NO_MASTER_KEY, WALLET_TYPE PASSWORD. 열렸지만 마스터 키가 없다. V$ENCRYPTION_KEYS 도 0건.

--------------------------------------------------------------------------------
 [4] 오류 재현 — 마스터 키 없이 암호화 테이블스페이스
--------------------------------------------------------------------------------

SQL> CONNECT / AS SYSDBA
Connected.
SYS@tdedb> CREATE TABLESPACE tde_ts DATAFILE '/u01/app/oracle/oradata/TDEDB/tde_ts01.dbf' SIZE 20M
  2    ENCRYPTION USING 'AES256' ENCRYPT;
CREATE TABLESPACE tde_ts DATAFILE '/u01/app/oracle/oradata/TDEDB/tde_ts01.dbf' SIZE 20M
*
ERROR at line 1:
ORA-28361: master key not yet set

-- ★ ORA-28361: master key not yet set. 2계층 키(테이블스페이스 키)를 암호화할 마스터 키가 없다.

--------------------------------------------------------------------------------
 [5] 오류 재현 — WITH BACKUP 없이 SET KEY
--------------------------------------------------------------------------------

SQL> CONNECT / AS SYSDBA
Connected.
SYS@tdedb> ADMINISTER KEY MANAGEMENT SET KEY IDENTIFIED BY "Tde#2026orcl";
ADMINISTER KEY MANAGEMENT SET KEY IDENTIFIED BY "Tde#2026orcl"
*
ERROR at line 1:
ORA-46631: keystore needs to be backed up

-- ★ ORA-46631: keystore needs to be backed up. 비밀번호 키스토어에서는 WITH BACKUP 이 필수다.

--------------------------------------------------------------------------------
 [6] 조치 — 마스터 키 설정
--------------------------------------------------------------------------------

SQL> CONNECT / AS SYSDBA
Connected.
SYS@tdedb> ADMINISTER KEY MANAGEMENT SET KEY USING TAG 'first' IDENTIFIED BY "Tde#2026orcl" WITH BACKUP USING 'first';

keystore altered.

SYS@tdedb> COL wrl_parameter FOR a40
SYS@tdedb> COL status FOR a20
SYS@tdedb> COL wallet_type FOR a16
SYS@tdedb> SELECT wrl_parameter, status, wallet_type, fully_backed_up FROM v$encryption_wallet;

WRL_PARAMETER                            STATUS               WALLET_TYPE      FULLY_BAC
---------------------------------------- -------------------- ---------------- ---------
/u01/app/oracle/admin/tdedb/wallet/tde/  OPEN                 PASSWORD         NO

1 row selected.

SYS@tdedb> COL tag FOR a8

SYS@tdedb> HOST ls -l /u01/app/oracle/admin/tdedb/wallet/tde
total 12
-rw-------. 1 oracle dba 4171 Oct 27 21:10 ewallet.p12
-rw-------. 1 oracle dba 2555 Oct 27 21:10 ewallet_2026102712102249_first.p12

-- ★ STATUS 가 OPEN 이 됐다. V$ENCRYPTION_KEYS 에 태그 first 인 키가 한 건 생겼다.
--    V$DATABASE_KEY_INFO 의 MASTERKEY_ACTIVATED 가 NO 에서 YES 로 바뀌었다. MASTERKEYID(07DF8DE5…)는
--    KEY_ID(AQffjeV8…)를 Base64 로 풀었을 때 맨 앞 01 다음에 오는 값과 같다.
--    ewallet_…_first.p12 는 WITH BACKUP 이 남긴 '변경 직전' 사본이다. 그래서 FULLY_BACKED_UP 은 NO 다.

================================================================================
 정리
================================================================================

-- - 생성(CLOSED) → 열기(OPEN_NO_MASTER_KEY) → SET KEY WITH BACKUP(OPEN).
-- - WALLET_ROOT 가 있으면 CREATE KEYSTORE 에 경로를 적지 않는다(ORA-46633).
-- - 마스터 키 전 암호화는 ORA-28361, WITH BACKUP 누락은 ORA-46631.
