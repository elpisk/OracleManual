================================================================================
 제10장 실습 05 — 재기동, auto-login, 키 교체
 대상    : oel7v9 tdedb
 목표    : 비밀번호 키스토어만 있는 DB 를 재기동했을 때의 영향을 보고 local auto-login 키스토어로 해결한다.
          마스터 키를 교체하고 키스토어를 백업한다
 소요    : 약 20분 (재기동 2회)
 변경    : cwallet.sso 생성, 마스터 키 교체
================================================================================

--------------------------------------------------------------------------------
 [2] 조치 — 열고 local auto-login 키스토어 만들기
--------------------------------------------------------------------------------

SQL> CONNECT / AS SYSDBA
Connected.
SYS@tdedb> ADMINISTER KEY MANAGEMENT SET KEYSTORE OPEN IDENTIFIED BY "Tde#2026orcl";

keystore altered.

SYS@tdedb> SELECT * FROM tde_lab.card_enc;

        ID CARD_NO
---------- --------------------
         1 CARD-4321-SECRET

1 row selected.

SYS@tdedb> ADMINISTER KEY MANAGEMENT CREATE LOCAL AUTO_LOGIN KEYSTORE FROM KEYSTORE IDENTIFIED BY "Tde#2026orcl";

keystore altered.

SYS@tdedb> HOST ls -l /u01/app/oracle/admin/tdedb/wallet/tde

-- ★ 비밀번호로 열자 바로 조회된다. CREATE LOCAL AUTO_LOGIN KEYSTORE 로 cwallet.sso 가 생겼다.
--    지금 열려 있는 것은 비밀번호 키스토어라 WALLET_TYPE 은 아직 PASSWORD 다.

--------------------------------------------------------------------------------
 [4] 마스터 키 교체와 백업
--------------------------------------------------------------------------------

-- auto-login 으로 열린 상태에서 비밀번호 키스토어를 고치는 작업이라 FORCE KEYSTORE 를 붙인다.

SQL> CONNECT / AS SYSDBA
Connected.
SYS@tdedb> ADMINISTER KEY MANAGEMENT SET KEY USING TAG 'rotate1' FORCE KEYSTORE IDENTIFIED BY "Tde#2026orcl" WITH BACKUP USING 'rotate1';

keystore altered.

SYS@tdedb> COL key_id FOR a54
SYS@tdedb> COL tag FOR a8
SYS@tdedb> SELECT key_id, tag, creation_time FROM v$encryption_keys ORDER BY creation_time;

   CUST_ID NAME                           CARD_NO
---------- ------------------------------ --------------------
         1 KIM                            1111-2222-3333-4444

1 row selected.

-- ★ V$ENCRYPTION_KEYS 가 2건(first, rotate1). 옛 키는 지워지지 않는다. 데이터는 다시 암호화하지 않았는데도 바로 조회된다.
--    BACKUP KEYSTORE 로 manual 백업을 만든 뒤 FULLY_BACKED_UP 이 YES 가 됐다.
--    WITH BACKUP 사본(first, rotate1)은 각각 변경 직전 상태다.

--------------------------------------------------------------------------------
 [5] 원본의 마지막 장면 — 비밀번호로 닫기
--------------------------------------------------------------------------------

SQL> CONNECT / AS SYSDBA
Connected.
SYS@tdedb> ADMINISTER KEY MANAGEMENT SET KEYSTORE CLOSE IDENTIFIED BY "Tde#2026orcl";
ADMINISTER KEY MANAGEMENT SET KEYSTORE CLOSE IDENTIFIED BY "Tde#2026orcl"
*
ERROR at line 1:
ORA-28417: password-based keystore is not open


SYS@tdedb> COL wrl_parameter FOR a40
SYS@tdedb> COL status FOR a20
SYS@tdedb> COL wallet_type FOR a16
SYS@tdedb> SELECT wrl_parameter, status, wallet_type, fully_backed_up FROM v$encryption_wallet;

WRL_PARAMETER                            STATUS               WALLET_TYPE      FULLY_BAC
---------------------------------------- -------------------- ---------------- ---------
/u01/app/oracle/admin/tdedb/wallet/tde/  OPEN                 LOCAL_AUTOLOGIN  YES

1 row selected.

SYS@tdedb> SELECT * FROM tde_lab.card_enc;

        ID CARD_NO
---------- --------------------
         1 CARD-4321-SECRET

1 row selected.

-- ★ 원본 자료는 비밀번호로 닫은 뒤 AUTOLOGIN 상태로 열려 있는 결과를 보여 준다.
--    이번에는 auto-login 으로 열려 있는 상태라 비밀번호 키스토어가 열려 있지 않다는 ORA-28417 이 났다.
--    키스토어는 여전히 OPEN, LOCAL_AUTOLOGIN 이고 데이터도 조회된다. auto-login 으로 연 키스토어를 닫으려면 IDENTIFIED BY 없이 CLOSE 한다.

================================================================================
 정리
================================================================================

-- - 비밀번호 키스토어만 있으면 재기동 후 CLOSED → 암호화 데이터 접근은 ORA-28365.
-- - CREATE LOCAL AUTO_LOGIN KEYSTORE 후에는 재기동해도 자동으로 열린다.
-- - 마스터 키 교체는 데이터 재암호화 없이 끝나며 옛 키는 키스토어에 남는다. 교체 후에는 따로 백업한다.
