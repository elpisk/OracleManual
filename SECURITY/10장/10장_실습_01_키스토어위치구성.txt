================================================================================
 제10장 실습 01 — 키스토어 위치 구성
 대상    : oel7v9 tdedb (TDE 실습 전용 DB, non-CDB 19.3, 06 에서 삭제)
 목표    : 19c 방식인 WALLET_ROOT(정적)와 TDE_CONFIGURATION(동적)으로 키스토어 위치를 구성한다.
          설정 순서를 바꾸거나 정적 파라미터를 메모리에만 바꾸려 할 때의 오류를 확인한다
 소요    : 약 15분 (재기동 1회)
 변경    : tdedb 의 wallet_root, tde_configuration
================================================================================

--------------------------------------------------------------------------------
 [1] 기준 상태
--------------------------------------------------------------------------------

-- TDE 실습은 인스턴스를 여러 번 재기동하고, 한 번 활성화한 마스터 키 기록이 DB 에 남는다(06 참고).
-- 다른 실습과 같이 쓰는 orcl 대신 DBCA 로 만든 전용 DB tdedb 에서 진행하고 마지막에 DB 를 통째로 지운다.

SQL> CONNECT / AS SYSDBA
Connected.
SYS@tdedb> SELECT name, open_mode, log_mode FROM v$database;

NAME      OPEN_MODE            LOG_MODE
--------- -------------------- ------------
TDEDB     READ WRITE           NOARCHIVELOG

1 row selected.

SYS@tdedb> COL wrl_parameter FOR a40
SYS@tdedb> COL status FOR a20
SYS@tdedb> COL wallet_type FOR a16
SYS@tdedb> SELECT wrl_parameter, status, wallet_type, fully_backed_up FROM v$encryption_wallet;

WRL_PARAMETER                            STATUS               WALLET_TYPE      FULLY_BAC
---------------------------------------- -------------------- ---------------- ---------
/u01/app/oracle/admin/tdedb/wallet       NOT_AVAILABLE        UNKNOWN          UNDEFINED

1 row selected.

SYS@tdedb> COL masterkeyid FOR a34
SYS@tdedb> SELECT masterkeyid, masterkey_activated FROM v$database_key_info;

MASTERKEYID                        MAS
---------------------------------- ---
2CA567A3FF484F36BF9B7AD99D4B58EC   NO

1 row selected.

SYS@tdedb> SHOW PARAMETER wallet_root

NAME                                 TYPE        VALUE
------------------------------------ ----------- ------------------------------
wallet_root                          string
SYS@tdedb> SHOW PARAMETER tde_configuration

NAME                                 TYPE        VALUE
------------------------------------ ----------- ------------------------------
tde_configuration                    string
SYS@tdedb> SHOW PARAMETER db_create_file_dest

NAME                                 TYPE        VALUE
------------------------------------ ----------- ------------------------------
db_create_file_dest                  string
SYS@tdedb> HOST ls -d /u01/app/oracle/admin/tdedb/wallet 2>/dev/null || echo not found
not found

-- ★ 키스토어 위치는 아무 설정이 없을 때의 기본값($ORACLE_BASE/admin/tdedb/wallet)이고 파일이 없어 NOT_AVAILABLE.
--    V$DATABASE_KEY_INFO 의 MASTERKEY_ACTIVATED 는 NO. 한 번도 마스터 키를 쓴 적 없는 DB 다.
--    db_create_file_dest 가 비어 있어 OMF 를 쓰지 않는다.

--------------------------------------------------------------------------------
 [2] 오류 재현 — WALLET_ROOT 없이 TDE_CONFIGURATION
--------------------------------------------------------------------------------

SQL> CONNECT / AS SYSDBA
Connected.
SYS@tdedb> ALTER SYSTEM SET tde_configuration = 'KEYSTORE_CONFIGURATION=FILE' SCOPE = BOTH;
ALTER SYSTEM SET tde_configuration = 'KEYSTORE_CONFIGURATION=FILE' SCOPE = BOTH
*
ERROR at line 1:
ORA-32017: failure in updating SPFILE
ORA-46693: The WALLET_ROOT location is missing or invalid.

-- ★ ORA-46693: The WALLET_ROOT location is missing or invalid.
--    TDE_CONFIGURATION 의 FILE 구성은 WALLET_ROOT 아래 tde 디렉터리를 쓴다는 뜻이라 WALLET_ROOT 가 먼저 있어야 한다.

--------------------------------------------------------------------------------
 [3] 조치 — WALLET_ROOT 설정과 재기동
--------------------------------------------------------------------------------

SQL> CONNECT / AS SYSDBA
Connected.
SYS@tdedb> HOST mkdir -p /u01/app/oracle/admin/tdedb/wallet

SYS@tdedb> ALTER SYSTEM SET wallet_root = '/u01/app/oracle/admin/tdedb/wallet' SCOPE = MEMORY;
ALTER SYSTEM SET wallet_root = '/u01/app/oracle/admin/tdedb/wallet' SCOPE = MEMORY
                 *
ERROR at line 1:
ORA-02095: specified initialization parameter cannot be modified


SYS@tdedb> ALTER SYSTEM SET wallet_root = '/u01/app/oracle/admin/tdedb/wallet' SCOPE = SPFILE;

System altered.

SYS@tdedb> SHUTDOWN IMMEDIATE
Database closed.
Database dismounted.
ORACLE instance shut down.
SYS@tdedb> STARTUP
ORACLE instance started.

Total System Global Area  943716976 bytes
Fixed Size                  8903280 bytes
Variable Size             247463936 bytes
Database Buffers          679477248 bytes
Redo Buffers                7872512 bytes
Database mounted.
Database opened.

-- ★ SCOPE = MEMORY 는 ORA-02095: 정적 파라미터라 실행 중에 바꿀 수 없다.
--    SPFILE 에 기록하고 재기동했다. TDE 도입에 정지 시간이 필요한 이유가 이 한 줄이다.

--------------------------------------------------------------------------------
 [4] TDE_CONFIGURATION 설정
--------------------------------------------------------------------------------

SQL> CONNECT / AS SYSDBA
Connected.
SYS@tdedb> ALTER SYSTEM SET tde_configuration = 'KEYSTORE_CONFIGURATION=FILE' SCOPE = BOTH;

System altered.

SYS@tdedb> SHOW PARAMETER wallet_root

NAME                                 TYPE        VALUE
------------------------------------ ----------- ------------------------------
wallet_root                          string      /u01/app/oracle/admin/tdedb/wa
                                                 llet
SYS@tdedb> SHOW PARAMETER tde_configuration

NAME                                 TYPE        VALUE
------------------------------------ ----------- ------------------------------
tde_configuration                    string      KEYSTORE_CONFIGURATION=FILE
SYS@tdedb> COL wrl_parameter FOR a40
SYS@tdedb> COL status FOR a20
SYS@tdedb> COL wallet_type FOR a16
SYS@tdedb> SELECT wrl_parameter, status, wallet_type, fully_backed_up FROM v$encryption_wallet;

WRL_PARAMETER                            STATUS               WALLET_TYPE      FULLY_BAC
---------------------------------------- -------------------- ---------------- ---------
/u01/app/oracle/admin/tdedb/wallet/tde/  NOT_AVAILABLE        UNKNOWN          UNDEFINED

1 row selected.

-- ★ 이번에는 성공. 키스토어 위치(WRL_PARAMETER)가 WALLET_ROOT 아래 tde/ 로 바뀌었다.
--    아직 키스토어 파일이 없으므로 NOT_AVAILABLE 이다.

================================================================================
 정리
================================================================================

-- - 순서: WALLET_ROOT(SPFILE + 재기동) → TDE_CONFIGURATION = 'KEYSTORE_CONFIGURATION=FILE'.
-- - 순서가 바뀌면 ORA-46693, WALLET_ROOT 를 메모리에서 바꾸려 하면 ORA-02095.
-- - 키스토어는 WALLET_ROOT/tde 에 놓인다.
