================================================================================
 제10장 실습 06 — 원복과 남는 것
 대상    : oel7v9 tdedb
 목표    : 암호화 객체를 모두 지운 뒤에도 DB 에 남는 마스터 키 기록을 확인하고, 실습 DB 를 삭제한다
 소요    : 약 10분
 변경    : tdedb 삭제
================================================================================

--------------------------------------------------------------------------------
 [1] 암호화 객체 제거
--------------------------------------------------------------------------------

SQL> CONNECT / AS SYSDBA
Connected.
SYS@tdedb> DROP USER tde_lab CASCADE;

User dropped.

SYS@tdedb> DROP TABLESPACE tde_ts INCLUDING CONTENTS AND DATAFILES;

Tablespace dropped.

SYS@tdedb> DROP TABLESPACE tde_plain INCLUDING CONTENTS AND DATAFILES;

Tablespace dropped.

SYS@tdedb> SELECT COUNT(*) FROM dba_tablespaces WHERE tablespace_name LIKE 'TDE%';

  COUNT(*)
----------
         0

1 row selected.

SYS@tdedb> SELECT COUNT(*) FROM v$encrypted_tablespaces;

  COUNT(*)
----------
         0

1 row selected.

SYS@tdedb> SELECT COUNT(*) FROM dba_encrypted_columns;

  COUNT(*)
----------
         0

1 row selected.

-- ★ 암호화 테이블스페이스 0, 암호화 컬럼 0.

--------------------------------------------------------------------------------
 [2] 객체를 다 지워도 남는 것
--------------------------------------------------------------------------------

SQL> CONNECT / AS SYSDBA
Connected.
SYS@tdedb> COL masterkeyid FOR a34
SYS@tdedb> SELECT masterkeyid, masterkey_activated FROM v$database_key_info;

MASTERKEYID                        MAS
---------------------------------- ---
9F10688EF4694F62BFB89A47674CB212   YES

1 row selected.

SYS@tdedb> COL key_id FOR a54
SYS@tdedb> COL tag FOR a8
SYS@tdedb> SELECT key_id, tag FROM v$encryption_keys ORDER BY creation_time;

KEY_ID                                                 TAG
------------------------------------------------------ --------
AQffjeV8kE8/v35zQU+icBEAAAAAAAAAAAAAAAAAAAAAAAAAAAAA   first
AZ8QaI70aU9iv7iaR2dMshIAAAAAAAAAAAAAAAAAAAAAAAAAAAAA   rotate1

2 rows selected.

-- ★ MASTERKEY_ACTIVATED 는 여전히 YES, MASTERKEYID 는 마지막 키(rotate1)다. 키스토어에는 두 키가 모두 있다.
--    한 번 마스터 키를 설정한 DB 는 이 기록을 되돌릴 수 없다. 이 상태에서 키스토어를 지우면 다음에 TDE 를 구성할 때
--    ORA-28374(typed master key not found in wallet)로 막힌다. 이 교안을 만들며 다른 DB 에서 실제로 겪은 일이다.
--    TDE 를 쓴 DB 의 키스토어는 객체를 다 지운 뒤에도 보관한다.

--------------------------------------------------------------------------------
 [3] 실습 DB 삭제
--------------------------------------------------------------------------------

[oracle@oel7v9 ~]$ dbca -silent -deleteDatabase -sourceDB tdedb -sysDBAUserName sys -sysDBAPassword 'Oracle_4U' 2>&1 | tail -4
84% complete
100% complete
Database deletion completed.
Look at the log file "/u01/app/oracle/cfgtoollogs/dbca/tdedb/tdedb3.log" for further details.
[oracle@oel7v9 ~]$ grep -c tdedb /etc/oratab
0
[oracle@oel7v9 ~]$ ls -d /u01/app/oracle/oradata/TDEDB /u01/app/oracle/admin/tdedb 2>&1
ls: cannot access /u01/app/oracle/admin/tdedb: No such file or directory
/u01/app/oracle/oradata/TDEDB
[oracle@oel7v9 ~]$ ps -ef | grep -c [p]mon_tdedb
0
[oracle@oel7v9 ~]$ rmdir /u01/app/oracle/oradata/TDEDB 2>/dev/null; ls -d /u01/app/oracle/oradata/TDEDB 2>/dev/null || echo removed
/u01/app/oracle/oradata/TDEDB

-- ★ dbca 로 tdedb 를 삭제했다. oratab 항목 0, 인스턴스 0, admin/tdedb 없음.
--    비어 있는 데이터 파일 디렉터리는 상위 디렉터리가 root 소유라 oracle 로 지워지지 않아 root 로 따로 정리했다.

================================================================================
 정리
================================================================================

-- - 암호화 객체를 지워도 V$DATABASE_KEY_INFO 의 마스터 키 활성화 기록은 남는다.
-- - TDE 를 쓴 DB 에서 키스토어를 지우면 안 된다. 실습 DB 는 DB 째로 삭제해 원복했다.
