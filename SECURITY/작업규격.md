# Oracle Database 19c Security 교안 작업 규격

ADG v2 규격(`oracle-adg-교안\v2\작업규격.md`)을 이 과정에 맞게 고친 것이다. 문체 규칙은 ADG 규격의
"문체"·"문체 추가 지시" 두 절을 그대로 따른다(아래 4절에 다시 적어 둠).

## 1. 산출물 (장별 3종만)

작업 폴더: `C:\Users\itwill\Downloads\OracleManual\SECURITY\NN장\` (NN = 두 자리)

| 파일 | 규격 |
|---|---|
| `본문.mk` → `{N}장_{제목}.docx` | 27,000~29,000자(검사 하한 26,000·상한 30,000). 학습 목표 → 본문 절 → 요약 → 퀴즈 6문항 → 실습 개요 |
| `슬라이드.mk` → `{N}장_{제목}.pptx` | 35~55장. 타이틀·학습목표·Agenda·섹션·요약·퀴즈·실습개요 외 모든 슬라이드에 노트 200~500자 |
| `{N}장_실습_{NN}_{주제}.txt` | **OEL7V9 실측** 트랜스크립트 3~7개. 파일마다 오류 → 원인 → 조치 → 재확인 흐름 1곳 이상 |

실습문제·정답·추가서술형·최종시험은 만들지 않는다(사용자 결정 2026-10-27).

빌드(파이썬: `C:\Users\itwill\AppData\Local\Programs\Python\Python314\python.exe`, `-I` 쓰지 않음):

```
python tools\docbuild.py NN장\본문.mk tools\template.docx NN장\{N}장_{제목}.docx
python tools\pptbuild.py NN장\슬라이드.mk NN장\{N}장_{제목}.pptx

```

마크업 문법은 ADG 규격과 같다(`@H1 @H2 @H3 @P @B @CODE @TBL @NOTE @BP @CASE @QUIZ @IMG`,
슬라이드 `@TITLE @SEC @SLIDE @PLAIN @NOTE`). PPT 과정명: `Oracle Database 19c Security 과정`.

## 2. 근거와 우선순위

1. **Oracle 19c 공식 매뉴얼** — 명령·파라미터·뷰·동작의 기준. 원본과 다르면 매뉴얼을 따른다.
   - Security Guide: https://docs.oracle.com/en/database/oracle/oracle-database/19/dbseg/
   - Advanced Security Guide(Data Redaction, TDE): https://docs.oracle.com/en/database/oracle/oracle-database/19/asoag/
   - PL/SQL Packages and Types Reference(DBMS_RLS, DBMS_FGA, DBMS_REDACT, DBMS_CRYPTO, DBMS_NETWORK_ACL_ADMIN, DBMS_AUDIT_MGMT)
2. **원본 강의 자료**(`Downloads\sec\`, 복원본은 스크래치 `src\*.md`) — 실습 흐름과 다룰 범위.
3. **OEL7V9 실측** — 트랜스크립트의 출력은 전부 실제 실행 결과.

원본의 11g식 문법(예: `CREATE_ACL`/`ASSIGN_ACL`, `sqlnet.ora`의 `ENCRYPTION_WALLET_LOCATION`,
512비트 인증서)은 19c 방식으로 바꿔 쓴다. 구버전 문법을 현장에서 마주칠 수 있는 곳만 Note 박스에서
한두 줄로 차이를 밝힌다.

## 3. 실습 랩 (OEL7V9)

- 호스트 `oel7v9`(172.16.225.50), Oracle 19.3 단일 홈 `/u01/app/oracle/product/19.3.0/dbhome_1`.
- 주 실습 DB `orcl`: non-CDB, ARCHIVELOG, **mixed 감사 모드**(Unified Auditing 옵션 FALSE, `audit_trail=DB`),
  지갑·TDE·syslog 설정 없음. HR·SCOTT 스키마 사용.
- 보조 DB `sales`: DB Link·TLS의 상대편. **이미 TDE 지갑(WALLET_ROOT, AUTOLOGIN)이 있으므로 그 설정은 건드리지 않는다.**
- 트랜스크립트 프롬프트: `SYS@orcl>`, `HR@orcl>`, `SCOTT@orcl>`, `[oracle@oel7v9 ~]$`.
- **장마다 실습이 끝나면 원복한다.** 만든 사용자·정책·컨텍스트·ACL·링크·지갑·파라미터를 지우고,
  `sqlnet.ora`·`listener.ora`·`tnsnames.ora`는 실습 전 백업본으로 되돌린다.
- 사용자 크론(`full_backup.sh`, 현재 주석 처리)과 RMAN 영구 설정은 건드리지 않는다.
- 실측에 쓴 접속 비밀번호는 교안에 그대로 써도 된다(버릴 실습 VM).

## 4. 문체

- 본문: 개조식(`@B`) + 평서체(`~다` 기본). 독자를 부르지 않는다. 절 도입 `@P` 1~2문장 허용.
- 금지: 재진술 맺음("~것이 핵심이다", "~라는 뜻이다"), 볼드 라벨 남발, 대조 공식("A가 아니라 B다") 장당 5회 이내,
  줄표 장당 10회 이내, "결국/즉/바로" 연속, 메타 표현("~라는 점", "~를 기억해 두자"), 근거 없는 수식어,
  매 절 끝 예고 불릿, "실측/우리 환경/여러분".
- 본문 설명은 개념 중심. 트랜스크립트 출력 숫자를 본문 설명의 근거로 쓰지 않는다.
- 노트: 강사가 그대로 읽을 수 있는 설명 말투, 200~500자, "이 슬라이드는~"으로 시작하지 않음.
