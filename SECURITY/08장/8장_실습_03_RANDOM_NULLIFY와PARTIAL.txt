 제8장 실습 03 — RANDOM·NULLIFY·숫자와 날짜 PARTIAL
 대상    : oel7v9 orcl
 목표    : 한 정책에 여러 방식의 컬럼을 추가하고, 정책 식을 역할 기반으로 바꾼다.
          이미 리댁션된 컬럼과 사용자 함수가 들어간 정책 식에서 나는 오류를 확인한다
 소요    : 약 25분
 변경    : MASK_SALARY_POLICY 에 컬럼 3개 추가, 역할 HR_PAYROLL 생성 (05 에서 철거)

--------------------------------------------------------------------------------
 [1] 컬럼 추가와 방식 변경
--------------------------------------------------------------------------------

-- COMMISSION_PCT 는 NULLIFY, EMAIL 은 RANDOM, HIRE_DATE 는 날짜 PARTIAL,
-- SALARY 는 FULL 에서 숫자 PARTIAL 로 바꾼다.
-- 날짜 형식 'm1d1YHMS' 는 월을 1, 일을 1 로 바꾸고 연·시·분·초는 유지한다.
-- 숫자 형식 '9,1,2' 는 1~2번째 자리를 9 로 바꾼다.

SQL> CONNECT hr/hr
Connected.
HR@orcl> BEGIN
  2    DBMS_REDACT.ALTER_POLICY(
  3      object_schema => 'HR', object_name => 'EMPLOYEES', policy_name => 'MASK_SALARY_POLICY',
  4      action        => DBMS_REDACT.ADD_COLUMN,
  5      column_name   => 'COMMISSION_PCT',
  6      function_type => DBMS_REDACT.NULLIFY);
  7    DBMS_REDACT.ALTER_POLICY(
  8      object_schema => 'HR', object_name => 'EMPLOYEES', policy_name => 'MASK_SALARY_POLICY',
  9      action        => DBMS_REDACT.ADD_COLUMN,
 10      column_name   => 'EMAIL',
 11      function_type => DBMS_REDACT.RANDOM);
 12    DBMS_REDACT.ALTER_POLICY(
 13      object_schema       => 'HR', object_name => 'EMPLOYEES', policy_name => 'MASK_SALARY_POLICY',
 14      action              => DBMS_REDACT.ADD_COLUMN,
 15      column_name         => 'HIRE_DATE',
 16      function_type       => DBMS_REDACT.PARTIAL,
 17      function_parameters => 'm1d1YHMS');
 18    DBMS_REDACT.ALTER_POLICY(
 19      object_schema       => 'HR', object_name => 'EMPLOYEES', policy_name => 'MASK_SALARY_POLICY',
 20      action              => DBMS_REDACT.MODIFY_COLUMN,
 21      column_name         => 'SALARY',
 22      function_type       => DBMS_REDACT.PARTIAL,
 23      function_parameters => '9,1,2');
 24  END;
 25  /

PL/SQL procedure successfully completed.

 정리

-- - NULLIFY 는 NULL, RANDOM 은 조회마다 다른 값, 숫자·날짜 PARTIAL 은 지정한 자리만 바꾼다.
-- - 컬럼 방식 변경은 MODIFY_COLUMN(ADD_COLUMN 이면 ORA-28060).
-- - 정책 식에 사용자 함수는 못 쓴다(ORA-28088). 역할 판정은 SYS_SESSION_ROLES.
