================================================================================
 제4장 실습 03 — 와일드카드·우선순위·거부 항목
 대상    : oel7v9 orcl
 목표    : 서브넷 와일드카드로 권한을 주고, 더 구체적인 호스트의 거부 ACE 가 우선하는 것을 확인한다.
          사용자 자신이 USER_HOST_ACES 로 판정 결과를 보는 방법을 익힌다
 소요    : 약 20분
 변경    : acl_u2 에 172.16.225.* http 허용, 172.16.225.50 거부 ACE 추가 후 제거
================================================================================

--------------------------------------------------------------------------------
 [1] 서브넷 단위로 허용
--------------------------------------------------------------------------------

SQL> CONNECT / AS SYSDBA
Connected.
SYS@orcl> BEGIN
  2    DBMS_NETWORK_ACL_ADMIN.APPEND_HOST_ACE(
  3      host => '172.16.225.*',
  4      ace  => xs$ace_type(privilege_list => xs$name_list('http'),
  5                          principal_name => 'ACL_U2',
  6                          principal_type => xs_acl.ptype_db));
  7  END;
  8  /

PL/SQL procedure successfully completed.

SYS@orcl> CONNECT acl_u2/oracle

--------------------------------------------------------------------------------
 [5] 조치 — 거부 항목 제거
--------------------------------------------------------------------------------

SQL> CONNECT / AS SYSDBA
Connected.
SYS@orcl> BEGIN
  2    DBMS_NETWORK_ACL_ADMIN.REMOVE_HOST_ACE(
  3      host => '172.16.225.50',
  4      ace  => xs$ace_type(privilege_list => xs$name_list('http'),
  5                          principal_name => 'ACL_U2',
  6                          principal_type => xs_acl.ptype_db,
  7                          granted        => FALSE),
  8      remove_empty_acl => TRUE);
  9  END;
 10  /

PL/SQL procedure successfully completed.

SYS@orcl> CONNECT acl_u2/oracle
Connected.
ACL_U2@orcl> SELECT SUBSTR(UTL_HTTP.REQUEST('http://172.16.225.50:8090/'), 1, 40) AS page FROM dual;

PAGE
------------------------------------------------------------------------------------------------------------------------
<html><body>ACL test page on oel7v9</bod

1 row selected.

-- ★ REMOVE_HOST_ACE 에 granted => FALSE 까지 같게 줘야 그 거부 ACE 가 지워진다.
--    remove_empty_acl => TRUE 라 비게 된 ACL 도 함께 사라졌고, 서브넷 허용이 다시 적용되어 페이지를 읽는다.

================================================================================
 정리
================================================================================

-- - 와일드카드는 도메인(*.example.com)과 IP 서브넷(172.16.225.*) 모두에 쓸 수 있다.
-- - 판정은 가장 구체적인 호스트(그 안에서는 포트 범위가 있는 ACL)부터 한다.
-- - granted => FALSE 로 거부 ACE 를 만든다. 제거할 때도 같은 granted 값을 준다.
-- - 일반 사용자는 USER_HOST_ACES 로 자기 판정 결과를 본다.
