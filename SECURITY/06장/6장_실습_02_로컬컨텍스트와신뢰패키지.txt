 목표    : 보안 관리 계정 ctxadm 에 컨텍스트·신뢰 패키지·보안 뷰를 만들고,
          값을 넣는 통로가 신뢰 패키지뿐이며 값은 세션마다 따로라는 것을 확인한다
 소요    : 약 25분
 변경    : ctxadm 사용자, 컨텍스트 C6_TASK_CTX, 테이블·패키지·뷰 (05 에서 철거)

--------------------------------------------------------------------------------
 [1] 보안 관리 계정과 업무 테이블
--------------------------------------------------------------------------------

-- 원본은 ateam 계정이 테이블과 패키지를 함께 소유했다. 여기서는 보안 관리 계정 ctxadm 하나에 모은다.

SQL> CONNECT / AS SYSDBA
Connected.
SYS@orcl> CREATE USER ctxadm IDENTIFIED BY oracle DEFAULT TABLESPACE users QUOTA 10M ON users;

User created.

SYS@orcl> GRANT CREATE SESSION, CREATE TABLE, CREATE VIEW, CREATE PROCEDURE, CREATE ANY CONTEXT, DROP ANY CONTEXT TO ctxadm;

Grant succeeded.

SYS@orcl> GRANT SELECT ON hr.employees TO ctxadm WITH GRANT OPTION;

Grant succeeded.

SYS@orcl> CONNECT ctxadm/oracle
Connected.
CTXADM@orcl> CREATE TABLE c6_tasks (
  2    task_id       NUMBER PRIMARY KEY,
  3    assigned_user VARCHAR2(30),
  4    task_details  VARCHAR2(200));

Table created.

CTXADM@orcl> INSERT INTO c6_tasks VALUES (1, 'USER_A', 'monthly report');

1 row created.

CTXADM@orcl> INSERT INTO c6_tasks VALUES (2, 'USER_B', 'server patch plan');

1 row created.

CTXADM@orcl> INSERT INTO c6_tasks VALUES (3, 'USER_A', 'new hire training');

1 row created.

CTXADM@orcl> COMMIT;

Commit complete.

-- ★ CREATE ANY CONTEXT, DROP ANY CONTEXT 는 시스템 권한이다. 컨텍스트는 스키마 객체가 아니라
--    DB 전체에서 이름이 하나뿐인 객체이기 때문이다.

--------------------------------------------------------------------------------
 [2] 패키지보다 먼저 컨텍스트 만들기
--------------------------------------------------------------------------------

SQL> CONNECT ctxadm/oracle
Connected.
CTXADM@orcl> CREATE CONTEXT c6_task_ctx USING ctxadm.c6_task_pkg;

Context created.

CTXADM@orcl> CONNECT / AS SYSDBA
Connected.
SYS@orcl> COL namespace FOR a12
SYS@orcl> COL schema FOR a8
SYS@orcl> COL package FOR a12
SYS@orcl> SELECT namespace, schema, package, type FROM dba_context WHERE namespace = 'C6_TASK_CTX';

NAMESPACE    SCHEMA   PACKAGE      TYPE
------------ -------- ------------ ----------------------
C6_TASK_CTX  CTXADM   C6_TASK_PKG  ACCESSED LOCALLY

1 row selected.

SYS@orcl> SELECT object_name FROM dba_objects WHERE owner = 'CTXADM' AND object_name = 'C6_TASK_PKG';

no rows selected

-- ★ USING 에 적은 C6_TASK_PKG 는 아직 없지만 컨텍스트는 만들어졌다.
--    컨텍스트는 이름과 신뢰 패키지의 연결만 기록한다. 유형은 기본값 ACCESSED LOCALLY 다.

--------------------------------------------------------------------------------
 [3] 신뢰 패키지와 보안 뷰
--------------------------------------------------------------------------------

SQL> CONNECT ctxadm/oracle
Connected.
CTXADM@orcl> CREATE OR REPLACE PACKAGE c6_task_pkg AS
  2    PROCEDURE set_app_user (p_user_id VARCHAR2);
  3    PROCEDURE clear_app_user;
  4  END;
  5  /

Package created.

CTXADM@orcl> CREATE OR REPLACE PACKAGE BODY c6_task_pkg AS
  2    PROCEDURE set_app_user (p_user_id VARCHAR2) IS
  3    BEGIN
  4      DBMS_SESSION.SET_CONTEXT('c6_task_ctx', 'app_user', p_user_id);
  5    END;
  6    PROCEDURE clear_app_user IS
  7    BEGIN
  8      DBMS_SESSION.CLEAR_CONTEXT('c6_task_ctx', NULL, 'app_user');
  9    END;
 10  END;
 11  /

Package body created.

CTXADM@orcl> CREATE OR REPLACE VIEW c6_secure_tasks AS
  2    SELECT task_id, assigned_user, task_details
  3      FROM c6_tasks
  4     WHERE assigned_user = SYS_CONTEXT('c6_task_ctx', 'app_user');

View created.

CTXADM@orcl> GRANT SELECT ON c6_secure_tasks TO hr;

Grant succeeded.

CTXADM@orcl> GRANT EXECUTE ON c6_task_pkg TO hr;

Grant succeeded.

-- ★ 보안 뷰는 WHERE 절에서 SYS_CONTEXT 를 읽는다. 값이 없으면 어느 행도 조건을 만족하지 않는다.
--    HR 에는 뷰 조회 권한과 패키지 실행 권한만 줬다. 원본 테이블 C6_TASKS 권한은 없다.

--------------------------------------------------------------------------------
 [4] 오류 재현 — 패키지 밖에서 값 넣기
--------------------------------------------------------------------------------

SQL> CONNECT hr/hr
Connected.
HR@orcl> EXEC DBMS_SESSION.SET_CONTEXT('c6_task_ctx', 'app_user', 'USER_A')
BEGIN DBMS_SESSION.SET_CONTEXT('c6_task_ctx', 'app_user', 'USER_A'); END;

*
ERROR at line 1:
ORA-01031: insufficient privileges
ORA-06512: at "SYS.DBMS_SESSION", line 141
ORA-06512: at line 1


HR@orcl> SELECT * FROM ctxadm.c6_secure_tasks;

no rows selected

-- ★ ORA-01031. DBMS_SESSION 실행 권한이 있어도 C6_TASK_CTX 에 값을 넣는 호출은
--    USING 에 지정한 패키지 안에서 나와야 한다. 값이 들어가지 않았으니 보안 뷰도 0건이다.

--------------------------------------------------------------------------------
 [5] 조치 — 신뢰 패키지로 값 넣고 지우기
--------------------------------------------------------------------------------

SQL> CONNECT hr/hr
Connected.
HR@orcl> COL task_details FOR a20
HR@orcl> COL assigned_user FOR a13
HR@orcl> EXEC ctxadm.c6_task_pkg.set_app_user('USER_A')

PL/SQL procedure successfully completed.

HR@orcl> SELECT * FROM ctxadm.c6_secure_tasks;

   TASK_ID ASSIGNED_USER TASK_DETAILS
---------- ------------- --------------------
         1 USER_A        monthly report
         3 USER_A        new hire training

2 rows selected.

HR@orcl> EXEC ctxadm.c6_task_pkg.set_app_user('USER_B')

PL/SQL procedure successfully completed.

HR@orcl> SELECT * FROM ctxadm.c6_secure_tasks;

   TASK_ID ASSIGNED_USER TASK_DETAILS
---------- ------------- --------------------
         2 USER_B        server patch plan

1 row selected.

HR@orcl> COL namespace FOR a12
HR@orcl> COL attribute FOR a10
HR@orcl> COL value FOR a8
HR@orcl> SELECT namespace, attribute, value FROM session_context;

NAMESPACE    ATTRIBUTE  VALUE
------------ ---------- --------
C6_TASK_CTX  APP_USER   USER_B

1 row selected.

HR@orcl> EXEC ctxadm.c6_task_pkg.clear_app_user

PL/SQL procedure successfully completed.

HR@orcl> SELECT COUNT(*) FROM session_context;

  COUNT(*)
----------
         0

1 row selected.

HR@orcl> SELECT * FROM ctxadm.c6_secure_tasks;

no rows selected

-- ★ USER_A 로 설정하면 2건, USER_B 로 바꾸면 1건이다. 같은 뷰가 세션의 값에 따라 다른 결과를 낸다.
--    SESSION_CONTEXT 에 C6_TASK_CTX.APP_USER = USER_B 가 보인다.
--    CLEAR_CONTEXT 로 지운 뒤에는 SESSION_CONTEXT 0건, 뷰도 0건이다.
--    연결 풀에서 세션을 돌려주기 전에 값을 지우지 않으면 다음 사용자가 앞 사용자 값을 이어받는다.

--------------------------------------------------------------------------------
 [6] 세션이 바뀌면
--------------------------------------------------------------------------------

SQL> CONNECT hr/hr
Connected.
HR@orcl> EXEC ctxadm.c6_task_pkg.set_app_user('USER_A')

PL/SQL procedure successfully completed.

HR@orcl> SELECT COUNT(*) FROM ctxadm.c6_secure_tasks;

  COUNT(*)
----------
         2

1 row selected.

HR@orcl> CONNECT hr/hr
Connected.
HR@orcl> SELECT COUNT(*) FROM ctxadm.c6_secure_tasks;

  COUNT(*)
----------
         0

1 row selected.

-- ★ 값을 넣은 세션에서는 2건, CONNECT 로 새로 연 세션에서는 0건이다.
--    로컬 컨텍스트 값은 세션 메모리(UGA)에 있고 로그아웃과 함께 사라진다.

================================================================================
 정리
================================================================================

-- - 컨텍스트 = 네임스페이스 이름 + 신뢰 패키지. 패키지보다 먼저 만들 수 있다.
-- - 값은 신뢰 패키지 안의 DBMS_SESSION.SET_CONTEXT 로만 넣는다(밖에서 호출 시 ORA-01031).
-- - 로컬 컨텍스트는 세션 단위. CLEAR_CONTEXT 로 지울 수 있다.
