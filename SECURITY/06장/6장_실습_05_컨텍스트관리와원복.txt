================================================================================
 제6장 실습 05 — 컨텍스트 관리와 원복
 대상    : oel7v9 orcl
 목표    : 같은 이름의 컨텍스트 생성 오류와 CREATE OR REPLACE 로 유형을 바꾼 결과를 보고,
          이 장에서 만든 것을 모두 철거한다
 소요    : 약 15분
 변경    : 이 장의 객체 전부 철거
================================================================================

--------------------------------------------------------------------------------
 [1] 오류 재현 — 이름이 겹치는 컨텍스트
--------------------------------------------------------------------------------

SQL> CONNECT ctxadm/oracle
Connected.
CTXADM@orcl> CREATE CONTEXT c6_task_ctx USING ctxadm.c6_other_pkg;
CREATE CONTEXT c6_task_ctx USING ctxadm.c6_other_pkg
*
ERROR at line 1:
ORA-00955: name is already used by an existing object


CTXADM@orcl> CREATE OR REPLACE CONTEXT c6_task_ctx USING ctxadm.c6_task_pkg ACCESSED GLOBALLY;

Context created.

CTXADM@orcl> CONNECT / AS SYSDBA
Connected.
SYS@orcl> COL namespace FOR a12
SYS@orcl> COL package FOR a12
SYS@orcl> SELECT namespace, package, type FROM dba_context WHERE namespace LIKE 'C6%' ORDER BY 1;

NAMESPACE    PACKAGE      TYPE
------------ ------------ ----------------------
C6_EMP_CTX   C6_EMP_PKG   ACCESSED LOCALLY
C6_GLOB_CTX  C6_GLOB_PKG  ACCESSED GLOBALLY
C6_POOL_CTX  C6_POOL_PKG  ACCESSED GLOBALLY
C6_TASK_CTX  C6_TASK_PKG  ACCESSED GLOBALLY

4 rows selected.

-- ★ 같은 이름으로 CREATE CONTEXT 하면 ORA-00955. 컨텍스트 이름은 DB 전체에서 하나다.
--    CREATE OR REPLACE 는 신뢰 패키지와 유형을 한 번에 바꾼다. C6_TASK_CTX 가 ACCESSED GLOBALLY 가 됐다.

--------------------------------------------------------------------------------
 [2] 유형이 바뀐 뒤의 기존 패키지
--------------------------------------------------------------------------------

SQL> CONNECT hr/hr
Connected.
HR@orcl> COL task_details FOR a20
HR@orcl> COL assigned_user FOR a13
HR@orcl> EXEC ctxadm.c6_task_pkg.set_app_user('USER_A')

PL/SQL procedure successfully completed.

HR@orcl> CONNECT hr/hr
Connected.
HR@orcl> SELECT * FROM ctxadm.c6_secure_tasks;

   TASK_ID ASSIGNED_USER TASK_DETAILS
---------- ------------- --------------------
         1 USER_A        monthly report
         3 USER_A        new hire training

2 rows selected.

HR@orcl> CONNECT / AS SYSDBA
Connected.
SYS@orcl> ALTER SYSTEM FLUSH GLOBAL CONTEXT;

System altered.

-- ★ 패키지·뷰는 그대로인데, 값을 넣은 세션을 끊고 새로 접속해도 USER_A 의 2건이 보인다.
--    유형만 바꿔도 값이 세션을 넘어 공유된다. 컨텍스트 정의 변경은 코드 변경과 같은 무게로 검토한다.
--    SYS 가 FLUSH GLOBAL CONTEXT 로 남은 값을 비웠다.
