================================================================================
 제6장 실습 01 — USERENV와 세션 컨텍스트 조회
 대상    : oel7v9 orcl (non-CDB, 19.3)
 목표    : 기본 제공 네임스페이스 USERENV 로 세션 정보를 읽고,
          데이터베이스가 채우는 값과 클라이언트가 바꿀 수 있는 값을 구분한다
 소요    : 약 15분
 변경    : 없음
================================================================================

--------------------------------------------------------------------------------
 [1] USERENV 로 세션 정보 읽기
--------------------------------------------------------------------------------

SQL> CONNECT hr/hr
Connected.
HR@orcl> COL session_user FOR a12
HR@orcl> COL current_schema FOR a14
HR@orcl> COL auth_method FOR a11
HR@orcl> COL ip FOR a15
HR@orcl> COL module FOR a12
HR@orcl> SELECT SYS_CONTEXT('USERENV', 'SESSION_USER')          AS session_user,
  2         SYS_CONTEXT('USERENV', 'CURRENT_SCHEMA')        AS current_schema,
  3         SYS_CONTEXT('USERENV', 'AUTHENTICATION_METHOD') AS auth_method,
  4         SYS_CONTEXT('USERENV', 'IP_ADDRESS')            AS ip,
  5         SYS_CONTEXT('USERENV', 'MODULE')                AS module
  6    FROM dual;

SESSION_USER CURRENT_SCHEMA AUTH_METHOD IP              MODULE
------------ -------------- ----------- --------------- ------------
HR           HR             PASSWORD                    SQL*Plus

1 row selected.

HR@orcl> ALTER SESSION SET CURRENT_SCHEMA = scott;

Session altered.

HR@orcl> SELECT SYS_CONTEXT('USERENV', 'SESSION_USER')   AS session_user,
  2         SYS_CONTEXT('USERENV', 'CURRENT_SCHEMA') AS current_schema
  3    FROM dual;

SESSION_USER CURRENT_SCHEMA
------------ --------------
HR           SCOTT

1 row selected.

-- ★ SESSION_USER 는 로그인한 사용자, CURRENT_SCHEMA 는 이름 해석 기준 스키마다.
--    ALTER SESSION SET CURRENT_SCHEMA 로 CURRENT_SCHEMA 는 SCOTT 로 바뀌었지만 SESSION_USER 는 HR 그대로다.
--    보안 판단에는 SESSION_USER 를 쓴다. IP_ADDRESS 는 서버 로컬(bequeath) 접속이라 비어 있다.

--------------------------------------------------------------------------------
 [2] 오류 재현 — 없는 USERENV 속성
--------------------------------------------------------------------------------

SQL> CONNECT hr/hr
Connected.
HR@orcl> SELECT SYS_CONTEXT('USERENV', 'DEPARTMENT') FROM dual;
SELECT SYS_CONTEXT('USERENV', 'DEPARTMENT') FROM dual
*
ERROR at line 1:
ORA-02003: invalid USERENV parameter


HR@orcl> SELECT SYS_CONTEXT('USERENV', 'SESSIONID') AS audsid, SYS_CONTEXT('USERENV', 'SID') AS sid FROM dual;

AUDSID
------------------------------------------------------------------------------------------------------------------------
SID
------------------------------------------------------------------------------------------------------------------------
3061667
29


1 row selected.

-- ★ USERENV 에 없는 속성을 읽으면 ORA-02003: invalid USERENV parameter.
--    사용자 정의 네임스페이스와 달리 USERENV 는 정해진 속성만 받는다. 철자를 고쳐 SESSIONID·SID 를 읽었다.

--------------------------------------------------------------------------------
 [3] 클라이언트가 바꿀 수 있는 USERENV 속성
--------------------------------------------------------------------------------

SQL> CONNECT hr/hr
Connected.
HR@orcl> COL client_id FOR a12
HR@orcl> COL module FOR a12
HR@orcl> COL action FOR a10
HR@orcl> EXEC DBMS_SESSION.SET_IDENTIFIER('kim.hr')

PL/SQL procedure successfully completed.

HR@orcl> EXEC DBMS_APPLICATION_INFO.SET_MODULE('payroll_ui', 'search')

PL/SQL procedure successfully completed.

HR@orcl> SELECT SYS_CONTEXT('USERENV', 'CLIENT_IDENTIFIER') AS client_id,
  2         SYS_CONTEXT('USERENV', 'MODULE')            AS module,
  3         SYS_CONTEXT('USERENV', 'ACTION')            AS action
  4    FROM dual;

CLIENT_ID    MODULE       ACTION
------------ ------------ ----------
kim.hr       payroll_ui   search

1 row selected.

-- ★ CLIENT_IDENTIFIER, MODULE, ACTION 은 세션이 스스로 설정한다. 별도 권한 없이 바뀌었다.
--    이 값은 감사·추적에는 유용하지만, 사용자가 위조할 수 있으므로 단독 보안 근거로 쓰지 않는다.

--------------------------------------------------------------------------------
 [4] 없는 네임스페이스와 SESSION_CONTEXT
--------------------------------------------------------------------------------

SQL> CONNECT hr/hr
Connected.
HR@orcl> COL v FOR a10
HR@orcl> SELECT NVL(SYS_CONTEXT('NO_SUCH_CTX', 'ANY_ATTR'), '(null)') AS v FROM dual;

V
----------
(null)

1 row selected.

HR@orcl> SELECT COUNT(*) FROM session_context;

  COUNT(*)
----------
         0

1 row selected.

-- ★ 존재하지 않는 네임스페이스도 SYS_CONTEXT 는 오류 없이 NULL 을 돌려준다.
--    SESSION_CONTEXT 는 이 세션에 설정된 사용자 정의 컨텍스트 값을 보여 준다. 아직 아무것도 없어 0건이다.

================================================================================
 정리
================================================================================

-- - USERENV 는 기본 제공 네임스페이스. 없는 속성은 ORA-02003, 없는 사용자 네임스페이스는 NULL.
-- - SESSION_USER·AUTHENTICATION_METHOD·IP_ADDRESS 는 서버가 채우는 값, CLIENT_IDENTIFIER·MODULE·ACTION 은 클라이언트가 바꾸는 값.
-- - 이 실습은 아무것도 만들지 않았다.
