================================================================================
 제6장 실습 04 — 전역 접근 컨텍스트와 CLIENT_IDENTIFIER
 대상    : oel7v9 orcl
 목표    : ACCESSED GLOBALLY 컨텍스트가 세션 사이에 값을 공유하는 방식을 보고,
          username·client_id 로 값을 볼 수 있는 세션을 좁히는 연결 풀 모델을 구성한다
 소요    : 약 30분
 변경    : C6_GLOB_CTX, C6_POOL_CTX, c6_apppool 사용자 (05 에서 철거)
================================================================================

--------------------------------------------------------------------------------
 [1] ACCESSED GLOBALLY 컨텍스트 (원본 방식)
--------------------------------------------------------------------------------

-- 원본의 전역 컨텍스트 예제처럼 SET_CONTEXT 에 username·client_id 를 주지 않는다.

SQL> CONNECT ctxadm/oracle
Connected.
CTXADM@orcl> CREATE CONTEXT c6_glob_ctx USING ctxadm.c6_glob_pkg ACCESSED GLOBALLY;

Context created.

CTXADM@orcl> CREATE OR REPLACE PACKAGE c6_glob_pkg AS
  2    PROCEDURE set_department;
  3  END;
  4  /

Package created.

CTXADM@orcl> CREATE OR REPLACE PACKAGE BODY c6_glob_pkg AS
  2    PROCEDURE set_department IS
  3      v_dept hr.employees.department_id%TYPE;
  4    BEGIN
  5      SELECT e.department_id INTO v_dept
  6        FROM hr.employees e JOIN c6_user_map m ON e.email = m.email
  7       WHERE m.username = SYS_CONTEXT('USERENV', 'SESSION_USER');
  8      DBMS_SESSION.SET_CONTEXT('c6_glob_ctx', 'dept_id', v_dept);
  9    EXCEPTION
 10      WHEN NO_DATA_FOUND THEN
 11        NULL;
 12    END;
 13  END;
 14  /

Package body created.

CTXADM@orcl> CREATE OR REPLACE VIEW c6_glob_emp AS
  2    SELECT employee_id, first_name, department_id
  3      FROM hr.employees
  4     WHERE department_id = SYS_CONTEXT('c6_glob_ctx', 'dept_id');

View created.

CTXADM@orcl> GRANT SELECT ON c6_glob_emp TO c6_king, c6_hunold, c6_nomap;

Grant succeeded.

CTXADM@orcl> GRANT EXECUTE ON c6_glob_pkg TO c6_king, c6_hunold;

Grant succeeded.

CTXADM@orcl> CONNECT / AS SYSDBA
Connected.
SYS@orcl> COL namespace FOR a12
SYS@orcl> SELECT namespace, type FROM dba_context WHERE namespace LIKE 'C6%' ORDER BY 1;

NAMESPACE    TYPE
------------ ----------------------
C6_EMP_CTX   ACCESSED LOCALLY
C6_GLOB_CTX  ACCESSED GLOBALLY
C6_TASK_CTX  ACCESSED LOCALLY

3 rows selected.

-- ★ DBA_CONTEXT 의 TYPE 이 ACCESSED GLOBALLY 다. 값은 세션 메모리가 아니라 SGA 에 저장된다.

 [3] 오류 재현 — 전역 컨텍스트 비우기
--------------------------------------------------------------------------------

SQL> CONNECT c6_king/oracle

C6_KING@orcl> ALTER SYSTEM FLUSH GLOBAL_CONTEXT;
ALTER SYSTEM FLUSH GLOBAL_CONTEXT
*
ERROR at line 1:
ORA-02000: missing SHARED_POOL/BUFFER_POOL/FLASH_CACHE/BUFFER_CACHE/GLOBAL CONTEXT/PASSWORDFILE_METADATA_CACHE keyword


C6_KING@orcl> ALTER SYSTEM FLUSH GLOBAL CONTEXT;
ALTER SYSTEM FLUSH GLOBAL CONTEXT
*
ERROR at line 1:
ORA-01031: insufficient privileges


C6_KING@orcl> EXEC DBMS_SESSION.CLEAR_ALL_CONTEXT('c6_glob_ctx')
BEGIN DBMS_SESSION.CLEAR_ALL_CONTEXT('c6_glob_ctx'); END;

*
ERROR at line 1:
ORA-01031: insufficient privileges
ORA-06512: at "SYS.DBMS_SESSION", line 237
ORA-06512: at line 1

-- ★ FLUSH GLOBAL_CONTEXT(밑줄)는 ORA-02000. 19.3 의 키워드는 GLOBAL CONTEXT(공백)다.
--    매뉴얼 본문의 GLOBAL_CONTEXT 표기를 그대로 치면 문법 오류가 난다.
--    문법을 고쳐도 일반 사용자는 ORA-01031. CLEAR_ALL_CONTEXT 도 신뢰 패키지 밖이라 ORA-01031.

--------------------------------------------------------------------------------
 [4] 조치 — CLIENT_IDENTIFIER 로 나누기 (연결 풀 모델)
--------------------------------------------------------------------------------

-- 애플리케이션 서버는 DB 계정 c6_apppool 하나로 접속하고, 최종 사용자는 CLIENT_IDENTIFIER 로 구분한다.
-- 신뢰 패키지는 username => 'C6_APPPOOL', client_id => 최종 사용자 로 값을 넣는다.

SQL> CONNECT / AS SYSDBA
Connected.
SYS@orcl> ALTER SYSTEM FLUSH GLOBAL CONTEXT;

System altered.

SYS@orcl> COL namespace FOR a12
SYS@orcl> SELECT COUNT(*) FROM global_context WHERE namespace LIKE 'C6%';

  COUNT(*)
----------
         0

1 row selected.

SYS@orcl> CREATE USER c6_apppool IDENTIFIED BY oracle;

User created.

SYS@orcl> GRANT CREATE SESSION TO c6_apppool;

Grant succeeded.

SYS@orcl> CONNECT ctxadm/oracle
Connected.
CTXADM@orcl> CREATE CONTEXT c6_pool_ctx USING ctxadm.c6_pool_pkg ACCESSED GLOBALLY;

Context created.

CTXADM@orcl> CREATE OR REPLACE PACKAGE c6_pool_pkg AS
  2    PROCEDURE init_client (p_client_id VARCHAR2);
  3  END;
  4  /

Package created.

CTXADM@orcl> CREATE OR REPLACE PACKAGE BODY c6_pool_pkg AS
  2    PROCEDURE init_client (p_client_id VARCHAR2) IS
  3      v_dept hr.employees.department_id%TYPE;
  4    BEGIN
  5      SELECT department_id INTO v_dept FROM hr.employees WHERE email = UPPER(p_client_id);
  6      DBMS_SESSION.SET_CONTEXT('c6_pool_ctx', 'dept_id', v_dept,
  7                               username  => 'C6_APPPOOL',
  8                               client_id => p_client_id);
  9    END;
 10  END;
 11  /

Package body created.

CTXADM@orcl> CREATE OR REPLACE VIEW c6_pool_emp AS
  2    SELECT employee_id, first_name, department_id
  3      FROM hr.employees
  4     WHERE department_id = SYS_CONTEXT('c6_pool_ctx', 'dept_id');

View created.

CTXADM@orcl> GRANT SELECT ON c6_pool_emp TO c6_apppool;

Grant succeeded.

CTXADM@orcl> GRANT EXECUTE ON c6_pool_pkg TO c6_apppool;

Grant succeeded.

-- ★ SYS 의 FLUSH GLOBAL CONTEXT 로 앞 단계 값을 비웠다. GLOBAL_CONTEXT 에서 C6% 0건.

--    소문자 'sking' 도 90 을 읽었다. ARPLS 는 client_id 가 대소문자를 구분한다고 적고 있으나 19.3 에서는
--    구분 없이 일치했다. 식별자는 한 가지 표기로 통일해 쓴다.

================================================================================
 정리
================================================================================

-- - ACCESSED GLOBALLY 값은 SGA 에 있고 username·client_id 로 볼 수 있는 세션이 정해진다. 둘 다 없으면 모두가 본다.
-- - 연결 풀 모델: 단일 DB 계정 + CLIENT_IDENTIFIER. 요청마다 SET_IDENTIFIER, 반납 전 CLEAR_IDENTIFIER.
-- - 전역 값 비우기는 ALTER SYSTEM FLUSH GLOBAL CONTEXT(공백, ALTER SYSTEM 권한).
