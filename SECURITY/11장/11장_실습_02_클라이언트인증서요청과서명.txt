================================================================================
 제11장 실습 02 — 클라이언트 인증서 요청과 서명
 대상    : oel7v9, oracle OS 사용자
 목표    : 클라이언트 지갑에서 인증서 요청을 만들고 서버 지갑(CA)으로 서명한 뒤,
          신뢰 인증서와 사용자 인증서를 클라이언트 지갑에 가져온다
 소요    : 약 15분
 변경    : /home/oracle/tls/client_wallet, 요청·인증서 파일
================================================================================

--------------------------------------------------------------------------------
 [1] 클라이언트 지갑과 인증서 요청
--------------------------------------------------------------------------------

[oracle@oel7v9 ~]$ orapki wallet create -wallet /home/oracle/tls/client_wallet -pwd 'Client#2026' -auto_login
Oracle PKI Tool Release 19.0.0.0.0 - Production
Version 19.3.0.0.0
Copyright (c) 2004, 2019, Oracle and/or its affiliates. All rights reserved.

Operation is successfully completed.
[oracle@oel7v9 ~]$ orapki wallet add -wallet /home/oracle/tls/client_wallet -dn 'CN=tls_client,O=itwill,C=KR' -keysize 2048 -pwd 'Client#2026'
Oracle PKI Tool Release 19.0.0.0.0 - Production
Version 19.3.0.0.0
Copyright (c) 2004, 2019, Oracle and/or its affiliates. All rights reserved.

Operation is successfully completed.
[oracle@oel7v9 ~]$ cd /home/oracle/tls
[oracle@oel7v9 tls]$ orapki wallet export -wallet /home/oracle/tls/client_wallet -dn 'CN=tls_client,O=itwill,C=KR' -request ./client_req.txt -pwd 'Client#2026'
Oracle PKI Tool Release 19.0.0.0.0 - Production
Version 19.3.0.0.0
Copyright (c) 2004, 2019, Oracle and/or its affiliates. All rights reserved.

Operation is successfully completed.
[oracle@oel7v9 tls]$ orapki wallet display -wallet /home/oracle/tls/client_wallet
Oracle PKI Tool Release 19.0.0.0.0 - Production
Version 19.3.0.0.0
Copyright (c) 2004, 2019, Oracle and/or its affiliates. All rights reserved.

Requested Certificates: 
Subject:        CN=tls_client,O=itwill,C=KR
User Certificates:
Trusted Certificates:

-- ★ -self_signed 없이 add 하면 키 쌍과 인증서 요청이 만들어진다. display 의 Requested Certificates 에
--    CN=tls_client,O=itwill,C=KR 이 보인다. 이 DN 이 03 에서 DB 사용자와 연결된다.

--------------------------------------------------------------------------------
 [2] CA(서버 지갑)로 서명
--------------------------------------------------------------------------------

[oracle@oel7v9 ~]$ cd /home/oracle/tls
[oracle@oel7v9 tls]$ orapki cert create -wallet /home/oracle/tls/server_wallet -request ./client_req.txt -cert ./client_signed.cert -validity 365 -pwd 'Server#2026'
Oracle PKI Tool Release 19.0.0.0.0 - Production
Version 19.3.0.0.0
Copyright (c) 2004, 2019, Oracle and/or its affiliates. All rights reserved.

Operation is successfully completed.
[oracle@oel7v9 tls]$ orapki cert display -cert ./client_signed.cert | head -8
Oracle PKI Tool Release 19.0.0.0.0 - Production
Version 19.3.0.0.0
Copyright (c) 2004, 2019, Oracle and/or its affiliates. All rights reserved.

Subject:        CN=tls_client,O=itwill,C=KR
Issuer:         CN=oel7v9,O=itwill,C=KR
Valid Until:    Wed Oct 27 20:33:48 KST 2027

-- ★ 서명된 인증서의 Subject 는 클라이언트 DN, Issuer 는 서버 자체 서명 인증서의 DN 이다.
--    유효 기간은 -validity 365 에 따라 1년 뒤까지다.

--------------------------------------------------------------------------------
 [3] 순서를 거꾸로 — CA 보다 사용자 인증서를 먼저
--------------------------------------------------------------------------------

[oracle@oel7v9 ~]$ cd /home/oracle/tls
[oracle@oel7v9 tls]$ orapki wallet add -wallet /home/oracle/tls/client_wallet -user_cert -cert ./client_signed.cert -pwd 'Client#2026'
Oracle PKI Tool Release 19.0.0.0.0 - Production
Version 19.3.0.0.0
Copyright (c) 2004, 2019, Oracle and/or its affiliates. All rights reserved.

Operation is successfully completed.

-- ★ 19.3 orapki 는 신뢰 인증서 없이도 사용자 인증서 가져오기를 허용했다. 지갑은 이 시점에 CA 를 모른다.

--------------------------------------------------------------------------------
 [4] 오류 재현 — CA 를 넣은 뒤 사용자 인증서를 다시 가져오기
--------------------------------------------------------------------------------

[oracle@oel7v9 ~]$ cd /home/oracle/tls
[oracle@oel7v9 tls]$ orapki wallet add -wallet /home/oracle/tls/client_wallet -trusted_cert -cert ./server_ca.cert -pwd 'Client#2026'
Oracle PKI Tool Release 19.0.0.0.0 - Production
Version 19.3.0.0.0
Copyright (c) 2004, 2019, Oracle and/or its affiliates. All rights reserved.

Operation is successfully completed.
[oracle@oel7v9 tls]$ orapki wallet add -wallet /home/oracle/tls/client_wallet -user_cert -cert ./client_signed.cert -pwd 'Client#2026'
Oracle PKI Tool Release 19.0.0.0.0 - Production
Version 19.3.0.0.0
Copyright (c) 2004, 2019, Oracle and/or its affiliates. All rights reserved.

PKI-04004: The user certificate is already installed in the wallet. 
Could not install user cert at./client_signed.cert
Please add all trusted certificates before adding the user certificate
[oracle@oel7v9 tls]$ orapki wallet display -wallet /home/oracle/tls/client_wallet
Oracle PKI Tool Release 19.0.0.0.0 - Production
Version 19.3.0.0.0
Copyright (c) 2004, 2019, Oracle and/or its affiliates. All rights reserved.

Requested Certificates: 
User Certificates:
Subject:        CN=tls_client,O=itwill,C=KR
Trusted Certificates: 
Subject:        CN=oel7v9,O=itwill,C=KR

-- ★ PKI-04004: The user certificate is already installed. 이미 들어 있는 인증서를 다시 넣으려 했다.
--    함께 나온 안내 "Please add all trusted certificates before adding the user certificate" 가 정상 순서다.
--    최종 display 에서 User Certificates 에 클라이언트 인증서, Trusted Certificates 에 서버 CA 가 있다.

================================================================================
 정리
================================================================================

-- - 클라이언트: 요청 생성 → 내보내기 / CA: 서명 / 클라이언트: 신뢰 인증서 → 사용자 인증서 순으로 가져온다.
-- - 19.3 orapki 는 순서를 바꿔도 막지 않지만, 안내 메시지대로 CA 를 먼저 넣는 것이 원칙이다.
