================================================================================
 제1장 실습 01 — 지갑 생성과 자격 증명 등록
 대상    : oel7v9 orcl (non-CDB, 19.3), oracle OS 사용자
 목표    : SEPS 용 DB 계정을 만들고 mkstore 로 지갑을 만든 뒤 자격 증명 두 개를 등록한다.
          지갑 비밀번호 복잡도 규칙과 지갑 파일 구성을 확인한다
 소요    : 약 15분
 변경    : DB 사용자 SEPS_APP·SEPS_RPT, /home/oracle/seps (05 에서 철거)
================================================================================

--------------------------------------------------------------------------------
 [1] SEPS 용 DB 계정 준비
--------------------------------------------------------------------------------

SQL> CONNECT / AS SYSDBA
Connected.
SYS@orcl> CREATE USER seps_app IDENTIFIED BY "SepsApp#1"
  2    DEFAULT TABLESPACE users QUOTA 10M ON users;

User created.

SYS@orcl> CREATE USER seps_rpt IDENTIFIED BY "SepsRpt#1";

User created.

SYS@orcl> GRANT CREATE SESSION, CREATE TABLE TO seps_app;

Grant succeeded.

SYS@orcl> GRANT CREATE SESSION TO seps_rpt;

Grant succeeded.

SYS@orcl> COL username FOR a10
SYS@orcl> COL profile FOR a10
SYS@orcl> SELECT username, account_status, profile FROM dba_users WHERE username LIKE 'SEPS%';

USERNAME   ACCOUNT_STATUS                   PROFILE
---------- -------------------------------- ----------
SEPS_RPT   OPEN                             DEFAULT
SEPS_APP   OPEN                             DEFAULT

2 rows selected.

-- ★ 지갑에 넣을 계정은 업무용 계정이다. SEPS_APP 은 04 의 Data Pump 실습을 위해 CREATE TABLE 과 할당량을 받았다.
--    두 계정 모두 DEFAULT 프로파일이라 FAILED_LOGIN_ATTEMPTS 는 10 이다.

--------------------------------------------------------------------------------
 [2] 지갑과 TNS_ADMIN 디렉터리
--------------------------------------------------------------------------------

-- 서버의 $ORACLE_HOME/network/admin 은 건드리지 않는다. 지갑과 클라이언트 설정을 /home/oracle/seps 아래에 따로 둔다.

[oracle@oel7v9 ~]$ mkdir -p /home/oracle/seps/wallet /home/oracle/seps/tns
[oracle@oel7v9 ~]$ chmod 700 /home/oracle/seps
[oracle@oel7v9 ~]$ ls -ld /home/oracle/seps /home/oracle/seps/*
drwx------. 4 oracle dba 31 Oct 27 20:23 /home/oracle/seps
drwxr-xr-x. 2 oracle dba  6 Oct 27 20:23 /home/oracle/seps/tns
drwxr-xr-x. 2 oracle dba  6 Oct 27 20:23 /home/oracle/seps/wallet

-- ★ 상위 디렉터리 /home/oracle/seps 를 700 으로 막았다. 하위 디렉터리는 755 지만 상위를 지나갈 수 없으므로 다른 OS 사용자는 들어올 수 없다.

--------------------------------------------------------------------------------
 [3] 오류 재현 — 짧은 지갑 비밀번호
--------------------------------------------------------------------------------

-- 실습 기록을 남기려고 printf 로 입력을 넘긴다. 운영에서는 대화식으로 입력한다.

[oracle@oel7v9 ~]$ printf 'oracle\noracle\n' | mkstore -wrl /home/oracle/seps/wallet -create
Oracle Secret Store Tool Release 19.0.0.0.0 - Production
Version 19.3.0.0.0

PKI-01002: Invalid password. Passwords must have a minimum length of eight characters and contain alphabetic characters combined with numbers or special characters. 
Enter password:   
PKI-01002: Invalid password. Passwords must have a minimum length of eight characters and contain alphabetic characters combined with numbers or special characters. 
[oracle@oel7v9 ~]$ ls -l /home/oracle/seps/wallet
total 0

-- ★ PKI-01002: 8자 이상, 영문자와 숫자 또는 특수 문자를 섞어야 한다.
--    mkstore 가 비밀번호를 다시 묻는 동안 두 번째 줄도 같은 이유로 거부됐고, 지갑 파일은 하나도 생기지 않았다.

 [4] 조치 — 복잡도를 맞춰 다시 생성
--------------------------------------------------------------------------------

[oracle@oel7v9 ~]$ ls -l /home/oracle/seps/wallet
total 8
-rw-------. 1 oracle dba 194 Oct 27 20:23 cwallet.sso
-rw-------. 1 oracle dba   0 Oct 27 20:23 cwallet.sso.lck
-rw-------. 1 oracle dba 149 Oct 27 20:23 ewallet.p12
-rw-------. 1 oracle dba   0 Oct 27 20:23 ewallet.p12.lck

-- ★ ewallet.p12(본체)와 cwallet.sso(auto-login 사본), 각각의 .lck 잠금 파일이 생겼다.
--    권한은 모두 600(-rw-------)으로 만들어진다. mkstore -create 로 만든 지갑은 일반 auto-login 지갑이다.

================================================================================
 정리
================================================================================

-- - 지갑 = ewallet.p12 + cwallet.sso. mkstore -create 는 auto-login 지갑을 만든다.
-- - 지갑 비밀번호는 복잡도 규칙(PKI-01002)을 지켜야 한다.
-- - 자격 증명은 접속 문자열을 키로 저장된다. 다음 실습에서 이 접속 문자열을 tnsnames 별칭과 맞춘다.
