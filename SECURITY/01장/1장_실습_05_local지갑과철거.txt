================================================================================
 제1장 실습 05 — local auto-login 지갑과 철거
 대상    : oel7v9 orcl, oracle·root OS 사용자
 목표    : 원본 자료 방식(orapki -auto_login_local)으로 지갑을 만들어 쓰고,
          지갑을 다른 OS 사용자에게 복사했을 때 local 지갑과 일반 지갑의 차이를 확인한 뒤 모두 철거한다
 소요    : 약 20분
 변경    : 임시 OS 사용자 sepscopy 생성 후 삭제. 이 장에서 만든 DB 객체·파일 전부 철거
================================================================================

--------------------------------------------------------------------------------
 [1] 원본 방식 — orapki 로 local auto-login 지갑
--------------------------------------------------------------------------------

-- 원본 자료는 orapki 로 지갑을 만들고 mkstore 로 자격 증명을 넣는다. sqlnet.ora 는 새 지갑을 가리키게 바꾼다.

[oracle@oel7v9 ~]$ mkdir -p /home/oracle/seps/wallet_local
[oracle@oel7v9 ~]$ orapki wallet create -wallet /home/oracle/seps/wallet_local -pwd 'Wallet#2026' -auto_login_local
Oracle PKI Tool Release 19.0.0.0.0 - Production
Version 19.3.0.0.0
Copyright (c) 2004, 2019, Oracle and/or its affiliates. All rights reserved.

Operation is successfully completed.
[oracle@oel7v9 ~]$ printf 'SepsApp#2\nSepsApp#2\nWallet#2026\n' | mkstore -wrl /home/oracle/seps/wallet_local -createCredential seps_app seps_app
Oracle Secret Store Tool Release 19.0.0.0.0 - Production
Version 19.3.0.0.0
Copyright (c) 2004, 2019, Oracle and/or its affiliates. All rights reserved.

Your secret/Password is missing in the command line 
Enter your secret/Password:   
Re-enter your secret/Password:   
Enter wallet password:   
[oracle@oel7v9 ~]$ ls -l /home/oracle/seps/wallet_local
total 8
-rw-------. 1 oracle dba 589 Oct 27 20:24 cwallet.sso
-rw-------. 1 oracle dba   0 Oct 27 20:24 cwallet.sso.lck
-rw-------. 1 oracle dba 544 Oct 27 20:24 ewallet.p12
-rw-------. 1 oracle dba   0 Oct 27 20:24 ewallet.p12.lck
[oracle@oel7v9 ~]$ cd /home/oracle/seps/tns
[oracle@oel7v9 tns]$ sed -i 's#/home/oracle/seps/wallet)#/home/oracle/seps/wallet_local)#' sqlnet.ora
[oracle@oel7v9 tns]$ grep DIRECTORY sqlnet.ora
    (METHOD_DATA = (DIRECTORY = /home/oracle/seps/wallet_local))
[oracle@oel7v9 tns]$ export TNS_ADMIN=/home/oracle/seps/tns
[oracle@oel7v9 tns]$ echo 'SHOW USER' | sqlplus -s -L /@seps_app
USER is "SEPS_APP"

-- ★ orapki 로 만든 local 지갑에도 mkstore 로 자격 증명을 넣을 수 있다. 같은 접속으로 잘 동작한다.
--    orapki 는 -pwd 로 비밀번호를 명령행에서 받았다. 실습 기록용이며 운영에서는 -pwd 를 빼고 대화식으로 입력한다.

--------------------------------------------------------------------------------
 [2] 오류 재현 — 지갑을 다른 OS 사용자에게 복사
--------------------------------------------------------------------------------

-- 다른 서버 대신 다른 OS 사용자(sepscopy)를 만들어 지갑 두 개와 TNS 설정을 복사한다.

[root@oel7v9 ~]# useradd -m sepscopy
[root@oel7v9 ~]# cp -r /home/oracle/seps/wallet_local /home/oracle/seps/wallet /home/oracle/seps/tns /home/sepscopy/
[root@oel7v9 ~]# chown -R sepscopy /home/sepscopy/wallet_local /home/sepscopy/wallet /home/sepscopy/tns
[root@oel7v9 ~]# sed -i 's#/home/oracle/seps/wallet_local)#/home/sepscopy/wallet_local)#' /home/sepscopy/tns/sqlnet.ora
[root@oel7v9 ~]# su - sepscopy -c "export ORACLE_HOME=/u01/app/oracle/product/19.3.0/dbhome_1 TNS_ADMIN=/home/sepscopy/tns; echo 'SHOW USER' | \$ORACLE_HOME/bin/sqlplus -s -L /@seps_app"
ERROR:
ORA-12578: TNS:wallet open failed


SP2-0751: Unable to connect to Oracle.  Exiting SQL*Plus
[root@oel7v9 ~]# sed -i 's#/home/sepscopy/wallet_local)#/home/sepscopy/wallet)#' /home/sepscopy/tns/sqlnet.ora
[root@oel7v9 ~]# su - sepscopy -c "export ORACLE_HOME=/u01/app/oracle/product/19.3.0/dbhome_1 TNS_ADMIN=/home/sepscopy/tns; echo 'SHOW USER' | \$ORACLE_HOME/bin/sqlplus -s -L /@seps_app"
USER is "SEPS_APP"
[root@oel7v9 ~]# pkill -u sepscopy; sleep 2
[root@oel7v9 ~]# userdel -r sepscopy
[root@oel7v9 ~]# id sepscopy
id: sepscopy: no such user

-- ★ local 지갑(wallet_local)은 ORA-12578: TNS:wallet open failed. 만든 OS 사용자가 아니면 열리지 않는다.
--    일반 auto-login 지갑(wallet)은 다른 사용자에게서도 그대로 열려 SEPS_APP 으로 접속됐다.
--    일반 지갑은 파일을 손에 넣은 누구나 쓸 수 있다는 뜻이다. 실습이 끝나면 임시 사용자는 지운다.

 정리
================================================================================

-- - local auto-login 지갑은 만든 OS 사용자·호스트 밖에서 ORA-12578 로 열리지 않는다.
-- - 일반 auto-login 지갑은 복사하면 어디서나 열린다. 지갑 파일 권한이 곧 계정 보안이다.
-- - 이 장에서 만든 사용자·디렉터리·지갑·OS 사용자를 모두 지웠다.
