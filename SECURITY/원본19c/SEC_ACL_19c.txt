-- 12c부터 ACL 파일을 직접 만들지 않는다. APPEND_HOST_ACE로 호스트에 ACE(접근 제어 항목)를 붙이면
--       ACL은 시스템이 NETWORK_ACL_<16진수> 이름으로 만든다. CREATE_ACL·ADD_PRIVILEGE는 디프리케이트
-- 원본 add_privilege(is_grant => FALSE) 는 granted => FALSE 인 ACE로 옮김

  2    PROCEDURE add_two (p_host VARCHAR2, p_lport NUMBER, p_uport NUMBER) IS

--       마지막 ACE 가 빠진 ACL 은 remove_empty_acl => TRUE 일 때 함께 지워짐 (끝의 정리 단계에서 실측)
