# 원본 강의 자료 19c 실측 변환 — 작업 규격

입력: `C:\Users\itwill\Downloads\sec\`의 파일 8개. PDF의 한글은 깨져 있으니 이미지 판독본을 쓴다. 판독본은 스크래치 `src\*.md`에 있고, PTW_RSRC_MGR는 아직 없어서 pdftoppm으로 렌더링해 판독한다.
출력: 이 폴더에 원본 파일 하나당 txt 하나를 만든다. 파일 이름은 `<원본 이름>_19c.txt`다(`SEC_ETC_19c.txt`, `Masking Data_19c.txt`, `PTW_RSRC_MGR_19c.txt` …). 인코딩은 UTF-8, 줄바꿈은 LF.

## 변환 원칙 (사용자 결정 2026-10-28: "원본 구성 유지 txt")
- 원본의 순서, 절 제목(`<<SSL>>`, `<< Local context >>` 등), 설명 항목, 실습 흐름을 그대로 따른다. 새 절을 만들거나 순서를 바꾸지 않는다.
- 명령과 SQL은 19c 문법으로 고친다. 예: ALTER SYSTEM SET ENCRYPTION KEY → ADMINISTER KEY MANAGEMENT, orapki/mkstore 대신 키스토어 SQL, DBMS_NETWORK_ACL_ADMIN 구 API → APPEND_HOST_ACE, 11g식 경로·파라미터 → WALLET_ROOT/TDE_CONFIGURATION.
  - 19c에서도 그대로 동작하는 명령은 원본 그대로 둔다.
- 출력은 OEL7V9에서 실측한 값으로 모두 바꾼다. 원본 출력을 남기지 않는다. 프롬프트와 출력은 고치지 않는다.
- 원본 설명 문장이 19c 기준으로 틀리면 고친다. 고친 곳과 명령을 바꾼 곳에는 바로 위에 `-- [19c] 무엇이 왜 바뀌었는지` 한두 줄을 단다. 그 밖의 해설은 넣지 않는다(설명은 최소한).
- 원본이 오류를 보여 주는 곳은 19.3에서 실제로 나는 오류로 바꾼다. 원본 의도와 다른 결과가 나오면 결과는 실측대로 두고 `-- [19c]` 주석으로 짚는다(예: 로컬 컨텍스트는 세션 단위라 0건).
- 파일 맨 앞 머리말:
```
================================================================================
 <원본 파일 이름> — Oracle 19c 실측 변환본
 원본    : sec\<파일 이름> (<쪽수>쪽)
 실측    : OEL7V9 orcl 19.3.0 non-CDB, 2026-10-28  (TDE 등 예외 DB는 여기에 명시)
 주요 변경: - ...
           - ...
================================================================================
```
- 원본의 표는 `|` 구분 텍스트 표로 옮긴다. 그림은 `[그림: 설명]` 한 줄로 바꾼다.
- 문체는 원본 문체를 따르되, 새로 쓰는 문장은 개조식 평서체로 쓴다. CLAUDE.md의 AI 문체 금지 규칙을 지킨다.

## 랩 규칙 (포크 동시 사용)
- 원본의 사용자·객체 이름을 그대로 쓰는 것이 원칙이다. 다른 포크와 겹칠 위험이 있으면 포크별로 다음 범위만 쓴다.
  - A: SSL·SEPS·Proxy·SAR
  - B: Context·Masking·CRYPTO·TDE·Masking Data
  - C: ACL·DBLINK·FGA·FGAC
  - D: syslog·RSRC
  - 다른 포크가 쓰는 이름(HR.EMPLOYEES 정책 등)은 피한다. HR.EMPLOYEES에 정책을 거는 것은 B만 하고, FGA는 C가 SCOTT 객체에 건다.
- orcl 재기동은 D만, 그것도 A·B·C가 모두 끝났다는 표식(스크래치 `raw\S\A.done`, `B.done`, `C.done`)이 생긴 뒤에만 한다. 기본 LISTENER도 재기동하지 않는다.
- 공용 sqlnet.ora·listener.ora·tnsnames.ora는 원칙적으로 수정하지 않는다. 클라이언트 쪽은 전용 TNS_ADMIN에 두고, TCPS는 별도 리스너로 한다. 서버 쪽을 어쩔 수 없이 바꿨다면 끝에서 md5가 `*.bak_sec_20261027`과 같아지게 되돌린다.
- TDE는 DBCA로 만든 임시 DB에서 실측하고 끝나면 지운다. 1일 실습 08의 d08tde 방식과 같다(`/u01/app/oracle/oradata`는 root 소유라 데이터 위치를 따로 잡는다). DBCA가 다시 쓴 tnsnames.ora는 백업으로 되돌린다. orcl의 기존 TDE 구성과 tde_keystore_keep은 건드리지 않는다.
- 기존 감사 기록은 지우지 않는다. EMP_FGA와 ORA_* 정책은 그대로 둔다.
- Resource Manager는 끝나면 resource_manager_plan을 원래 값으로 되돌리고, 만든 plan·consumer group·매핑을 지운다.
- syslog 변경(audit_syslog_level, unified_audit_systemlog, /etc/rsyslog.conf)은 끝나면 원래 값과 원래 파일로 되돌리고 rsyslog를 재시작한다.
- sales DB, 사용자 크론, RMAN 설정은 건드리지 않는다. 실습 객체는 끝나면 모두 지우고 지워졌는지 확인한다.
- 실측 원본 json은 스크래치 `raw\S\<이름>.json`에 둔다. 러너는 각 포크가 자기 복사본(`lab\s_A.py` 등)을 쓴다.
