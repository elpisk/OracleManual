KEY WORDS
- DB/NETWORK LINK

- 네트워크 정보는 이미 셋팅되어야 함.
- Local naming : c1(clone DB)
  -- [환경] c1 → SALES. 같은 서버의 sales DB 를 원격으로 쓰고, sales 에 SCOTT 샘플 스키마를 미리 만들어 둠
- CLONE DB의 SCOTT 계정의 EMP TABLE을 수정할 수 있는 PROCEDURE를 작성하기
  ROLE을 생성하여 있는 PROCEDURE를 HR 계정이 실행할 수 있는 권한과 EMP TABLE 을 질의할 수 있는 권한을 넘겨주어야 한다. 생성된 VIEW는 SYNONYM(EMP)을 만들어 질의하자.

-DB LINK 생성
SYS@orcl> create database link test
  2  connect to scott identified by tiger using 'sales';

Database link created.

-PROCEDURE 생성
SYS@orcl> create or replace procedure update_scott_sal
  2  (p_empno number, p_sal number)
  3  is
  4  begin
  5   update emp@test set sal = p_sal
  6   where   empno = p_empno;
  7  end;
  8  /

Procedure created.

-ROLE 생성
SYS@orcl> create role scott_r1;

Role created.

-권한 넘겨주기
SYS@orcl> grant execute on update_scott_sal to scott_r1;

Grant succeeded.

SYS@orcl> grant scott_r1 to hr;

Grant succeeded.

-HR에서 PROCEDURE 실행하기
--  HR 비밀번호 oracle → hr

== NETWORK LINK

-- [환경] 원본의 ORCL(원본 DB) → PROD(대상 DB) 구성을 orcl → sales 로 옮김. 접속 별칭 t1 → ORCL

- ORCL에서
SYS@orcl> COLUMN name FORMAT A9
SYS@orcl> select p.con_id, p.name, p.open_mode,
  2         ew.wrl_type,ew.wallet_type,ew.status
  3    from v$database p, v$encryption_wallet ew
  4   where p.con_id=ew.con_id
  5   order by 1;

    CON_ID NAME      OPEN_MODE            WRL_TYPE             WALLET_TYPE          STATUS
---------- --------- -------------------- -------------------- -------------------- ------------------------------
         0 ORCL      READ WRITE           FILE                 LOCAL_AUTOLOGIN      OPEN

1 row selected.

--  orcl 은 TDE 키스토어가 열려 있다(LOCAL_AUTOLOGIN). 아래 덤프 암호화는 비밀번호 방식이라 키스토어와 무관함

-- 원본의 HR.EMP(219,136행)를 HR.EMPLOYEES 107행 × 2048 로 재현
SYS@orcl> create table hr.emp as select * from hr.employees;

Table created.

SYS@orcl> begin
  2    for i in 1 .. 11 loop
  3      insert into hr.emp select * from hr.emp;
  4    end loop;
  5    commit;
  6  end;
  7  /

PL/SQL procedure successfully completed.
