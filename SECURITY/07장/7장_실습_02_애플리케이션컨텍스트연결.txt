================================================================================
 제7장 실습 02 — 애플리케이션 컨텍스트로 조건 넘기기
 대상    : oel7v9 orcl
 목표    : 정책 함수가 읽을 부서 번호를 애플리케이션 컨텍스트로 넘긴다.
          컨텍스트 값은 신뢰 패키지만 넣을 수 있고, 세션마다 따로라는 것을 확인한다
 소요    : 약 20분
 변경    : 컨텍스트 HR_CONTEXT, 패키지 sysadmin_vpd.hr_ctx_pkg (05 에서 철거)
================================================================================

--------------------------------------------------------------------------------
 [1] 컨텍스트와 신뢰 패키지 만들기
--------------------------------------------------------------------------------

-- CREATE CONTEXT ... USING 에 적은 패키지가 그 네임스페이스의 값을 넣을 수 있는 유일한 통로다.
-- 패키지가 아직 없어도 컨텍스트는 만들어진다.

SQL> CONNECT sysadmin_vpd/oracle
Connected.
SYSADMIN_VPD@orcl> CREATE CONTEXT hr_context USING sysadmin_vpd.hr_ctx_pkg;

Context created.

SYSADMIN_VPD@orcl> CREATE OR REPLACE PACKAGE hr_ctx_pkg AS
  2    PROCEDURE set_dept (p_deptno IN NUMBER);
  3  END;
  4  /

Package created.

SYSADMIN_VPD@orcl> CREATE OR REPLACE PACKAGE BODY hr_ctx_pkg AS
  2    PROCEDURE set_dept (p_deptno IN NUMBER) IS
  3    BEGIN
  4      DBMS_SESSION.SET_CONTEXT('HR_CONTEXT', 'DEPT', p_deptno);
  5    END;
  6  END;
  7  /

Package body created.

SYSADMIN_VPD@orcl> GRANT EXECUTE ON hr_ctx_pkg TO scott;

Grant succeeded.

SYSADMIN_VPD@orcl> CONNECT / AS SYSDBA
Connected.
SYS@orcl> COL namespace FOR a12
SYS@orcl> COL schema FOR a14
SYS@orcl> COL package FOR a12
SYS@orcl> SELECT namespace, schema, package, type FROM dba_context WHERE namespace = 'HR_CONTEXT';

NAMESPACE    SCHEMA         PACKAGE      TYPE
------------ -------------- ------------ ----------------------
HR_CONTEXT   SYSADMIN_VPD   HR_CTX_PKG   ACCESSED LOCALLY

1 row selected.

-- ★ TYPE 이 ACCESSED LOCALLY 다. 값이 그 값을 넣은 세션 안에서만 보인다는 뜻이다.
--    여러 세션이 값을 공유하는 ACCESSED GLOBALLY 는 6장에서 다룬다.

--------------------------------------------------------------------------------
 [2] 오류 재현 — 패키지를 거치지 않고 값 넣기
--------------------------------------------------------------------------------

SQL> CONNECT scott/tiger
Connected.
SCOTT@orcl> EXEC DBMS_SESSION.SET_CONTEXT('HR_CONTEXT', 'DEPT', 10)
BEGIN DBMS_SESSION.SET_CONTEXT('HR_CONTEXT', 'DEPT', 10); END;

*
ERROR at line 1:
ORA-01031: insufficient privileges
ORA-06512: at "SYS.DBMS_SESSION", line 141
ORA-06512: at line 1

-- ★ ORA-01031. DBMS_SESSION 실행 권한이 있어도, HR_CONTEXT 에 값을 넣는 호출은
--    USING 에 지정한 패키지 안에서 나온 것이어야 한다. 사용자가 스스로 부서를 바꿔 넣는 길을 막는 장치다.

--------------------------------------------------------------------------------
 [3] 오류 재현 — 다른 세션에서 넣은 값
--------------------------------------------------------------------------------

-- 원본 실습은 SYS 세션에서 set_hr_context(20) 을 실행한 뒤 SCOTT 세션에서 조회했다.
-- 같은 흐름을 그대로 따라 해 본다.

SQL> CONNECT / AS SYSDBA
Connected.
SYS@orcl> EXEC sysadmin_vpd.hr_ctx_pkg.set_dept(20)

PL/SQL procedure successfully completed.

SYS@orcl> COL dept FOR a6
SYS@orcl> SELECT SYS_CONTEXT('HR_CONTEXT', 'DEPT') AS dept FROM dual;

DEPT
------
20

1 row selected.

SYS@orcl> CONNECT scott/tiger
Connected.
SCOTT@orcl> COL dept FOR a6
SCOTT@orcl> SELECT SYS_CONTEXT('HR_CONTEXT', 'DEPT') AS dept FROM dual;

DEPT
------


1 row selected.

SCOTT@orcl> SELECT COUNT(*) FROM emp;

  COUNT(*)
----------
         0

1 row selected.

-- ★ SYS 세션에는 20 이 들어갔지만 CONNECT 로 새로 열린 SCOTT 세션에서는 NULL 이고 0건이다.
--    로컬 컨텍스트는 세션 메모리(UGA)에 있다. 값은 조회할 세션이 직접 넣어야 한다.

--------------------------------------------------------------------------------
 [4] 조치 — SCOTT 세션이 스스로 값 넣기
--------------------------------------------------------------------------------

SQL> CONNECT scott/tiger
Connected.
SCOTT@orcl> EXEC sysadmin_vpd.hr_ctx_pkg.set_dept(20)

PL/SQL procedure successfully completed.

SCOTT@orcl> COL dept FOR a6
SCOTT@orcl> SELECT SYS_CONTEXT('HR_CONTEXT', 'DEPT') AS dept FROM dual;

DEPT
------
20

1 row selected.

SCOTT@orcl> SELECT empno, ename, deptno FROM emp;

     EMPNO ENAME          DEPTNO
---------- ---------- ----------
      7369 SMITH              20
      7566 JONES              20
      7788 SCOTT              20
      7876 ADAMS              20
      7902 FORD               20

5 rows selected.

SCOTT@orcl> EXEC sysadmin_vpd.hr_ctx_pkg.set_dept(10)

PL/SQL procedure successfully completed.

SCOTT@orcl> SELECT empno, ename, deptno FROM emp;

     EMPNO ENAME          DEPTNO
---------- ---------- ----------
      7782 CLARK              10
      7839 KING               10
      7934 MILLER             10

3 rows selected.

SCOTT@orcl> SELECT ename FROM emp WHERE deptno = 20;

no rows selected

-- ★ 같은 SELECT 가 컨텍스트 값에 따라 20번 5건, 10번 3건으로 바뀐다.
--    마지막 조회는 WHERE deptno = 20 을 직접 줬지만 0건이다. 사용자 조건과 정책 술어가 AND 로 합쳐졌다.
--    실습을 단순하게 하려고 SCOTT 가 아무 부서나 넣을 수 있게 했다. 실제 시스템에서는 패키지가
--    로그인 사용자를 보고 부서를 직접 찾아 넣는다(6장 LOGON 트리거 방식).

--------------------------------------------------------------------------------

--------------------------------------------------------------------------------

SQL> CONNECT scott/tiger
Connected.
SCOTT@orcl> EXEC sysadmin_vpd.hr_ctx_pkg.set_dept(30)

SCOTT@orcl> SET AUTOTRACE TRACEONLY EXPLAIN
SCOTT@orcl> SELECT ename FROM emp WHERE sal > 1000;

================================================================================
 정리
================================================================================

-- - 컨텍스트 값은 USING 에 지정한 신뢰 패키지로만 넣을 수 있다(우회 시 ORA-01031).
-- - 로컬 컨텍스트는 세션 단위다. 다른 세션에서 넣은 값은 보이지 않는다.
-- - 정책 술어는 사용자 조건과 AND 로 합쳐지고 실행 계획의 술어 정보에 그대로 보인다.
