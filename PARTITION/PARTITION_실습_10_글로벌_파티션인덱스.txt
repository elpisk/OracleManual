--------------------------------------------------------------------------------
[1] 시나리오 개요
--------------------------------------------------------------------------------
-- GLOBAL 인덱스는 테이블 파티션 구조와 무관하게 만든다.
-- 테이블은 사번으로 자르고 인덱스는 입사일로 자르는 것이 가능하다.
-- 조회 조건이 파티션 키와 다를 때 유일한 선택지다.
--
-- 대가가 있다. 인덱스가 테이블 파티션 하나에 종속되지 않으므로
-- 파티션 하나를 지우면 인덱스 전체가 무효가 된다. 이 실습은 그 과정을 그대로 재현한다.
--
-- 목표
--   (1) 글로벌 파티션 인덱스는 반드시 접두여야 한다는 제약을 확인한다 (ORA-14038)
--   (2) 인덱스 파티션 단위 프루닝을 계획으로 본다
--   (3) DROP PARTITION 이 글로벌 인덱스 전체를 UNUSABLE 로 만드는 것을 확인한다
--   (4) ORA-14086 / ORA-14078 을 만나고 파티션 단위 복구 방법을 익힌다
--   (5) UPDATE INDEXES 절과 글로벌 비파티션 인덱스의 차이를 비교한다
-- 작업 유형 : 인덱스 설계 + 장애 대응

-- 복구 방법
--   ORA-14086: a partitioned index may not be rebuilt as a whole
--     파티션 인덱스는 통째로 REBUILD 할 수 없다. 파티션 단위로만 가능하다.
--     파티션이 100개면 REBUILD 문장 100개가 필요하다.
--     실무에서는 dba_ind_partitions 를 읽어 문장을 생성하는 스크립트를 쓴다.

[8] 실무 포인트
--------------------------------------------------------------------------------
-- 1. LOCAL 과 GLOBAL 선택 기준
--      조회 조건 = 파티션 키                  -> LOCAL (기본 선택)
--      조회 조건 <> 파티션 키                 -> GLOBAL
--      파티션 키를 포함하지 않는 유일성 필요   -> GLOBAL UNIQUE
--      파티션을 주기적으로 DROP·EXCHANGE      -> LOCAL 로 몰아넣는 설계를 재검토
--    한 테이블에 둘을 섞어 쓰는 것은 정상이다. 인덱스마다 판단한다.
--
-- 2. 글로벌 파티션 인덱스는 반드시 접두다 (ORA-14038).
--    인덱스 선두 컬럼과 인덱스 파티션 키가 같아야 한다.
--
-- 3. 글로벌 인덱스가 있으면 모든 파티션 DDL 에 UPDATE INDEXES 를 붙인다.
--    붙이지 않으면 인덱스 전체가 UNUSABLE 이 되고, 오류 없이 성능만 나빠진다.
--    절차서에 문장 템플릿을 박아 두는 것이 가장 확실한 예방책이다.
--
-- 4. 상태 점검 쿼리는 두 개다.
--      SELECT index_name, partition_name FROM dba_ind_partitions WHERE status <> 'USABLE';
--      SELECT index_name FROM dba_indexes WHERE status = 'UNUSABLE';
--    파티션 인덱스는 dba_indexes.status 가 N/A 이므로 첫 번째 쿼리가 없으면 못 찾는다.
--
-- 5. 복구는 파티션 단위다 (ORA-14086).
--    복구 스크립트를 미리 만들어 둔다.
--      SELECT 'ALTER INDEX '||index_owner||'.'||index_name||
--             ' REBUILD PARTITION '||partition_name||' ONLINE;'
--      FROM   dba_ind_partitions WHERE status <> 'USABLE';
--    ONLINE 을 붙이면 서비스 중에도 리빌드할 수 있다.
--
-- 6. 이 실습에서 본 오류
--    ORA-14038  비접두 글로벌 파티션 인덱스 생성   -> 선두 컬럼을 파티션 키로
--    ORA-01502  UNUSABLE 인덱스 사용               -> REBUILD PARTITION
--    ORA-14086  파티션 인덱스 전체 REBUILD         -> 파티션 단위로 반복
--    ORA-14078  글로벌 인덱스 마지막 파티션 DROP    -> SPLIT/MERGE 로 구조 조정
