## 1. 과정 개요

### 1-1. 대상과 목표

| 항목 | 내용 |
|---|---|
| 대상 | 단일 인스턴스 19c 를 운영해 본 DBA. ADMIN(DBCA·Oracle Net·PDB)과 BACKUP&RECOVERY(RMAN) 수준을 전제한다 |
| 목표 | 2노드 RAC 를 설치 단계부터 읽고, Clusterware·ASM·RAC DB·서비스를 CLI 로 운영하며, 노드·디스크·인스턴스 장애를 스스로 진단하고 기준 상태로 되돌린다 |
| 다루지 않는 것 | Flex Cluster, 정책 기반 서버 풀(개념만), EM GUI, 클라이언트 드라이버별 AC 설정 — `RAC_챕터_목록.md` 3-1 절과 같다 |

### 1-2. 흐름

```
Day 1  클러스터 토대      아키텍처 → Clusterware → 설치 준비 → GI 설치(판독)
Day 2  클러스터 저장소    OCR·Voting → ASM 인스턴스·디스크그룹 → 파일 → 리밸런스·장애
Day 3  RAC 데이터베이스   ASM 도구·마이그레이션 → DB 생성 → 인스턴스 관리 → 스토리지
Day 4  운영 서비스        srvctl·crsctl → 서비스 → 부하·AC → 백업·복구
Day 5  확장과 종합        노드 추가·삭제 → One Node → 진단·성능 → 종합 실기평가
```

아래 층(Clusterware·ASM)을 먼저 세우고 그 위에 DB 와 서비스를 올린다. 원 교안 20장의 순서를 바꾸지 않는다.

## 5. 실습 환경

### 5-1. 사양

| 항목 | 값 |
|---|---|
| 구성 | `RAC_챕터_목록.md` 4장과 같다. `rac1`·`rac2`, `racdb1`·`racdb2`, `+CRS`·`+DATA`·`+FRA` |
| 수강생 PC | 2노드 VM 각 8GB → **호스트 메모리 32GB 권장**, 디스크 여유 200GB 이상 |
| 사전 구축 | 과정 시작 전에 `RAC/scripts/run_all.py` 로 GI·DB 설치까지 마치고 `90_snapshot.ps1 -BackupShared` 로 기준 스냅샷 `rac-base` 를 뜬다. 설치에 몇 시간이 걸리므로 수업 중에는 하지 않는다 |
| 설치 가이드 | 수강생 배포용 `RAC_Install_Guide_rac1_rac2_v2.docx`. 수료 후 직접 다시 구축하는 과제로 쓴다 |

### 5-2. 스냅샷 운영

- **⚠ 실습은 하루 끝에 몰았다.** Day 2 의 8장 06·07, Day 4 의 15장 05·17장 05·06 이다. 끝나면 두 노드를 모두 정지하고 `rac-base` 로 복원한다
- **스냅샷은 두 노드를 동시에 정지한 상태에서만 뜨고 복원한다.** 한쪽만 되돌리면 OCR·Voting File 시점이 어긋나 클러스터가 깨진다
- 공유 디스크는 VM 스냅샷에 포함되지 않으므로 `-BackupShared` 로 뜬 백업을 함께 되돌린다
- 복원에 10~15분이 걸리므로 해당 일자의 마지막 블록에 포함했다

## 6. 평가

### 6-1. 일일 과제

장별 실습문제 [하-01]~[하-10]·[중-01]~[중-05] 15문항. 정답 docx 로 자가 채점하고 다음 날 아침 복습 시간에 오답을 다룬다. 일자별 문항 수는 Day 1·2·4 가 60, Day 3 이 75, Day 5 가 45 다.

### 6-2. 종합 실기평가 (Day 5, 3시간)

기존 최종실습시험 6세트(`RAC/최종실습시험/`)는 세트당 3~4시간이라 5일 과정에서 모두 치를 수 없다. 두 가지 안이 있다.

| 안 | 방식 | 장점 | 비용 |
|---|---|---|---|
| **A (권장)** | 6세트에서 Section 을 골라 3시간짜리 통합 세트를 새로 엮는다. 02(OCR·ASM) · 04(RAC DB 관리) · 05(서비스) · 06(백업) 에서 한 Section 씩 | 과정 전체를 고르게 평가한다 | 문제지·모범답안 1세트 신규 제작. 배점 100점 재조정 |
| B | 06 세트(백업·노드 관리·종합 운영)를 그대로 쓴다 | 추가 제작이 없다 | 1~16장이 평가에서 빠진다 |

어느 안이든 나머지 세트는 수료 후 자습용으로 배포한다. 통과 기준은 기존 시험과 같은 70점이다.
