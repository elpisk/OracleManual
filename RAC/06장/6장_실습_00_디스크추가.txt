-- 새 디스크도 WWN 이 나온다. EnableUUID 가 이미 켜져 있기 때문이다.
-- sda 만 두 노드에서 값이 다르다. 각 VM 의 OS 디스크라 공유가 아니다.
-- 나머지 14장은 두 노드에서 WWN 이 같다.
--
-- 새 디스크는 4GB 라 crs1~3 과 크기가 같다. 설치 가이드 4-2 의 스크립트는
-- 크기로 이름을 정하므로 그대로 다시 돌리면 4GB 디스크 9장이 모두
-- crs1~crs9 가 된다. 노드마다 장치 순서가 다르면 crs1 이 엉뚱한 디스크에
-- 붙고, 그 상태로 재부팅하면 CSSD 가 보팅 파일을 찾지 못한다.
-- 그래서 기존 규칙은 손대지 않고 새 WWN 만 골라 덧붙인다.

--------------------------------------------------------------------------------
 [7] 규칙 추가 — rac1 에서 만든다
--------------------------------------------------------------------------------

[root@rac1 ~]# RULE=/etc/udev/rules.d/99-oracle-asmdisk.rules
[root@rac1 ~]# cp -p $RULE /root/99-oracle-asmdisk.rules.bak
[root@rac1 ~]# ti=1
[root@rac1 ~]# for d in /dev/sd?; do
>   id=$(/lib/udev/scsi_id -g -u -d $d 2>/dev/null)
>   [ -z "$id" ] && continue
>   grep -q "$id" $RULE && continue
>   [ "$(lsblk -bdno SIZE $d)" = "4294967296" ] || continue
>   echo "KERNEL==\"sd?\", SUBSYSTEM==\"block\", PROGRAM==\"/lib/udev/scsi_id -g -u -d \$devnode\", RESULT==\"$id\", SYMLINK+=\"asmdisk/test$ti\", OWNER=\"grid\", GROUP=\"asmadmin\", MODE=\"0660\"" >> $RULE
>   echo "$(basename $d) -> test$ti"
>   ti=$((ti+1))
> done
sdj -> test1
sdk -> test2
sdl -> test3
sdm -> test4
sdn -> test5
sdo -> test6

-- grep -q "$id" 로 이미 규칙에 있는 WWN 8개를 건너뛰었다. sda 는 WWN 이
-- 규칙에 없지만 4GB 가 아니라서 걸러졌다. 크기 조건을 빼면 OS 디스크가
-- test1 이 된다.

[root@rac1 ~]# wc -l $RULE

 [11] 정리
--------------------------------------------------------------------------------

-- 한 일
--   1) racdb · Clusterware 정지 → 두 VM 정지 → vmx 백업
--   2) vdiskmanager 로 4GB × 6 생성(-t 2, 한 장 22~38초)
--   3) 두 vmx 의 scsi0:10~15 에 independent-persistent 로 연결
--   4) rac1 에서 새 WWN 만 골라 udev 규칙 6줄 추가(8줄 → 14줄)
--   5) 같은 규칙 파일을 rac2 로 복사, 양 노드 reload · trigger
--   6) racdb 기동
--
-- 확인한 것
--   1) 규칙 반영 전 새 장치는 root:disk 라 ASM 이 보지 못한다
--   2) 반영 후 grid:asmadmin 0660, /dev/asmdisk/test1~6 링크가 생긴다
--   3) 두 노드의 규칙 파일 md5 와 test1~6 WWN 이 같다
--   4) 양 노드 ASM 에서 CANDIDATE 6장이 보인다
--   5) 부팅 직후의 CRS-4535 와 CRS-5019 는 기동 중의 정상 메시지다
--
-- 주의
--   - 설치 가이드의 크기 기준 스크립트를 다시 돌리지 않는다. 4GB 가
--     crs 디스크와 겹친다
--   - 규칙 파일은 한 노드에서 만들고 복사한다. root 는 ssh 등가가 없어
--     비밀번호를 넣어야 한다
--   - scsi0 의 남은 번호는 이것으로 다 썼다
--
-- 다음 실습 03 에서 v$asm_disk 로 이 6장을 자세히 읽는다.
