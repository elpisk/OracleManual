NAME       TYPE   V
---------- ------ -
CRS        NORMAL Y
DATA       EXTERN N
FRA        EXTERN N

-- CRS 만 Y 다. Normal 중복도라 3개를 담고 있다.
-- DATA 와 FRA 는 External 이며 지금은 Voting File 을 담고 있지 않다.

 [2] 오류 재현 — 개별 추가와 삭제
--------------------------------------------------------------------------------

[root@rac1 ~]# crsctl add css votedisk /dev/asmdisk/crs1
CRS-4258: Addition and deletion of voting files are not allowed because the
          voting files are on ASM

[root@rac1 ~]# crsctl delete css votedisk 838fca0461384f6cbfe0440187190bd9
CRS-4258: Addition and deletion of voting files are not allowed because the
          voting files are on ASM

-- 권한 문제인지 확인하려고 grid 로도 실행해 본다.
[grid@rac1 ~]$ crsctl add css votedisk /dev/asmdisk/crs1
CRS-4258: Addition and deletion of voting files are not allowed because the
          voting files are on ASM

-- 오류 : CRS-4258
-- 원인 파악 : root 와 grid 가 같은 메시지를 받는다. 권한 문제가 아니다.
--             Voting File 이 ASM 에 있으면 개수와 배치는 전적으로 디스크그룹의
--             중복도가 결정한다. 사람이 하나만 더 넣으면 개수가 짝수가 되어
--             과반수 규칙이 깨지고, 하나만 빼면 중복도가 보장하는 손실 허용치와
--             어긋난다. 그래서 개별 조작을 아예 막는다.
-- 조치     : 남은 수단은 crsctl replace votedisk 하나다. 디스크그룹 단위로
--             통째로 교체한다.
-- 재확인   : 구성이 그대로인지 본다.

[root@rac1 ~]# crsctl query css votedisk | tail -1
Located 3 voting disk(s).

--------------------------------------------------------------------------------
 [3] 오류 재현 — 같은 디스크그룹으로 replace
--------------------------------------------------------------------------------

[root@rac1 ~]# crsctl replace votedisk +CRS
CRS-4261: Diskgroup +CRS is already configured with voting files
CRS-4000: Command Replace failed, or completed with errors.

-- 오류 : CRS-4261, CRS-4000
-- 원인 파악 : replace 는 다른 디스크그룹으로의 이동을 위한 명령이다.
--             같은 디스크그룹을 지정하면 옮길 곳이 없다. CRS-4261 이 판정이고
--             CRS-4000 은 명령 실패 통보다.
--             "같은 디스크그룹 안에서 Voting File 만 새로 만들고 싶다" 는
--             요구는 이 명령으로 충족되지 않는다. 그 경우 디스크를 내렸다
--             올리는 방법(실습 06)을 쓴다.
-- 조치     : 다른 디스크그룹을 지정한다.
-- 재확인   : Located 3 voting disk(s) 로 변화 없음.

CRS-4000: Command Replace failed, or completed with errors.

-- 오류 : CRS-4648 / CLSU-00107 / ORA-15001 / CRS-4646 / CRS-4628 / CRS-4000
-- 원인 파악 : 세 계층이 겹쳐 있다.
--
--     CRS  계층   CRS-4648, CRS-4646, CRS-4628, CRS-4000
--     CLSU 계층   CLSU-00107, CLSU-00101, CLSU-00104
--     ASM  계층   ORA-15001, ORA-06512
--
--             실제 원인은 맨 아래의 ORA-15001 이다. 디스크그룹이 없거나
--             마운트되지 않았다. 오류 스택은 위에서부터가 아니라 아래에서부터
--             읽어야 한다.
--             ORA-06512 at SYS.X$DBMS_DISKGROUP 은 crsctl 이 ASM 에게 요청을
--             보낼 때 내부 패키지를 PL/SQL 로 호출한다는 사실을 보여 준다.
-- 조치     : 존재하고 마운트된 디스크그룹을 지정한다.
-- 재확인   : CRS-4628 이 있는지 확인한다. 이 줄이 가장 중요하다.
--             "Change to configuration failed, but was successfully rolled back"
--             실패했지만 롤백에 성공했다는 뜻이며, 구성이 중간 상태로 남지
--             않았다는 보증이다.
--             이 줄이 없는 실패는 위험하다. 그때는 아래 명령으로 현재 상태를
--             직접 확인해야 한다.

[root@rac1 ~]# crsctl query css votedisk
 1. ONLINE   838fca0461384f6cbfe0440187190bd9 (/dev/asmdisk/crs1) [CRS]
 2. ONLINE   4c38f09d6d7b4f1fbfc0e6b7055c8515 (/dev/asmdisk/crs2) [CRS]
 3. ONLINE   370e2d1c1e604f6ebfd6c8aa3b8c0d35 (/dev/asmdisk/crs3) [CRS]
Located 3 voting disk(s).

-- FUID 세 개가 그대로다. 롤백이 실제로 이루어졌다.

 [5] +DATA 로 옮긴다 — External 중복도의 결과
--------------------------------------------------------------------------------

[root@rac1 ~]# crsctl replace votedisk +DATA
Successful addition of voting disk 9e65129747454fcbbfe39f012596a4a3.
Successful deletion of voting disk 838fca0461384f6cbfe0440187190bd9.
Successful deletion of voting disk 4c38f09d6d7b4f1fbfc0e6b7055c8515.
Successful deletion of voting disk 370e2d1c1e604f6ebfd6c8aa3b8c0d35.
Successfully replaced voting disk group with +DATA.
CRS-4266: Voting file(s) successfully replaced

-- 출력 순서가 핵심이다.
--   1) Successful addition   새 위치에 먼저 만든다
--   2) Successful deletion   그다음 옛 위치를 지운다 (3개)
--
-- 이 순서 덕분에 어느 순간에도 Voting File 이 0개가 되지 않는다.
-- 그래서 클러스터를 내리지 않고 옮길 수 있다.
-- CRS-4266 은 성공 메시지다.

[root@rac1 ~]# crsctl query css votedisk
##  STATE    File Universal Id                File Name Disk group
--  -----    -----------------                --------- ---------
 1. ONLINE   9e65129747454fcbbfe39f012596a4a3 (/dev/asmdisk/data1) [DATA]
Located 1 voting disk(s).

-- 3개가 1개가 되었다. +DATA 가 External 중복도이기 때문이다.
-- 개수를 우리가 정한 것이 아니라 디스크그룹의 중복도가 정했다.

-- 지금 상태는 위험하다. Voting File 이 1개뿐이므로 data1 디스크 하나가
-- 죽으면 클러스터 전체가 내려간다. 손실 허용치가 0이다.
-- 실습 목적을 달성했으므로 곧바로 되돌린다.

-- 재현한 오류
--   CRS-4258   개별 add/delete 금지. root 와 grid 모두 같은 메시지
--   CRS-4261   같은 디스크그룹으로 replace
--   CRS-4648 외 롤백을 동반한 실패. CRS-4628 이 보증한다
--
-- 확인한 것
--   1) Voting File 개수는 중복도가 정한다. Normal 3개, External 1개
--   2) replace 는 addition 이 먼저, deletion 이 나중이다. 그래서 무중단
--   3) FUID 는 새로 만들 때마다 새로 부여된다
--   4) 오류 스택은 맨 아래부터 읽는다. 실제 원인은 ORA-15001 이었다
--   5) CRS-4628 이 있으면 중간 상태로 남지 않았다는 보증이다
--   6) ASM alert.log 에 allocation, deletion, refresh 가 순서대로 남는다
--   7) 두 노드의 ASM 인스턴스가 함께 refresh 한다
--
-- 갱신된 대조 기준
--   Voting FUID   e6a57fb4 / be1b37d2 / 038ff992
--   Voting 개수   3
--   OCR ID        665666554 (변화 없음)
--
-- 실습 06 에서 이 중 세 번째 FUID 가 다시 바뀐다.
