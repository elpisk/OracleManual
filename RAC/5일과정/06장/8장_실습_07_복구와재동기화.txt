-- 시각을 보면 20:30:22 에 시작해 20:30:32 에 끝났다. 약 9초다.
--
-- 답은 이 줄에 있다.
--   NOTE: Starting resync using Staleness Registry and ATE scan for group 5
--
-- ASM 은 디스크가 오프라인인 동안 그 디스크에 반영하지 못한 변경을
-- Staleness Registry 라는 별도 구조에 기록해 둔다. 디스크가 돌아오면
-- 전체를 다시 복사하지 않고 그 목록에 있는 익스텐트만 갱신한다.
-- 이것이 fast mirror resync 다.
--
-- ATE 는 Allocation Table Entry 로 익스텐트 할당 정보를 뜻한다.
--
-- 실습에서는 40초 동안만 오프라인이었고 그사이 변경이 거의 없었으므로
-- 옮길 것이 몇 개 되지 않았다.
--
-- op = assign mandatory 도 눈여겨보라. 5장에서 디스크를 내릴 때 나온
-- clear mandatory 와 정확히 대칭이다.

 [8] 5장의 ORA-15283 이 여기서 완결된다
--------------------------------------------------------------------------------

-- 5장에서 +CRS 의 디스크를 내리려 했을 때 이런 오류를 만났다.
--
--   ORA-15032: not all alterations performed
--   ORA-15283: ASM operation requires compatible.rdbms of 11.1.0.0.0 or higher
--
-- 그때는 왜 11.1 이 필요한지 알 수 없었다. 이제 이유가 분명하다.
-- fast mirror resync 가 11.1 에서 도입된 기능이기 때문이다.
-- Staleness Registry 라는 구조 자체가 11.1 에서 추가되었으므로 그 이하
-- 호환성으로는 디스크 OFFLINE 을 허용할 수 없었다.
--
-- 오프라인을 허용해 놓고 재동기화 구조가 없으면, 디스크가 돌아올 때마다
-- 전체 리밸런스를 해야 한다. 그럴 바에는 아예 막는 편이 낫다는 판단이다.

SQL> select name, value from v$asm_attribute
  2   where group_number=(select group_number from v$asm_diskgroup where name='CRS')
  3     and name like 'compatible%';

NAME                VALUE
------------------- ------------
compatible.asm      19.0.0.0.0
compatible.rdbms    11.2.0.0.0

-- 5장에서 10.1 에서 11.2 로 올린 값이다. 되돌릴 수 없는 변경이었다.

 [11] 정리
--------------------------------------------------------------------------------

-- 확인한 것
--   1) 강제 제거된 디스크는 add ... force 로만 되돌릴 수 있다
--   2) 그때는 전체 리밸런스가 일어난다
--   3) 오프라인 시 USED_MB 가 유지된다. 데이터를 지우지 않는다
--   4) 타이머 안에 online 하면 약 9초에 끝난다
--   5) alert.log 의 Starting resync using Staleness Registry 가 근거다
--   6) op = assign mandatory 는 5장의 clear mandatory 와 대칭이다
--   7) 239초 대 9초. 26배 차이다
--   8) 5장의 ORA-15283 이 막았던 것이 바로 이 기능이었다
--
-- 실무 지침
--   계획된 스토리지 작업이라면
--     1) DISK_REPAIR_TIME 을 작업 시간보다 길게 확인한다
--     2) 작업 직전에 해당 디스크를 명시적으로 offline 한다
--     3) 작업 후 online 하면 fast mirror resync 로 빠르게 복구된다
--   타이머를 넘기면 전체 리밸런스가 필요하고 헤더 정리도 해야 한다.
