-- 세 스크립트의 권한이 다르다.
--   root.sh        755  누구나 실행 가능. 내부에서 UID 를 검사한다
--   rootcrs.sh     750  root 와 oinstall 그룹만. 실행 자체가 제한된다
--   deinstall      750  소유자가 grid 다. root 는 실행되지만 내부에서 거부
--
-- root.sh 가 405 바이트로 작다는 점도 눈에 띈다. 실제 작업은 rootcrs.sh 가
-- 하고 root.sh 는 그것을 호출하는 얇은 래퍼다. 8046 바이트인 rootcrs.sh 가
-- 본체인 셈이다.

         Used space (kbytes)      :      84208
         Available space (kbytes) :     407476
         ID                       :  665666554

                                    Device/File integrity check succeeded

                                    Device/File not configured
                                    Device/File not configured

-- ocrcheck 는 grid 로도 실행된다. 조회 명령이기 때문이다.
-- Device/File not configured 네 줄은 오류가 아니다. OCR 은 최대 5벌까지
-- 다중화할 수 있는데 지금은 1벌만 쓰고 있어 나머지 자리가 비어 있다는 뜻이다.

-- 이어서 백업 상태를 본다.
[grid@rac1 ~]$ ocrconfig -showbackup
PROT-24: Auto backups for the Oracle Cluster Registry are not available
PROT-25: Manual backups for the Oracle Cluster Registry are not available

-- 원인 파악
--   PROT-24 는 자동 백업이, PROT-25 는 수동 백업이 없다는 뜻이다.
--   즉 이 클러스터에는 OCR 백업이 하나도 없다.
--
--   root 로 실행해도 결과가 같다. 권한 문제가 아니다.
[root@rac1 ~]# /u01/app/19.3.0/grid/bin/ocrconfig -showbackup
PROT-24: Auto backups for the Oracle Cluster Registry are not available
PROT-25: Manual backups for the Oracle Cluster Registry are not available

--   Clusterware 는 OCR 을 4시간마다 자동 백업한다. 그런데 없다는 것은
--   설치 후 아직 첫 자동 백업 주기가 돌지 않았거나, 백업 위치에 접근하지
--   못했거나, 클러스터가 계속 켜져 있지 않았다는 뜻이다.
--   이 실습 환경은 필요할 때만 VM 을 켜므로 자동 백업 주기를 채우지 못했다.

-- 조치 — 수동 백업을 만들면 즉시 해소된다. 5장에서 다룬다.
--   ocrconfig -manualbackup   (root 권한 필요)
--   이 실습에서는 실행하지 않는다. 5장의 주제이기 때문이다.

-- 재확인
--   지금 상태를 기록해 두고 5장에서 백업을 만든 뒤 다시 조회해 비교한다.
[grid@rac1 ~]$ ocrconfig -showbackup 2>&1 | tee ~/ocr_backup_before.txt
PROT-24: Auto backups for the Oracle Cluster Registry are not available
PROT-25: Manual backups for the Oracle Cluster Registry are not available

-- 배운 것
--   설치가 끝났다고 운영 준비가 끝난 것이 아니다.
--   OCR 백업이 없는 상태는 정상이 아니며 설치 직후 점검에서 잡아야 한다.
--   PROT-24 와 PROT-25 를 보면 즉시 수동 백업을 만들고 자동 백업이
--   동작하는지 확인한다. 5장에서 그 절차를 다룬다.
--   조회 도구(ocrcheck)와 변경 도구(ocrconfig)의 권한 요구가 다르다는 점도
--   함께 기억한다.
