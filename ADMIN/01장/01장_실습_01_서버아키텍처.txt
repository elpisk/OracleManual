[5단계] 인스턴스 시작 3단계(NOMOUNT -> MOUNT -> OPEN) 직접 실습
======================================================================

- 단계별 실습을 위해 데이터베이스를 정상 종료
SYS@cdb1> shutdown immediate
Database closed.
Database dismounted.
ORACLE instance shut down.

- (실수) 인스턴스를 NOMOUNT로 시작하려다 옵션 철자를 잘못 입력
SYS@cdb1> startup nomont
SP2-0714: invalid combination of STARTUP options

- 원인: NOMOUNT 옵션의 철자 오류(nomont). 올바른 키워드로 재시도
SYS@cdb1> startup nomount
ORACLE instance started.

Total System Global Area 2046827888 bytes
Fixed Size                  9145712 bytes
Variable Size            1358954496 bytes
Database Buffers          671088640 bytes
Redo Buffers                7639040 bytes

- NOMOUNT 단계: SGA 할당 + 백그라운드 프로세스만 기동된 상태(STATUS=STARTED)
-   아직 어떤 데이터베이스와도 연결되지 않음
SYS@cdb1> select status from v$instance;

STATUS
------------
STARTED

- (실수) NOMOUNT 상태에서 데이터베이스 정보 조회 시도 -> 제어 파일을 아직 안 읽어 실패
SYS@cdb1> select name, open_mode from v$database;
select name, open_mode from v$database
                            *
ERROR at line 1:
ORA-01507: database not mounted

- 원인: V$DATABASE는 '제어 파일'에서 읽는 정보이므로 MOUNT 단계 이후에만 조회 가능.
-   MOUNT 단계로 진행하여 제어 파일을 읽게 함
SYS@cdb1> alter database mount;

Database altered.

- MOUNT 단계: 제어 파일을 읽어 데이터 파일/리두 로그 위치를 인스턴스가 인식(STATUS=MOUNTED)
SYS@cdb1> select status from v$instance;

STATUS
------------
MOUNTED

- MOUNT 상태에서는 V$DATABASE 조회가 가능해짐(단, 데이터 자체에는 아직 접근 불가)
SYS@cdb1> select name, open_mode from v$database;

NAME      OPEN_MODE
--------- --------------------
CDB1      MOUNTED

- OPEN 단계: 데이터 파일과 리두 로그를 열어 사용자가 데이터에 접근 가능하게 함
SYS@cdb1> alter database open;

Database altered.

SYS@cdb1> select status from v$instance;

STATUS
------------
OPEN

- OPEN 완료 후 데이터 접근이 실제로 가능한지 확인(대표 딕셔너리 조회)
SYS@cdb1> select count(*) from dba_tablespaces;

  COUNT(*)
----------
         5

- 참고: CDB가 OPEN 되어도 PDB는 자동으로 열리지 않고 MOUNTED 상태로 남을 수 있음
SYS@cdb1> select con_id, name, open_mode from v$pdbs order by con_id;

    CON_ID NAME                           OPEN_MODE
---------- ------------------------------ ----------
         2 PDB$SEED                       READ ONLY
         3 SALESPDB                       MOUNTED
         4 HRPDB                          MOUNTED

- 모든 PDB를 한꺼번에 READ WRITE로 오픈
SYS@cdb1> alter pluggable database all open;

Pluggable database altered.

SYS@cdb1> select con_id, name, open_mode from v$pdbs order by con_id;

    CON_ID NAME                           OPEN_MODE
---------- ------------------------------ ----------
         2 PDB$SEED                       READ ONLY
         3 SALESPDB                       READ WRITE
         4 HRPDB                          READ WRITE

- [정리] 아키텍처를 '3+2'로 확인 완료:
-   3대 구조 = 메모리(SGA) + 프로세스(백그라운드) + 저장소(데이터/제어/리두 파일)
-   2대 실체 = 인스턴스(메모리+프로세스, 휘발성) + 데이터베이스(저장소, 영구)
-   기동 순서 = 인스턴스(NOMOUNT) -> 데이터베이스 인식(MOUNT) -> 사용 가능(OPEN)
