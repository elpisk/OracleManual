-- 2장 실습_05: MMON(Manageability Monitor)/MMNL 프로세스 확인 및 AWR 스냅샷

- CDB1 루트에 SYSDBA로 접속된 상태에서 시작 (AWR 조회/생성은 루트에서 수행)
SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

======================================================================
[1단계] MMON / MMNL 프로세스 존재 확인
======================================================================

- 관리성 모니터 본체(MMON)와 보조(MMNL, lite)가 기동되어 있는지 확인
SYS@cdb1> select name, description from v$bgprocess
  2  where name in ('MMON','MMNL') and paddr <> '00'
  3  order by name;

NAME  DESCRIPTION
----- ----------------------------------------------------------------
MMNL  Manageability Monitor Process 2
MMON  Manageability Monitor Process

======================================================================
[2단계] MMON이 자동 생성한 AWR 스냅샷 확인
======================================================================

- MMON은 기본 1시간마다 AWR 스냅샷을 자동 생성함. 최근 스냅샷 5개 조회
SYS@cdb1> select snap_id, begin_interval_time, end_interval_time
  2  from   dba_hist_snapshot
  3  order  by snap_id desc
  4  fetch  first 5 rows only;

   SNAP_ID BEGIN_INTERVAL_TIME            END_INTERVAL_TIME
---------- ------------------------------ ------------------------------
       184 24-JUL-26 03.00.12.000 PM      24-JUL-26 04.00.27.000 PM
       183 24-JUL-26 02.00.55.000 PM      24-JUL-26 03.00.12.000 PM
       182 24-JUL-26 01.00.40.000 PM      24-JUL-26 02.00.55.000 PM
       181 24-JUL-26 12.00.24.000 PM      24-JUL-26 01.00.40.000 PM
       180 24-JUL-26 11.00.09.000 AM      24-JUL-26 12.00.24.000 PM

- 현재 AWR 스냅샷 수집 간격/보존 기간 설정 확인
SYS@cdb1> select snap_interval, retention from dba_hist_wr_control
  2  where dbid = (select dbid from v$database);

SNAP_INTERVAL       RETENTION
------------------- -------------------
+00000 01:00:00.0   +00008 00:00:00.0

======================================================================
[3단계] AWR 스냅샷 수동 생성 (DBMS_WORKLOAD_REPOSITORY.CREATE_SNAPSHOT)
======================================================================

- (실수) 패키지명을 축약해서 호출 (DBMS_WORKLOAD가 아니라 전체 이름이어야 함)
SYS@cdb1> exec dbms_workload.create_snapshot;
BEGIN dbms_workload.create_snapshot; END;

      *
ERROR at line 1:
ORA-06550: line 1, column 7:
PLS-00201: identifier 'DBMS_WORKLOAD.CREATE_SNAPSHOT' must be declared

- 원인: 패키지 이름 오류. 올바른 이름은 DBMS_WORKLOAD_REPOSITORY.
-   정확한 패키지명으로 재시도 (MMON을 거치지 않고 즉시 스냅샷 생성)
SYS@cdb1> exec dbms_workload_repository.create_snapshot;

PL/SQL procedure successfully completed.

- 방금 생성된 스냅샷이 최신 SNAP_ID로 추가되었는지 확인 (184 -> 185)
SYS@cdb1> select max(snap_id) as latest_snap from dba_hist_snapshot;

LATEST_SNAP
-----------
        185

======================================================================
[4단계] 서버 생성 알림(Server-Generated Alerts) 조회
======================================================================

- MMON은 임계치 초과 시 서버 생성 알림을 발행함. 현재 미해결(outstanding) 알림 확인
SYS@cdb1> select reason, object_type, object_name, message_level
  2  from   dba_outstanding_alerts
  3  order  by reason;

no rows selected

- 과거에 해제(정상 복귀)된 알림 이력도 함께 확인 (최근 3건)
SYS@cdb1> select reason, resolution, object_name
  2  from   dba_alert_history
  3  order  by creation_time desc
  4  fetch  first 3 rows only;

REASON                                   RESOLUTION      OBJECT_NAME
---------------------------------------- --------------- ---------------
Tablespace [USERS] is 85 percent full    cleared         USERS
Metrics "Current Open Cursors Count" ...  cleared
Tablespace [SYSAUX] is 85 percent full   cleared         SYSAUX

- [정리] MMON/MMNL 확인 완료:
-   MMON = AWR 스냅샷 자동 생성(기본 1시간)/서버 생성 알림/기준선 계산/자동 진단
-   MMNL = ASH 플러시 등 가볍고 빈번한 작업 담당(보조)
-   수동 스냅샷 = DBMS_WORKLOAD_REPOSITORY.CREATE_SNAPSHOT, 알림 = DBA_OUTSTANDING_ALERTS/DBA_ALERT_HISTORY
