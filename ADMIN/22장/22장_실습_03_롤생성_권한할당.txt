-- 22장 실습_03: 롤(Role) 생성 및 권한 할당 실습 (CREATE ROLE, 롤에 권한/롤 부여)

SYS@cdb1> alter session set container = salespdb;

Session altered.

======================================================================
[1단계] 롤 생성
======================================================================

SYS@salespdb> create role hr_clerk_role;

Role created.

SYS@salespdb> create role hr_manager_role;

Role created.

- (오류) 이미 존재하는 롤 이름으로 다시 생성 시도
SYS@salespdb> create role hr_clerk_role;
create role hr_clerk_role
*
ERROR at line 1:
ORA-01921: role name 'HR_CLERK_ROLE' conflicts with another user or role name

- 원인: 롤 이름은 사용자/다른 롤과 이름 공간을 공유한다. 이미 있는 이름은 재사용 불가.
-   필요하면 기존 롤을 수정(GRANT/REVOKE)하거나 다른 이름을 쓴다.

======================================================================
[2단계] 롤에 시스템 권한과 객체 권한 담기
======================================================================

SYS@salespdb> grant create session to hr_clerk_role;
Grant succeeded.

SYS@salespdb> grant select, insert, update on hr.employees to hr_clerk_role;
Grant succeeded.

- (오류) 롤에 WITH GRANT OPTION 으로 객체 권한 부여 시도
SYS@salespdb> grant select on hr.employees to hr_clerk_role with grant option;
grant select on hr.employees to hr_clerk_role with grant option
*
ERROR at line 1:
ORA-01931: cannot grant SELECT to a role

- 원인: WITH GRANT OPTION 객체 권한은 롤에 부여할 수 없다(사용자/PUBLIC 만 가능).
-   수정: 옵션 없이 부여한다(이미 2단계에서 SELECT 는 담겨 있다).

======================================================================
[3단계] 계층적 롤 구성 (롤에 다른 롤 부여)
======================================================================

- 관리자 롤이 사원 롤을 포함하도록 계층 구성
SYS@salespdb> grant hr_clerk_role to hr_manager_role;
Grant succeeded.

SYS@salespdb> grant delete on hr.employees to hr_manager_role;
Grant succeeded.

- (오류) 순환 참조 시도: 사원 롤에 관리자 롤을 부여
SYS@salespdb> grant hr_manager_role to hr_clerk_role;
grant hr_manager_role to hr_clerk_role
*
ERROR at line 1:
ORA-01934: circular role grant detected

- 원인: 롤 계층은 단방향이어야 한다. A->B 가 있으면 B->A 는 순환이라 금지.

======================================================================
[4단계] 사용자에게 롤 부여
======================================================================

SYS@salespdb> create user scott identified by Tiger#1;
User created.

SYS@salespdb> grant hr_clerk_role to scott;
Grant succeeded.

- 롤에 담긴 권한 확인 (사원 롤)
SYS@salespdb> select privilege from role_sys_privs where role='HR_CLERK_ROLE';

--------------------
CREATE SESSION

SYS@salespdb> select table_name, privilege from role_tab_privs

EMPLOYEES   UPDATE

======================================================================
[5단계] 롤을 통한 간접 권한 사용 확인
======================================================================

SYS@salespdb> connect scott/Tiger#1@salespdb
Connected.

- scott 은 직접 부여받은 객체 권한이 없지만, 롤을 통해 조회가 가능하다.
SCOTT@salespdb> select count(*) from hr.employees;

  COUNT(*)
----------
       107

- 현재 세션에서 활성화된 롤 확인
SCOTT@salespdb> select role from session_roles order by role;

ROLE
--------------------
HR_CLERK_ROLE

- [정리] CREATE ROLE 로 롤 생성(ORA-01921 이름 충돌 주의), 롤에 시스템/객체/롤을 담되
-   롤에는 WITH GRANT OPTION 불가(ORA-01931), 순환 부여 금지(ORA-01934).
