-- 22장 실습_05: 멀티테넌트 환경에서 롤 부여 실습 (공통 롤 / 로컬 롤)

SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

======================================================================
[1단계] (오류) 공통 롤을 접두사 없이 생성 시도
======================================================================

- (실수) 루트에서 공통 롤을 C## 접두사 없이 생성
SYS@cdb1> create role monitor_role container=all;
create role monitor_role container=all
*
ERROR at line 1:
ORA-65096: invalid common user or role name

- 원인: 공통 롤 이름은 반드시 C##(또는 c##) 접두사로 시작해야 한다.

======================================================================
[2단계] (수정) 공통 롤 생성 및 권한 담기
======================================================================

SYS@cdb1> create role c##monitor_role container=all;

Role created.

- 공통 롤에 CONTAINER=ALL 로 딕셔너리 조회 롤을 담는다.
SYS@cdb1> grant select_catalog_role to c##monitor_role container=all;

Grant succeeded.

======================================================================
[3단계] 공통 사용자에게 공통 롤 부여
======================================================================

SYS@cdb1> create user c##dba_common identified by Comm#2024 container=all;
User created.
SYS@cdb1> grant create session to c##dba_common container=all;
Grant succeeded.

SYS@cdb1> grant c##monitor_role to c##dba_common container=all;

Grant succeeded.

- 확인: 공통 롤 부여는 여러 컨테이너에 COMMON=YES 로 나타난다.
SYS@cdb1> select grantee, granted_role, common, con_id
  2  from   cdb_role_privs
  3  where  grantee='C##DBA_COMMON' and granted_role='C##MONITOR_ROLE'
  4  order  by con_id;

GRANTEE        GRANTED_ROLE      COM     CON_ID
-------------- ----------------- --- ----------
C##DBA_COMMON  C##MONITOR_ROLE   YES          1
C##DBA_COMMON  C##MONITOR_ROLE   YES          3

======================================================================
[4단계] 로컬 롤 생성 및 (오류) 로컬 롤을 CONTAINER=ALL로 부여 시도
======================================================================

SYS@cdb1> alter session set container = salespdb;
Session altered.

- 로컬 롤은 접두사 없이 PDB 안에서 생성
SYS@salespdb> create role sales_report_role;
Role created.

SYS@salespdb> grant select on hr.employees to sales_report_role;
Grant succeeded.

- salespdb 로컬 사용자 생성
SYS@salespdb> create user scott identified by Tiger#1;
User created.
SYS@salespdb> grant create session to scott;
Grant succeeded.

- (실수) PDB 안에서 CONTAINER=ALL 로 로컬 롤 부여 시도
SYS@salespdb> grant sales_report_role to scott container=all;
grant sales_report_role to scott container=all
*
ERROR at line 1:
ORA-65050: Common DDL operations only allowed in CDB$ROOT

- 원인: CONTAINER=ALL(공통 작업)은 루트에서만 가능. PDB 안에서는 로컬 부여만 된다.

======================================================================
[5단계] (수정) 로컬 롤을 로컬 부여, 공통 롤을 로컬 사용자에 로컬 부여
======================================================================

- 로컬 롤은 로컬(기본 CURRENT)로 부여한다.
SYS@salespdb> grant sales_report_role to scott;
Grant succeeded.

- 공통 롤 c##monitor_role 은 존재하므로 로컬 사용자 scott 에게 로컬로 부여 가능하다.
SYS@salespdb> grant c##monitor_role to scott;
Grant succeeded.

- 확인: scott 이 받은 롤들 (로컬 사용자라 COMMON=NO 로 부여됨)
SYS@salespdb> select grantee, granted_role, common
  2  from   dba_role_privs where grantee='SCOTT' order by granted_role;

GRANTEE   GRANTED_ROLE        COM
--------- ------------------- ---
SCOTT     C##MONITOR_ROLE     NO
SCOTT     SALES_REPORT_ROLE   NO

- scott 접속해 롤을 통한 조회 확인
SYS@salespdb> connect scott/Tiger#1@salespdb
Connected.
SCOTT@salespdb> select role from session_roles order by role;

ROLE
--------------------
C##MONITOR_ROLE
SALES_REPORT_ROLE
SELECT_CATALOG_ROLE

- [정리] 공통 롤=C## 접두사+루트(ORA-65096/65050 주의), 로컬 롤=접두사 없이 PDB.
-   공통 롤 자체는 전역에 있지만 로컬 사용자는 자기 PDB에서 로컬로만 받는다.
SCOTT@salespdb> exit
Disconnected from Oracle Database 19c Enterprise Edition Release 19.0.0.0.0 - Production
Version 19.3.0.0.0
