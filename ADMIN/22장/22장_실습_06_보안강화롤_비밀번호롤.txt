-- 22장 실습_06: 보안 강화된 롤(비밀번호 필요 롤) 구성 실습 (IDENTIFIED BY, SET ROLE, DEFAULT ROLE)

SYS@cdb1> alter session set container = salespdb;

Session altered.

======================================================================
[1단계] 비밀번호로 보호되는 롤 생성
======================================================================

SYS@salespdb> create role hr_admin_role identified by Adm1n#2024;

Role created.

- 위험한 권한(DELETE)을 이 보안 롤에 담는다.
SYS@salespdb> grant delete on hr.employees to hr_admin_role;
Grant succeeded.

- 인증 유형 확인 -> PASSWORD
SYS@salespdb> select role, authentication_type from dba_roles where role='HR_ADMIN_ROLE';

ROLE            AUTHENTICA
--------------- ----------
HR_ADMIN_ROLE   PASSWORD

======================================================================
[2단계] 사용자에게 부여 후 기본 롤에서 제외
======================================================================

SYS@salespdb> create user scott identified by Tiger#1;
User created.
SYS@salespdb> grant create session to scott;
SYS@salespdb> grant select, delete on hr.employees to scott;  -- 비교용 직접 권한은 주지 않음
Grant succeeded.
SYS@salespdb> revoke delete on hr.employees from scott;  -- 직접 DELETE 는 회수(롤로만 통제)
Revoke succeeded.
SYS@salespdb> grant hr_admin_role to scott;
Grant succeeded.

- 이 보안 롤을 로그인 시 자동 활성화되지 않도록 기본에서 제외
SYS@salespdb> alter user scott default role all except hr_admin_role;

User altered.

======================================================================
[3단계] (오류) 로그인 직후 롤이 꺼진 상태에서 DELETE 시도
======================================================================

SYS@salespdb> connect scott/Tiger#1@salespdb
Connected.

- 로그인 직후 활성 롤 확인 -> hr_admin_role 은 보이지 않는다.
SCOTT@salespdb> select role from session_roles order by role;

no rows selected

- (실수) 롤이 꺼진 상태에서 DELETE 시도
SCOTT@salespdb> delete from hr.employees where employee_id = -1;
delete from hr.employees where employee_id = -1
                 *
ERROR at line 1:
ORA-01031: insufficient privileges

- 원인: hr_admin_role 이 비밀번호 롤이라 자동 활성화되지 않았고, DELETE 권한이 꺼져 있다.

======================================================================
[4단계] (오류) 비밀번호 없이 SET ROLE 시도
======================================================================

- (실수) 비밀번호를 제시하지 않고 롤 활성화 시도
SCOTT@salespdb> set role hr_admin_role;
ERROR:
ORA-01979: missing or invalid password for role 'HR_ADMIN_ROLE'


- 원인: 비밀번호 필요 롤은 SET ROLE 시 반드시 비밀번호를 제시해야 한다.

======================================================================
[5단계] (수정) 비밀번호와 함께 롤 활성화
======================================================================

SCOTT@salespdb> set role hr_admin_role identified by Adm1n#2024;

Role set.

- 이제 활성 롤에 나타나고 DELETE 가 가능하다.
SCOTT@salespdb> select role from session_roles;

ROLE
--------------------
HR_ADMIN_ROLE

SCOTT@salespdb> delete from hr.employees where employee_id = -1;

0 rows deleted.

- 작업이 끝나면 롤을 꺼서 최소 권한 상태로 되돌린다.
SCOTT@salespdb> set role all except hr_admin_role;

Role set.

SCOTT@salespdb> select role from session_roles;

no rows selected

- [정리] 비밀번호 롤(IDENTIFIED BY) + DEFAULT ROLE 제외로 위험 권한을 평소엔 꺼 둔다.
-   롤 꺼짐 상태의 작업은 ORA-01031, 비밀번호 없는 SET ROLE 은 ORA-01979.
SCOTT@salespdb> exit
