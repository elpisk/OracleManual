-- 22장 실습_07: 롤과 시스템/객체 권한 회수 실습 (REVOKE, 연쇄 회수 확인)

SYS@cdb1> alter session set container = salespdb;

Session altered.

======================================================================
[1단계] 실습 준비: 사용자/롤/권한 구성
======================================================================

SYS@salespdb> create user scott identified by Tiger#1;
User created.
SYS@salespdb> create role hr_clerk_role;
Role created.
SYS@salespdb> grant create session, create table to hr_clerk_role;
Grant succeeded.
SYS@salespdb> grant select on hr.employees to hr_clerk_role;
Grant succeeded.
SYS@salespdb> grant hr_clerk_role to scott;
Grant succeeded.

- scott 에게 직접 CREATE VIEW 도 부여(간접/직접 비교용)
SYS@salespdb> grant create view to scott;
Grant succeeded.

======================================================================
[2단계] (오류) 롤로 얻은 권한을 사용자에게서 직접 회수 시도
======================================================================

- scott 은 CREATE TABLE 을 hr_clerk_role 을 통해 간접적으로 갖고 있다.
- (실수) 사용자에게서 직접 회수 시도
SYS@salespdb> revoke create table from scott;
revoke create table from scott
*
ERROR at line 1:
ORA-01952: system privileges not granted to 'SCOTT'

- 원인: CREATE TABLE 은 scott 에게 '직접' 부여된 적이 없고 롤을 통해 간접 보유한다.
-   간접 권한은 사용자에게서 직접 회수할 수 없다. 롤에서 빼거나 롤을 회수해야 한다.

======================================================================
[3단계] (수정) 롤에서 권한 회수 (모든 보유자에 즉시 반영)
======================================================================

- 롤에서 CREATE TABLE 을 회수하면 scott 을 포함한 모든 보유자에게 반영된다.
SYS@salespdb> revoke create table from hr_clerk_role;

Revoke succeeded.

SYS@salespdb> select privilege from role_sys_privs where role='HR_CLERK_ROLE';

PRIVILEGE
--------------------
CREATE SESSION

- 직접 부여된 CREATE VIEW 는 롤과 무관하므로 그대로 남아 있다.
SYS@salespdb> select privilege from dba_sys_privs where grantee='SCOTT';

PRIVILEGE
--------------------
CREATE VIEW

======================================================================
[4단계] 객체 권한 연쇄 회수 확인
======================================================================

- 재부여 경로 구성: HR -> hr_report(WITH GRANT OPTION) -> hr_analyst
SYS@salespdb> create user hr_report identified by Rep#2024;
User created.
SYS@salespdb> create user hr_analyst identified by Ana#2024;
User created.
SYS@salespdb> grant create session to hr_report, hr_analyst;
Grant succeeded.

SYS@salespdb> connect hr/hr@salespdb
Connected.
HR@salespdb> grant select on employees to hr_report with grant option;
Grant succeeded.

HR@salespdb> connect hr_report/Rep#2024@salespdb
Connected.
HR_REPORT@salespdb> grant select on hr.employees to hr_analyst;
Grant succeeded.

- 현재 EMPLOYEES 의 SELECT 부여 상태 확인
HR_REPORT@salespdb> connect hr/hr@salespdb
Connected.
HR@salespdb> select grantee, privilege, grantable from user_tab_privs
  2  where table_name='EMPLOYEES' and privilege='SELECT' order by grantee;

GRANTEE      PRIVILEGE   GRA
------------ ----------- ---
HR_ANALYST   SELECT      NO
HR_REPORT    SELECT      YES

- HR 이 hr_report 의 SELECT 를 회수 -> hr_analyst 것도 연쇄 회수된다.
HR@salespdb> revoke select on employees from hr_report;

Revoke succeeded.

HR@salespdb> select grantee, privilege from user_tab_privs
  2  where table_name='EMPLOYEES' and privilege='SELECT';

no rows selected

- 확인: hr_analyst 로 접속해 조회하면 이제 실패한다(연쇄 회수됨).
HR@salespdb> connect hr_analyst/Ana#2024@salespdb
Connected.
HR_ANALYST@salespdb> select count(*) from hr.employees;
select count(*) from hr.employees
                          *
ERROR at line 1:
ORA-00942: table or view does not exist

======================================================================
[5단계] 롤 회수와 멀티테넌트 공통 회수
======================================================================

HR_ANALYST@salespdb> connect sys@salespdb as sysdba
Enter password:
Connected.

- 롤 자체를 사용자에게서 회수
SYS@salespdb> revoke hr_clerk_role from scott;
Revoke succeeded.

SYS@salespdb> select granted_role from dba_role_privs where grantee='SCOTT';

no rows selected

- 멀티테넌트: 공통 부여는 루트에서 CONTAINER=ALL 로만 회수해야 한다.
SYS@salespdb> alter session set container = cdb$root;
Session altered.
SYS@cdb1> revoke create session from c##dba_common container=all;
Revoke succeeded.

- [정리] 간접(롤) 권한 직접 회수는 ORA-01952 -> 롤에서 회수.
-   객체 권한 회수는 연쇄되어 하위 사용자 접근이 ORA-00942 로 끊긴다.
-   공통 부여 회수는 루트에서 CONTAINER=ALL 로 수행한다.
