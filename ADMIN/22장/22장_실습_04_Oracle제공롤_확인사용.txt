-- 22장 실습_04: Oracle 제공 롤 확인 및 사용 실습 (CONNECT/RESOURCE/DBA/SELECT_CATALOG_ROLE)

SYS@cdb1> alter session set container = salespdb;

Session altered.

======================================================================
[1단계] 제공 롤에 담긴 실제 권한 확인
======================================================================

- CONNECT 롤은 보안 강화로 사실상 CREATE SESSION 하나만 담고 있다.
SYS@salespdb> select privilege from role_sys_privs where role='CONNECT' order by privilege;

PRIVILEGE
--------------------
CREATE SESSION

- RESOURCE 롤은 객체 생성 권한을 담지만 CREATE SESSION 이 없다.
SYS@salespdb> select privilege from role_sys_privs where role='RESOURCE' order by privilege;

PRIVILEGE
--------------------
CREATE CLUSTER
CREATE INDEXTYPE
CREATE OPERATOR
CREATE PROCEDURE
CREATE SEQUENCE
CREATE TABLE
CREATE TRIGGER
CREATE TYPE

8 rows selected.

======================================================================
[2단계] (오류) RESOURCE 만 부여하고 로그인 시도
======================================================================

SYS@salespdb> create user appown identified by App#2024;
User created.

- (실수) RESOURCE 만 부여
SYS@salespdb> grant resource to appown;
Grant succeeded.

- appown 으로 접속 시도 -> CREATE SESSION 이 없어 실패
SYS@salespdb> connect appown/App#2024@salespdb
ERROR:
ORA-01045: user APPOWN lacks CREATE SESSION privilege; logon denied


Warning: You are no longer connected to ORACLE.

- 원인: RESOURCE 롤에는 CREATE SESSION 이 없다. 접속하려면 CONNECT(또는 CREATE SESSION)가 필요.

======================================================================
[3단계] (수정) CONNECT 함께 부여
======================================================================

SYS@salespdb> connect sys@salespdb as sysdba
Enter password:
Connected.
SYS@salespdb> grant connect to appown;
Grant succeeded.

- 이제 접속되고, RESOURCE 로 테이블도 만들 수 있다.
SYS@salespdb> connect appown/App#2024@salespdb
Connected.
APPOWN@salespdb> create table t_demo (id number);

Table created.

======================================================================
[4단계] SELECT_CATALOG_ROLE 로 딕셔너리 조회 권한 부여
======================================================================

APPOWN@salespdb> connect sys@salespdb as sysdba
Enter password:
Connected.

- 모니터링 담당 계정 생성
SYS@salespdb> create user mon identified by Mon#2024;
User created.
SYS@salespdb> grant create session to mon;
Grant succeeded.

- (오류) 권한 없이 DBA_ 뷰 조회 시도
SYS@salespdb> connect mon/Mon#2024@salespdb
Connected.
MON@salespdb> select count(*) from dba_tables;
select count(*) from dba_tables
                     *
ERROR at line 1:
ORA-00942: table or view does not exist

- 원인: DBA_TABLES 조회 권한이 없다. 권한이 없어 객체 자체가 보이지 않아 ORA-00942 가 난다.
- 수정: SELECT_CATALOG_ROLE 을 부여한다.
MON@salespdb> connect sys@salespdb as sysdba
Enter password:
Connected.
SYS@salespdb> grant select_catalog_role to mon;
Grant succeeded.

- 이제 딕셔너리 뷰 조회가 가능하다.
SYS@salespdb> connect mon/Mon#2024@salespdb
Connected.
MON@salespdb> select count(*) from dba_tables;

  COUNT(*)
----------
      2314

======================================================================
[5단계] 롤 목록과 인증 유형 확인
======================================================================

MON@salespdb> connect sys@salespdb as sysdba
Enter password:
Connected.
SYS@salespdb> select role, oracle_maintained, authentication_type
  2  from   dba_roles
  3  where  role in ('CONNECT','RESOURCE','DBA','SELECT_CATALOG_ROLE')
  4  order  by role;

ROLE                   ORA AUTHENTICA
---------------------- --- ----------
CONNECT                Y   NONE
DBA                    Y   NONE
RESOURCE               Y   NONE
SELECT_CATALOG_ROLE    Y   NONE

- [정리] RESOURCE 는 CREATE SESSION 없음(ORA-01045), 딕셔너리 미권한은 ORA-00942.
-   제공 롤은 부여 전 ROLE_SYS_PRIVS 로 내용을 반드시 확인하고 최소한으로 사용한다.
