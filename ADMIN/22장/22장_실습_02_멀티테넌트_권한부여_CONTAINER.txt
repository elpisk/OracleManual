-- 22장 실습_02: 멀티테넌트 환경에서 권한 부여 (CONTAINER=ALL/CURRENT, 공통/로컬 권한)

- 루트 컨테이너 확인
SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

======================================================================
[1단계] 공통 사용자 생성 후 (오류) 로컬 대상에 공통 부여 시도
======================================================================

- CDB 루트에 공통 사용자 생성 (C## 접두사 필수)
SYS@cdb1> create user c##dba_common identified by Comm#2024 container=all;

User created.

- salespdb 에 로컬 사용자도 하나 만든다.
SYS@cdb1> alter session set container = salespdb;
Session altered.
SYS@salespdb> create user hr_dev identified by Dev#2024;
User created.
SYS@salespdb> alter session set container = cdb$root;
Session altered.

- (실수) 루트에서 로컬 사용자 hr_dev 에게 CONTAINER=ALL 로 부여 시도
SYS@cdb1> grant create session to hr_dev container=all;
grant create session to hr_dev container=all
                        *
ERROR at line 1:
ORA-65030: one may not grant a Common Privilege to a Local Role or User

- 원인: 공통 부여(CONTAINER=ALL)의 대상은 공통 사용자/공통 롤이어야 한다.
-   hr_dev 는 salespdb 에만 존재하는 로컬 사용자라 공통 부여 대상이 될 수 없다.

======================================================================
[2단계] (수정) 공통 사용자에게 공통 권한 부여
======================================================================

- 공통 사용자 c##dba_common 에게 CONTAINER=ALL 로 부여 -> 성공
SYS@cdb1> grant create session to c##dba_common container=all;

Grant succeeded.

- 확인: 공통 부여는 COMMON=YES, 여러 컨테이너에 나타난다.
SYS@cdb1> select grantee, privilege, common, con_id
  2  from   cdb_sys_privs
  3  where  grantee='C##DBA_COMMON' order by con_id;

GRANTEE        PRIVILEGE        COM     CON_ID
-------------- ---------------- --- ----------
C##DBA_COMMON  CREATE SESSION   YES          1
C##DBA_COMMON  CREATE SESSION   YES          3

======================================================================
[3단계] (오류) PDB 내부에서 CONTAINER=ALL 사용 시도
======================================================================

SYS@cdb1> alter session set container = salespdb;
Session altered.

- (실수) PDB 안에서 CONTAINER=ALL 로 부여 시도
SYS@salespdb> grant create table to c##dba_common container=all;
grant create table to c##dba_common container=all
*
ERROR at line 1:
ORA-65050: Common DDL operations only allowed in CDB$ROOT

- 원인: CONTAINER=ALL(공통 부여)은 CDB$ROOT 에서만 가능하다. PDB 내부에서는 불가.

======================================================================
[4단계] (수정) 로컬 권한 부여 (CONTAINER=CURRENT 기본)
======================================================================

- PDB 안에서는 로컬 부여만 가능. 절을 생략하면 CURRENT(로컬)로 동작.
SYS@salespdb> grant create table to hr_dev;

Grant succeeded.

- 확인: 로컬 부여는 COMMON=NO
SYS@salespdb> select grantee, privilege, common
  2  from   dba_sys_privs where grantee='HR_DEV';

GRANTEE   PRIVILEGE        COM
--------- ---------------- ---
HR_DEV    CREATE TABLE     NO

======================================================================
[5단계] 절 생략의 함정: 루트에서 부여했는데 PDB에 안 나타남
======================================================================

SYS@salespdb> alter session set container = cdb$root;
Session altered.

- (주의) 루트에서 CONTAINER 절 없이 공통 사용자에게 부여 -> 루트에만 적용된다.
SYS@cdb1> grant create table to c##dba_common;
Grant succeeded.

- salespdb(con_id=3)에는 이 CREATE TABLE 부여가 없음을 확인
SYS@cdb1> select con_id, privilege from cdb_sys_privs
  2  where grantee='C##DBA_COMMON' and privilege='CREATE TABLE' order by con_id;

    CON_ID PRIVILEGE
---------- --------------------
         1 CREATE TABLE

- 원인/교훈: 루트에서도 절을 생략하면 CURRENT(루트에만) 이다.
-   모든 PDB에 걸치려면 반드시 CONTAINER=ALL 을 명시해야 한다.
SYS@cdb1> grant create table to c##dba_common container=all;
Grant succeeded.

- 이제 salespdb 에도 나타난다.
SYS@cdb1> select con_id, privilege from cdb_sys_privs
  2  where grantee='C##DBA_COMMON' and privilege='CREATE TABLE' order by con_id;

    CON_ID PRIVILEGE
---------- --------------------
         1 CREATE TABLE
         3 CREATE TABLE

- [정리] 공통 부여는 (루트 접속 + 공통 대상 + CONTAINER=ALL)의 세 조건이 모두 필요하다.
-   ORA-65030(대상), ORA-65050(위치), 절 생략(범위)의 세 함정을 구분하라.
SYS@cdb1> exit

Version 19.3.0.0.0
