-- 9장 실습_01: Oracle Net Services 구성요소 및 기본 리스너(LISTENER) 확인

- 먼저 Oracle Net 구성 파일이 놓이는 표준 디렉터리를 확인 (network/admin)
[oracle@dbsvr ~]$ echo $ORACLE_HOME
/u01/app/oracle/product/19.0.0/dbhome_1

[oracle@dbsvr ~]$ ls -1 $ORACLE_HOME/network/admin
listener.ora
samples
sqlnet.ora
tnsnames.ora

======================================================================
[1단계] 세 개의 .ora 구성 파일 내용 확인 (구성요소와 파일의 대응)
======================================================================

- listener.ora: 리스너 이름/대기 프로토콜 주소를 정의 (서버 측 구성)
[oracle@dbsvr ~]$ cat $ORACLE_HOME/network/admin/listener.ora
LISTENER =
  (DESCRIPTION_LIST =
    (DESCRIPTION =
      (ADDRESS = (PROTOCOL = TCP)(HOST = dbsvr.example.com)(PORT = 1521))
      (ADDRESS = (PROTOCOL = IPC)(KEY = EXTPROC1521))
    )
  )

- tnsnames.ora: 넷 서비스 이름(연결 식별자)을 연결 기술자로 매핑
[oracle@dbsvr ~]$ cat $ORACLE_HOME/network/admin/tnsnames.ora
SALESPDB =
  (DESCRIPTION =
    (ADDRESS = (PROTOCOL = TCP)(HOST = dbsvr.example.com)(PORT = 1521))
    (CONNECT_DATA =
      (SERVER = DEDICATED)
      (SERVICE_NAME = salespdb.example.com)
    )
  )

- sqlnet.ora: 프로파일(네이밍 우선순위/도메인 등)을 정의
[oracle@dbsvr ~]$ cat $ORACLE_HOME/network/admin/sqlnet.ora
NAMES.DIRECTORY_PATH = (EZCONNECT, TNSNAMES)
NAMES.DEFAULT_DOMAIN = example.com

======================================================================
[2단계] 기본 리스너 LISTENER의 상태/대기 주소/등록 서비스 확인
======================================================================

- (실수) 유틸리티 이름을 잘못 입력 (lsnrctrl)
[oracle@dbsvr ~]$ lsnrctrl status
bash: lsnrctrl: command not found

- 확인 포인트: Alias=LISTENER(기본 리스너), 대기 포트=1521(기본 TCP 포트),
-   Services Summary에 서비스들이 동적 서비스 등록으로 채워져 있음(status READY)

- 각 서비스의 핸들러(전용/디스패처) 상세는 services 로 확인

- 핸들러가 DEDICATED 이므로 현재 salespdb는 전용 서버 방식으로 서비스되고 있음

======================================================================
[3단계] 동적 서비스 등록 확인 — 서비스가 아직 안 보이면 즉시 등록 유도
======================================================================

- SQL*Plus로 CDB에 SYSDBA로 접속 (로컬 OS 인증, 리스너를 거치지 않는 IPC 경로)
[oracle@dbsvr ~]$ sqlplus / as sysdba

SQL*Plus: Release 19.0.0.0.0 - Production on Mon Jul 27 10:24:03 2026
Version 19.3.0.0.0

Connected to:
Oracle Database 19c Enterprise Edition Release 19.0.0.0.0 - Production

- 프롬프트를 사용자@인스턴스 형태로 지정 (실습 환경 glogin.sql 설정)
SQL> set sqlprompt "_user'@'_connect_identifier> "
SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

- 인스턴스가 리스너에 등록하는 서비스 이름 확인
SYS@cdb1> show parameter service_names

NAME             TYPE        VALUE
---------------- ----------- ------------------------------
service_names    string      cdb1.example.com

- LREG가 리스너에 즉시 등록하도록 강제 (동적 등록은 기본 약 60초 주기라 지연될 수 있음)
SYS@cdb1> alter system register;

System altered.

- 리스너 위치 파라미터도 확인 (동적 등록 대상 리스너 주소)
SYS@cdb1> show parameter local_listener

NAME             TYPE        VALUE
---------------- ----------- ------------------------------
local_listener   string      LISTENER_CDB1

- [정리] 구성요소 -> 파일 대응 확인 완료:
-   리스너(listener.ora) / 넷 서비스 이름(tnsnames.ora) / 프로파일(sqlnet.ora)
-   기본 리스너 LISTENER는 TCP 포트 1521에서 대기하며, 동적 서비스 등록으로
-   사용 가능한 데이터베이스 서비스가 자동으로 채워짐(status READY)
SYS@cdb1> exit
Disconnected from Oracle Database 19c Enterprise Edition Release 19.0.0.0.0 - Production
Version 19.3.0.0.0
[oracle@dbsvr ~]$
