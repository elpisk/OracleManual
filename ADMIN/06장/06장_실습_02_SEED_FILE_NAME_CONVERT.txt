-- 6장 실습_02: SEED FILE_NAME_CONVERT 절로 시드 PDB 파일 위치 지정 실습
-- 목표: CDB 시드(PDB$SEED) 데이터 파일을 별도 seed 디렉터리에 배치한다.
--       대상 디렉터리 누락 시의 오류를 겪고, mkdir로 해결한 뒤 시드 파일 위치를 검증한다.
-- 전제: 인스턴스 CDB2용 초기화 파라미터(initCDB2.ora)가 준비되어 있고, DB_NAME=CDB2.

======================================================================
[0단계] 사전 준비: 루트 디렉터리만 만들고 seed 디렉터리는 '일부러' 빠뜨린다
======================================================================

- 루트 데이터 파일용 디렉터리는 생성한다.
[oracle@dbsvr ~]$ mkdir -p /u01/app/oradata/CDB2

- (의도적으로) 시드 디렉터리(.../CDB2/seed)는 아직 만들지 않는다 → 오류 재현용
[oracle@dbsvr ~]$ ls -d /u01/app/oradata/CDB2/seed
ls: cannot access '/u01/app/oradata/CDB2/seed': No such file or directory

[oracle@dbsvr ~]$ export ORACLE_SID=CDB2

======================================================================
[1단계] 인스턴스 NOMOUNT 기동
======================================================================

[oracle@dbsvr ~]$ sqlplus / as sysdba

SQL*Plus: Release 19.0.0.0.0 - Production on Fri Jul 24 10:41:07 2026
Version 19.3.0.0.0

Connected to an idle instance.

SQL> set sqlprompt "_user'@'_connect_identifier> "
SYS@CDB2> startup nomount
ORACLE instance started.

Total System Global Area 1610612736 bytes
Fixed Size                  9137664 bytes
Variable Size             520093696 bytes
Database Buffers          1073741824 bytes
Redo Buffers                7639552 bytes

======================================================================
[2단계] SEED FILE_NAME_CONVERT로 CREATE DATABASE 실행 (오류 재현)
======================================================================

- 시드 파일을 .../CDB2/seed 로 보내도록 SEED FILE_NAME_CONVERT를 지정
-   그러나 대상 디렉터리(seed)가 없으므로 시드 파일 생성에서 실패할 것이다.
SYS@CDB2> create database cdb2 enable pluggable database
  2    seed file_name_convert=('/u01/app/oradata/CDB2','/u01/app/oradata/CDB2/seed');
create database cdb2 enable pluggable database
*
ERROR at line 1:
ORA-01119: error in creating database file
'/u01/app/oradata/CDB2/seed/system01.dbf'
ORA-27040: file create error, unable to create file
Linux-x86_64 Error: 2: No such file or directory

- 원인: SEED FILE_NAME_CONVERT의 '대상' 디렉터리 /u01/app/oradata/CDB2/seed 가
--   존재하지 않는다. 이 절은 루트 경로(.../CDB2)를 시드 경로(.../CDB2/seed)로
--   '치환'만 할 뿐, 디렉터리를 만들어 주지는 않는다.

======================================================================
[3단계] 해결: seed 디렉터리를 만들고 재시도
======================================================================

- SQL*Plus를 벗어나지 않고 호스트 명령으로 디렉터리 생성 (! 또는 HOST)
SYS@CDB2> !mkdir -p /u01/app/oradata/CDB2/seed

- 실패한 인스턴스를 정리하고 다시 NOMOUNT (실패 후에는 재기동이 안전)
SYS@CDB2> shutdown abort
ORACLE instance shut down.
SYS@CDB2> startup nomount
ORACLE instance started.

Total System Global Area 1610612736 bytes
Fixed Size                  9137664 bytes
Variable Size             520093696 bytes
Database Buffers          1073741824 bytes
Redo Buffers                7639552 bytes

- 이번에는 대상 디렉터리가 존재하므로 정상 생성된다.
SYS@CDB2> create database cdb2 enable pluggable database
  2    seed file_name_convert=('/u01/app/oradata/CDB2','/u01/app/oradata/CDB2/seed');

Database created.

======================================================================
[4단계] 시드 파일이 seed 디렉터리에 만들어졌는지 검증
======================================================================

- 컨테이너 구성 확인: CON_ID=2 가 PDB$SEED
SYS@CDB2> select con_id, name, open_mode from v$containers order by con_id;

    CON_ID NAME                           OPEN_MODE
---------- ------------------------------ ----------
         1 CDB$ROOT                       READ WRITE
         2 PDB$SEED                       READ ONLY

- 시드(CON_ID=2) 데이터 파일 경로가 .../CDB2/seed 아래인지 확인 (핵심 검증)
SYS@CDB2> select f.name
  2  from v$datafile f
  3  where f.con_id = 2
  4  order by f.file#;

NAME
------------------------------------------------------------
/u01/app/oradata/CDB2/seed/system01.dbf
/u01/app/oradata/CDB2/seed/sysaux01.dbf

- 비교: 루트(CON_ID=1) 데이터 파일은 .../CDB2 아래(치환 소스 경로)에 있다.
SYS@CDB2> select f.name
  2  from v$datafile f
  3  where f.con_id = 1
  4  order by f.file#;

NAME
------------------------------------------------------------
/u01/app/oradata/CDB2/system01.dbf
/u01/app/oradata/CDB2/sysaux01.dbf
/u01/app/oradata/CDB2/undotbs01.dbf

- OS에서도 시드 파일이 실제로 생성되었는지 확인
SYS@CDB2> !ls -1 /u01/app/oradata/CDB2/seed
sysaux01.dbf
system01.dbf

- [정리]
--   1) SEED FILE_NAME_CONVERT=('소스','대상')은 루트 경로를 시드 경로로 치환한다.
--   2) '대상' 디렉터리는 사전에 반드시 존재해야 한다(없으면 ORA-01119/ORA-27040).
--   3) 검증은 v$datafile을 CON_ID=2(시드)로 필터링해 경로가 seed 하위인지 본다.
