-- 6장 실습_01: CREATE DATABASE 문(ENABLE PLUGGABLE DATABASE)으로 CDB 생성 실습
-- 목표: SQL*Plus에서 인스턴스를 NOMOUNT로 띄우고 CREATE DATABASE로 새 CDB(cdb1)를 만든다.
--       DBCA 없이 수동으로 만드는 전 과정을 확인하고, 흔한 오류를 직접 겪고 고친다.

======================================================================
[0단계] 사전 준비: 디렉터리 생성과 ORACLE_SID 설정
======================================================================

- 데이터 파일/컨트롤 파일/시드 파일이 들어갈 디렉터리를 먼저 만든다.
-   CREATE DATABASE는 '파일'은 만들지만 '디렉터리'는 만들지 않는다.
[oracle@dbsvr ~]$ mkdir -p /u01/app/oradata/CDB1/seed
[oracle@dbsvr ~]$ mkdir -p /u02/app/oradata/CDB1

- 이 인스턴스를 식별할 ORACLE_SID를 설정한다.
[oracle@dbsvr ~]$ export ORACLE_SID=CDB1

- 초기화 파라미터 파일(initCDB1.ora)을 확인한다(사전에 작성해 둠).
[oracle@dbsvr ~]$ cat $ORACLE_HOME/dbs/initCDB1.ora
DB_NAME=CDB1
CONTROL_FILES=('/u01/app/oradata/CDB1/control01.ctl','/u02/app/oradata/CDB1/control02.ctl')
DB_BLOCK_SIZE=8192
ENABLE_PLUGGABLE_DATABASE=TRUE
MAX_PDBS=10
SGA_TARGET=1536M
PGA_AGGREGATE_TARGET=512M
UNDO_TABLESPACE=undotbs

======================================================================
[1단계] SQL*Plus 접속 후 인스턴스를 NOMOUNT로 기동
======================================================================

[oracle@dbsvr ~]$ sqlplus / as sysdba

SQL*Plus: Release 19.0.0.0.0 - Production on Fri Jul 24 10:02:41 2026
Version 19.3.0.0.0

Copyright (c) 1982, 2019, Oracle.  All rights reserved.

Connected to an idle instance.

- 프롬프트를 보기 좋게 지정(실습 환경 glogin.sql 설정)
SQL> set sqlprompt "_user'@'_connect_identifier> "

- (실수) 새 데이터베이스를 만들 것인데 습관적으로 STARTUP(=OPEN)을 시도
SYS@CDB1> startup
ORA-01078: failure in processing system parameters
LRM-00109: could not open parameter file '/u01/app/oracle/product/19c/dbs/initCDB1.ora'

- 원인 분석: STARTUP은 파라미터 파일을 찾아 OPEN까지 시도한다. 아직 데이터베이스가
--   없으므로 OPEN은 불가능하다. 새 DB 생성은 반드시 NOMOUNT에서 시작해야 한다.
--   (파일은 dbs 아래 존재하지만, 새 DB 생성 흐름에 맞게 NOMOUNT로 다시 시도)
SYS@CDB1> startup nomount
ORACLE instance started.

Total System Global Area 1610612736 bytes
Fixed Size                  9137664 bytes
Variable Size             520093696 bytes
Database Buffers          1073741824 bytes
Redo Buffers                7639552 bytes

- NOMOUNT 단계 확인: SGA+백그라운드 프로세스만 기동된 상태(STATUS=STARTED)
SYS@CDB1> select status from v$instance;

STATUS
------------
STARTED

- 이 인스턴스가 CDB 생성 모드로 준비되었는지 파라미터로 확인
SYS@CDB1> show parameter enable_pluggable_database

NAME                                 TYPE        VALUE
------------------------------------ ----------- --------
enable_pluggable_database            boolean     TRUE

======================================================================
[2단계] CREATE DATABASE 실행 (ENABLE PLUGGABLE DATABASE)
======================================================================

SYS@CDB1> create database cdb1

  6    extent management local
  7    datafile '/u01/app/oradata/CDB1/system01.dbf' size 325m

 10       tempfile '/u01/app/oradata/CDB1/temp01.dbf' size 20m
 11    undo tablespace undotbs

create database cdb1
*
ERROR at line 1:
ORA-01119: error in creating database file '/u03/app/oradata/CDB1/redo1a.log'
ORA-27040: file create error, unable to create file
Linux-x86_64 Error: 2: No such file or directory

- 원인: 리두 로그 파일 경로 /u03/app/oradata/CDB1 디렉터리가 존재하지 않는다.
--   CREATE DATABASE는 디렉터리를 만들지 않으므로 대상 경로가 미리 있어야 한다.
--   (해결) 존재하는 경로로 바로잡아 재실행. 여기서는 /u01 경로로 통일한다.

SYS@CDB1> create database cdb1
  2    user sys identified by p1 user system identified by p2
  3    logfile group 1 ('/u01/app/oradata/CDB1/redo1a.log') size 100m,
  4            group 2 ('/u01/app/oradata/CDB1/redo2a.log') size 100m
  5    character set al32utf8 national character set al16utf16
  6    extent management local
  7    datafile '/u01/app/oradata/CDB1/system01.dbf' size 325m
  8    sysaux datafile '/u01/app/oradata/CDB1/sysaux01.dbf' size 325m
  9    default temporary tablespace temp
 10       tempfile '/u01/app/oradata/CDB1/temp01.dbf' size 20m
 11    undo tablespace undotbs
 12       datafile '/u01/app/oradata/CDB1/undotbs01.dbf' size 200m
 13    enable pluggable database
 14    seed file_name_convert=('/u01/app/oradata/CDB1','/u01/app/oradata/CDB1/seed');

Database created.

======================================================================
[3단계] 생성 결과 확인: CDB 여부와 컨테이너 구성
======================================================================

- 데이터베이스가 CDB로 열렸는지 확인 (CDB=YES 이어야 함)
SYS@CDB1> select name, open_mode, cdb from v$database;

NAME      OPEN_MODE            CDB
--------- -------------------- ---
CDB1      READ WRITE           YES

- 인스턴스 상태가 OPEN 인지 확인 (CREATE DATABASE가 자동으로 OPEN까지 진행)
SYS@CDB1> select status from v$instance;

STATUS
------------
OPEN

- 컨테이너 구성 확인: CDB$ROOT(1)와 PDB$SEED(2)가 만들어졌는지 본다.
SYS@CDB1> select con_id, name, open_mode from v$containers order by con_id;

    CON_ID NAME                           OPEN_MODE
---------- ------------------------------ ----------
         1 CDB$ROOT                       READ WRITE
         2 PDB$SEED                       READ ONLY

- 시드(PDB$SEED)만 존재하고 아직 사용자 PDB는 없음을 확인
SYS@CDB1> select con_id, name from v$pdbs order by con_id;

    CON_ID NAME
---------- ------------------------------
         2 PDB$SEED

- 루트의 데이터 파일이 SYSTEM/SYSAUX/UNDO에 대해 만들어졌는지 확인
SYS@CDB1> select file#, name from v$datafile where con_id=1 order by file#;

     FILE# NAME
---------- ------------------------------------------------------------
         1 /u01/app/oradata/CDB1/system01.dbf
         3 /u01/app/oradata/CDB1/sysaux01.dbf
         4 /u01/app/oradata/CDB1/undotbs01.dbf

- [정리]
--   1) 새 DB 생성은 NOMOUNT에서 출발(STARTUP=OPEN 시도는 실패).
--   2) CREATE DATABASE의 대상 경로 디렉터리는 반드시 사전 생성.
--   3) ENABLE PLUGGABLE DATABASE 절이 CDB$ROOT + PDB$SEED를 함께 생성.
--   4) 다음 실습_03에서 catcdb.sql로 데이터 딕셔너리를 구축한다.
SYS@CDB1> exit
Disconnected from Oracle Database 19c Enterprise Edition Release 19.0.0.0.0 - Production
Version 19.3.0.0.0
[oracle@dbsvr ~]$
