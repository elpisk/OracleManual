================================================================================
 32장 실습 01 — 서버 생성 알림(Server-Generated Alerts) 설정
 목표: 서버 생성 알림 인프라를 확인한다. STATISTICS_LEVEL 전제, MMON의 역할,
       알림 큐(ALERT_QUE), 사전 정의 알림(테이블스페이스 사용률)을 점검한다.
 환경: CDB=cdb1 (루트 컨테이너에서 SYS로 수행)
================================================================================

-- [1] 알림/메트릭 인프라가 동작하려면 STATISTICS_LEVEL이 TYPICAL 또는 ALL 이어야 한다.
$ sqlplus sys@cdb1 as sysdba

SYS@cdb1> SHOW PARAMETER statistics_level

NAME                                 TYPE        VALUE
------------------------------------ ----------- --------
statistics_level                     string      TYPICAL

-- TYPICAL(기본)이므로 서버 생성 알림·메트릭이 정상 동작한다.

--------------------------------------------------------------------------------
-- [2] 알림을 감시·생성하는 주체는 MMON 백그라운드 프로세스다. 존재를 확인한다.
--------------------------------------------------------------------------------
SYS@cdb1> SELECT name, description
  2       FROM  v$bgprocess
  3      WHERE  name = 'MMON';

NAME  DESCRIPTION
----- ----------------------------------------
MMON  Manageability Monitor Process

-- MMON이 SGA의 메트릭을 주기적으로 평가하여 임계값 초과 시 알림을 생성한다.

--------------------------------------------------------------------------------
-- [3] 서버 생성 알림이 등록되는 큐(ALERT_QUE)를 확인한다.
--------------------------------------------------------------------------------
SYS@cdb1> SELECT name, queue_type, enqueue_enabled, dequeue_enabled
  2       FROM  dba_queues
  3      WHERE  name = 'ALERT_QUE';

NAME       QUEUE_TYPE     ENQUEUE DEQUEUE
---------- -------------- ------- -------
ALERT_QUE  NORMAL_QUEUE   YES     YES

-- EM 또는 사용자 프로그램이 이 큐를 구독하면 알림을 즉시 통지받을 수 있다.

--------------------------------------------------------------------------------
-- [4] 사전 정의 알림 중 대표는 테이블스페이스 사용률 알림이다.
--     현재 데이터베이스 수준의 기본 임계값을 조회한다.
--------------------------------------------------------------------------------
SYS@cdb1> COLUMN metrics_name FORMAT A30
SYS@cdb1> SELECT metrics_name, warning_value, critical_value, object_type
  2       FROM  dba_thresholds
  3      WHERE  metrics_name LIKE 'Tablespace%'
  4        AND  object_name IS NULL;

METRICS_NAME                   WARNING_VALUE CRITICAL_VALUE OBJECT_TYPE
------------------------------ ------------- -------------- -----------
Tablespace Space Usage          85            97             SYSTEM

-- 기본값은 경고 85%, 위험 97% 이다. (별도 설정 없이 감시된다)

--------------------------------------------------------------------------------
-- [5] (오류 → 원인 → 수정)
--     알림 인프라를 잘못 이해하여 STATISTICS_LEVEL을 BASIC 으로 바꾸려다
--     발생하는 부작용을 확인한다.
--------------------------------------------------------------------------------
SYS@cdb1> ALTER SYSTEM SET statistics_level = BASIC;

System altered.

SYS@cdb1> -- BASIC 으로 바꾸면 AWR·메트릭·서버 생성 알림 인프라가 비활성화된다.
SYS@cdb1> -- 이 상태에서 메트릭 뷰를 조회하면 값이 갱신되지 않는다.
SYS@cdb1> SELECT COUNT(*) FROM v$sysmetric;

  COUNT(*)
----------
         0

SYS@cdb1> -- 원인 파악: BASIC 은 관리성(Manageability) 기능을 끈다. 알림/메트릭이 멈춘다.
SYS@cdb1> -- 수정: 즉시 TYPICAL(기본값)로 되돌린다.
SYS@cdb1> ALTER SYSTEM SET statistics_level = TYPICAL;

System altered.

SYS@cdb1> SELECT COUNT(*) FROM v$sysmetric;

  COUNT(*)
----------
        24

-- TYPICAL 로 복구하니 메트릭 수집이 다시 동작한다.

--------------------------------------------------------------------------------
-- [정리]
--------------------------------------------------------------------------------
-- 1) 서버 생성 알림은 MMON이 메트릭을 평가해 임계값 초과 시 자동 생성한다.
-- 2) 알림은 ALERT_QUE(Advanced Queuing)에 등록되어 EM/구독자에게 전달된다.
-- 3) 반드시 STATISTICS_LEVEL 이 TYPICAL 또는 ALL 이어야 한다(BASIC 은 비활성).
-- 4) 테이블스페이스 사용률은 사전 정의 알림으로 기본 85%/97% 임계값을 가진다.

SYS@cdb1> EXIT
