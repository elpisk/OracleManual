-- 24장 실습_06: CDB와 PDB에서의 감사 액션 확인 (공통/로컬 정책, CONTAINER, CDB_UNIFIED_AUDIT_TRAIL)
-- 목표: 공통 정책과 로컬 정책의 생성 위치 규칙을 확인하고, 컨테이너별 감사 레코드를 조회한다.

SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

======================================================================
[1단계] (오류 -> 원인 -> 수정) PDB에서 공통 정책 생성 시도
======================================================================

- PDB 로 이동한다.
SYS@cdb1> alter session set container = pdb1;

Session altered.

- (실수) PDB 안에서 CONTAINER=ALL(공통) 정책을 만들려 한다.
SYS@cdb1> create audit policy c_secure_pol
  2    actions create user, drop user
  3    container = all;
create audit policy c_secure_pol
*
ERROR at line 1:
ORA-65040: operation not allowed from within a pluggable database

- 원인: 공통 정책은 루트(CDB$ROOT)에서만 만들 수 있다. PDB 에서는 로컬 정책만 가능.
- 수정: 루트로 돌아가 공통 정책을 만든다.
SYS@cdb1> alter session set container = cdb$root;

Session altered.

SYS@cdb1> create audit policy c_secure_pol
  2    actions create user, alter user, drop user
  3    container = all;

Audit policy created.

SYS@cdb1> audit policy c_secure_pol;

Audit succeeded.

======================================================================
[2단계] PDB에서 로컬 정책 생성
======================================================================

SYS@cdb1> alter session set container = pdb1;

Session altered.

- 로컬 정책은 CONTAINER 절 생략(기본 CURRENT).
SYS@cdb1> create audit policy l_emp_pol
  2    actions select on hr.employees;

Audit policy created.

SYS@cdb1> audit policy l_emp_pol;

Audit succeeded.

======================================================================
[3단계] 공통/로컬 정책 구분 확인
======================================================================

- 루트로 돌아가 AUDIT_UNIFIED_POLICIES 의 COMMON 컬럼으로 구분한다.
SYS@cdb1> alter session set container = cdb$root;

Session altered.

SYS@cdb1> select policy_name, common, con_id
  2  from   audit_unified_policies
  3  where  policy_name in ('C_SECURE_POL')
  4  and    rownum <= 1;

POLICY_NAME    COMMON  CON_ID
-------------- ------- -------
C_SECURE_POL   YES           1

- 공통 정책(C_SECURE_POL)은 루트(CON_ID 1)에 COMMON=YES 로 존재한다.

======================================================================
[4단계] 감사 활동 발생 및 CDB 전체 조회
======================================================================

- PDB 에서 감사 대상 활동을 유발.
SYS@cdb1> connect hr/Oracle_123@pdb1
Connected.
HR@cdb1> select department_id from employees where rownum = 1;

DEPARTMENT_ID
-------------
           90

- 루트에서 CDB 전체 감사 추적을 CON_ID 별로 조회.
HR@cdb1> connect sys/Oracle_123@cdb1 as sysdba
Connected.
SYS@cdb1> select con_id, dbusername, action_name, object_name, unified_audit_policies
  2  from   cdb_unified_audit_trail
  3  where  object_name = 'EMPLOYEES'
  4  order  by event_timestamp desc
  5  fetch first 3 rows only;

CON_ID  DBUSERNAME  ACTION_NAME  OBJECT_NAME  UNIFIED_AUDIT_POLICIES
------- ----------- ------------ ------------ ----------------------
     3  HR          SELECT       EMPLOYEES    L_EMP_POL

- CON_ID 3(PDB1)에서 발생한 SELECT 가 로컬 정책 L_EMP_POL 로 감사되었다.
- 공통 정책은 CON_ID 1(루트)에서 관리되지만, 실제 감사 레코드는 활동이
-   일어난 컨테이너의 감사 추적에 저장된다.

======================================================================
[정리]
======================================================================
- 공통 정책은 루트에서 CONTAINER=ALL 로만 생성(PDB에서 시도 시 ORA-65040).
- 로컬 정책은 해당 PDB에서 생성하며 로컬 객체 감사에 사용한다.
- CDB 전체 조회는 CDB_UNIFIED_AUDIT_TRAIL(CON_ID로 컨테이너 구분).
- 정리
SYS@cdb1> noaudit policy c_secure_pol;

Noaudit succeeded.

SYS@cdb1> drop audit policy c_secure_pol;

Audit policy dropped.

SYS@cdb1> alter session set container = pdb1;

Session altered.

SYS@cdb1> noaudit policy l_emp_pol;

Noaudit succeeded.

SYS@cdb1> drop audit policy l_emp_pol;

Audit policy dropped.
