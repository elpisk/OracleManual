-- 24장 실습_04: 조건(Condition)을 지정한 감사 정책 생성 (WHEN ... EVALUATE PER)
-- 목표: SYS_CONTEXT 를 이용한 조건부 감사 정책을 만든다.

SYS@cdb1> alter session set container = pdb1;

Session altered.

======================================================================
[1단계] (오류 -> 원인 -> 수정) 작은따옴표 이스케이프 실수
======================================================================

- (실수) 조건 식 안의 문자열을 작은따옴표 하나로만 감쌌다.
SYS@cdb1> create audit policy offnet_emp_pol
  2    actions select on hr.employees
  3    when 'SYS_CONTEXT('USERENV','IP_ADDRESS') NOT LIKE '192.168.%''
  4    evaluate per session;
  when 'SYS_CONTEXT('USERENV','IP_ADDRESS') NOT LIKE '192.168.%''
                     *
ERROR at line 3:
ORA-46372: audit condition syntax error at 'USERENV' near position 18

- 원인: WHEN 조건은 전체를 작은따옴표로 감싸므로, 조건 안의 작은따옴표는
-   두 개('')로 이스케이프해야 한다. 하나만 쓰면 문자열이 조기에 닫혀 구문 오류.
- 수정: 내부 작은따옴표를 모두 '' 로 바꾼다.
SYS@cdb1> create audit policy offnet_emp_pol
  2    actions select on hr.employees
  3    when 'SYS_CONTEXT(''USERENV'',''IP_ADDRESS'') NOT LIKE ''192.168.%'''
  4    evaluate per session;

Audit policy created.

======================================================================
[2단계] (오류 -> 원인 -> 수정) EVALUATE PER 누락
======================================================================

- (실수) 조건은 맞게 썼으나 EVALUATE PER 절을 빠뜨린 다른 정책을 시도.
SYS@cdb1> create audit policy night_emp_pol
  2    actions select on hr.employees
  3    when 'TO_CHAR(SYSDATE,''HH24'') NOT BETWEEN ''09'' AND ''18''';
  when 'TO_CHAR(SYSDATE,''HH24'') NOT BETWEEN ''09'' AND ''18'''
                                                                *
ERROR at line 3:
ORA-46372: audit condition syntax error at '' near position 61

- 원인: WHEN 조건에는 반드시 EVALUATE PER {STATEMENT|SESSION|INSTANCE} 가 따라와야 한다.
- 수정: 시각은 세션 중에도 바뀌므로 STATEMENT 단위로 평가한다.
SYS@cdb1> create audit policy night_emp_pol
  2    actions select on hr.employees
  3    when 'TO_CHAR(SYSDATE,''HH24'') NOT BETWEEN ''09'' AND ''18'''
  4    evaluate per statement;

Audit policy created.

======================================================================
[3단계] 정책 활성화 및 조건 확인
======================================================================

SYS@cdb1> audit policy offnet_emp_pol;

Audit succeeded.

SYS@cdb1> audit policy night_emp_pol;

Audit succeeded.

- 조건(WHEN)과 평가 단위 확인
SYS@cdb1> select policy_name, condition_eval_opt, audit_condition
  2  from   audit_unified_policies
  3  where  policy_name in ('OFFNET_EMP_POL','NIGHT_EMP_POL')
  4  and    audit_condition is not null;

POLICY_NAME     CONDITION_EVAL_OPT  AUDIT_CONDITION
--------------- ------------------- ------------------------------------------
OFFNET_EMP_POL  SESSION             SYS_CONTEXT('USERENV','IP_ADDRESS') NOT ...
NIGHT_EMP_POL   STATEMENT           TO_CHAR(SYSDATE,'HH24') NOT BETWEEN '09'...

======================================================================
[정리]
======================================================================
- WHEN 조건 안의 작은따옴표는 두 개('')로 이스케이프한다(실수 시 ORA-46372).
- WHEN 조건에는 EVALUATE PER 절이 반드시 필요하다.
- 세션 내내 고정값(IP)은 SESSION, 변하는 값(시각)은 STATEMENT 로 평가한다.
- 정리
SYS@cdb1> noaudit policy offnet_emp_pol;

Noaudit succeeded.

SYS@cdb1> noaudit policy night_emp_pol;

Noaudit succeeded.

SYS@cdb1> drop audit policy offnet_emp_pol;

Audit policy dropped.

SYS@cdb1> drop audit policy night_emp_pol;

Audit policy dropped.
