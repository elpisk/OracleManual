-- 24장 실습_07: 통합 감사 정책 수정 (ALTER AUDIT POLICY - ADD/DROP, CONDITION)
-- 목표: 활성화 상태를 유지한 채 무중단으로 정책 항목을 추가/제거한다.

SYS@cdb1> alter session set container = pdb1;

Session altered.

- 실습용 정책 생성 및 활성화
SYS@cdb1> create audit policy ddl_pol
  2    actions create table, drop table
  3    privileges alter any table;

Audit policy created.

SYS@cdb1> audit policy ddl_pol;

Audit succeeded.

======================================================================
[1단계] (오류 -> 원인 -> 수정) 존재하지 않는 정책 수정 시도
======================================================================

- (실수) 정책명 오타(DDL_POLICY)로 ALTER.
SYS@cdb1> alter audit policy ddl_policy add actions truncate table;
alter audit policy ddl_policy add actions truncate table
*
ERROR at line 1:
ORA-46381: One or more audit policies specified in AUDIT/NOAUDIT statement do not exist.

- 원인: DDL_POLICY 정책이 없다(정확한 이름은 DDL_POL).
- 수정: 올바른 이름으로 ALTER 한다.
SYS@cdb1> alter audit policy ddl_pol add actions truncate table, comment;

Audit policy altered.

======================================================================
[2단계] 항목 제거 (DROP)
======================================================================

- 더 이상 필요 없는 권한 감사를 제거한다.
SYS@cdb1> alter audit policy ddl_pol drop privileges alter any table;

Audit policy altered.

- 변경 결과 확인 (활성화 상태는 그대로 유지됨)
SYS@cdb1> select audit_option, audit_option_type
  2  from   audit_unified_policies
  3  where  policy_name = 'DDL_POL'
  4  order  by audit_option;

AUDIT_OPTION    AUDIT_OPTION_TYPE
--------------- --------------------
COMMENT         STANDARD ACTION
CREATE TABLE    STANDARD ACTION
DROP TABLE      STANDARD ACTION
TRUNCATE TABLE  STANDARD ACTION

- ALTER ANY TABLE 권한 감사는 제거되었고, TRUNCATE/COMMENT 가 추가되었다.

- 정책이 여전히 활성화 상태인지 확인 (무중단)
SYS@cdb1> select policy_name, enabled_option
  2  from   audit_unified_enabled_policies
  3  where  policy_name = 'DDL_POL';

POLICY_NAME  ENABLED_OPTION
------------ ---------------
DDL_POL      BY USER

======================================================================
[3단계] 조건(CONDITION) 추가 및 제거
======================================================================

- 조건이 없던 정책에 조건을 추가한다(APP 사용자만 감사).
SYS@cdb1> alter audit policy ddl_pol
  2    condition 'SYS_CONTEXT(''USERENV'',''SESSION_USER'')=''APP'''
  3    evaluate per session;

Audit policy altered.

- 조건 확인
SYS@cdb1> select policy_name, condition_eval_opt, audit_condition
  2  from   audit_unified_policies
  3  where  policy_name = 'DDL_POL' and audit_condition is not null
  4  and    rownum = 1;

POLICY_NAME  CONDITION_EVAL_OPT  AUDIT_CONDITION
------------ ------------------- ------------------------------------------
DDL_POL      SESSION             SYS_CONTEXT('USERENV','SESSION_USER')='APP'

- 조건을 제거한다.
SYS@cdb1> alter audit policy ddl_pol drop condition;

Audit policy altered.

======================================================================
[정리]
======================================================================
- ALTER AUDIT POLICY ... ADD/DROP 으로 무중단 항목 조정(활성화·BY 설정 유지).
- 없는 정책 수정은 ORA-46381 -> 정확한 정책명 확인.
- 조건은 CONDITION+EVALUATE PER 로 교체, DROP CONDITION 으로 제거.
- DROP 후 재생성보다 ALTER 가 감사 공백을 없애 안전하다.
- 정리
SYS@cdb1> noaudit policy ddl_pol;

Noaudit succeeded.

SYS@cdb1> drop audit policy ddl_pol;

Audit policy dropped.
