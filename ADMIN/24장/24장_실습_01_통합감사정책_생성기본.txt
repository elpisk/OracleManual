-- 24장 실습_01: 통합 감사(Unified Auditing) 정책 생성 기본
-- 목표: CREATE AUDIT POLICY 로 첫 감사 정책을 만들고 활성화한 뒤, 감사 레코드를 확인한다.

- 루트 컨테이너로 SYSDBA 접속된 상태 확인
SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

- 통합 감사 사용 여부(순수 통합 감사 모드인지) 확인
SYS@cdb1> select value from v$option where parameter = 'Unified Auditing';

VALUE
----------
FALSE

- FALSE 이면 혼합 모드다. 혼합 모드에서도 통합 감사 정책은 정상 동작한다.

======================================================================
[1단계] 기본 감사 정책 생성
======================================================================

- CREATE USER / DROP USER 액션을 감사하는 정책을 만든다.
SYS@cdb1> create audit policy acct_pol
  2    actions create user, alter user, drop user;

Audit policy created.

======================================================================
[2단계] (오류 -> 원인 -> 수정) 같은 이름으로 재생성 시도
======================================================================

- (실수) 액션을 바꾸려고 동일 이름으로 다시 CREATE 를 실행.
SYS@cdb1> create audit policy acct_pol
  2    actions create user, drop user;
create audit policy acct_pol
*
ERROR at line 1:
ORA-46358: Unified audit policy acct_pol already exists.

- 원인: 이미 존재하는 정책 이름으로 CREATE 하면 중복 오류가 난다.
- 수정: 정의를 바꾸려면 ALTER AUDIT POLICY 를 쓰거나, 필요 시 DROP 후 재생성한다.
SYS@cdb1> alter audit policy acct_pol
  2    add actions alter user;

Audit policy altered.

======================================================================
[3단계] 정책 활성화 (생성 != 활성화)
======================================================================

- 생성만으로는 감사가 시작되지 않는다. AUDIT POLICY 로 활성화한다.
SYS@cdb1> audit policy acct_pol;

Audit succeeded.

- 활성화 여부 확인
SYS@cdb1> select policy_name, enabled_option, entity_name
  2  from   audit_unified_enabled_policies
  3  where  policy_name = 'ACCT_POL';

POLICY_NAME   ENABLED_OPTION   ENTITY_NAME
------------- ---------------- ------------
ACCT_POL      BY USER          ALL USERS

======================================================================
[4단계] 감사 대상 활동 발생 및 감사 레코드 확인
======================================================================

- 테스트용 사용자를 만들어 CREATE USER 액션을 유발한다.
SYS@cdb1> create user c##aud_test identified by Oracle_123;

User created.

- 감사 레코드 확인 (통합 감사 추적)
SYS@cdb1> select dbusername, action_name, object_name, return_code
  2  from   unified_audit_trail
  3  where  unified_audit_policies = 'ACCT_POL'
  4  order  by event_timestamp desc
  5  fetch first 3 rows only;

DBUSERNAME  ACTION_NAME   OBJECT_NAME    RETURN_CODE
----------- ------------- -------------- -----------
SYS         CREATE USER   C##AUD_TEST              0

- RETURN_CODE 0 은 성공을 의미한다. 정책이 정상적으로 감사하고 있음을 확인.

======================================================================
[정리]
======================================================================
- CREATE AUDIT POLICY 는 정의만, AUDIT POLICY 로 활성화해야 감사가 시작된다.
- 동일 이름 재생성은 ORA-46358, 정의 변경은 ALTER AUDIT POLICY 를 사용한다.
- 정리(뒷정리)
SYS@cdb1> noaudit policy acct_pol;

Noaudit succeeded.

SYS@cdb1> drop user c##aud_test;

User dropped.

SYS@cdb1> exit
