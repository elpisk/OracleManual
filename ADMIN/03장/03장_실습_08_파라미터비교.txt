- 관리 방식 판별에 쓰는 핵심 파라미터들을 V$PARAMETER로 조회
SYS@cdb1> select name, value from v$parameter
  2  where name in ('memory_target','memory_max_target',

- 판별: memory_target=0 AND sga_target>0 → ASMM + 자동 PGA

======================================================================
[2단계] 판별 규칙을 CASE 식으로 자동 표시
======================================================================

- 세 파라미터로 관리 방식을 문자열로 판별하는 쿼리
SYS@cdb1> select
  2    case when m.value > 0 then 'AMM (완전 자동)'
  3         when s.value > 0 then 'ASMM + 자동 PGA'
  4         else '수동(Manual)'
  5    end as mode
  6  from (select value from v$parameter where name='memory_target') m,
  7       (select value from v$parameter where name='sga_target') s;

MODE
------------------
ASMM + 자동 PGA

======================================================================
[3단계] SGA/PGA 어드바이저를 함께 조회 (오류 → 수정)
======================================================================

- (실수) SGA 어드바이저 뷰 이름을 v$sga_advice 로 잘못 입력
SYS@cdb1> select sga_size, sga_size_factor, estd_db_time
  2  from v$sga_advice order by sga_size;
from v$sga_advice order by sga_size

- 원인: 뷰 이름 오류. 올바른 이름은 V$SGA_TARGET_ADVICE
SYS@cdb1> select sga_size as sga_mb, sga_size_factor as factor,
  2         estd_db_time
  3  from v$sga_target_advice
  4  where sga_size_factor in (0.5, 1, 1.5) order by sga_size;

======================================================================
[4단계] 두 어드바이저를 비교해 SGA와 PGA 중 어디에 투자할지 판단
======================================================================

- PGA 어드바이저도 함께 확인
SYS@cdb1> select round(pga_target_for_estimate/1024/1024) as pga_mb,
  2         pga_target_factor as factor,
  3         estd_pga_cache_hit_percentage as hit_pct
  4  from v$pga_target_advice
  5  where pga_target_factor in (1, 2) order by pga_target_factor;

    PGA_MB     FACTOR    HIT_PCT
---------- ---------- ----------
       700        1.0         98
      1400        2.0         99

- 해석: SGA를 키워도 DB 시간이 거의 안 줄고, PGA도 이미 98% → 현재 배분이 균형적

======================================================================
[5단계] 파라미터 계층 정리 확인
======================================================================

- 우선순위 규칙을 주석으로 정리
-   memory_target>0                  -> AMM (상위, SGA_TARGET/PGA_TARGET은 하한)
-   memory_target=0 AND sga_target>0 -> ASMM + 자동 PGA
-   memory_target=0 AND sga_target=0 -> 수동(개별 풀 파라미터가 직접 결정)
SYS@cdb1> select 'memory_target > sga_target > shared_pool_size 순으로 상위가 우선' as rule from dual;

RULE
-----------------------------------------------------------------
memory_target > sga_target > shared_pool_size 순으로 상위가 우선
