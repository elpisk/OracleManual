- CDB 수준 PGA 목표/하드리밋 확인 (PDB 값은 이 예산 안에서 의미)

NAME                                 TYPE        VALUE
------------------------------------ ----------- ------
pga_aggregate_limit                  big integer 2G
pga_aggregate_target                 big integer 700M

======================================================================
[2단계] 특정 PDB(hrpdb)로 이동해 PGA 제한 설정 (오류 → 수정)
======================================================================

SYS@cdb1> alter session set container = hrpdb;

Session altered.

- (실수) PDB의 PGA_AGGREGATE_LIMIT을 CDB 전체 LIMIT(2G)보다 크게 설정 시도
HR@cdb1> alter system set pga_aggregate_limit = 3G scope=both;
alter system set pga_aggregate_limit = 3G
*
ERROR at line 1:
ORA-02097: parameter cannot be modified because specified value is invalid
ORA-00093: pga_aggregate_limit must be between 0 and CDB-level limit

- 원인: PDB의 PGA_AGGREGATE_LIMIT은 CDB 전체 LIMIT 범위 안이어야 함. 적정 값으로 재시도
HR@cdb1> alter system set pga_aggregate_target = 300M scope=both;

System altered.

HR@cdb1> alter system set pga_aggregate_limit = 600M scope=both;

System altered.

- 컨테이너별 PGA 파라미터 확인
SYS@cdb1> select con_id, name, value
  2  from v$system_parameter
  3  where name in ('pga_aggregate_target','pga_aggregate_limit')
  4    and con_id in (0,3,4) order by con_id, name;

- 컨테이너별 실제 PGA 사용량 확인 (V$PROCESS를 CON_ID로 집계)
SYS@cdb1> select con_id, round(sum(pga_used_mem)/1024/1024,1) as pga_mb,
  2         count(*) as procs
  3  from v$process where pga_used_mem > 0
  4  group by con_id order by con_id;

- PGA_AGGREGATE_LIMIT 초과 시 PGA 최다 사용 세션의 콜이 종료됨(ORA-04036) — 개념 확인
SYS@cdb1> select 'LIMIT 초과 시 해당 PDB의 PGA 최다 사용 세션 콜 종료(ORA-04036)' as note from dual;

NOTE
-----------------------------------------------------------------
LIMIT 초과 시 해당 PDB의 PGA 최다 사용 세션 콜 종료(ORA-04036)

- [정리] PDB PGA_AGGREGATE_TARGET(목표)/PGA_AGGREGATE_LIMIT(하드리밋)로 PDB의 PGA 사용을 제한한다.
-   PDB 값은 CDB 전체 예산 범위 안에서의 세분 배분이며, 더 강한 격리는 Resource Manager로 보완한다.
