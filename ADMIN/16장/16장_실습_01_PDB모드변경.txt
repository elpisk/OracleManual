-- 16장 실습_01: PDB 모드 변경(READ WRITE / READ ONLY / MIGRATE) 실습 - ALL/EXCEPT·FORCE 옵션

- CDB 루트에 SYSDBA로 연결된 상태에서 현재 컨테이너 확인
SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

- 실습에 사용할 PDB들의 현재 오픈 모드 확인 (시드는 항상 READ ONLY)
SYS@cdb1> select con_id, name, open_mode from v$pdbs order by con_id;

    CON_ID NAME                           OPEN_MODE
---------- ------------------------------ ----------
         2 PDB$SEED                       READ ONLY
         3 PDB1                           MOUNTED
         4 PDB2                           MOUNTED
         5 PDB3                           MOUNTED

======================================================================
[1단계] 시드를 제외한 모든 PDB를 한 번에 오픈 (ALL)
======================================================================

- ALL은 PDB$SEED를 자동으로 제외하고 나머지 사용자 PDB만 READ WRITE로 연다
SYS@cdb1> alter pluggable database all open;

Pluggable database altered.

SYS@cdb1> select con_id, name, open_mode from v$pdbs order by con_id;

    CON_ID NAME                           OPEN_MODE
---------- ------------------------------ ----------
         2 PDB$SEED                       READ ONLY
         3 PDB1                           READ WRITE
         4 PDB2                           READ WRITE
         5 PDB3                           READ WRITE

======================================================================
[2단계] 특정 PDB만 제외하고 닫기 (ALL EXCEPT)
======================================================================

- pdb1만 남기고 나머지를 즉시 닫는다 (커밋 안 된 트랜잭션은 롤백)
SYS@cdb1> alter pluggable database all except pdb1 close immediate;

Pluggable database altered.

SYS@cdb1> select con_id, name, open_mode from v$pdbs order by con_id;

    CON_ID NAME                           OPEN_MODE
---------- ------------------------------ ----------
         2 PDB$SEED                       READ ONLY
         3 PDB1                           READ WRITE
         4 PDB2                           MOUNTED
         5 PDB3                           MOUNTED

======================================================================
[3단계] READ ONLY로 전환 (실수 -> 오류 -> FORCE로 재시도)
======================================================================

- (실수) 이미 READ WRITE로 열려 있는 pdb1을 그냥 READ ONLY로 열려고 시도
SYS@cdb1> alter pluggable database pdb1 open read only;
alter pluggable database pdb1 open read only
*
ERROR at line 1:
ORA-65019: pluggable database PDB1 already open

- 원인: 이미 열린 PDB의 오픈 모드를 바꾸려면 먼저 닫거나 FORCE 옵션을 써야 한다.
-   FORCE는 닫는 단계를 생략하고 곧바로 다른 모드로 강제 전환한다.
SYS@cdb1> alter pluggable database pdb1 open read only force;

Pluggable database altered.

- READ ONLY로 바뀌었는지 확인
SYS@cdb1> select name, open_mode, restricted from v$pdbs where name='PDB1';

NAME                           OPEN_MODE  RES
------------------------------ ---------- ---
PDB1                           READ ONLY  NO

- READ ONLY 상태에서 데이터 변경이 실제로 막히는지 확인
SYS@cdb1> alter session set container = pdb1;

Session altered.

SYS@pdb1> create table t_mode_test(c1 number);
create table t_mode_test(c1 number)
*
ERROR at line 1:
ORA-16000: database or pluggable database open for read-only access

- 예상대로 READ ONLY라 DDL이 거부된다. 다시 READ WRITE로 강제 전환
SYS@pdb1> alter session set container = cdb$root;

Session altered.

SYS@cdb1> alter pluggable database pdb1 open read write force;

Pluggable database altered.

======================================================================
[4단계] MIGRATE(업그레이드) 모드로 오픈
======================================================================

- 패치·업그레이드 스크립트 실행을 위한 제한 모드. 먼저 닫은 뒤 UPGRADE로 연다
SYS@cdb1> alter pluggable database pdb2 close immediate;

Pluggable database altered.

SYS@cdb1> alter pluggable database pdb2 open upgrade;

Pluggable database altered.

- MIGRATE 모드로 열렸는지 확인 (일반 사용자 접속은 차단됨)
SYS@cdb1> select name, open_mode from v$pdbs where name='PDB2';

NAME                           OPEN_MODE
------------------------------ ----------
PDB2                           MIGRATE

- 업그레이드가 끝났다고 가정하고 정상 READ WRITE로 복귀
SYS@cdb1> alter pluggable database pdb2 close immediate;

Pluggable database altered.

SYS@cdb1> alter pluggable database pdb2 open read write;

Pluggable database altered.

======================================================================
[5단계] RESTRICTED 모드 오픈과 자동 오픈(SAVE STATE)
======================================================================

- 제한 모드 오픈: RESTRICTED SESSION 권한자만 접속 가능 (유지관리용)
SYS@cdb1> alter pluggable database pdb3 open read write restricted force;

Pluggable database altered.

SYS@cdb1> select name, open_mode, restricted from v$pdbs where name='PDB3';

NAME                           OPEN_MODE  RES
------------------------------ ---------- ---
PDB3                           READ WRITE YES

- 점검이 끝나면 제한을 풀고 정상 오픈
SYS@cdb1> alter pluggable database pdb3 open read write force;

Pluggable database altered.

- 인스턴스 재기동 시 자동으로 열리도록 현재 오픈 상태 저장
SYS@cdb1> alter pluggable database all save state;

Pluggable database altered.

- 저장된 자동 오픈 상태 확인
SYS@cdb1> select con_name, instance_name, state from dba_pdb_saved_states order by con_name;

CON_NAME             INSTANCE_NAME        STATE
-------------------- -------------------- --------------
PDB1                 cdb1                 OPEN
PDB2                 cdb1                 OPEN
PDB3                 cdb1                 OPEN

- [정리] 핵심 확인 완료:
-   ALL = 시드 제외 전체 대상, ALL EXCEPT = 특정 PDB만 제외
-   이미 열린 PDB의 모드 전환은 FORCE 필요(ORA-65019 회피)
-   MIGRATE=업그레이드용 제한, RESTRICTED=권한자 전용, SAVE STATE=재기동 자동 오픈
