======================================================================
[2단계] LOCAL_LISTENER 지정 (실수 -> 오류 -> 수정)
======================================================================

- (실수) 주소 문자열의 괄호를 잘못 닫아 구문 오류 발생
SYS@pdb1> alter system set local_listener =
  2    '(ADDRESS=(PROTOCOL=TCP)(HOST=dbsvr)(PORT=1523)'
  3    scope=both;
alter system set local_listener =
*
ERROR at line 1:
ORA-00119: invalid specification for system parameter LOCAL_LISTENER
ORA-00132: syntax error or unresolved network name '(ADDRESS=(PROTOCOL=TCP)(HOST=dbsvr)(PORT=1523)'

- 원인: ADDRESS 괄호가 하나 덜 닫혔다. 올바른 괄호로 재시도
SYS@pdb1> alter system set local_listener =
  2    '(ADDRESS=(PROTOCOL=TCP)(HOST=dbsvr)(PORT=1523))'
  3    scope=both;

System altered.

- 지정된 값 확인
SYS@pdb1> show parameter local_listener

NAME                                 TYPE        VALUE
------------------------------------ ----------- --------------------------------------------
local_listener                       string      (ADDRESS=(PROTOCOL=TCP)(HOST=dbsvr)(PORT=1523))

======================================================================
[3단계] 서비스 즉시 재등록 후 포트별 등록 확인
======================================================================

- LREG가 새 리스너에 서비스를 등록하도록 즉시 재등록 요청
SYS@pdb1> alter system register;

System altered.

- OS 셸에서 1523 리스너에 pdb1 서비스가 잡혔는지 확인
SYS@pdb1> !lsnrctl services listener_pdb1

Services Summary...

- 이제 클라이언트는 1523 포트로만 pdb1에 접속할 수 있다 (다른 PDB는 여전히 1521)
SYS@pdb1> !sqlplus system/oracle@//dbsvr:1523/pdb1 <<< "select sys_context('USERENV','CON_NAME') con from dual;"

CON
------------------------------
PDB1

======================================================================
[4단계] DBMS_XDB_CONFIG로 XML DB HTTP 포트 분리 (선택)
======================================================================

- pdb1 전용 HTTP 포트를 8081로 지정 (ORDS/APEX 같은 웹 엔드포인트 분리 목적)
SYS@pdb1> exec dbms_xdb_config.sethttpport(8081);

PL/SQL procedure successfully completed.

- 설정된 HTTP 포트 확인
SYS@pdb1> select dbms_xdb_config.gethttpport() as http_port from dual;

 HTTP_PORT
----------
      8081

- 해석: LOCAL_LISTENER는 SQL*Net(SQL*Plus/JDBC) 접속을 포트 단위로 분리하고,
-   DBMS_XDB_CONFIG는 XML DB의 HTTP/FTP 프로토콜 포트를 PDB별로 분리한다.

- [정리] PDB별 네트워크 엔드포인트 분리:
-   SQL*Net 분리 -> LOCAL_LISTENER(ISPDB_MODIFIABLE=TRUE) + ALTER SYSTEM REGISTER
-   XML DB(HTTP/FTP) 분리 -> DBMS_XDB_CONFIG.SETHTTPPORT / SETFTPPORT
