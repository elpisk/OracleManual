-- 16장 실습_02: PDB 설정 변경 및 초기화 파라미터 영향 확인 - 테이블스페이스·STORAGE·open_cursors

- CDB 루트에 SYSDBA로 연결된 상태에서 시작
SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

- pdb1을 정상 오픈 상태로 준비
SYS@cdb1> alter pluggable database pdb1 open read write force;

Pluggable database altered.

======================================================================
[1단계] pdb1으로 컨텍스트 전환 후 기본 테이블스페이스 지정
======================================================================

SYS@cdb1> alter session set container = pdb1;

Session altered.

SYS@pdb1> show con_name

CON_NAME
------------------------------
PDB1

- 애플리케이션용 영구 테이블스페이스를 미리 생성
SYS@pdb1> create tablespace app_data
  2    datafile '/u02/oradata/CDB1/pdb1/app_data01.dbf' size 200m
  3    autoextend on next 50m maxsize 2g;

Tablespace created.

- PDB의 기본 영구 테이블스페이스로 지정
SYS@pdb1> alter pluggable database default tablespace app_data;

Pluggable database altered.

- 기본 테이블스페이스가 바뀌었는지 DATABASE_PROPERTIES에서 확인
SYS@pdb1> select property_value from database_properties
  2  where property_name = 'DEFAULT_PERMANENT_TABLESPACE';

PROPERTY_VALUE
--------------------
APP_DATA

======================================================================
[2단계] STORAGE 절로 저장 공간 상한 지정 (실수 -> 오류 -> 수정)
======================================================================

- (실수) MAXSIZE 값에 단위를 빠뜨리고 숫자만 입력
SYS@pdb1> alter pluggable database storage (maxsize 5);
alter pluggable database storage (maxsize 5)
                                          *
ERROR at line 1:
ORA-02097: parameter cannot be modified because specified value is invalid
ORA-00933: SQL command not properly ended

- 원인: MAXSIZE는 K/M/G 같은 크기 단위를 붙여야 한다. 단위를 붙여 재시도
SYS@pdb1> alter pluggable database storage (maxsize 5g);

Pluggable database altered.

- 임시 공간까지 함께 제한
SYS@pdb1> alter pluggable database storage (maxsize 5g max_shared_temp_size 1g);

Pluggable database altered.

- 루트로 돌아와 저장 한도가 적용됐는지 확인
SYS@pdb1> alter session set container = cdb$root;

Session altered.

SYS@cdb1> select con_id, round(max_size/1024/1024/1024,1) as max_gb
  2  from v$pdbs where con_id = 3;

    CON_ID     MAX_GB
---------- ----------
         3          5

======================================================================
[3단계] PDB에서 open_cursors 변경 및 격리성 확인
======================================================================

- 루트의 현재 open_cursors 값 확인
SYS@cdb1> show parameter open_cursors

NAME                                 TYPE        VALUE
------------------------------------ ----------- -----
open_cursors                         integer     50

- pdb1으로 전환해 값을 500으로 상향 (SCOPE=BOTH: 메모리+저장 동시 반영)
SYS@cdb1> alter session set container = pdb1;

Session altered.

SYS@pdb1> alter system set open_cursors = 500 scope=both;

System altered.

SYS@pdb1> show parameter open_cursors

NAME                                 TYPE        VALUE
------------------------------------ ----------- -----
open_cursors                         integer     500

- 루트로 돌아와 루트 값이 그대로 50인지 확인 (변경이 PDB에만 국한됨)
SYS@pdb1> alter session set container = cdb$root;

Session altered.

SYS@cdb1> show parameter open_cursors

NAME                                 TYPE        VALUE
------------------------------------ ----------- -----
open_cursors                         integer     50

======================================================================
[4단계] 파라미터가 PDB에서 수정 가능한지 판별 (ISPDB_MODIFIABLE)
======================================================================

- PDB에서 바꿀 수 있는 파라미터인지 V$PARAMETER로 확인
SYS@cdb1> select name, ispdb_modifiable
  2  from v$parameter
  3  where name in ('open_cursors','sga_target','db_block_size',
  4                 'cpu_count','nls_date_format')
  5  order by name;

NAME                 ISPDB_MODIFIABLE
-------------------- ----------------
cpu_count            TRUE
db_block_size        FALSE
nls_date_format      TRUE
open_cursors         TRUE
sga_target           TRUE

- 해석: db_block_size는 FALSE라 PDB에서 변경 불가(루트 전용), open_cursors 등은 TRUE라 PDB별 조정 가능.

- [정리] PDB 설정 관리 핵심:
-   기본 테이블스페이스=ALTER PLUGGABLE DATABASE DEFAULT TABLESPACE
-   저장 한도=STORAGE(MAXSIZE ... MAX_SHARED_TEMP_SIZE ...) (단위 필수)
-   파라미터 변경은 ISPDB_MODIFIABLE=TRUE일 때 PDB에만 격리 적용
