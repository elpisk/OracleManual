-- 21장 실습_02: 멀티테넌트 환경에서 사용자 생성(공통/로컬) 실습

- 루트 컨테이너로 SYSDBA 접속된 상태에서 현재 컨테이너 확인
SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

======================================================================
[1단계] 루트에서 공통 사용자 생성 (C## 접두사)
======================================================================

- 공통 사용자는 루트에서 CONTAINER=ALL(기본)로 생성, 이름은 C## 로 시작
SYS@cdb1> create user c##report_admin identified by Welcome_123
  2  default tablespace users temporary tablespace temp
  3  quota unlimited on users
  4  container=all;

User created.

SYS@cdb1> grant create session to c##report_admin container=all;

Grant succeeded.

- 공통 여부 확인: COMMON=YES
SYS@cdb1> select username, common, con_id
  2  from   cdb_users where username='C##REPORT_ADMIN' order by con_id;

USERNAME           COM     CON_ID
------------------ --- ----------
C##REPORT_ADMIN    YES          1
C##REPORT_ADMIN    YES          3

- 해석: 하나의 공통 사용자가 루트(CON_ID=1)와 salespdb(CON_ID=3) 모두에 동일 정체성으로 존재.

======================================================================
[2단계] (실수 -> 오류 -> 재시도) C## 없이 공통 사용자 생성
======================================================================

- (실수) 루트에서 접두사 없이 공통 사용자 생성 시도
SYS@cdb1> create user report_admin identified by pw container=all;
create user report_admin identified by pw container=all
            *
ERROR at line 1:
ORA-65096: invalid common user or role name

- 원인: 루트에서 CONTAINER=ALL 로 만드는 공통 사용자는 이름이 C##(c##) 로 시작해야 함.
-   접두사를 붙여 재실행하면 성공.
SYS@cdb1> create user c##report2 identified by Welcome_123 container=all;

User created.

======================================================================
[3단계] PDB에서 로컬 사용자 생성
======================================================================

- 대상 PDB로 컨테이너 전환 (PDB에서는 CONTAINER=CURRENT 가 기본)
SYS@cdb1> alter session set container = salespdb;

Session altered.

SYS@salespdb> create user local_app identified by Str0ng_Pw#9
  2  default tablespace users quota 50m on users;

User created.

SYS@salespdb> grant create session to local_app;

Grant succeeded.

- 로컬 여부 확인: COMMON=NO
SYS@salespdb> select username, common from dba_users
  2  where username in ('LOCAL_APP','C##REPORT_ADMIN') order by username;

USERNAME           COM
------------------ ---
C##REPORT_ADMIN    YES
LOCAL_APP          NO

- 해석: LOCAL_APP 은 salespdb 안에만 존재하는 로컬 사용자(COMMON=NO).

======================================================================
[4단계] (실수 -> 오류 -> 재시도) PDB에서 C## 이름으로 로컬 사용자 생성
======================================================================

- (실수) PDB(로컬 컨텍스트)에서 C## 접두사 이름으로 사용자 생성 시도
SYS@salespdb> create user c##localbad identified by pw;
create user c##localbad identified by pw
            *
ERROR at line 1:
ORA-65094: invalid local user or role name

- 원인: 로컬 사용자 이름에는 C## 접두사를 쓸 수 없다.
-   접두사 없는 이름으로 재실행하면 성공.
SYS@salespdb> create user localgood identified by pw;

User created.

======================================================================
[정리] 실습 객체 삭제
======================================================================

SYS@salespdb> drop user local_app cascade;
User dropped.
SYS@salespdb> drop user localgood cascade;
User dropped.
SYS@salespdb> alter session set container = cdb$root;
Session altered.
SYS@cdb1> drop user c##report_admin cascade;
User dropped.
SYS@cdb1> drop user c##report2 cascade;
User dropped.

- [정리] 핵심 확인 완료:
-   공통 사용자=루트+CONTAINER=ALL+C## 접두사, 로컬 사용자=PDB+접두사 금지.
-   접두사 위반 시 ORA-65096(공통)/ORA-65094(로컬) 발생.
SYS@cdb1> exit
