-- 21장 실습_05: 비밀번호 인증 및 비밀번호 파일 인증 실습

======================================================================
[1단계] 비밀번호 인증 계정 생성 및 대소문자 구분 확인
======================================================================

- salespdb 로 전환하여 비밀번호 인증 계정 생성
SYS@cdb1> alter session set container = salespdb;

Session altered.

SYS@salespdb> create user pwuser identified by Str0ng_Pw#9
  2  default tablespace users quota 5m on users;
User created.
SYS@salespdb> grant create session to pwuser;
Grant succeeded.

- 19c 비밀번호는 기본 대소문자 구분(SEC_CASE_SENSITIVE_LOGON=TRUE)
SYS@salespdb> connect sys@cdb1 as sysdba
Enter password:
Connected.
SYS@cdb1> show parameter sec_case_sensitive_logon

NAME                        TYPE     VALUE
--------------------------- -------- ------
sec_case_sensitive_logon    boolean  TRUE

======================================================================
[2단계] (실수 -> 오류 -> 재시도) 대소문자를 틀린 비밀번호로 접속
======================================================================

- (실수) 비밀번호 대소문자를 틀리게 입력(str0ng_pw#9)
SYS@cdb1> connect pwuser/str0ng_pw#9@salespdb
ERROR:
ORA-01017: invalid username/password; logon denied


Warning: You are no longer connected to ORACLE.

- 원인: 19c 비밀번호는 대소문자를 구분한다. 'S'와 's'가 달라 인증 실패(ORA-01017).
-   정확한 대소문자로 재입력하면 성공.
SYS@cdb1> connect pwuser/Str0ng_Pw#9@salespdb
Connected.

PWUSER@salespdb> show user
USER is "PWUSER"

- 인증 유형 확인: PASSWORD
PWUSER@salespdb> connect sys@cdb1 as sysdba
Enter password:
Connected.
SYS@cdb1> select username, authentication_type from dba_users
  2  where username='PWUSER';

USERNAME     AUTHENTICATION_TYPE
------------ -------------------
PWUSER       PASSWORD

======================================================================
[3단계] 비밀번호 파일 확인 (관리 접속용)
======================================================================

- REMOTE_LOGIN_PASSWORDFILE 파라미터 확인 (EXCLUSIVE 권장)
SYS@cdb1> show parameter remote_login_passwordfile

NAME                          TYPE     VALUE
----------------------------- -------- ---------
remote_login_passwordfile     string   EXCLUSIVE

- 비밀번호 파일에 등록된 관리 사용자 목록
SYS@cdb1> select username, sysdba, sysbackup from v$pwfile_users;

USERNAME     SYSDB SYSBA
------------ ----- -----
SYS          TRUE  FALSE

======================================================================
[4단계] 관리 권한 부여 시 비밀번호 파일에 자동 등록 확인
======================================================================

- 공통 사용자에게 SYSBACKUP 관리 권한 부여
SYS@cdb1> create user c##bkpadmin identified by Bkp_Pw#77 container=all;
User created.
SYS@cdb1> grant sysbackup to c##bkpadmin container=all;
Grant succeeded.

- v$pwfile_users 에 자동 등록됨
SYS@cdb1> select username, sysdba, sysbackup from v$pwfile_users
  2  order by username;

USERNAME       SYSDB SYSBA
-------------- ----- -----
C##BKPADMIN    FALSE TRUE
SYS            TRUE  FALSE

- 원격에서 SYSBACKUP 으로 접속 테스트 (비밀번호 파일 인증 경로)
SYS@cdb1> connect c##bkpadmin/Bkp_Pw#77@cdb1 as sysbackup
Connected.
C##BKPADMIN@cdb1> show user
USER is "SYSBACKUP"

- 해석: 관리 권한을 받은 계정은 비밀번호 파일에 자동 등록되어 원격 관리 접속이 가능.
-   원격 SYSDBA/SYSBACKUP 접속은 비밀번호 파일 인증이 반드시 필요하다.

======================================================================
[정리] 실습 객체 삭제
======================================================================

C##BKPADMIN@cdb1> connect sys@cdb1 as sysdba
Enter password:
Connected.
SYS@cdb1> drop user c##bkpadmin cascade;
User dropped.
SYS@cdb1> alter session set container=salespdb;
Session altered.
SYS@salespdb> drop user pwuser cascade;
User dropped.

- [정리] 핵심 확인 완료:
-   비밀번호 인증은 대소문자 구분(ORA-01017 주의), 인증유형 PASSWORD.
-   관리 권한 계정은 V$PWFILE_USERS 에 자동 등록, 원격 관리 접속에 비밀번호 파일 필수.
