-- 21장 실습_03: CDB와 PDB에 공통 사용자 생성 및 컨테이너별 권한 실습

- 루트 컨테이너로 SYSDBA 접속된 상태에서 현재 컨테이너 확인
SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

======================================================================
[1단계] 루트에서 공통 사용자 생성 후 모든 컨테이너에 접속 권한 부여
======================================================================

SYS@cdb1> create user c##ops_admin identified by Welcome_123
  2  default tablespace users temporary tablespace temp
  3  quota unlimited on users container=all;

User created.

- CONTAINER=ALL 로 CREATE SESSION 부여 → 루트+모든 PDB에서 접속 가능
SYS@cdb1> grant create session to c##ops_admin container=all;

Grant succeeded.

======================================================================
[2단계] (실수 -> 오류 -> 재시도) CONTAINER=CURRENT 로 권한 부여의 한계
======================================================================

- (실수) SELECT ANY TABLE 을 CONTAINER=CURRENT(루트에서만)로 부여
SYS@cdb1> grant select any table to c##ops_admin container=current;

Grant succeeded.

- PDB로 전환 후 그 권한이 PDB에도 적용되는지 확인
SYS@cdb1> alter session set container = salespdb;

Session altered.

- c##ops_admin 으로 salespdb 접속하여 다른 스키마 조회 시도
SYS@salespdb> connect c##ops_admin@salespdb
Enter password:
Connected.

C##OPS_ADMIN@salespdb> select count(*) from hr.employees;
select count(*) from hr.employees
                        *
ERROR at line 1:
ORA-00942: table or view does not exist

- 원인: SELECT ANY TABLE 을 CONTAINER=CURRENT(루트)로만 줘서 salespdb 에는 적용 안 됨.
-   공통 사용자라도 각 컨테이너에서 권한을 별도로 가져야 한다.

- 해결: 루트로 돌아가 CONTAINER=ALL 로 다시 부여
C##OPS_ADMIN@salespdb> connect sys@cdb1 as sysdba
Enter password:
Connected.

SYS@cdb1> grant select any table to c##ops_admin container=all;

Grant succeeded.

======================================================================
[3단계] 권한이 모든 컨테이너에 적용됨을 확인
======================================================================

SYS@cdb1> connect c##ops_admin@salespdb
Enter password:
Connected.

C##OPS_ADMIN@salespdb> select count(*) from hr.employees;

  COUNT(*)
----------
       107

- 해석: CONTAINER=ALL 로 부여하니 salespdb 에서도 조회 성공.

======================================================================
[4단계] 컨테이너별 공통 사용자 권한 적용 범위 확인
======================================================================

C##OPS_ADMIN@salespdb> connect sys@cdb1 as sysdba
Enter password:
Connected.

SYS@cdb1> select grantee, privilege, common, con_id
  2  from   cdb_sys_privs
  3  where  grantee='C##OPS_ADMIN' and privilege='SELECT ANY TABLE'
  4  order  by con_id;

GRANTEE        PRIVILEGE          COM     CON_ID
-------------- ------------------ --- ----------
C##OPS_ADMIN   SELECT ANY TABLE   YES          1
C##OPS_ADMIN   SELECT ANY TABLE   YES          3

- 해석: CON_ID 1(루트)과 3(salespdb) 모두에 공통(COMMON=YES) 권한이 적용됨.

======================================================================
[정리] 실습 객체 삭제
======================================================================

SYS@cdb1> drop user c##ops_admin cascade;
User dropped.

- [정리] 핵심 확인 완료:
-   공통 사용자는 모든 PDB에 존재하나, 권한은 CONTAINER 절 범위에 따라 적용.
-   CONTAINER=CURRENT는 현재 컨테이너만, CONTAINER=ALL은 모든 컨테이너에 적용.
SYS@cdb1> exit
