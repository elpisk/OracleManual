-- 14장 실습_01: FILE_NAME_CONVERT 절로 PDB$SEED에서 새 PDB 생성

- 이 실습은 CDB1 루트에 SYSDBA로 접속한 상태에서 진행한다.
- PDB 시드(PDB$SEED)의 데이터 파일을 새 PDB(PDB1)의 대상 디렉터리로 복사하여
-   비어 있는 새 PDB를 만든다. 파일 위치는 FILE_NAME_CONVERT 절로 명시적으로 지정한다.
[oracle@dbsvr ~]$ sqlplus / as sysdba

- 현재 컨테이너가 루트(CDB$ROOT)인지 확인 (PDB 생성은 루트에서 수행한다)
SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

======================================================================
[1단계] 시드의 실제 데이터 파일 경로 확인
======================================================================

- FILE_NAME_CONVERT의 '원본' 문자열은 시드 파일의 실제 경로에 정확히
-   포함되어 있어야 한다. 먼저 시드(CON_ID=2)의 파일 경로를 확인한다.
SYS@cdb1> select file_name from cdb_data_files where con_id=2
  2  union all
  3  select file_name from cdb_temp_files where con_id=2;

FILE_NAME
--------------------------------------------------------------
/u01/app/oracle/oradata/CDB1/pdbseed/system01.dbf
/u01/app/oracle/oradata/CDB1/pdbseed/sysaux01.dbf
/u01/app/oracle/oradata/CDB1/pdbseed/undotbs01.dbf
/u01/app/oracle/oradata/CDB1/pdbseed/temp012024-01-01.dbf

- 원본 디렉터리는 .../CDB1/pdbseed 이고, 새 PDB는 .../CDB1/pdb1 로 만든다.

======================================================================
[2단계] (실수) 대상 디렉터리를 만들지 않고 바로 생성 시도 -> 파일 오류
======================================================================

- FILE_NAME_CONVERT 절은 OS 디렉터리를 자동 생성하지 않는다.
-   대상 디렉터리가 없으면 파일 생성 단계에서 오류가 난다.
SYS@cdb1> create pluggable database pdb1
  2    admin user admin1 identified by "Welcome_1234" roles=(connect)
  3    file_name_convert=('/u01/app/oracle/oradata/CDB1/pdbseed',
  4                       '/u01/app/oracle/oradata/CDB1/pdb1');
create pluggable database pdb1
*
ERROR at line 1:
ORA-19504: failed to create file
"/u01/app/oracle/oradata/CDB1/pdb1/system01.dbf"
ORA-27040: file create error, unable to create file
Linux-x86_64 Error: 2: No such file or directory

- 원인: 대상 디렉터리 /u01/app/oracle/oradata/CDB1/pdb1 가 존재하지 않음.
-   SQL*Plus 안에서 host 명령으로 디렉터리를 만든 뒤 재시도한다.
SYS@cdb1> host mkdir -p /u01/app/oracle/oradata/CDB1/pdb1

======================================================================
[3단계] 대상 디렉터리 생성 후 재시도 -> 성공
======================================================================

SYS@cdb1> create pluggable database pdb1
  2    admin user admin1 identified by "Welcome_1234" roles=(connect)
  3    file_name_convert=('/u01/app/oracle/oradata/CDB1/pdbseed',
  4                       '/u01/app/oracle/oradata/CDB1/pdb1');

Pluggable database created.

- 생성은 성공했지만 아직 사용 준비가 끝난 것은 아니다(STATUS=NEW).

======================================================================
[4단계] 생성 결과 검증 (CDB_PDBS / CDB_TABLESPACES / CDB_DATA_FILES)
======================================================================

- 새 PDB가 목록에 있는지, STATUS와 CON_ID를 확인
SYS@cdb1> select pdb_name, status, con_id from cdb_pdbs order by con_id;

PDB_NAME             STATUS         CON_ID
-------------------- -------------- ----------
PDB$SEED             NORMAL                  2
PDB1                 NEW                     4

- 새 PDB(CON_ID=4)의 테이블스페이스 확인 (SYSTEM/SYSAUX/UNDO)
SYS@cdb1> select tablespace_name from cdb_tablespaces
  2  where con_id=4 order by tablespace_name;

TABLESPACE_NAME
------------------------------
SYSAUX
SYSTEM
TEMP
UNDOTBS1

- 데이터 파일이 FILE_NAME_CONVERT 대상 경로에 복사되었는지 물리 경로 확인
SYS@cdb1> select tablespace_name, file_name from cdb_data_files
  2  where con_id=4 order by tablespace_name;

TABLESPACE_NAME  FILE_NAME
---------------- ---------------------------------------------------
SYSAUX           /u01/app/oracle/oradata/CDB1/pdb1/sysaux01.dbf
SYSTEM           /u01/app/oracle/oradata/CDB1/pdb1/system01.dbf
UNDOTBS1         /u01/app/oracle/oradata/CDB1/pdb1/undotbs01.dbf

- 해석: 원본(.../pdbseed)의 파일들이 대상(.../pdb1)으로 정확히 치환되어 복사됨.

======================================================================
[정리]
======================================================================
- FILE_NAME_CONVERT=('원본','대상')는 시드 경로를 새 PDB 경로로 치환한다.
- 대상 디렉터리는 반드시 미리 존재해야 한다(자동 생성되지 않음 -> ORA-27040).
- 생성 직후 STATUS=NEW. 다음 실습(02)에서 OPEN하여 NORMAL로 만든다.
