-- 14장 실습_02: 생성된 PDB 상태(NEW -> NORMAL) 확인 및 OPEN

- 실습_01에서 만든 PDB1은 STATUS=NEW, OPEN_MODE=MOUNTED 상태이다.
-   이 실습에서는 라이프사이클(NEW -> OPEN -> NORMAL)을 직접 관찰한다.
[oracle@dbsvr ~]$ sqlplus / as sysdba

SQL*Plus: Release 19.0.0.0.0 - Production on Wed Jul 22 10:22:40 2026
Version 19.3.0.0.0

Connected to:
Oracle Database 19c Enterprise Edition Release 19.0.0.0.0 - Production
Version 19.3.0.0.0

SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

======================================================================
[1단계] 생성 직후 상태 확인 (STATUS=NEW, OPEN_MODE=MOUNTED)
======================================================================

- CDB_PDBS.STATUS(생애 상태)와 V$PDBS.OPEN_MODE(현재 상태)를 함께 본다.
SYS@cdb1> select p.pdb_name, p.status, v.open_mode
  2  from cdb_pdbs p join v$pdbs v on p.con_id=v.con_id
  3  where p.pdb_name='PDB1';

PDB_NAME             STATUS         OPEN_MODE
-------------------- -------------- ----------
PDB1                 NEW            MOUNTED

- 해석: 한 번도 열린 적이 없어 STATUS=NEW, 닫혀 있어 OPEN_MODE=MOUNTED.

======================================================================
[2단계] (실수) NEW 상태에서 PDB로 컨텍스트만 바꿔 조회 시도
======================================================================

- PDB가 MOUNTED이면 그 안에서 일반 조회를 할 수 없다.
SYS@cdb1> alter session set container=pdb1;

Session altered.

SYS@pdb1> select count(*) from all_objects;
select count(*) from all_objects
                     *
ERROR at line 1:
ORA-01219: database or pluggable database not open: queries allowed on fixed
tables or views only

- 원인: PDB1이 아직 열려 있지 않다(MOUNTED). 루트로 돌아가 PDB를 연다.
SYS@pdb1> alter session set container=cdb$root;

Session altered.

======================================================================
[3단계] 개방 전 점검을 위해 RESTRICTED 모드로 먼저 열기
======================================================================

- 일반 사용자에게 바로 개방하기 전에 RESTRICTED로 열어 초기 상태를 점검한다.
SYS@cdb1> alter pluggable database pdb1 open restricted;

Pluggable database altered.

- 처음 열리는 순간 통합 처리가 수행되어 STATUS가 바뀐다. 다시 확인한다.
SYS@cdb1> select p.pdb_name, p.status, v.open_mode, v.restricted
  2  from cdb_pdbs p join v$pdbs v on p.con_id=v.con_id
  3  where p.pdb_name='PDB1';

PDB_NAME             STATUS         OPEN_MODE  RES
-------------------- -------------- ---------- ---
PDB1                 NORMAL         READ WRITE YES

- 해석: 처음 열면서 STATUS=NORMAL로 확정. RESTRICTED=YES는 제한 모드 표시.

======================================================================
[4단계] 점검 후 일반 개방(READ WRITE)으로 다시 열기
======================================================================

- 제한 모드를 풀려면 닫았다가 일반 모드로 다시 연다.
SYS@cdb1> alter pluggable database pdb1 close immediate;

Pluggable database altered.

SYS@cdb1> alter pluggable database pdb1 open;

Pluggable database altered.

SYS@cdb1> select name, open_mode, restricted from v$pdbs where name='PDB1';

NAME                 OPEN_MODE  RES
-------------------- ---------- ---
PDB1                 READ WRITE NO

- 이제 RESTRICTED=NO. 일반 사용자도 접속할 수 있다.

======================================================================
[5단계] ADMIN USER 계정으로 접속 확인 및 상태 재확인
======================================================================

- 서비스 이름 pdb1(생성 시 자동 생성)으로 admin1 접속을 시도한다.
SYS@cdb1> connect admin1/"Welcome_1234"@localhost:1521/pdb1
Connected.

ADMIN1@pdb1> show con_name

CON_NAME
------------------------------
PDB1

- STATUS는 한 번 NORMAL이 되면 껐다 켜도 유지된다(영구 표식).
ADMIN1@pdb1> connect / as sysdba
Connected.
SYS@cdb1> alter pluggable database pdb1 close immediate;

Pluggable database altered.

SYS@cdb1> select pdb_name, status from cdb_pdbs where pdb_name='PDB1';

PDB_NAME             STATUS
-------------------- --------------
PDB1                 NORMAL

- 닫아도 STATUS는 NORMAL 유지(OPEN_MODE만 MOUNTED로 바뀜).
SYS@cdb1> alter pluggable database pdb1 open;

Pluggable database altered.

======================================================================
[정리]
======================================================================
- 생성 직후: STATUS=NEW, OPEN_MODE=MOUNTED.
- 처음 OPEN(READ WRITE/RESTRICTED) 순간 통합 처리 -> STATUS=NORMAL(영구).
- STATUS(생애 상태)와 OPEN_MODE(현재 상태)는 다른 개념이다.
- NEW/MOUNTED 상태에서 일반 조회를 시도하면 ORA-01219가 난다 -> 먼저 OPEN.
