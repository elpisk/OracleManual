 27장 실습 03 — PDB 환경에서 Data Pump 사용 (FULL=Y, CDB/PDB 범위)
 목표: '접속 대상 = 작업 범위' 확인 / PDB FULL vs CDB$ROOT FULL 차이 체험
 환경: CDB=cdb1, PDB=pdb1
================================================================================

-- [1] PDB1 단위 FULL 내보내기 (그 PDB만 대상)
$ expdp system@pdb1 FULL=Y DIRECTORY=dp_dir DUMPFILE=pdb1_full.dmp \
        LOGFILE=pdb1_full.log

-- PDB에 접속한 FULL=Y 는 그 PDB 안의 사용자 데이터만 담는다(루트/타 PDB 제외).

--------------------------------------------------------------------------------
-- [2] 첫 시도: 일반 로컬 사용자로 CDB 전체 FULL 시도 → 실패
--------------------------------------------------------------------------------
$ expdp system@cdb1 FULL=Y DIRECTORY=dp_dir DUMPFILE=cdb_full.dmp \
        LOGFILE=cdb_full.log

Export: Release 19.0.0.0.0 - Production on Wed Aug 5 11:08:41 2026
Connected to: Oracle Database 19c Enterprise Edition Release 19.0.0.0.0

ORA-39002: invalid operation
ORA-39358: Export VERSION 12.1 or later requires a full database ...
-- (또한 CDB$ROOT에서 DIRECTORY DP_DIR 은 PDB 안에만 존재하므로 접근 불가)
ORA-39070: Unable to open the log file.
ORA-29283: invalid file operation

-- 원인 파악:
--   (a) DP_DIR 디렉터리 객체는 PDB1 안에서 만들었기 때문에 CDB$ROOT에는 없다.
--       디렉터리 객체는 컨테이너에 종속된다.
--   (b) CDB 전체 FULL 내보내기는 루트에 접속해 CDB 수준 디렉터리 객체가 필요하다.

--------------------------------------------------------------------------------
-- [3] 수정: CDB$ROOT에 디렉터리 객체를 만들고 루트에서 FULL 내보내기
--------------------------------------------------------------------------------
$ sqlplus sys@cdb1 as sysdba
SYS@cdb1> SHOW CON_NAME
CON_NAME
------------------------------
CDB$ROOT
SYS@cdb1> CREATE DIRECTORY dp_root AS '/u01/app/oracle/dpdump';
Directory created.
SYS@cdb1> GRANT READ, WRITE ON DIRECTORY dp_root TO system;
Grant succeeded.
SYS@cdb1> EXIT

$ expdp \"sys@cdb1 as sysdba\" FULL=Y DIRECTORY=dp_root \
        DUMPFILE=cdb_full.dmp LOGFILE=cdb_full.log

Connected to: Oracle Database 19c Enterprise Edition Release 19.0.0.0.0
Starting "SYS"."SYS_EXPORT_FULL_01":  ... FULL=Y DIRECTORY=dp_root
Processing object type DATABASE_EXPORT/PLUGTS_FULL/PLUGTS_TABLESPACE
Processing object type DATABASE_EXPORT/SCHEMA/TABLE/TABLE_DATA
-- 루트 + 모든 PDB(PDB1)의 사용자 데이터가 포함된다.
. . exported "PDB1"."HR"."EMPLOYEES"           107 rows
. . exported "PDB1"."SH"."SALES"            918843 rows
Job "SYS"."SYS_EXPORT_FULL_01" successfully completed ...

--------------------------------------------------------------------------------
-- [4] 범위 비교 확인: DBA_DATAPUMP_JOBS 로 작업 모니터링
--------------------------------------------------------------------------------
$ sqlplus system@pdb1
SYSTEM@pdb1> SELECT owner_name, job_name, operation, job_mode, state
  2          FROM dba_datapump_jobs;

OWNER_NAME  JOB_NAME               OPERATION  JOB_MODE  STATE
----------- ---------------------- ---------- --------- ----------
SYSTEM      SYS_EXPORT_FULL_01     EXPORT     FULL      NOT RUNNING

-- 결론:
--   1) 접속한 컨테이너가 작업 범위를 결정한다.
--      PDB 접속 FULL=Y → 그 PDB만 / CDB$ROOT 접속 FULL=Y → CDB 전체.
--   2) 디렉터리 객체는 컨테이너 종속 — 루트 작업은 루트 디렉터리 객체가 필요.
--   3) CDB 전체 FULL 은 SYSDBA/공통 사용자로 루트에 접속해 수행한다.
