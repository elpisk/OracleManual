-- 13장 실습_06: CMCTL 유틸리티로 Connection Manager 시작/중지/상태 확인

- CMCTL(Oracle Connection Manager Control)로 CMAN을 시작·중지·모니터링한다.
-   인자 없이 실행하면 대화형 CMCTL> 프롬프트로, 명령을 붙여 실행하면 비대화형(스크립트용)으로 동작한다.
[oracle@proxysvr ~]$ export TNS_ADMIN=$ORACLE_HOME/network/admin

======================================================================
[1단계] 비대화형 상태 확인: 아직 미기동 상태
======================================================================

- 스크립트 친화적으로 명령을 한 줄에 붙여 실행 (cmctl <command> <process_type> -c <name>)
[oracle@proxysvr ~]$ cmctl show status -c cman01

CMCTL for Linux: Version 19.0.0.0.0 - Production on 22-JUL-2026 15:02:11

Copyright (c) 1996, 2019, Oracle.  All rights reserved.

TNS-04077: No connection manager is currently running for the specified alias.

======================================================================
[2단계] 대화형 진입: administer -> startup(게이트웨이+관리 프로세스)
======================================================================

- 대화형 CMCTL 진입
[oracle@proxysvr ~]$ cmctl

CMCTL for Linux: Version 19.0.0.0.0 - Production on 22-JUL-2026 15:03:40

Copyright (c) 1996, 2019, Oracle.  All rights reserved.

Welcome to CMCTL, type "help" for information.

- (실수) 관리 대상을 지정하는 명령을 오타(adminster)로 입력
CMCTL> adminster cman01
CMCTL-0004: The command name "adminster" was not recognized.
Type "help" to see a list of valid commands.

- 원인: 명령어 철자 오류(adminster -> administer). 올바른 명령으로 재시도
CMCTL> administer cman01
Current instance cman01 is not yet started
Connections refer to (address=(protocol=tcp)(host=proxysvr)(port=1521)).
The command completed successfully.

- 게이트웨이+관리 프로세스를 모두 시작 (process_type 생략 시 기본값 cman)
CMCTL:cman01> startup
Starting Oracle Connection Manager instance cman01. Please wait...
TNSLSNR for Linux: Version 19.0.0.0.0 - Production
Version 19.3.0.0.0
Log messages written to /u01/app/oracle/network/log/cman01.log
Listening on: (ADDRESS=(PROTOCOL=tcp)(HOST=proxysvr)(PORT=1521))

Connecting to (ADDRESS=(PROTOCOL=tcp)(HOST=proxysvr)(PORT=1521))
Number of filtering rules currently in effect: 3
Manager mode consists of CMADMIN and CMGW processes.
The command completed successfully.

======================================================================
[4단계] 파라미터 동적 변경 (Modifier): 로그 레벨 상향
======================================================================

- 문제 진단을 위해 로그 레벨을 동적으로 상향(SET). CMADMIN이 떠 있어야 동적 변경이 가능하다.
CMCTL:cman01> set log_level admin
CMAN parameter log_level was set to admin
The command completed successfully.

- 변경 반영 확인
CMCTL:cman01> show parameter log_level
The command completed successfully.
Parameters currently in use for cman01
------------------------------
LOG_LEVEL = ADMIN

======================================================================
[5단계] 부분 중지/전체 중지 (Operational)
======================================================================

- 자원 절약을 위해 관리 프로세스(CMADMIN)만 중지 -> 게이트웨이만 남아 기본 기능은 계속 수행
CMCTL:cman01> shutdown adm
The command completed successfully.

- CMADMIN을 내렸으므로 이제 상태 조회 같은 관리 요청은 불가해진다 (게이트웨이는 여전히 동작)
CMCTL:cman01> show status
TNS-04078: Command cannot be executed. Administrative process CMADMIN is down.

- 상태를 다시 조회하려면 관리 프로세스를 다시 올린다
CMCTL:cman01> startup adm
Starting administrative process CMADMIN. Please wait...
The command completed successfully.

- 관리 프로세스 복구 후 상태 조회 정상 (Num of gateways started 3 유지)
CMCTL:cman01> show status
Status of the Instance
----------------------------
Instance name             cman01
Version                   CMAN for Linux: Version 19.0.0.0.0 - Production
Num of gateways started   3
Average Load level        0
Log Level                 ADMIN
Trace Level               USER
The command completed successfully.

- CMAN 전체(게이트웨이+관리) 중지
CMCTL:cman01> shutdown
Shutting down Oracle Connection Manager instance cman01. Please wait...
The command completed successfully.

CMCTL:cman01> exit

[6단계] 비대화형 재기동으로 자동화 확인
======================================================================

- 기동 스크립트/자동화에서 쓰는 비대화형 방식으로 다시 기동
[oracle@proxysvr ~]$ cmctl startup -c cman01

CMCTL for Linux: Version 19.0.0.0.0 - Production on 22-JUL-2026 15:12:33

TNSLSNR for Linux: Version 19.0.0.0.0 - Production

- OS 레벨에서 CMADMIN / CMGW 프로세스 기동 확인
[oracle@proxysvr ~]$ ps -ef | grep -E 'cmadmin|cmgw' | grep -v grep
oracle    9820     1  0 15:12 ?        00:00:00 cmadmin cman01 -inherit
oracle    9822     1  0 15:12 ?        00:00:00 cmgw0 cman01 -inherit
oracle    9823     1  0 15:12 ?        00:00:00 cmgw1 cman01 -inherit
oracle    9824     1  0 15:12 ?        00:00:00 cmgw2 cman01 -inherit

- [정리]
-   · cmctl 은 인자 없이 실행하면 대화형(CMCTL>), 명령을 붙이면 비대화형(자동화용)으로 동작한다.
-   · 대화형에서는 administer <이름> 으로 대상을 지정한 뒤 startup/show status/show services 등을 쓴다.
-   · process_type: cman(게이트웨이+관리, 기본), cm(게이트웨이만), adm(관리만) 을 대상으로 지정할 수 있다.
-   · 동적 조회/변경(show, set)은 관리 프로세스(CMADMIN)가 떠 있어야 하며, 자원 절약 시 게이트웨이만 남길 수 있다.
[oracle@proxysvr ~]$
