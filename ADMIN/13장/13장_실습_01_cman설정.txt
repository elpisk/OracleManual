-- 13장 실습_01: cman.ora 파일 구성(ADDRESS / RULE_LIST / PARAMETER_LIST)

- Oracle Connection Manager(CMAN)는 프록시 전용 호스트(proxysvr)에 Instant Client
-   미디어로 설치되어 있다고 가정한다. CMAN 소프트웨어 홈으로 환경변수를 설정한다.
[oracle@proxysvr ~]$ echo $ORACLE_HOME
/u01/app/oracle/product/19.0.0/client_1

- CMAN 구성 파일들이 위치할 network/admin 디렉터리로 이동
[oracle@proxysvr ~]$ export TNS_ADMIN=$ORACLE_HOME/network/admin
[oracle@proxysvr ~]$ cd $TNS_ADMIN
[oracle@proxysvr admin]$ pwd
/u01/app/oracle/product/19.0.0/client_1/network/admin

======================================================================
[1단계] 샘플에서 복사: 백지에서 쓰지 말고 배포 샘플을 복사해 편집
======================================================================

- cman.ora는 괄호 중첩과 들여쓰기에 민감하므로 samples 디렉터리의 예제를 복사해 시작
-   (괄호 하나만 어긋나도 CMAN이 기동하지 않거나 규칙이 무시될 수 있다)
[oracle@proxysvr admin]$ ls samples/

======================================================================
[2단계] ADDRESS / RULE_LIST / PARAMETER_LIST 세 영역 작성
======================================================================

- cman.ora의 최상위 구조는 'CMAN이름 = (CONFIGURATION = ...)' 형태이다.
-   CONFIGURATION 블록 안에 ADDRESS, RULE_LIST, PARAMETER_LIST 세 영역이 나란히 들어간다.
-   (실수) 아래 heredoc에서 RULE_LIST 첫 규칙의 닫는 괄호 하나를 빠뜨린 채 작성한다.
[oracle@proxysvr admin]$ cat > cman.ora <<'EOF'
cman01=
  (CONFIGURATION=
    (ADDRESS=(PROTOCOL=tcp)(HOST=proxysvr)(PORT=1521))
    (RULE_LIST=
      (RULE=(SRC=192.0.2.0/24)(DST=dbsvr)(SRV=*)(ACT=accept)
        (ACTION_LIST=(AUT=off)(MCT=120)(MIT=30))
      (RULE=(SRC=192.0.2.0/24)(DST=proxysvr)(SRV=cmon)(ACT=accept)))
    (PARAMETER_LIST=
      (LOG_LEVEL=SUPPORT)
      (TRACING=on)
      (MAX_GATEWAY_PROCESSES=8)
      (MIN_GATEWAY_PROCESSES=3)))
EOF

- 작성한 파일 내용을 눈으로 확인 (괄호 짝을 셈해 보면 첫 RULE의 닫는 ')'가 하나 부족함)
[oracle@proxysvr admin]$ cat cman.ora
cman01=
  (CONFIGURATION=
    (ADDRESS=(PROTOCOL=tcp)(HOST=proxysvr)(PORT=1521))
    (RULE_LIST=
      (RULE=(SRC=192.0.2.0/24)(DST=dbsvr)(SRV=*)(ACT=accept)
        (ACTION_LIST=(AUT=off)(MCT=120)(MIT=30))
      (RULE=(SRC=192.0.2.0/24)(DST=proxysvr)(SRV=cmon)(ACT=accept)))
    (PARAMETER_LIST=
      (LOG_LEVEL=SUPPORT)
      (TRACING=on)
      (MAX_GATEWAY_PROCESSES=8)
      (MIN_GATEWAY_PROCESSES=3)))

======================================================================
[3단계] 문법 검증: CMCTL로 기동 시도 -> 괄호 오류 -> 수정
======================================================================

- CMCTL을 대화형으로 실행하고 cman01을 관리 대상으로 지정
[oracle@proxysvr admin]$ cmctl

CMCTL for Linux: Version 19.0.0.0.0 - Production on 22-JUL-2026 13:52:07

Copyright (c) 1996, 2019, Oracle.  All rights reserved.

Welcome to CMCTL, type "help" for information.

CMCTL> administer cman01
Current instance cman01 is not yet started
Connections refer to (address=(protocol=tcp)(host=proxysvr)(port=1521)).
The command completed successfully.

- (실수의 결과) 기동을 시도하니 cman.ora 파싱 단계에서 괄호 짝 오류로 실패
CMCTL:cman01> startup
Starting Oracle Connection Manager instance cman01. Please wait...
TNS-04012: Unable to start Oracle Connection Manager instance.
TNS-04099: The configuration information for the instance was not found.
TNS-04061: cman.ora contains an error in the RULE_LIST parameter.

- 원인: RULE_LIST의 첫 번째 RULE에서 ACTION_LIST 뒤 닫는 괄호가 하나 부족하여
-   두 번째 RULE이 첫 RULE 안에 잘못 포함됨. CMCTL을 나가 파일을 수정한다.
CMCTL:cman01> exit

- 첫 RULE의 ACTION_LIST 뒤에 닫는 괄호 ')' 를 하나 보완하여 다시 작성 (괄호 짝을 맞춤)
[oracle@proxysvr admin]$ cat > cman.ora <<'EOF'
cman01=
  (CONFIGURATION=
    (ADDRESS=(PROTOCOL=tcp)(HOST=proxysvr)(PORT=1521))
    (RULE_LIST=
      (RULE=(SRC=192.0.2.0/24)(DST=dbsvr)(SRV=*)(ACT=accept)
        (ACTION_LIST=(AUT=off)(MCT=120)(MIT=30)))
      (RULE=(SRC=192.0.2.0/24)(DST=proxysvr)(SRV=cmon)(ACT=accept)))
    (PARAMETER_LIST=
      (LOG_LEVEL=SUPPORT)
      (TRACING=on)
      (MAX_GATEWAY_PROCESSES=8)
      (MIN_GATEWAY_PROCESSES=3)))
EOF

- [정리]
-   · cman.ora는 'CMAN이름=(CONFIGURATION=(ADDRESS=)(RULE_LIST=)(PARAMETER_LIST=))' 구조.
-   · ADDRESS(필수)=수신 프로토콜/호스트/포트, RULE_LIST=접근 규칙, PARAMETER_LIST=동작 파라미터.
-   · 괄호 짝/들여쓰기가 곧 문법이다. 샘플 복사 후 수정하고, CMCTL 기동으로 즉시 검증한다.
