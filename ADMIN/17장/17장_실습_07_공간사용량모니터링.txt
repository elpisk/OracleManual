[2단계] 테이블스페이스별 사용률(%) 계산
======================================================================

SYS@cdb1> select df.tablespace_name,
  2         round(df.total_mb,1) as total_mb,
  3         round(df.total_mb - nvl(fs.free_mb,0),1) as used_mb,
  4         round(100*(df.total_mb - nvl(fs.free_mb,0))/df.total_mb,1) as pct_used
  5  from (select tablespace_name, sum(bytes)/1024/1024 total_mb
  6        from dba_data_files group by tablespace_name) df
  7  left join (select tablespace_name, sum(bytes)/1024/1024 free_mb
  8        from dba_free_space group by tablespace_name) fs
  9    on df.tablespace_name = fs.tablespace_name
 10  order by pct_used desc;

TABLESPACE_NAME   TOTAL_MB   USED_MB   PCT_USED
----------------- -------- --------- ----------
SYSTEM               280.0     268.4       95.9
SYSAUX               420.0     360.5       85.8
USERS                  5.0       1.3       26.0

[3단계] 자동 확장 고려한 '최대 용량' 대비 사용률
======================================================================

- AUTOEXTEND ON인 경우 진짜 여유는 MAXBYTES 기준으로 봐야 정확
SYS@cdb1> select tablespace_name,
  2         sum(bytes)/1024/1024 as cur_mb,
  3         sum(decode(autoextensible,'YES',maxbytes,bytes))/1024/1024 as max_mb,
  4         autoextensible
  5  from   dba_data_files
  6  group  by tablespace_name, autoextensible
  7  order  by tablespace_name;

TABLESPACE_NAME    CUR_MB     MAX_MB  AUT
---------------- -------- ---------- ----
SYSAUX              420.0    32768.0  YES
SYSTEM              280.0    32768.0  YES
USERS                 5.0      500.0  YES

======================================================================
[4단계] 특정 테이블스페이스가 가득 차는 상황 재현 후 자동 확장 확인
======================================================================

- USERS를 작게 만들고(자동확장 off) 대량 삽입으로 공간 부족 유발
SYS@cdb1> alter database datafile
  2  '/u01/app/oracle/oradata/CDB1/salespdb/users01.dbf'
  3  autoextend off;

Database altered.

SYS@cdb1> create table hr.fill_demo (id number, pad char(500))
  2  segment creation immediate tablespace users;

Table created.

SYS@cdb1> insert into hr.fill_demo
  2  select level, 'x' from dual connect by level <= 100000;
insert into hr.fill_demo
*
ERROR at line 1:
ORA-01653: unable to extend table HR.FILL_DEMO by 128 in tablespace USERS

- 원인: 자동확장을 꺼서 데이터 파일이 더 늘지 못함 -> 익스텐트 확장 실패
-   자동 확장을 다시 켜고 상한(MAXSIZE)을 지정해 해결
SYS@cdb1> alter database datafile
  2  '/u01/app/oracle/oradata/CDB1/salespdb/users01.dbf'
  3  autoextend on next 10m maxsize 500m;

Database altered.

SYS@cdb1> insert into hr.fill_demo
  2  select level, 'x' from dual connect by level <= 100000;

100000 rows created.

SYS@cdb1> commit;

Commit complete.

[6단계] 정리 및 원복

- [정리]
-   사용률 = (DBA_DATA_FILES 총량 - DBA_FREE_SPACE 빈공간) / 총량
-   AUTOEXTEND ON이면 MAXBYTES 기준으로 진짜 여유 판단
-   부족 시: 데이터 파일 추가 또는 AUTOEXTEND ON + MAXSIZE 로 선제 대응
