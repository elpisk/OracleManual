======================================================================
[3단계] 익스텐트 관점: DBA_EXTENTS (연속 블록의 묶음)
======================================================================

- 세그먼트를 구성하는 익스텐트들의 시작 블록/크기 확인
-   AUTOALLOCATE라 세그먼트가 커질수록 익스텐트 크기가 커짐(64KB -> 1MB)
SYS@cdb1> select extent_id, file_id, block_id, blocks,
  2         bytes/1024 as kb
  3  from   dba_extents
  4  where  owner='HR' and segment_name='SEG_DEMO'
  5  order  by extent_id
  6  fetch first 8 rows only;

 EXTENT_ID    FILE_ID   BLOCK_ID     BLOCKS       KB
---------- ---------- ---------- ---------- --------
         0          7        128          8       64
         1          7        136          8       64
         2          7        144          8       64
...
         7          7        256        128     1024

- 익스텐트 '내부' 블록은 연속(BLOCK_ID ~ BLOCK_ID+BLOCKS-1)이라는 점 확인
-   서로 다른 익스텐트는 반드시 인접하지는 않음

======================================================================
[4단계] 블록 관점: 익스텐트가 블록으로 구성됨을 계산으로 확인
======================================================================

- (실수) 블록당 바이트를 파라미터 조회 없이 임의로 4096으로 가정해 계산 -> 값이 안 맞음
SYS@cdb1> select blocks, blocks*4096/1024/1024 as guess_mb
  2  from   dba_segments
  3  where  owner='HR' and segment_name='SEG_DEMO';

    BLOCKS   GUESS_MB
---------- ----------
       640       2.50

- 원인: 이 DB의 블록 크기는 4KB가 아니라 8KB. 실제 블록 크기로 다시 계산
SYS@cdb1> select blocks,
  2         blocks*(select value from v$parameter
  3                 where name='db_block_size')/1024/1024 as real_mb
  4  from   dba_segments
  5  where  owner='HR' and segment_name='SEG_DEMO';

    BLOCKS    REAL_MB
---------- ----------
       640       5.00

- 5.00 MB = DBA_SEGMENTS.MB 와 일치 -> 세그먼트=익스텐트합, 익스텐트=연속블록합 확인

======================================================================
[5단계] 정리 및 실습 객체 삭제
======================================================================

- 세그먼트/익스텐트/블록의 포함 관계를 한 화면으로 재확인
SYS@cdb1> select 'segment' lvl, count(*) cnt from dba_segments
  2  where owner='HR' and segment_name='SEG_DEMO'
  3  union all
  4  select 'extent', count(*) from dba_extents
  5  where owner='HR' and segment_name='SEG_DEMO';

LVL            CNT
-------- ----------
segment          1
extent          19

- [정리] 1개의 세그먼트 = 19개 익스텐트, 각 익스텐트 = 연속된 블록들의 묶음
SYS@cdb1> drop table hr.seg_demo purge;

Table dropped.
