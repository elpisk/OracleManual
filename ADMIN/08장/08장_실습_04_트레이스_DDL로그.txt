======================================================================
[1단계] 현재 세션의 기본 트레이스 파일 경로 확인
======================================================================

- V$DIAG_INFO 의 'Default Trace File' 이 현재 세션이 쓰는 트레이스 파일 경로
SYS@cdb1> set linesize 120
SYS@cdb1> col value format a70
SYS@cdb1> select value from v$diag_info where name = 'Default Trace File';

VALUE
----------------------------------------------------------------------
/u01/app/oracle/diag/rdbms/cdb1/cdb1/trace/cdb1_ora_12345.trc

- 백그라운드 프로세스 트레이스 파일명에는 프로세스명이 포함됨(예: cdb1_dbw0_..., cdb1_lgwr_...)
SYS@cdb1> host ls /u01/app/oracle/diag/rdbms/cdb1/cdb1/trace/ | grep -E "dbw0|lgwr|pmon" | head
cdb1_dbw0_11990.trc
cdb1_lgwr_11994.trc
cdb1_pmon_11980.trc

======================================================================
[2단계] DDL 로깅 활성화 전 상태 확인
======================================================================

SYS@cdb1> show parameter enable_ddl_logging

NAME                                 TYPE        VALUE
------------------------------------ ----------- ------------------------------
enable_ddl_logging                   boolean     FALSE

======================================================================
[3단계] DDL 로깅 활성화 (즉시 + 지속)
======================================================================

- (실수) 불리언 파라미터에 잘못된 문자열 값을 지정
SYS@cdb1> alter system set enable_ddl_logging = YES scope=both;
alter system set enable_ddl_logging = YES scope=both
*
ERROR at line 1:
ORA-00096: invalid value YES for parameter enable_ddl_logging, must be from
among false, true, off, on

- 원인: boolean 파라미터는 TRUE/FALSE(또는 ON/OFF)만 허용. 올바른 값으로 재시도
SYS@cdb1> alter system set enable_ddl_logging = TRUE scope=both;

System altered.

SYS@cdb1> show parameter enable_ddl_logging

NAME                                 TYPE        VALUE
------------------------------------ ----------- ------------------------------
enable_ddl_logging                   boolean     TRUE

======================================================================
[4단계] 테스트용 DDL 실행 후 로그 기록 확인
======================================================================

- 테스트용 사용자 생성 후 삭제 (DDL 두 건 발생)
SYS@cdb1> create user app_user identified by "Oracle_123" ;

User created.

SYS@cdb1> drop user app_user;

User dropped.

- 텍스트 DDL 로그 확인: 타임스탬프 + DDL 문이 그대로 기록됨
SYS@cdb1> host more /u01/app/oracle/diag/rdbms/cdb1/cdb1/log/ddl_cdb1.log
Mon Jul 27 10:09:51 2026
create user app_user identified by *
Mon Jul 27 10:10:07 2026
drop user app_user

- XML 형식 DDL 로그도 동일 정보를 담고 있음 (.../log/ddl/log.xml)
SYS@cdb1> host ls /u01/app/oracle/diag/rdbms/cdb1/cdb1/log/ddl/
log.xml

======================================================================
[5단계] 실습 정리 — DDL 로깅 원복
======================================================================

- 라이선스(Lifecycle Management Pack)와 로그 증가를 고려해 실습 후 비활성화
SYS@cdb1> alter system set enable_ddl_logging = FALSE scope=both;

System altered.

- [정리]
-   트레이스 파일 경로는 V$DIAG_INFO('Default Trace File')로 확인, 백그라운드 트레이스명엔 프로세스명 포함
-   ENABLE_DDL_LOGGING=TRUE 로 DDL 이력 기록(XML log.xml + 텍스트 ddl_<sid>.log)
-   boolean 파라미터는 TRUE/FALSE/ON/OFF 만 허용(ORA-00096 주의), 활성화 전 라이선스 확인
SYS@cdb1> exit
[oracle@dbsvr ~]$
