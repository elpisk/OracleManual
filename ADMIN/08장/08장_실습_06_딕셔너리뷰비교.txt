======================================================================
[1단계] 데이터 딕셔너리 탐색 (DICTIONARY / DICT_COLUMNS)
======================================================================

- 이름에 'TABLESPACE' 가 들어간 딕셔너리 객체 검색
SYS@cdb1> col table_name format a22
SYS@cdb1> col comments   format a55
SYS@cdb1> select table_name, comments from dictionary
  2  where table_name like '%TABLESPACES'
  3  and table_name like 'DBA%';

TABLE_NAME             COMMENTS
---------------------- -------------------------------------------------------
DBA_TABLESPACES        Description of all tablespaces in the database
DBA_TABLESPACE_GROUPS  Description of all tablespace groups

======================================================================
[2단계] USER_ vs ALL_ vs DBA_ 범위 비교 (테이블 개수로 확인)
======================================================================

- 현재 사용자(SYS)가 소유한 테이블 수 (USER_)
SYS@cdb1> select count(*) as user_tables from user_tables;

USER_TABLES
-----------
       1043

- 현재 사용자가 접근 권한을 가진 테이블 수 (ALL_) — USER_ 보다 크거나 같음
SYS@cdb1> select count(*) as all_tables from all_tables;

ALL_TABLES
----------
       1180

- 이 컨테이너(루트)의 모든 테이블 수 (DBA_) — ALL_ 보다 크거나 같음
SYS@cdb1> select count(*) as dba_tables from dba_tables;

DBA_TABLES
----------
       1180

- 해석: USER_ ⊆ ALL_ ⊆ DBA_ 의 포함 관계. 넓은 뷰일수록 더 많은 행을 보여 줌

======================================================================
[3단계] 권한이 없는 사용자는 DBA_ 뷰를 볼 수 없음 (일반 계정 시나리오)
======================================================================

- HR PDB 로 전환 후 일반 사용자로 접속하여 확인
SYS@cdb1> alter session set container = hrpdb;

Session altered.

SYS@cdb1> connect hr/hr@localhost:1521/hrpdb
Connected.

- (실수) 일반 사용자가 DBA_ 뷰 조회 시도
HR@hrpdb> select count(*) from dba_tables;
select count(*) from dba_tables
                     *
ERROR at line 1:
ORA-00942: table or view does not exist

- 원인: DBA_ 뷰는 DBA 권한(SELECT ANY DICTIONARY / SELECT_CATALOG_ROLE 등)이 있어야 조회 가능
-        일반 사용자는 USER_ 또는 ALL_ 뷰를 사용해야 함
HR@hrpdb> select count(*) from user_tables;

  COUNT(*)
----------
         7

HR@hrpdb> select count(*) from all_tables;

  COUNT(*)
----------
        58

======================================================================
[4단계] CDB_ vs DBA_ 비교 (루트에서 컨테이너를 가로지르는 조회)
======================================================================

- 다시 루트로 SYSDBA 접속
HR@hrpdb> connect / as sysdba
Connected.
SYS@cdb1> alter session set container = cdb$root;

Session altered.

- CDB_ 뷰: 모든 PDB 의 테이블스페이스를 CON_ID 로 구분해 한 번에 조회
SYS@cdb1> col tablespace_name format a18
SYS@cdb1> select con_id, tablespace_name, contents
  2  from cdb_tablespaces
  3  where tablespace_name in ('SYSTEM','USERS')
  4  order by con_id, tablespace_name;

    CON_ID TABLESPACE_NAME    CONTENTS
---------- ------------------ ---------
         1 SYSTEM             PERMANENT
         3 SYSTEM             PERMANENT
         3 USERS              PERMANENT
         4 SYSTEM             PERMANENT
         4 USERS              PERMANENT

- 특정 PDB 로 전환하면 DBA_ 뷰는 그 컨테이너 하나만 보여 줌
SYS@cdb1> alter session set container = salespdb;

Session altered.

SYS@cdb1> select tablespace_name, contents from dba_tablespaces
  2  where tablespace_name in ('SYSTEM','USERS') order by tablespace_name;

TABLESPACE_NAME    CONTENTS
------------------ ---------
SYSTEM             PERMANENT
USERS              PERMANENT

- 해석: CDB_ = CDB 전체(모든 PDB, CON_ID 구분), DBA_ = 현재 컨테이너 하나

- [정리]
-   범위: USER_(소유) ⊆ ALL_(접근가능) ⊆ DBA_(한 컨테이너 전체) ⊆ CDB_(CDB 전체)
-   권한: USER_/ALL_ 은 모든 사용자, DBA_/CDB_ 는 DBA 권한 필요(ORA-00942 주의)
-   딕셔너리 탐색은 DICTIONARY(DICT)/DICT_COLUMNS 로 뷰 이름과 컬럼을 검색
