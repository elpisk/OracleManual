======================================================================
[1단계] SHOW PARAMETER 로 파라미터 조회 (이름에 특정 단어 포함)
======================================================================

- 이름에 'sga'가 포함된 파라미터의 NAME/TYPE/VALUE 확인
SYS@cdb1> show parameter sga

NAME                                 TYPE        VALUE
------------------------------------ ----------- ------------------------------
allow_group_access_to_sga            boolean     FALSE
sga_max_size                         big integer 2G
sga_min_size                         big integer 0
sga_target                           big integer 2G
unified_audit_sga_queue_size         integer     1048576

- (실수) 파라미터 이름 철자를 잘못 입력 -> 아무 행도 나오지 않음
SYS@cdb1> show parameter sgaa

- 원인: 'sgaa'가 이름에 포함된 파라미터가 없어 결과가 비어 있음. 올바른 단어로 재조회
SYS@cdb1> show parameter processes

NAME                                 TYPE        VALUE
------------------------------------ ----------- ------------------------------
aq_tm_processes                      integer     1
db_writer_processes                  integer     1
processes                            integer     320

======================================================================
[2단계] V$PARAMETER 로 세밀 조회 (SHOW PARAMETER 로는 불가능한 조건/조인)
======================================================================

- 변경 특성 세 컬럼을 함께 확인: 세션/시스템/PDB 변경 가능 여부
SYS@cdb1> select name, isses_modifiable, issys_modifiable, ispdb_modifiable
  2  from v$parameter
  3  where name in ('nls_date_format','sga_target','processes')
  4  order by name;

NAME              ISSES_MODIFIABLE  ISSYS_MODIFIABLE  ISPDB_MODIFIABLE
----------------- ----------------- ----------------- -----------------
nls_date_format   TRUE              FALSE             TRUE
processes         FALSE             FALSE             FALSE
sga_target        FALSE             IMMEDIATE         FALSE

- 해석: nls_date_format=세션 레벨 변경 가능, sga_target=시스템 즉시 변경 가능,
-        processes=정적 파라미터(재시작 필요)

- 기본 파라미터 중 관리자가 명시적으로 바꾼(기본값이 아닌) 항목만 조회
SYS@cdb1> select name, value from v$parameter
  2  where isbasic = 'TRUE' and isdefault = 'FALSE'
  3  order by name;

NAME                      VALUE
------------------------- ----------------------------------------
audit_trail               DB
compatible                19.0.0
control_files             /u01/app/oracle/oradata/CDB1/control01.ctl
db_name                   cdb1
sga_target                2147483648

======================================================================
[3단계] ALTER SESSION 으로 '내 세션만' 변경
======================================================================

- 현재 세션의 날짜 표시 형식을 보기 좋게 변경 (세션 레벨 파라미터)
SYS@cdb1> alter session set nls_date_format = 'DD-MON-YYYY HH24:MI:SS';

Session altered.

- 변경 확인: 이 세션에서만 유효 (다른 세션에는 영향 없음)
SYS@cdb1> select sysdate from dual;

SYSDATE
--------------------
27-JUL-2026 09:07:41

======================================================================
[4단계] ALTER SYSTEM 으로 '인스턴스 전체' 변경 (즉시 적용 파라미터)
======================================================================

- 변경 전 현재 값 기록
SYS@cdb1> show parameter open_cursors

NAME                                 TYPE        VALUE
------------------------------------ ----------- ------------------------------
open_cursors                         integer     300

- open_cursors 는 즉시 변경 가능(IMMEDIATE). 메모리+SPFILE 동시 반영
SYS@cdb1> alter system set open_cursors = 400 scope=both;

System altered.

- 변경 확인 (즉시 반영됨)
SYS@cdb1> show parameter open_cursors

NAME                                 TYPE        VALUE
------------------------------------ ----------- ------------------------------
open_cursors                         integer     400

- (실습 정리) 원래 값으로 복원 (실습 후 되돌리는 습관)
SYS@cdb1> alter system set open_cursors = 300 scope=both;

System altered.

- [정리]
-   SHOW PARAMETER = 이름 포함 검색(간편), V$PARAMETER = 조건/조인(세밀)
-   ALTER SESSION = 내 세션만, ALTER SYSTEM = 인스턴스 전체
-   변경 가능 여부는 ISSES_/ISSYS_/ISPDB_MODIFIABLE 로 판단
