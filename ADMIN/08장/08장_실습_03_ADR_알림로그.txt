======================================================================
[1단계] ADR base 위치를 결정하는 파라미터 확인
======================================================================

- DIAGNOSTIC_DEST 가 ADR base 를 지정 (미지정 시 ORACLE_BASE, 없으면 $ORACLE_HOME/log)
SYS@cdb1> show parameter diagnostic_dest

NAME                                 TYPE        VALUE
------------------------------------ ----------- ------------------------------
diagnostic_dest                      string      /u01/app/oracle

======================================================================
[2단계] V$DIAG_INFO 로 ADR 구조와 주요 경로 확인
======================================================================

SYS@cdb1> set linesize 120
SYS@cdb1> col name format a22
SYS@cdb1> col value format a70
SYS@cdb1> select name, value from v$diag_info;

NAME                   VALUE
---------------------- ----------------------------------------------------------------------
Diag Enabled           TRUE
ADR Base               /u01/app/oracle
ADR Home               /u01/app/oracle/diag/rdbms/cdb1/cdb1
Diag Trace             /u01/app/oracle/diag/rdbms/cdb1/cdb1/trace
Diag Alert             /u01/app/oracle/diag/rdbms/cdb1/cdb1/alert
Diag Incident          /u01/app/oracle/diag/rdbms/cdb1/cdb1/incident
Diag Cdump             /u01/app/oracle/diag/rdbms/cdb1/cdb1/cdump
Default Trace File     /u01/app/oracle/diag/rdbms/cdb1/cdb1/trace/cdb1_ora_12345.trc

8 rows selected.

- 해석: ADR home = <base>/diag/rdbms/<db_id>/<instance_id>
-        텍스트 알림 로그(alert_SID.log)는 Diag Trace 디렉터리에 위치

======================================================================
[3단계] OS 셸에서 알림 로그 파일 확인
======================================================================

SYS@cdb1> host

- (실수) trace 가 아닌 alert 디렉터리에서 alert_cdb1.log 를 찾으려 함
[oracle@dbsvr ~]$ ls /u01/app/oracle/diag/rdbms/cdb1/cdb1/alert/alert_cdb1.log
ls: cannot access '/u01/app/oracle/diag/rdbms/cdb1/cdb1/alert/alert_cdb1.log': No such file or directory

- 원인: alert 디렉터리에는 XML 로그(log.xml)만 있고, 텍스트 알림 로그는 trace 디렉터리에 있음
[oracle@dbsvr ~]$ ls /u01/app/oracle/diag/rdbms/cdb1/cdb1/alert/
log.xml

- 올바른 위치(trace)에서 텍스트 알림 로그 확인
[oracle@dbsvr ~]$ ls -l /u01/app/oracle/diag/rdbms/cdb1/cdb1/trace/alert_cdb1.log
-rw-r----- 1 oracle oinstall 148213 Jul 27 09:14 /u01/app/oracle/diag/rdbms/cdb1/cdb1/trace/alert_cdb1.log

- 알림 로그의 마지막 부분 확인 (최근 기동/관리 작업 메시지)
[oracle@dbsvr ~]$ tail -n 12 /u01/app/oracle/diag/rdbms/cdb1/cdb1/trace/alert_cdb1.log

======================================================================
[4단계] ADRCI 유틸리티로 알림 로그 조회
======================================================================

SYS@cdb1> host adrci

ADRCI: Release 19.0.0.0.0 - Production on Mon Jul 27 09:45:12 2026
Copyright (c) 1982, 2019, Oracle and/or its affiliates.  All rights reserved.
ADR base = "/u01/app/oracle"

- 등록된 ADR home 목록 확인
adrci> show homes
ADR Homes:
diag/rdbms/cdb1/cdb1

- 조사할 home 지정
adrci> set homepath diag/rdbms/cdb1/cdb1

- 알림 로그의 마지막 10줄 조회 (텍스트 에디터 없이 ADRCI 로 확인 가능)
adrci> show alert -tail 10
...
2026-07-27T09:14:31.884301+09:00
Completed: ALTER DATABASE OPEN

adrci> exit

- [정리]
-   ADR base 는 DIAGNOSTIC_DEST 로 지정, 구조는 V$DIAG_INFO 로 확인
-   텍스트 알림 로그(alert_SID.log)는 'trace' 디렉터리(Diag Trace), XML 로그는 'alert' 디렉터리
-   조회는 OS 텍스트 도구(tail/less) 또는 ADRCI(show alert) 로 가능
SYS@cdb1> exit
