- 루트 컨테이너 확인
SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

======================================================================
[1단계] 언두 파라미터/모드 관련 뷰
======================================================================

- V$PARAMETER로 언두 핵심 파라미터 확인
SYS@cdb1> select name, value from v$parameter
  2  where name in ('undo_management','undo_tablespace','undo_retention','temp_undo_enabled')
  3  order by name;

NAME                 VALUE
-------------------- ----------
temp_undo_enabled    FALSE
undo_management      AUTO
undo_retention       900
undo_tablespace      UNDOTBS2

- DATABASE_PROPERTIES로 로컬 언두 모드 여부 확인
SYS@cdb1> select property_name, property_value
  2  from   database_properties where property_name='LOCAL_UNDO_ENABLED';

PROPERTY_NAME          PROPERTY_VALUE
---------------------- ---------------
LOCAL_UNDO_ENABLED     TRUE

======================================================================
[2단계] 언두 테이블스페이스/세그먼트 관련 뷰
======================================================================

- DBA_TABLESPACES: 언두 TS와 보존 보장(RETENTION) 상태
SYS@cdb1> select tablespace_name, contents, status, retention
  2  from   dba_tablespaces where contents='UNDO';

TABLESPACE_NAME      CONTENTS  STATUS    RETENTION
-------------------- --------- --------- -----------
UNDOTBS2             UNDO      ONLINE    NOGUARANTEE

- CDB_TABLESPACES: 컨테이너별 언두 TS(로컬 언두 모드에서 PDB마다 존재)
SYS@cdb1> select con_id, tablespace_name from cdb_tablespaces
  2  where contents='UNDO' order by con_id;

    CON_ID TABLESPACE_NAME
---------- ---------------
         1 UNDOTBS2
         3 UNDOTBS1
         4 UNDOTBS1

- DBA_ROLLBACK_SEGS: 자동 생성된 언두 세그먼트
SYS@cdb1> select count(*) seg_cnt, status from dba_rollback_segs
  2  where tablespace_name='UNDOTBS2' group by status;

   SEG_CNT STATUS
---------- ----------------
        10 ONLINE

======================================================================
[3단계] 언두 사용량/범주 관련 뷰
======================================================================

- (실수 -> 오류 -> 재시도) 존재하지 않는 뷰 이름으로 조회
SYS@cdb1> select * from v$undo_stat;
select * from v$undo_stat
              *
ERROR at line 1:
ORA-00942: table or view does not exist

- 원인: 뷰 이름 오타. 올바른 이름은 V$UNDOSTAT (언더스코어 없음)
SYS@cdb1> select to_char(begin_time,'HH24:MI') b, undoblks, txncount,
  2         maxquerylen, tuned_undoretention, ssolderrcnt, nospaceerrcnt
  3  from   v$undostat order by begin_time desc fetch first 3 rows only;

B      UNDOBLKS TXNCOUNT MAXQUERYLEN TUNED_UNDORETENTION SSOLDERRCNT NOSPACEERRCNT
----- --------- -------- ----------- ------------------- ----------- -------------
16:00       120       35         210                 900           0             0
15:50        95       28         180                 900           0             0
15:40       210       52          95                 900           0             0

- DBA_UNDO_EXTENTS: 언두 범주별(ACTIVE/UNEXPIRED/EXPIRED) 공간
SYS@cdb1> select tablespace_name, status, sum(bytes)/1024/1024 mb
  2  from   dba_undo_extents group by tablespace_name, status order by 1,2;

TABLESPACE_NAME      STATUS          MB
-------------------- ---------- --------
UNDOTBS2             ACTIVE          8.0
UNDOTBS2             EXPIRED       290.0
UNDOTBS2             UNEXPIRED      52.0

- 해석: ACTIVE=미커밋, UNEXPIRED=커밋됐으나 보존 기간 내, EXPIRED=재사용 가능.

======================================================================
[4단계] 트랜잭션/세션별 언두 사용 및 임시 언두 뷰
======================================================================

- V$TRANSACTION: 현재 활성 트랜잭션별 언두 사용량
SYS@cdb1> select s.sid, t.used_ublk, t.used_urec, t.status
  2  from   v$transaction t join v$session s on t.addr=s.taddr;

no rows selected

- 해석: 현재 활성 트랜잭션이 없음(모두 커밋/롤백됨). DML 진행 중이면 행이 나타남.

- V$TEMP_UNDO_STAT: 임시 언두 사용 통계 (임시 언두 사용 시)
SYS@cdb1> select count(*) from v$temp_undo_stat;

  COUNT(*)
----------
        24
