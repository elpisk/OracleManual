-- 15장 실습_06: PDB 언플러그(UNPLUG INTO) 후 다른 CDB 에 플러그인

======================================================================
[1단계] 소스 CDB1 에서 PDB1 언플러그 준비
======================================================================

- 소스 CDB1 루트로 접속
[oracle@dbsvr ~]$ export ORACLE_SID=cdb1
[oracle@dbsvr ~]$ sqlplus / as sysdba

SYS@cdb1> select name, open_mode from v$pdbs where name='PDB1';

NAME       OPEN_MODE
---------- ----------
PDB1       READ WRITE

======================================================================
[2단계] (실수 -> 오류 -> 재시도) 열린 상태에서 언플러그 시도
======================================================================

- (실수) PDB 가 열린 채로 언플러그 시도
SYS@cdb1> alter pluggable database pdb1 unplug into '/tmp/pdb1.xml';
alter pluggable database pdb1 unplug into '/tmp/pdb1.xml'
*
ERROR at line 1:
ORA-65025: Pluggable database PDB1 is not closed on all instances.

- 원인: 언플러그하려면 PDB 가 모든 인스턴스에서 닫혀 있어야 함. 닫고 재시도
SYS@cdb1> alter pluggable database pdb1 close immediate;

Pluggable database altered.

======================================================================
[3단계] PDB1 을 XML 매니페스트로 언플러그
======================================================================

SYS@cdb1> alter pluggable database pdb1 unplug into '/tmp/pdb1.xml';

Pluggable database altered.

- 언플러그된 PDB 의 STATUS 는 UNPLUGGED
SYS@cdb1> select pdb_name, status from cdb_pdbs where pdb_name='PDB1';

PDB_NAME   STATUS
---------- ----------
PDB1       UNPLUGGED

======================================================================
[4단계] 소스 CDB1 에서 등록 제거 (데이터 파일 보존)
======================================================================

- 데이터 파일을 그대로 두고(KEEP DATAFILES) CDB1 의 PDB 등록만 제거
SYS@cdb1> drop pluggable database pdb1 keep datafiles;

Pluggable database dropped.

SYS@cdb1> select pdb_name from cdb_pdbs where pdb_name='PDB1';

no rows selected

======================================================================
[5단계] 대상 CDB2 에서 호환성 점검 후 플러그
======================================================================

- 대상 CDB2 루트로 전환
[oracle@dbsvr ~]$ export ORACLE_SID=cdb2
[oracle@dbsvr ~]$ sqlplus / as sysdba

- 플러그 전 호환성 사전 점검
SYS@cdb2> set serveroutput on
SYS@cdb2> begin
  2    if dbms_pdb.check_plug_compatibility('/tmp/pdb1.xml') then
  3      dbms_output.put_line('COMPATIBLE');
  4    else
  5      dbms_output.put_line('NOT COMPATIBLE');
  6    end if;
  7  end;
  8  /
COMPATIBLE

PL/SQL procedure successfully completed.

- NOCOPY 로 원래 위치의 데이터 파일을 그대로 사용해 플러그
SYS@cdb2> create pluggable database pdb1 using '/tmp/pdb1.xml' nocopy;

Pluggable database created.

======================================================================
[6단계] PDB1 열기 및 위반 확인
======================================================================

SYS@cdb2> alter pluggable database pdb1 open;

Pluggable database altered.

SYS@cdb2> select pdb_name, status from cdb_pdbs where pdb_name='PDB1';

PDB_NAME   STATUS
---------- ----------
PDB1       NORMAL

- 플러그 후 위반 사항이 없는지 확인
SYS@cdb2> select name, cause, type, message
  2  from pdb_plug_in_violations where name='PDB1';

no rows selected

- [정리 완료] 언플러그/플러그:
-   UNPLUG INTO 'xml' (닫힘 필수) -> DROP ... KEEP DATAFILES
-   -> USING 'xml' NOCOPY/COPY/MOVE -> OPEN -> PDB_PLUG_IN_VIOLATIONS 확인
SYS@cdb2> exit
Disconnected from Oracle Database 19c Enterprise Edition Release 19.0.0.0.0
