-- 15장 실습_08: Hot Cloning 으로 운영 중인 원격 PDB 복제 및 증분 갱신(REFRESH)

======================================================================
[사전] 전제조건 확인 - 두 CDB 모두 로컬 언두 모드
======================================================================

- 대상 CDB2 루트로 접속
SYS@cdb2> select property_value from database_properties
  2  where property_name='LOCAL_UNDO_ENABLED';

PROPERTY_VALUE
--------------------
TRUE

======================================================================
[1단계] 원본 CDB1 로의 데이터베이스 링크 생성
======================================================================

SYS@cdb2> create database link link_cdb1
  2  connect to c##clone identified by "Welcome_1234"
  3  using 'cdb1';

Database link created.

- 링크 검증
SYS@cdb2> select name from v$database@link_cdb1;

NAME
---------
CDB1

======================================================================
[2단계] (실수 -> 오류 -> 재시도) 리프레셔블 카피를 READ WRITE 로 열기
======================================================================

- 운영 중(READ WRITE)인 원격 PDB1 을 60분 간격 리프레셔블 카피로 생성
-   원본을 멈추지 않는 hot clone 이 핵심
SYS@cdb2> create pluggable database pdb3 from pdb1@link_cdb1
  2  refresh mode every 60 minutes
  3  create_file_dest = '/u02/oradata/CDB2/pdb3';

Pluggable database created.

- (실수) 리프레셔블 카피를 READ WRITE 로 열려고 시도
SYS@cdb2> alter pluggable database pdb3 open read write;
alter pluggable database pdb3 open read write
*
ERROR at line 1:
ORA-65341: cannot open pluggable database in read/write mode

- 원인: 리프레셔블 카피는 갱신 대상이므로 READ ONLY 로만 열 수 있음
SYS@cdb2> alter pluggable database pdb3 open read only;

Pluggable database altered.

- 리프레시 모드 확인
SYS@cdb2> select pdb_name, refresh_mode, refresh_interval
  2  from cdb_pdbs where pdb_name='PDB3';

PDB_NAME   REFRESH_MODE   REFRESH_INTERVAL
---------- -------------- ----------------
PDB3       AUTO                         60

======================================================================
[3단계] 수동 증분 리프레시 (닫고 -> REFRESH -> 다시 열기)
======================================================================

- 즉시 최신 데이터로 갱신하려면 수동 REFRESH
SYS@cdb2> alter pluggable database pdb3 close immediate;

Pluggable database altered.

SYS@cdb2> alter pluggable database pdb3 refresh;

Pluggable database altered.

SYS@cdb2> alter pluggable database pdb3 open read only;

Pluggable database altered.

======================================================================
[4단계] 독립 PDB 로 승격 (REFRESH MODE NONE)
======================================================================

- 갱신을 멈추고 READ WRITE 가능한 독립 PDB 로 전환
SYS@cdb2> alter pluggable database pdb3 close immediate;
Pluggable database altered.

SYS@cdb2> alter pluggable database pdb3 refresh mode none;

Pluggable database altered.

- 이제 READ WRITE 로 열 수 있음
SYS@cdb2> alter pluggable database pdb3 open read write;

Pluggable database altered.

SYS@cdb2> select pdb_name, refresh_mode from cdb_pdbs where pdb_name='PDB3';

PDB_NAME   REFRESH_MODE
---------- --------------
PDB3       NONE

- [정리 완료] Hot Cloning / 리프레셔블 카피:
-   FROM pdb@link REFRESH MODE EVERY n MINUTES (원본 운영 중 복제)
-   READ ONLY 전용, 수동 REFRESH = CLOSE->REFRESH->OPEN READ ONLY
-   REFRESH MODE NONE 으로 독립 PDB 승격
SYS@cdb2> exit
Disconnected from Oracle Database 19c Enterprise Edition Release 19.0.0.0.0
