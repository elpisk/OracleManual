- 대상 CDB(cdb1) 루트로 접속
[oracle@dbsvr ~]$ export ORACLE_SID=cdb1
[oracle@dbsvr ~]$ sqlplus / as sysdba

SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

======================================================================
[1단계] 플러그 전 호환성 사전 점검 (CHECK_PLUG_COMPATIBILITY)
======================================================================

- 앞 실습(15장_실습_02)에서 만든 /tmp/ORCL.xml 로 호환성 검사
SYS@cdb1> set serveroutput on
SYS@cdb1> declare
  2    compat boolean;
  3  begin
  4    compat := dbms_pdb.check_plug_compatibility(
  5                pdb_descr_file => '/tmp/ORCL.xml');
  6    dbms_output.put_line(case when compat then 'COMPATIBLE'
  7                              else 'NOT COMPATIBLE' end);
  8  end;
  9  /
COMPATIBLE

PL/SQL procedure successfully completed.

======================================================================
[2단계] non-CDB 를 PDB2 로 플러그 (데이터 파일 복사)
======================================================================

- USING 절로 XML 지정, COPY 로 데이터 파일을 새 위치에 복사
SYS@cdb1> create pluggable database pdb2 using '/tmp/ORCL.xml'
  2  copy
  3  file_name_convert = ('/u01/oradata/ORCL', '/u02/oradata/CDB1/pdb2');

Pluggable database created.

- 플러그 직후 STATUS 확인 (아직 변환 전)
SYS@cdb1> select pdb_name, status from cdb_pdbs where pdb_name = 'PDB2';

PDB_NAME   STATUS
---------- ----------
PDB2       NEW

======================================================================
[3단계] (실수 -> 오류 -> 재시도) 변환 스크립트 없이 OPEN 시도
======================================================================

- (실수) noncdb_to_pdb.sql 을 실행하지 않고 곧바로 열기
SYS@cdb1> alter pluggable database pdb2 open;

Warning: PDB altered with errors.

- 위반 사항 확인: non-CDB 딕셔너리가 정리되지 않아 오류 발생
SYS@cdb1> select type, message from pdb_plug_in_violations
  2  where name = 'PDB2' and status = 'PENDING';

TYPE     MESSAGE
-------- ----------------------------------------------------------
ERROR    PDB plugged in is a non-CDB, requires noncdb_to_pdb.sql
         be run.

- 원인: non-CDB 플러그는 반드시 noncdb_to_pdb.sql 을 OPEN 전에 실행해야 함.
-   PDB 를 닫고 스크립트를 실행한다.
SYS@cdb1> alter pluggable database pdb2 close immediate;

Pluggable database altered.
