-- 15장 실습_02: DBMS_PDB.DESCRIBE 로 non-CDB 를 언플러그 PDB 로 변환

======================================================================
[사전] 원본 non-CDB(ORCL) 접속 및 버전 확인
======================================================================

- non-CDB ORCL 에 SYSDBA 로 접속 (별도 인스턴스)
[oracle@dbsvr ~]$ export ORACLE_SID=orcl
[oracle@dbsvr ~]$ sqlplus / as sysdba

SYS@orcl> select name, cdb from v$database;

NAME      CDB
--------- ---
ORCL      NO

- DBMS_PDB 기법은 non-CDB 가 12c 이상이어야 함 (버전 확인)
SYS@orcl> select version_full from v$instance;

VERSION_FULL
--------------------
19.3.0.0.0

======================================================================
[1단계] (실수 -> 오류 -> 재시도) READ WRITE 상태에서 DESCRIBE 시도
======================================================================

- 현재 오픈 모드 확인
SYS@orcl> select open_mode from v$database;

OPEN_MODE
--------------------
READ WRITE

- (실수) 읽기 전용으로 전환하지 않고 DESCRIBE 실행
SYS@orcl> exec dbms_pdb.describe('/tmp/ORCL.xml');
BEGIN dbms_pdb.describe('/tmp/ORCL.xml'); END;
*
ERROR at line 1:
ORA-65022: The database must be open in READ ONLY mode to describe a
non-CDB for plug in.
ORA-06512: at "SYS.DBMS_PDB", line 1

- 원인: DESCRIBE 는 일관된 스냅샷이 필요하므로 non-CDB 를 READ ONLY 로 열어야 함
SYS@orcl> shutdown immediate
Database closed.
Database dismounted.
ORACLE instance shut down.

SYS@orcl> startup open read only
ORACLE instance started.
Database mounted.
Database opened.

======================================================================
[2단계] DBMS_PDB.DESCRIBE 로 XML 매니페스트 생성
======================================================================

- 미래 PDB 를 기술하는 XML 파일 생성 (데이터 파일 목록 포함)
SYS@orcl> begin
  2    dbms_pdb.describe(pdb_descr_file => '/tmp/ORCL.xml');
  3  end;
  4  /

PL/SQL procedure successfully completed.

- non-CDB 의 데이터 파일 목록 확인 (이 파일들이 XML 에 기술됨)
SYS@orcl> select file_name from dba_data_files order by file_id;

FILE_NAME
--------------------------------------------------
/u01/oradata/ORCL/system01.dbf
/u01/oradata/ORCL/sysaux01.dbf
/u01/oradata/ORCL/undotbs01.dbf
/u01/oradata/ORCL/users01.dbf

======================================================================
[3단계] 생성된 XML 파일 확인 (쉘)
======================================================================

- XML 파일이 정상 생성되었는지 확인
SYS@orcl> host ls -l /tmp/ORCL.xml
-rw-r--r-- 1 oracle oinstall  8452 Aug  4 10:22 /tmp/ORCL.xml

- XML 내부에 데이터 파일 경로가 기록되었는지 일부 확인
SYS@orcl> host grep -i path /tmp/ORCL.xml | head -2
      <path>/u01/oradata/ORCL/system01.dbf</path>
      <path>/u01/oradata/ORCL/sysaux01.dbf</path>

- [정리] 이제 XML(/tmp/ORCL.xml) + 데이터 파일들이 '언플러그된 PDB' 를 구성함.
-   다음 실습(15장_실습_03)에서 이 XML 로 대상 CDB 에 PDB2 로 플러그하고
-   noncdb_to_pdb.sql 을 실행한다.
