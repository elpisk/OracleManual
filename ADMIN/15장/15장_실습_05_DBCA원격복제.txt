-- 15장 실습_05: DBCA 를 이용한 원격 PDB 복제 (-createFromRemotePDB)

======================================================================
[1단계] 원격 CDB(CDB1) 에 복제용 공통 사용자 준비
======================================================================

- 원격 CDB1 루트에서 DB 링크가 사용할 공통 사용자 생성/권한 부여
SYS@cdb1> create user c##remote_user identified by "Welcome_1234"
  2  container=all;

User created.

SYS@cdb1> grant create session, create pluggable database
  2  to c##remote_user container=all;

Grant succeeded.

- 원격 CDB1 이 로컬 언두 + ARCHIVELOG 인지 확인 (전제조건)
SYS@cdb1> archive log list
Database log mode              Archive Mode
Automatic archival             Enabled

SYS@cdb1> select property_value from database_properties
  2  where property_name='LOCAL_UNDO_ENABLED';

PROPERTY_VALUE
--------------------
TRUE

======================================================================
[2단계] (실수 -> 오류 -> 재시도) 권한 누락 상태로 DBCA 실행
======================================================================

- (실수) c##remote_user 에 CREATE PLUGGABLE DATABASE 를 주지 않은 채 실행했다고 가정
[oracle@dbsvr ~]$ export ORACLE_SID=CDB2
[oracle@dbsvr ~]$ dbca -silent -createPluggableDatabase \
>   -createFromRemotePDB -remotePDBName PDB1 \
>   -remoteDBConnString CDB1 \
>   -sysDBAUserName system -sysDBAPassword Welcome_1234 \
>   -remoteDBSYSDBAUserName SYS -remoteDBSYSDBAUserPassword Welcome_1234 \
>   -dbLinkUsername c##remote_user -dbLinkUserPassword Welcome_1234 \
>   -sourceDB CDB2 -pdbName PDB2

[FATAL] ORA-65094: invalid local user or role name  /  privilege check failed
       ORA-01031: insufficient privileges on remote database

- 원인: 원격 사용자에 CREATE PLUGGABLE DATABASE 권한이 없음.
-   [1단계]에서 권한을 부여했으므로 재실행한다.

======================================================================
[3단계] DBCA Silent 모드로 원격 PDB1 -> 로컬 CDB2 의 PDB2 복제
======================================================================

[oracle@dbsvr ~]$ dbca -silent -createPluggableDatabase \
>   -createFromRemotePDB \
>   -remotePDBName PDB1 \
>   -remoteDBConnString CDB1 \
>   -sysDBAUserName system \
>   -sysDBAPassword Welcome_1234 \
>   -remoteDBSYSDBAUserName SYS \
>   -remoteDBSYSDBAUserPassword Welcome_1234 \
>   -dbLinkUsername c##remote_user \
>   -dbLinkUserPassword Welcome_1234 \
>   -sourceDB CDB2 -pdbName PDB2

======================================================================
[4단계] 대상 CDB2 에서 복제된 PDB2 검증
======================================================================

[oracle@dbsvr ~]$ export ORACLE_SID=CDB2
[oracle@dbsvr ~]$ sqlplus / as sysdba

SYS@cdb2> select pdb_name, status, con_id from cdb_pdbs
  2  where pdb_name = 'PDB2';

PDB_NAME   STATUS   CON_ID
---------- -------- ----------
PDB2       NORMAL            3

- 오픈 모드 확인 (DBCA 가 자동으로 열어 둠)
SYS@cdb2> select name, open_mode from v$pdbs where name='PDB2';

NAME       OPEN_MODE
---------- ----------
PDB2       READ WRITE

- DBCA 가 생성한 DB 링크 확인 (작업 후 정리 대상)
SYS@cdb2> select db_link from cdb_db_links where con_id=1
  2  and db_link like '%PDB%';

DB_LINK
--------------------
DBCA_PDB2_LINK.REGRESS.RDBMS.DEV.US.ORACLE.COM

- [정리 완료] DBCA -createFromRemotePDB 내부 단계:
-   링크 확인(있으면 삭제) -> 링크 생성 -> 원격 PDB 로부터 생성
-   -> MOUNT 검증 -> 열기. 전제: 원격 로컬언두+ARCHIVELOG, 원격 사용자 권한
SYS@cdb2> exit
Disconnected from Oracle Database 19c Enterprise Edition Release 19.0.0.0.0
