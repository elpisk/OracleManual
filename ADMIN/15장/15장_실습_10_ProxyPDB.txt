-- 15장 실습_10: Proxy PDB 생성 및 원격 PDB 조회(CONTAINERS 절)

======================================================================
[사전] 전제조건 - 두 CDB 로컬 언두 + ARCHIVELOG
======================================================================

- 로컬 CDB1 루트로 접속 (프록시 PDB 를 담을 CDB)
SYS@cdb1> select property_value from database_properties
  2  where property_name='LOCAL_UNDO_ENABLED';

PROPERTY_VALUE
--------------------
TRUE

======================================================================
[1단계] 원격 CDB2 로의 데이터베이스 링크 생성
======================================================================

- (원격 CDB2 세션) 링크가 사용할 공통 사용자 준비
SYS@cdb2> create user c##proxy identified by "Welcome_1234" container=all;
User created.
SYS@cdb2> grant create session, create pluggable database
  2  to c##proxy container=all;
Grant succeeded.

- (로컬 CDB1) 프록시 PDB 를 담을 CDB 루트에 DB 링크 생성
SYS@cdb1> create database link link_cdb2
  2  connect to c##proxy identified by "Welcome_1234"
  3  using 'cdb2';

Database link created.

======================================================================
[2단계] (실수 -> 오류 -> 재시도) AS PROXY 절 누락
======================================================================

- (실수) AS PROXY 절 없이 생성하면 일반 복제가 되어 의도와 다름
SYS@cdb1> create pluggable database pxpdb1 from pdb1@link_cdb2;

Pluggable database created.

- 확인: IS_PROXY_PDB 가 NO -> 프록시가 아니라 일반 복제본이 만들어짐
SYS@cdb1> select pdb_name, is_proxy_pdb from cdb_pdbs
  2  where pdb_name='PXPDB1';

PDB_NAME   IS_PROXY_PDB
---------- ------------
PXPDB1     NO

- 원인: AS PROXY 절이 빠짐. 잘못 만든 PDB 를 삭제하고 재생성
SYS@cdb1> drop pluggable database pxpdb1 including datafiles;

Pluggable database dropped.

======================================================================
[3단계] AS PROXY 절로 프록시 PDB 정상 생성
======================================================================

- CDB2 의 pdb1 을 가리키는 대리자로 생성
SYS@cdb1> create pluggable database pxpdb1 as proxy
  2  from pdb1@link_cdb2;

Pluggable database created.

- 이번에는 IS_PROXY_PDB 가 YES
SYS@cdb1> select pdb_name, is_proxy_pdb from cdb_pdbs
  2  where pdb_name='PXPDB1';

PDB_NAME   IS_PROXY_PDB
---------- ------------
PXPDB1     YES

======================================================================
[4단계] 프록시 PDB 열기 및 원격 데이터 조회
======================================================================

- 프록시 PDB 에 접속해 열기
SYS@cdb1> alter session set container = pxpdb1;
Session altered.

SYS@pxpdb1> alter pluggable database pxpdb1 open;

Pluggable database altered.

- 프록시 PDB 에서 실행 -> 실제로는 원격 pdb1 에서 실행되어 결과 반환
SYS@pxpdb1> select * from app.c;

        ID VAL
---------- --------------------
         1 REMOTE-ROW-1
         2 REMOTE-ROW-2

======================================================================
[5단계] CONTAINERS() 절로 CDB 를 가로지르는 통합 조회
======================================================================

- 애플리케이션 루트에서 로컬 PDB + 프록시(원격) PDB 데이터를 한 번에 집계
SYS@cdb1> alter session set container = cdb$root;
Session altered.

SYS@cdb1> select sum(revenue) revenue, year, CDB$NAME, CON$NAME
  2  from   containers(sales_data)
  3  where  year = 2014
  4  group by year, CDB$NAME, CON$NAME
  5  order by CON$NAME;

   REVENUE  YEAR CDB$NAME  CON$NAME
---------- ----- --------- ---------
  10000000  2014 CDB1      DOLLS
  20000000  2014 CDB2      DOODLES
  15000000  2014 CDB1      ROBOTS

- 해석: CONTAINERS() 가 로컬(ROBOTS/DOLLS)과 프록시를 통한 원격(DOODLES)을 통합 집계

- [정리 완료] Proxy PDB:
-   AS PROXY FROM pdb@link (데이터 이동 없이 참조), IS_PROXY_PDB=YES 로 확인
-   프록시 PDB 내 문장은 원격 프록시된 PDB 에서 실행
-   CONTAINERS() 절로 여러 CDB 분산 데이터를 통합 조회
SYS@cdb1> exit
Disconnected from Oracle Database 19c Enterprise Edition Release 19.0.0.0.0
