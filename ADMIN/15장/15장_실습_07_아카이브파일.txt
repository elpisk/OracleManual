-- 15장 실습_07: 아카이브 파일(.pdb) 을 이용한 PDB 언플러그/플러그

======================================================================
[1단계] 소스 CDB1 에서 PDB2 를 단일 아카이브(.pdb)로 언플러그
======================================================================

- 소스 CDB1 루트로 접속
SYS@cdb1> select name, open_mode from v$pdbs where name='PDB2';

NAME       OPEN_MODE
---------- ----------
PDB2       READ WRITE

- 언플러그 전 반드시 닫기
SYS@cdb1> alter pluggable database pdb2 close immediate;

Pluggable database altered.

======================================================================
[2단계] (실수 -> 오류 -> 재시도) 존재하지 않는 디렉터리로 언플러그
======================================================================

- (실수) 존재하지 않는 경로에 아카이브 생성 시도
SYS@cdb1> alter pluggable database pdb2 unplug into '/nodir/pdb2.pdb';
alter pluggable database pdb2 unplug into '/nodir/pdb2.pdb'
*
ERROR at line 1:
ORA-65170: Directory /nodir does not exist or is not writable.

- 원인: 대상 디렉터리가 없거나 쓰기 불가. 유효한 경로로 재시도
SYS@cdb1> host mkdir -p /u03/archive
SYS@cdb1> alter pluggable database pdb2 unplug into '/u03/archive/pdb2.pdb';

Pluggable database altered.

- 확장자 .pdb 로 지정하면 XML + 모든 데이터 파일이 하나의 압축 파일로 생성됨
SYS@cdb1> host ls -lh /u03/archive/pdb2.pdb
-rw-r--r-- 1 oracle oinstall 512M Aug  4 11:05 /u03/archive/pdb2.pdb

- 언플러그 후 소스에서 등록 제거 (데이터 파일 보존)
SYS@cdb1> drop pluggable database pdb2 keep datafiles;

Pluggable database dropped.

======================================================================
[3단계] 아카이브 파일 하나만 대상 서버로 전송 (쉘)
======================================================================

- 여러 파일 대신 .pdb 하나만 전송하면 됨 (누락 위험 없음)
SYS@cdb1> host scp /u03/archive/pdb2.pdb oracle@dbsvr2:/u03/archive/
pdb2.pdb                              100%  512MB   85.3MB/s   00:06

======================================================================
[4단계] 대상 CDB2 에서 .pdb 하나로 플러그
======================================================================

- 대상 CDB2 루트로 접속
[oracle@dbsvr2 ~]$ export ORACLE_SID=cdb2
[oracle@dbsvr2 ~]$ sqlplus / as sysdba

- 아카이브에서 직접 호환성 테스트 (추출 불필요)
SYS@cdb2> set serveroutput on
SYS@cdb2> begin
  2    if dbms_pdb.check_plug_compatibility('/u03/archive/pdb2.pdb') then
  3      dbms_output.put_line('COMPATIBLE');
  4    end if;
  5  end;
  6  /
COMPATIBLE

PL/SQL procedure successfully completed.

- .pdb 하나만 USING 절에 지정 (XML 을 따로 풀 필요 없음)
SYS@cdb2> create pluggable database pdb_new using '/u03/archive/pdb2.pdb';

Pluggable database created.

SYS@cdb2> alter pluggable database pdb_new open;

Pluggable database altered.

- 결과 확인
SYS@cdb2> select pdb_name, status from cdb_pdbs where pdb_name='PDB_NEW';

PDB_NAME   STATUS
---------- ----------
PDB_NEW    NORMAL

- [정리 완료] 아카이브 파일(.pdb):
-   UNPLUG INTO '....pdb' = XML+데이터파일 일체형 압축, 플러그는 .pdb 하나만 USING
-   이점: 이동 단위 1개, 압축 절약, 경로 누락 실수 방지
SYS@cdb2> exit
Disconnected from Oracle Database 19c Enterprise Edition Release 19.0.0.0.0
