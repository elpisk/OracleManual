-- 15장 실습_01: CREATE PLUGGABLE DATABASE ... FROM 으로 동일 CDB 내 PDB 복제

- 루트로 접속해 현재 컨테이너 확인
SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

- 언두 모드 확인 (로컬 언두 권장 - 19c 기본)
SYS@cdb1> select property_value from database_properties
  2  where property_name = 'LOCAL_UNDO_ENABLED';

PROPERTY_VALUE
--------------------
TRUE

======================================================================
[1단계] 원본 PDB(PDB1) 상태 확인
======================================================================

- 복제 원본이 될 PDB1의 상태와 오픈 모드 확인
SYS@cdb1> select pdb_name, status, open_mode
  2  from cdb_pdbs c join v$pdbs v on c.pdb_id = v.con_id
  3  where pdb_name = 'PDB1';

PDB_NAME   STATUS   OPEN_MODE
---------- -------- ----------
PDB1       NORMAL   READ WRITE

======================================================================
[2단계] (실수 -> 오류 -> 재시도) 원본이 READ WRITE인 채 복제 시도
======================================================================

- (실수) 원본을 안정화하지 않고 곧바로 복제 시도
SYS@cdb1> create pluggable database pdb3 from pdb1
  2  create_file_dest = '/u02/oradata/CDB1/pdb3';
create pluggable database pdb3 from pdb1
*
ERROR at line 1:
ORA-65081: database or pluggable database is not open in read only or
read write consistent mode

- 원인: 로컬 복제 시 원본은 READ ONLY 이거나 닫혀 있어야 일관 사본을 얻음.
-   (환경에 따라 hot 클론이 가능하나, 여기서는 안전하게 READ ONLY 로 전환)
SYS@cdb1> alter pluggable database pdb1 close immediate;

Pluggable database altered.

SYS@cdb1> alter pluggable database pdb1 open read only;

Pluggable database altered.

======================================================================
[3단계] OMF 방식으로 PDB1 -> PDB3 복제
======================================================================

- CREATE_FILE_DEST 절로 이 문장에 한해 대상 디렉터리 지정(OMF)
SYS@cdb1> create pluggable database pdb3 from pdb1
  2  create_file_dest = '/u02/oradata/CDB1/pdb3';

Pluggable database created.

- 생성 직후 STATUS 는 NEW, OPEN_MODE 는 MOUNTED
SYS@cdb1> select pdb_name, status from cdb_pdbs where pdb_name = 'PDB3';

PDB_NAME   STATUS
---------- ----------
PDB3       NEW

======================================================================
[4단계] PDB3 열기 및 원본 복귀
======================================================================

SYS@cdb1> alter pluggable database pdb3 open;

Pluggable database altered.

- 원본 PDB1 을 다시 READ WRITE 로 복귀
SYS@cdb1> alter pluggable database pdb1 open read write force;

Pluggable database altered.

- 복제 결과 확인: PDB3 는 자체 서비스 이름을 가진 정상 PDB
SYS@cdb1> select pdb_name, status, con_id from cdb_pdbs order by con_id;

PDB_NAME   STATUS   CON_ID
---------- -------- ----------
PDB$SEED   NORMAL            2
PDB1       NORMAL            3
PDB3       NORMAL            4

======================================================================
[5단계] NO DATA 절로 구조만 복제 (참고)
======================================================================

- 데이터 없이 메타데이터만 복제하는 예 (빈 테스트 PDB)
SYS@cdb1> create pluggable database pdb3_meta from pdb1
  2  create_file_dest = '/u02/oradata/CDB1/pdb3_meta'
  3  no data;

Pluggable database created.

SYS@cdb1> alter pluggable database pdb3_meta open;

Pluggable database altered.

- [정리] 실습에서 만든 PDB 삭제 (데이터 파일 포함)
SYS@cdb1> alter pluggable database pdb3_meta close immediate;

Pluggable database altered.

SYS@cdb1> drop pluggable database pdb3_meta including datafiles;

Pluggable database dropped.

- [정리 완료] 동일 CDB 내 복제 = CREATE PLUGGABLE DATABASE 새PDB FROM 원본PDB
-   위치지정 = OMF(CREATE_FILE_DEST/DB_CREATE_FILE_DEST) 또는 non-OMF(FILE_NAME_CONVERT)
-   구조만 복제 = NO DATA 절
SYS@cdb1> exit
Disconnected from Oracle Database 19c Enterprise Edition Release 19.0.0.0.0
