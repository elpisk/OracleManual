-- 15장 실습_04: 데이터베이스 링크를 이용한 원격 non-CDB/PDB 복제

- 대상(로컬) CDB(cdb1) 루트로 접속
SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

======================================================================
[1단계] 원격 non-CDB(ORCL) 를 READ ONLY 로 설정
======================================================================

- (원격 서버 세션) 복제 중 변경을 막기 위해 원본을 읽기 전용으로
SYS@orcl> shutdown immediate
Database closed.
ORACLE instance shut down.
SYS@orcl> startup open read only
Database opened.

======================================================================
[2단계] 로컬 CDB 에 원격 접속용 데이터베이스 링크 생성
======================================================================

- 원격 non-CDB 로 연결되는 DB 링크 생성
SYS@cdb1> create database link link_orcl
  2  connect to system identified by "Welcome_1234"
  3  using 'orcl';

Database link created.

- (실수 -> 오류 -> 재시도) 링크 검증: 원격 접속 테스트
SYS@cdb1> select name from v$database@link_orcl;
select name from v$database@link_orcl
                            *
ERROR at line 1:
ORA-12154: TNS:could not resolve the connect identifier specified

- 원인: tnsnames.ora 에 'orcl' 서비스가 등록되지 않음. 등록 후 재시도
SYS@cdb1> host tnsping orcl
...
OK (10 msec)

- 링크 재검증 (이제 원격 이름 조회 성공)
SYS@cdb1> select name, cdb from v$database@link_orcl;

NAME      CDB
--------- ---
ORCL      NO

======================================================================
[3단계] 원격 non-CDB 전체를 NON$CDB 로 지목해 복제
======================================================================

- FROM NON$CDB@링크 로 non-CDB 전체를 PDB_ORCL 로 복제
SYS@cdb1> create pluggable database pdb_orcl
  2  from NON$CDB@link_orcl
  3  create_file_dest = '/u02/oradata/CDB1/pdb_orcl';

Pluggable database created.

- 복제 직후 상태 확인 (아직 변환 전)
SYS@cdb1> select pdb_name, status from cdb_pdbs where pdb_name='PDB_ORCL';

PDB_NAME    STATUS
----------- ----------
PDB_ORCL    NEW

======================================================================
[4단계] non-CDB 였으므로 noncdb_to_pdb.sql 실행
======================================================================

- PDB_ORCL 컨텍스트로 전환 후 변환 스크립트 실행
SYS@cdb1> alter session set container = pdb_orcl;

Session altered.

SYS@pdb_orcl> @$ORACLE_HOME/rdbms/admin/noncdb_to_pdb.sql
...
DOC> noncdb_to_pdb.sql completed

- 루트 복귀 후 열기
SYS@pdb_orcl> alter session set container = cdb$root;
Session altered.

SYS@cdb1> alter pluggable database pdb_orcl open;

Pluggable database altered.

SYS@cdb1> select pdb_name, status from cdb_pdbs where pdb_name='PDB_ORCL';

PDB_NAME    STATUS
----------- ----------
PDB_ORCL    NORMAL

======================================================================
[5단계] 원격 PDB 복제 (참고: NON$CDB 대신 PDB 이름 사용)
======================================================================

- 원격 CDB 의 salespdb 를 복제하는 경우 FROM 절 형태
SYS@cdb1> create pluggable database sales_copy
  2  from salespdb@link_remote_cdb
  3  create_file_dest = '/u02/oradata/CDB1/sales_copy';

Pluggable database created.

- [정리] 원격 원본을 다시 READ WRITE 로 복귀 (원격 세션)
SYS@orcl> shutdown immediate
SYS@orcl> startup

- [정리 완료] DB 링크 복제:
-   non-CDB 전체 = FROM NON$CDB@link, 원격 PDB = FROM PDB이름@link
-   원본은 READ ONLY 로 두었다가 복제 후 복귀, non-CDB 는 noncdb_to_pdb.sql 필요
SYS@cdb1> exit
Disconnected from Oracle Database 19c Enterprise Edition Release 19.0.0.0.0
