================================================================================
 29장 실습 01 — 사전 예방적 유지관리(Proactive Maintenance) 인프라 개요 확인
 목표: AWR 스냅샷 설정 확인 → 자동 유지관리 작업의 큰 그림(3계층) 조회로 확인
       (수집=AWR → 진단=ADDM/Advisor → 자동 실행=Automated Maintenance Tasks)
 환경: CDB=cdb1, PDB=pdb1, OS=Oracle Linux 7 (oracle 계정)
================================================================================

-- [1] CDB 루트에 SYS로 접속한다. 자동 유지관리 인프라는 대부분 CDB 차원의 객체다.
$ sqlplus sys@cdb1 as sysdba

SQL*Plus: Release 19.0.0.0.0 - Production on Wed Aug 12 21:40:03 2026
Copyright (c) 1982, 2019, Oracle.  All rights reserved.

Connected to:
Oracle Database 19c Enterprise Edition Release 19.0.0.0.0 - Production

SYS@cdb1> -- 현재 컨테이너가 루트(CDB$ROOT)인지 확인한다.
SYS@cdb1> SHOW CON_NAME

CON_NAME
------------------------------
CDB$ROOT

--------------------------------------------------------------------------------
-- [2] 사전 예방적 관리의 토대인 AWR 스냅샷 설정(간격/보존)을 확인한다.
--------------------------------------------------------------------------------
SYS@cdb1> -- SNAP_INTERVAL 은 스냅샷 간격, RETENTION 은 보존 기간이다.
SYS@cdb1> SELECT snap_interval, retention, topnsql
  2       FROM  dba_hist_wr_control;

SNAP_INTERVAL        RETENTION            TOPNSQL
-------------------- -------------------- ----------
+00000 01:00:00.0    +00008 00:00:00.0    DEFAULT

-- 기본값: 스냅샷 1시간 간격, 8일 보존. 이 정보가 ADDM/어드바이저 진단의 근거가 된다.

SYS@cdb1> -- MMON 이 AWR 스냅샷을 자동 생성한다. 최근 스냅샷 몇 개를 확인한다.
SYS@cdb1> SELECT snap_id, begin_interval_time
  2       FROM  dba_hist_snapshot
  3      ORDER BY snap_id DESC FETCH FIRST 3 ROWS ONLY;

   SNAP_ID BEGIN_INTERVAL_TIME
---------- ---------------------------------
       412 12-AUG-26 09.00.14.000 PM
       411 12-AUG-26 08.00.11.000 PM
       410 12-AUG-26 07.00.08.000 PM

--------------------------------------------------------------------------------
-- [3] (오류 → 원인 → 수정) 오타난 뷰 이름으로 조회하다 실패한다.
--------------------------------------------------------------------------------
SYS@cdb1> -- 자동 유지관리 작업 목록을 보려다 뷰 이름을 DBA_AUTO_TASK_CLIENT 로 잘못 입력했다.
SYS@cdb1> SELECT client_name, status FROM dba_auto_task_client;
SELECT client_name, status FROM dba_auto_task_client
                                *
ERROR at line 1:
ORA-00942: table or view does not exist

SYS@cdb1> -- 원인 파악: 뷰 이름에 밑줄 위치가 틀렸다. 올바른 이름은 DBA_AUTOTASK_CLIENT 이다.
SYS@cdb1> --   (AUTOTASK 는 한 단어, AUTO_TASK 가 아니다)
SYS@cdb1> SELECT view_name FROM dba_views
  2       WHERE view_name LIKE 'DBA_AUTOTASK%' ORDER BY view_name;

VIEW_NAME
------------------------------
DBA_AUTOTASK_CLIENT
DBA_AUTOTASK_CLIENT_HISTORY
DBA_AUTOTASK_JOB_HISTORY
DBA_AUTOTASK_OPERATION
DBA_AUTOTASK_SCHEDULE
DBA_AUTOTASK_TASK
DBA_AUTOTASK_WINDOW_CLIENTS
DBA_AUTOTASK_WINDOW_HISTORY

8 rows selected.

SYS@cdb1> -- 수정: 올바른 뷰 이름으로 다시 조회한다.
SYS@cdb1> SELECT client_name, status FROM dba_autotask_client ORDER BY client_name;

CLIENT_NAME                        STATUS
---------------------------------- ----------
auto optimizer stats collection    ENABLED
auto space advisor                 ENABLED
sql tuning advisor                 ENABLED

--------------------------------------------------------------------------------
-- [4] 3계층 인프라를 한눈에 확인한다: 수집(AWR) → 진단(ADDM) → 자동 실행.
--------------------------------------------------------------------------------
SYS@cdb1> -- 진단 계층: ADDM 이 만들어 낸 최근 태스크를 확인한다.
SYS@cdb1> SELECT task_name, status, execution_start
  2       FROM  dba_advisor_tasks
  3      WHERE advisor_name = 'ADDM'
  4      ORDER BY execution_start DESC FETCH FIRST 3 ROWS ONLY;

TASK_NAME                      STATUS      EXECUTION_START
------------------------------ ----------- ---------------------
ADDM:1234567890_1_412          COMPLETED   12-AUG-26 09.00.20 PM
ADDM:1234567890_1_411          COMPLETED   12-AUG-26 08.00.16 PM
ADDM:1234567890_1_410          COMPLETED   12-AUG-26 07.00.13 PM

-- 스냅샷(수집)마다 ADDM(진단)이 자동 실행되고 있음을 확인했다.

--------------------------------------------------------------------------------
-- [정리]
--------------------------------------------------------------------------------
-- 1) 사전 예방적 관리 인프라 = 수집(AWR) → 진단(ADDM/Advisor) → 자동 실행(자동 작업).
-- 2) AWR 기본값: 1시간 간격 스냅샷, 8일 보존. MMON 이 스냅샷을 생성한다.
-- 3) 자동 유지관리 작업은 DBA_AUTOTASK_CLIENT 로 조회한다(AUTOTASK 는 한 단어).
-- 4) 스냅샷마다 ADDM 진단이 자동 수행되어, 자동 작업의 판단 근거가 축적된다.

SYS@cdb1> EXIT
