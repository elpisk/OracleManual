================================================================================
 34장 실습 09 — ASMCMD 유틸리티로 파일/디렉터리 관리
 목표: ASMCMD 로 디스크 그룹을 탐색하고 파일 복사·사용량 확인·디렉터리 관리 등을 수행한다.
       (오류→원인→수정) 잘못된 명령/경로로 인한 오류를 바로잡는다.
 환경: ASM 인스턴스 +ASM, grid 계정
================================================================================

$ asmcmd -p
ASMCMD [+] > lsdg
State    Type    Total_MB  Free_MB  Req_mir_free_MB  Usable_file_MB  Name
MOUNTED  NORMAL     40960    38112             4096           17008  DATA/
MOUNTED  EXTERN     20480    19004                0           19004  FRA/

-- [1] 디스크 목록과 접속 클라이언트를 확인한다.
ASMCMD [+] > lsdsk
Path
/dev/oracleasm/disks/DISK1
/dev/oracleasm/disks/DISK2
...
ASMCMD [+] > lsct DATA
DB_Name  Status     Software_Version  Instance_Name
orcl     CONNECTED  19.0.0.0.0        orcl

--------------------------------------------------------------------------------
-- [2] (오류 → 원인 → 수정) 존재하지 않는 디렉터리로 이동한다.
--------------------------------------------------------------------------------
ASMCMD [+] > cd +DATA/orcl/datafiles
ASMCMD-8001: diskgroup '+DATA/orcl/datafiles' does not exist or is not mounted

-- 원인 파악: 디렉터리 이름 오타(datafiles → datafile).
-- 수정: 올바른 경로로 이동한다.
ASMCMD [+] > cd +DATA/orcl/datafile
ASMCMD [+DATA/orcl/datafile] > ls -l
Type      Redund  Striped  Sys  Name
DATAFILE  MIRROR  COARSE   Y    system.257.1048576001
DATAFILE  MIRROR  COARSE   Y    users.259.1048576789

-- [3] 사용량을 확인한다(du: 미러 포함 사용량).
ASMCMD [+DATA/orcl/datafile] > du
Used_MB      Mirror_used_MB
   4820                9640

--------------------------------------------------------------------------------
-- [4] (오류 → 원인 → 수정) 대상 디렉터리 없이 파일을 복사한다.
--------------------------------------------------------------------------------
ASMCMD [+DATA/orcl/datafile] > cp users.259.1048576789 /backup2/users.dbf
ASMCMD-8018: source or target directory '/backup2' does not exist

-- 원인 파악: 대상 로컬 디렉터리 /backup2 가 없다.
-- 수정: 디렉터리를 만든 뒤 복사한다.
ASMCMD [+DATA/orcl/datafile] > !mkdir -p /backup2
ASMCMD [+DATA/orcl/datafile] > cp users.259.1048576789 /backup2/users.dbf
copying +DATA/orcl/datafile/users.259.1048576789 -> /backup2/users.dbf

-- [5] ASM 내부에 관리용 디렉터리를 만들고 확인한다.
ASMCMD [+DATA/orcl/datafile] > cd +DATA/orcl
ASMCMD [+DATA/orcl] > mkdir archive_alias
ASMCMD [+DATA/orcl] > ls
archive_alias/
controlfile/
datafile/
...

-- 정리: lsdg/lsdsk/lsct 로 저장소를 점검하고, 경로 오타(ASMCMD-8001)와 대상 디렉터리 부재
-- (ASMCMD-8018)를 바로잡아 파일 복사·디렉터리 관리를 완료했다.
ASMCMD [+DATA/orcl] > exit
