================================================================================
 34장 실습 06 — 디스크 그룹 호환성(Compatibility) 속성 설정
 목표: COMPATIBLE.ASM / COMPATIBLE.RDBMS 를 확인·상향하고 비가역성을 이해한다.
       (오류→원인→수정) 호환성을 낮추려는 시도 실패, ASM<RDBMS 제약 위반 오류.
 환경: ASM 인스턴스 +ASM, grid(SYSASM), 디스크 그룹 DGNORM
================================================================================

$ sqlplus / as sysasm

-- [1] 현재 호환성 속성을 확인한다.
SQL> SELECT name, compatibility, database_compatibility FROM v$asm_diskgroup
  2   WHERE name='DGNORM';
NAME    COMPATIBILITY   DATABASE_COMPATIBILITY
------- --------------- ----------------------
DGNORM  19.0.0.0.0      19.0.0.0.0

-- [2] 개별 속성값을 상세히 확인한다.
SQL> SELECT name, value FROM v$asm_attribute a JOIN v$asm_diskgroup g
  2   ON a.group_number=g.group_number
  3   WHERE g.name='DGNORM' AND a.name LIKE 'compatible%';
NAME              VALUE
----------------- ----------
compatible.asm    19.0.0.0.0
compatible.rdbms  19.0.0.0.0

--------------------------------------------------------------------------------
-- [3] (오류 → 원인 → 수정) 호환성을 낮추려 시도한다.
--------------------------------------------------------------------------------
SQL> ALTER DISKGROUP dgnorm SET ATTRIBUTE 'compatible.rdbms'='12.2.0.0';
ALTER DISKGROUP dgnorm SET ATTRIBUTE 'compatible.rdbms'='12.2.0.0'
*
ERROR at line 1:
ORA-15242: could not set attribute compatible.rdbms
ORA-15244: new compatibility setting less than current (19.0.0.0.0)

-- 원인 파악: 호환성 속성은 한 번 올리면 되돌릴 수 없다(비가역). 낮추기 불가.
-- 수정: 낮출 수 없으므로 원래 값을 유지한다. (필요 시 새 디스크 그룹을 만든다.)

--------------------------------------------------------------------------------
-- [4] (오류 → 원인 → 수정) 새 디스크 그룹에서 ASM<RDBMS 제약을 위반해 본다.
--------------------------------------------------------------------------------
SQL> CREATE DISKGROUP dgc EXTERNAL REDUNDANCY
  2    DISK '/dev/oracleasm/disks/DISK15' NAME c_0001
  3    ATTRIBUTE 'compatible.asm'='12.2.0.0',
  4              'compatible.rdbms'='19.0.0.0';
CREATE DISKGROUP dgc EXTERNAL REDUNDANCY
*
ERROR at line 1:
ORA-15283: ASM operation requires compatible.asm of 19.0.0.0.0 or higher

-- 원인 파악: COMPATIBLE.ASM 은 COMPATIBLE.RDBMS 이상이어야 한다(제약 위반).
-- 수정: compatible.asm 을 19.0.0.0 이상으로 맞춘다.
SQL> CREATE DISKGROUP dgc EXTERNAL REDUNDANCY
  2    DISK '/dev/oracleasm/disks/DISK15' NAME c_0001
  3    ATTRIBUTE 'compatible.asm'='19.0.0.0',
  4              'compatible.rdbms'='19.0.0.0';
Diskgroup created.

-- [5] 정리를 위해 실습용 dgc 를 삭제한다.
SQL> DROP DISKGROUP dgc INCLUDING CONTENTS;
Diskgroup dropped.

-- 정리: 호환성 상향은 비가역(ORA-15244)이며 COMPATIBLE.ASM>=RDBMS 제약(ORA-15283)이 있다.
-- 19c 신기능(Flex/파일 그룹/향상된 스크러빙)은 호환성 상향이 전제다.
SQL> EXIT
