================================================================================
 34장 실습 08 — ASM 파일명 규칙 / 별칭(Alias) / 템플릿(Template) 관리
 목표: 완전한 이름과 별칭의 관계를 확인하고, 사용자 정의 템플릿을 추가한다.
       (오류→원인→수정) 이미 존재하는 별칭 생성 시도 오류, 잘못된 템플릿 속성 오류.
 환경: ASM 인스턴스 +ASM, grid(SYSASM), 디스크 그룹 DGNORM
================================================================================

$ sqlplus / as sysasm

-- [1] 시스템 템플릿(파일 유형별 기본 정책)을 확인한다.
SQL> SELECT name, redundancy, stripe, system FROM v$asm_template t
  2   JOIN v$asm_diskgroup g ON t.group_number=g.group_number
  3   WHERE g.name='DGNORM' AND t.name IN ('CONTROLFILE','DATAFILE','ONLINELOG');
NAME         REDUNDANCY  STRIPE  SYSTEM
------------ ----------- ------- ------
CONTROLFILE  HIGH        FINE    Y
DATAFILE     MIRROR      COARSE  Y
ONLINELOG    MIRROR      FINE    Y

-- [2] 파일의 완전한 이름과 별칭을 조회한다.
SQL> SELECT reference_index, alias_index, name FROM v$asm_alias a
  2   JOIN v$asm_diskgroup g ON a.group_number=g.group_number
  3   WHERE g.name='DGNORM' AND rownum<=5;
... users.259.1049 ...

--------------------------------------------------------------------------------
-- [3] (오류 → 원인 → 수정) 사용자 정의 템플릿을 잘못된 속성으로 추가한다.
--------------------------------------------------------------------------------
SQL> ALTER DISKGROUP dgnorm ADD TEMPLATE hot_ctl ATTRIBUTES (SUPER FINE);
ALTER DISKGROUP dgnorm ADD TEMPLATE hot_ctl ATTRIBUTES (SUPER FINE)
                                                        *
ERROR at line 1:
ORA-15304: name "SUPER" is not a valid attribute for a template

-- 원인 파악: 리던던시 키워드는 UNPROTECTED/MIRROR/HIGH 등이어야 한다('SUPER'는 무효).
-- 수정: 올바른 리던던시(HIGH)와 스트라이핑(FINE)으로 다시 추가한다.
SQL> ALTER DISKGROUP dgnorm ADD TEMPLATE hot_ctl ATTRIBUTES (HIGH FINE);
Diskgroup altered.

-- [4] 추가된 사용자 정의 템플릿을 확인한다(SYSTEM=N).
SQL> SELECT name, redundancy, stripe, system FROM v$asm_template t
  2   JOIN v$asm_diskgroup g ON t.group_number=g.group_number
  3   WHERE g.name='DGNORM' AND t.name='HOT_CTL';
NAME     REDUNDANCY  STRIPE  SYSTEM
-------- ----------- ------- ------
HOT_CTL  HIGH        FINE    N

-- [5] 템플릿을 지정해 별칭으로 파일을 만든다(예시).
SQL> ALTER DISKGROUP dgnorm ADD ALIAS '+DGNORM/orcl/hot_ctl.f'
  2    FOR '+DGNORM/orcl/controlfile/current.260.1049';
Diskgroup altered.

-- 정리: 완전한 이름(시스템 생성)과 별칭(사용자 지정)의 관계, 템플릿의 리던던시/스트라이핑
-- 속성을 확인했고, 잘못된 속성명(ORA-15304)을 유효한 값으로 수정했다.
SQL> EXIT
