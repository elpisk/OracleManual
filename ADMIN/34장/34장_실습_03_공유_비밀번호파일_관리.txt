================================================================================
 34장 실습 03 — ASM 공유 비밀번호 파일 생성/관리
 목표: orapwd 로 ASM 비밀번호 파일을 만들고 ASMCMD 의 pwget/pwcopy/pwset 으로
       로컬 파일을 디스크 그룹의 공유 파일로 전환한다.
       (오류→원인→수정) 잘못된 format 옵션과 존재하지 않는 경로 참조 오류.
 환경: ASM 인스턴스 +ASM, grid 계정
================================================================================

--------------------------------------------------------------------------------
-- [1] (오류 → 원인 → 수정) orapwd 를 잘못된 형식 옵션으로 실행한다.
--------------------------------------------------------------------------------
$ orapwd file='+DATA/orapwASM' asm=y format=9 password=Welcome1#
OPW-00028: Invalid command-line argument or missing value: format=9

-- 원인 파악: ASM 공유 비밀번호 파일은 format=12(또는 12.2) 이상이어야 한다.
-- 수정: format=12 로 다시 생성한다.
$ orapwd file='+DATA/orapwASM' asm=y format=12 password=Welcome1#
Enter password for SYS: ********
-- (생성 완료)

-- [2] ASMCMD 로 진입하여 현재 비밀번호 파일 위치를 확인한다.
$ asmcmd
ASMCMD> pwget --asm
+DATA/orapwASM

--------------------------------------------------------------------------------
-- [3] (오류 → 원인 → 수정) 존재하지 않는 로컬 경로를 복사하려 한다.
--------------------------------------------------------------------------------
ASMCMD> pwcopy --asm /u01/app/grid/dbs/orapwASM_missing +DATA/orapwASM_bak
ASMCMD-8002: no orapwd file found in the location '/u01/app/grid/dbs/orapwASM_missing'

-- 원인 파악: 원본 경로에 비밀번호 파일이 없다(파일명 오타).
-- 수정: 실제 로컬 파일 경로를 확인 후 올바른 경로로 복사한다.
ASMCMD> ls -l /u01/app/grid/product/19.0.0/dbs/orapw+ASM
orapw+ASM
ASMCMD> pwcopy --asm /u01/app/grid/product/19.0.0/dbs/orapw+ASM +DATA/orapwASM_bak
copying /u01/app/grid/.../orapw+ASM -> +DATA/orapwASM_bak

-- [4] 인스턴스가 참조할 공유 비밀번호 파일 위치를 등록한다.
ASMCMD> pwset --asm +DATA/orapwASM
ASMCMD> pwget --asm
+DATA/orapwASM

-- [5] 등록된 사용자 조회로 공유 파일이 유효한지 확인한다.
ASMCMD> exit
$ sqlplus / as sysasm
SQL> SELECT username, sysasm FROM v$pwfile_users;
USERNAME   SYSASM
---------- ------
SYS        TRUE

-- 정리: format=12 로 공유 비밀번호 파일을 만들고, 디스크 그룹(+DATA)에 두어
-- 클러스터 노드가 하나의 파일을 공유하도록 구성했다(RAC 인증 불일치 예방).
SQL> EXIT
