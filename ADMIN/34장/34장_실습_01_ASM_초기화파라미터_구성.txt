================================================================================
 34장 실습 01 — ASM 인스턴스 초기화 파라미터 구성
 목표: ASM 인스턴스에 SYSASM으로 접속하여 INSTANCE_TYPE, ASM_DISKGROUPS,
       ASM_DISKSTRING, ASM_POWER_LIMIT 등 핵심 파라미터를 확인·변경한다.
       (오류→원인→수정) 잘못된 SCOPE 지정과 정적 파라미터 변경 오류를 다룬다.
 환경: Grid Infrastructure(단일 노드), ASM 인스턴스 +ASM, grid 계정 사용
================================================================================

$ id grid
uid=54322(grid) gid=54321(oinstall) groups=54321(oinstall),54327(asmadmin),54328(asmdba)

-- grid 계정은 asmadmin(OSASM) 그룹 소속 → OS 인증으로 SYSASM 접속 가능
$ export ORACLE_SID=+ASM
$ sqlplus / as sysasm

SQL*Plus: Release 19.0.0.0.0
Connected to:
Oracle Database 19c Enterprise Edition Release 19.0.0.0.0

-- [1] 인스턴스 유형이 ASM인지 확인한다.
SQL> SHOW PARAMETER instance_type
NAME            TYPE     VALUE
--------------- -------- --------
instance_type   string   asm

-- [2] ASM 관련 파라미터를 한꺼번에 조회한다.
SQL> SHOW PARAMETER asm
NAME                              TYPE     VALUE
--------------------------------- -------- -----------------------------
asm_diskgroups                    string   DATA, FRA
asm_diskstring                    string   /dev/oracleasm/disks/*
asm_power_limit                   integer  1
asm_preferred_read_failure_groups string

--------------------------------------------------------------------------------
-- [3] (오류 → 원인 → 수정) INSTANCE_TYPE 을 동적으로 바꾸려 시도한다.
--------------------------------------------------------------------------------
SQL> ALTER SYSTEM SET instance_type='RDBMS' SCOPE=MEMORY;
ALTER SYSTEM SET instance_type='RDBMS' SCOPE=MEMORY
*
ERROR at line 1:
ORA-02095: specified initialization parameter cannot be modified

-- 원인 파악: INSTANCE_TYPE 은 정적(static) 파라미터라 MEMORY/BOTH 로 즉시 변경 불가.
--            (게다가 ASM 인스턴스의 정체성을 바꾸는 값이므로 실무에서 변경하지 않는다.)
-- 수정: 굳이 바꿔야 한다면 SPFILE 로만 반영하고 인스턴스를 재기동해야 한다. 여기서는 원복.
SQL> -- (변경하지 않고 넘어간다)

--------------------------------------------------------------------------------
-- [4] 리밸런싱 속도(ASM_POWER_LIMIT)는 동적 파라미터다. BOTH 로 변경한다.
--------------------------------------------------------------------------------
SQL> ALTER SYSTEM SET asm_power_limit=4 SCOPE=BOTH;
System altered.

SQL> SHOW PARAMETER asm_power_limit
NAME            TYPE     VALUE
--------------- -------- --------
asm_power_limit integer  4

-- [5] 디스크 검색 문자열을 확인하고, 필요한 경로만 남기도록 좁힌다.
SQL> ALTER SYSTEM SET asm_diskstring='/dev/oracleasm/disks/*' SCOPE=BOTH;
System altered.

-- [6] SPFILE 위치를 확인한다(디스크 그룹에 있어야 노드 간 공유에 유리).
SQL> SHOW PARAMETER spfile
NAME    TYPE     VALUE
------- -------- ------------------------------------------
spfile  string   +DATA/ASM/ASMPARAMETERFILE/registry.253.10

-- [7] 마운트된 디스크 그룹을 확인한다.
SQL> SELECT name, state, type, total_mb, free_mb FROM v$asm_diskgroup;
NAME  STATE     TYPE    TOTAL_MB  FREE_MB
----- --------- ------- --------- --------
DATA  MOUNTED   NORMAL     40960    38120
FRA   MOUNTED   EXTERN     20480    19004

-- 정리: INSTANCE_TYPE(정적)과 ASM_POWER_LIMIT/ASM_DISKSTRING(동적)의 차이를 확인했다.
-- ASM_POWER_LIMIT 은 업무 시간엔 낮게, 유지보수 창에선 높게 조정하는 것이 실무 지침이다.
SQL> EXIT
