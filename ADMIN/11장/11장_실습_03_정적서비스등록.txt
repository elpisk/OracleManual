======================================================================
[3단계] 섹션 이름을 규칙대로 수정 (SID_LIST_SALESPDBS)
======================================================================

- 백업본을 되살린 뒤 올바른 섹션 이름으로 다시 작성
[oracle@dbsvr admin]$ cp listener.ora.bak_20260722 listener.ora
[oracle@dbsvr admin]$ cat >> listener.ora <<'EOF'

SALESPDBS =
  (DESCRIPTION_LIST =
    (DESCRIPTION =
      (ADDRESS = (PROTOCOL = TCP)(HOST = dbsvr)(PORT = 1561))
    )
  )

SID_LIST_SALESPDBS =
  (SID_LIST =
    (SID_DESC =
      (GLOBAL_DBNAME = salespdb.example.com)
      (ORACLE_HOME = /u01/app/oracle/product/19.0.0/dbhome_1)
      (SID_NAME = cdb1)
    )
    (SID_DESC =
      (GLOBAL_DBNAME = hrpdb.example.com)
      (ORACLE_HOME = /u01/app/oracle/product/19.0.0/dbhome_1)
      (SID_NAME = cdb1)
    )
  )
EOF

- 파라미터 의미:
--   GLOBAL_DBNAME = 클라이언트가 접속에 쓸 서비스 이름(도메인까지 정확히 일치해야 함)
--   ORACLE_HOME   = 리스너가 원격 startup 시 사용할 홈 경로
--   SID_NAME      = 서비스를 떠받치는 인스턴스 SID
--   * CDB 환경이라 두 PDB 항목의 SID_NAME이 동일(cdb1)하게 반복됨
