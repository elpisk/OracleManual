-- 11장 실습_04: ALTER SYSTEM REGISTER로 즉시 서비스 등록 실습
--   목표: 리스너를 재시작해 등록 지연(최대 60초)을 재현하고,
--         ALTER SYSTEM REGISTER로 즉시 등록되는 것을 확인한다.
--   주의: 테스트용 CDB에서만 수행. 기본 리스너를 잠시 내렸다 올린다.

--   않았다는 신호다. 최대 60초 기다리거나, 즉시 등록을 강제하면 해결된다.

======================================================================
[3단계] ALTER SYSTEM REGISTER로 즉시 등록 강제
======================================================================

[oracle@dbsvr ~]$ sqlplus / as sysdba

SQL*Plus: Release 19.0.0.0.0 - Production on Wed Jul 22 13:41:20 2026
Version 19.3.0.0.0

Copyright (c) 1982, 2019, Oracle.  All rights reserved.

Connected to:
Oracle Database 19c Enterprise Edition Release 19.0.0.0.0 - Production
Version 19.3.0.0.0

SQL> set sqlprompt "_user'@'_connect_identifier> "

- 실행 위치 확인: 루트에서 실행하면 인스턴스의 모든 서비스(PDB 포함)가 갱신됨
SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

- (실수) 명령 철자 오류 -> 올바른 키워드로 재시도
SYS@cdb1> alter system reguster;
alter system reguster
             *
ERROR at line 1:
ORA-02000: missing REGISTER keyword

- 원인: REGISTER 철자 오류(reguster). 올바르게 다시 실행
SYS@cdb1> alter system register;

System altered.

- 이 명령은 LREG가 다음 폴링을 기다리지 않고 지금 바로 리스너에 등록하게 한다.

- LREG의 마지막 등록 이후 리스너 인식 상태를 알림로그/뷰로 참고 확인

LOCAL LISTENER  dbsvr                1521

- [정리]
--   * 리스너 재시작 직후에는 다음 폴링 주기(최대 60초) 전까지 서비스가 비어 보인다.
--   * 이때 접속하면 ORA-12514(서비스 미등록)이며, ORA-12541(리스너 미도달)과 다르다.
--   * ALTER SYSTEM REGISTER는 60초를 기다리지 않고 즉시 등록을 강제한다.
--   * 루트(CDB$ROOT)에서 실행하면 인스턴스의 모든 서비스(PDB 포함)가 한 번에 갱신된다.
--   * 자동화 스크립트에서는 리스너 기동 직후 헬스체크 전에 이 명령을 넣어 오탐을 막는다.
