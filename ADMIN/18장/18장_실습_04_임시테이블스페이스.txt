======================================================================
[1단계] 임시 테이블스페이스 생성 (TEMPFILE 사용)
======================================================================

- (실수) 임시 테이블스페이스인데 DATAFILE 절을 사용 -> 오류
SYS@cdb1> create temporary tablespace temp_work
  2    datafile '/u01/app/oracle/oradata/CDB1/pdb1/temp_work01.dbf' size 200M;
  datafile '/u01/app/oracle/oradata/CDB1/pdb1/temp_work01.dbf' size 200M
  *
ERROR at line 2:
ORA-25139: invalid option for CREATE TEMPORARY TABLESPACE

- 원인: 임시 테이블스페이스는 DATAFILE이 아니라 TEMPFILE로 구성한다. 수정
SYS@cdb1> create temporary tablespace temp_work
  2    tempfile '/u01/app/oracle/oradata/CDB1/pdb1/temp_work01.dbf' size 200M
  3    autoextend on next 100M maxsize 4G
  4    extent management local uniform size 1M;

Tablespace created.

- 임시 테이블스페이스는 CONTENTS=TEMPORARY로 표시됨
SYS@cdb1> select tablespace_name, contents, extent_management, allocation_type
  2  from   dba_tablespaces where tablespace_name = 'TEMP_WORK';

TABLESPACE_NAME  CONTENTS  EXTENT_MAN ALLOCATIO
---------------- --------- ---------- ---------
TEMP_WORK        TEMPORARY LOCAL      UNIFORM

- 임시 파일은 DBA_TEMP_FILES에서 조회 (DBA_DATA_FILES에는 없음)
SYS@cdb1> select file_name, bytes/1024/1024 as mb, autoextensible
  2  from   dba_temp_files where tablespace_name = 'TEMP_WORK';

FILE_NAME                                                     MB  AUT
------------------------------------------------------------ --- ---
/u01/app/oracle/oradata/CDB1/pdb1/temp_work01.dbf            200 YES

======================================================================
[2단계] 기본 임시 테이블스페이스 변경
======================================================================

SYS@cdb1> alter database default temporary tablespace temp_work;

Database altered.

SYS@cdb1> select property_value from database_properties
  2  where property_name = 'DEFAULT_TEMP_TABLESPACE';

PROPERTY_VALUE
--------------------
TEMP_WORK

======================================================================
[3단계] 임시 테이블스페이스 그룹 구성
======================================================================

- temp_work를 그룹 temp_grp에 소속 (그룹은 자동 생성됨)
SYS@cdb1> alter tablespace temp_work tablespace group temp_grp;

Tablespace altered.

- 두 번째 임시 테이블스페이스를 만들면서 같은 그룹에 소속
SYS@cdb1> create temporary tablespace temp_work2
  2    tempfile '/u01/app/oracle/oradata/CDB1/pdb1/temp_work2_01.dbf' size 200M
  3    tablespace group temp_grp;

Tablespace created.

- 그룹 구성 확인
SYS@cdb1> select group_name, tablespace_name from dba_tablespace_groups
  2  order by group_name, tablespace_name;

GROUP_NAME   TABLESPACE_NAME
------------ ------------------------------
TEMP_GRP     TEMP_WORK
TEMP_GRP     TEMP_WORK2

- 그룹을 데이터베이스 기본 임시 테이블스페이스로 지정 (부하 분산)
SYS@cdb1> alter database default temporary tablespace temp_grp;

Database altered.

SYS@cdb1> select property_value from database_properties
  2  where property_name = 'DEFAULT_TEMP_TABLESPACE';

PROPERTY_VALUE
--------------------
TEMP_GRP

======================================================================
[4단계] 임시 공간 사용량 모니터링
======================================================================

- 현재 임시 세그먼트 사용 현황 (사용 중인 세션이 없으면 결과 없음)
SYS@cdb1> select tablespace_name, segtype, blocks
  2  from   v$tempseg_usage order by tablespace_name;

no rows selected

- 임시 테이블스페이스별 총/여유 공간 확인
SYS@cdb1> select tablespace_name,
  2         round(tablespace_size/1024/1024,1)  as total_mb,
  3         round(free_space/1024/1024,1)       as free_mb
  4  from   dba_temp_free_space order by tablespace_name;

TABLESPACE_NAME    TOTAL_MB    FREE_MB
------------------ ---------- ----------
TEMP_WORK               200        199
TEMP_WORK2              200        200

- [정리]
-   1) 임시 테이블스페이스는 TEMPFILE로 구성(DATAFILE 사용 시 ORA-25139)
-   2) 기본 임시 테이블스페이스는 ALTER DATABASE DEFAULT TEMPORARY TABLESPACE로 지정
-   3) 임시 테이블스페이스 그룹으로 병렬 정렬 부하 분산 가능
-   4) V$TEMPSEG_USAGE / DBA_TEMP_FREE_SPACE로 사용량 모니터링
