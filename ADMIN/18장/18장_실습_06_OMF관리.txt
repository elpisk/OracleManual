======================================================================
[1단계] OMF 파라미터 확인 및 설정 (루트에서)
======================================================================

SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

- 현재 DB_CREATE_FILE_DEST 값 확인 (비어 있으면 OMF 미사용)
SYS@cdb1> show parameter db_create_file_dest

NAME                                 TYPE        VALUE
------------------------------------ ----------- ------------------------------
db_create_file_dest                  string

- (실수) OMF를 켜지 않은 상태에서 경로 없이 테이블스페이스 생성 시도
SYS@cdb1> alter session set container = pdb1;

Session altered.

SYS@cdb1> create tablespace omf_data;
create tablespace omf_data
*
ERROR at line 1:
ORA-02199: missing DATAFILE/TEMPFILE clause

- 원인: DB_CREATE_FILE_DEST가 없으면 파일 경로를 생략할 수 없다.
-   OMF 목적지를 먼저 지정 (SCOPE=BOTH로 즉시+영구 반영)
SYS@cdb1> alter system set db_create_file_dest='/u01/app/oracle/oradata'
  2    scope=both;

System altered.

SYS@cdb1> show parameter db_create_file_dest

NAME                                 TYPE        VALUE
------------------------------------ ----------- ------------------------------
db_create_file_dest                  string      /u01/app/oracle/oradata

======================================================================
[2단계] OMF로 테이블스페이스 생성 (경로 지정 없이)
======================================================================

SYS@cdb1> create tablespace omf_data;

Tablespace created.

- Oracle이 o1_mf_ 규칙으로 파일 이름을 자동 생성 (기본 100MB, 자동확장 ON)
SYS@cdb1> select file_name, bytes/1024/1024 as mb, autoextensible
  2  from   dba_data_files where tablespace_name = 'OMF_DATA';

FILE_NAME                                                              MB  AUT
--------------------------------------------------------------------- --- ---
/u01/app/oracle/oradata/CDB1/8F.../datafile/o1_mf_omf_data_l7k2m3n_.dbf 100 YES

======================================================================
[3단계] OMF를 쓰되 크기 정책은 직접 지정
======================================================================

SYS@cdb1> create tablespace omf_sized
  2    datafile size 500M autoextend on next 200M maxsize 10G;

Tablespace created.

- 이름/경로는 자동, 크기 정책은 명시한 값이 적용됨
SYS@cdb1> select file_name, bytes/1024/1024 as mb, maxbytes/1024/1024 as max_mb
  2  from   dba_data_files where tablespace_name = 'OMF_SIZED';

FILE_NAME                                                       MB    MAX_MB
--------------------------------------------------------------- ----- ----------
/u01/.../8F.../datafile/o1_mf_omf_size_l7k2p9q_.dbf             500      10240

======================================================================
[4단계] OMF 테이블스페이스 삭제 시 파일 자동 제거
======================================================================

- 삭제 전 파일 경로 기록
SYS@cdb1> select file_name from dba_data_files where tablespace_name = 'OMF_DATA';

FILE_NAME
---------------------------------------------------------------------
/u01/app/oracle/oradata/CDB1/8F.../datafile/o1_mf_omf_data_l7k2m3n_.dbf

- OMF는 AND DATAFILES를 생략해도 관련 파일을 자동 삭제한다 (고아 파일 없음)
SYS@cdb1> drop tablespace omf_data including contents;

Tablespace dropped.

- OS에서 파일이 자동으로 제거되었는지 확인
SYS@cdb1> host ls /u01/app/oracle/oradata/CDB1/8F*/datafile/o1_mf_omf_data*
ls: cannot access '/u01/app/oracle/oradata/CDB1/8F*/datafile/o1_mf_omf_data*': No such file or directory

- [정리]
-   1) DB_CREATE_FILE_DEST 미설정 시 경로 생략 불가(ORA-02199)
-   2) OMF는 o1_mf_ 규칙으로 파일 이름/위치 자동 관리(기본 100MB·자동확장)
-   3) OMF를 쓰면서도 SIZE/AUTOEXTEND/MAXSIZE는 직접 지정 가능
-   4) DROP 시 OMF 파일 자동 삭제 -> 고아 파일이 남지 않음
