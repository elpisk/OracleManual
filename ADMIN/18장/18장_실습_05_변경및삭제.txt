SYS@cdb1> alter session set container = pdb1;

======================================================================
[0단계] 실습용 테이블스페이스와 테이블 준비
======================================================================

SYS@cdb1> create tablespace hist_data
  2    datafile '/u01/app/oracle/oradata/CDB1/pdb1/hist_data01.dbf' size 100M;

Tablespace created.

SYS@cdb1> create table hr.orders (id number, amount number)
  2    tablespace hist_data;

Table created.

SYS@cdb1> insert into hr.orders values (1, 1000);

1 row created.

SYS@cdb1> commit;

Commit complete.

======================================================================
[1단계] 온라인 / 오프라인 전환
======================================================================

SYS@cdb1> alter tablespace hist_data offline normal;

Tablespace altered.

- 오프라인 상태 확인
SYS@cdb1> select tablespace_name, status from dba_tablespaces
  2  where tablespace_name = 'HIST_DATA';

TABLESPACE_NAME   STATUS
----------------- ---------
HIST_DATA         OFFLINE

- (실수) 오프라인 상태에서 데이터 조회 시도 -> 접근 불가
SYS@cdb1> select * from hr.orders;
select * from hr.orders
                 *
ERROR at line 1:
ORA-00376: file 31 cannot be read at this time
ORA-01110: data file 31: '/u01/app/oracle/oradata/CDB1/pdb1/hist_data01.dbf'

- 원인: 테이블스페이스가 오프라인이라 세그먼트에 접근할 수 없음. 다시 온라인으로.
SYS@cdb1> alter tablespace hist_data online;

Tablespace altered.

SYS@cdb1> select * from hr.orders;

        ID     AMOUNT
---------- ----------
         1       1000

======================================================================
[2단계] 읽기 전용 / 읽기 쓰기 전환
======================================================================

SYS@cdb1> alter tablespace hist_data read only;

Tablespace altered.

- (실수) 읽기 전용 상태에서 갱신 시도 -> 차단
SYS@cdb1> update hr.orders set amount = amount * 1.1;
update hr.orders set amount = amount * 1.1
       *
ERROR at line 1:
ORA-00372: file 31 cannot be modified at this time
ORA-01110: data file 31: '/u01/app/oracle/oradata/CDB1/pdb1/hist_data01.dbf'

- 원인: 읽기 전용이라 DML 불가. 조회는 정상 동작함을 확인
SYS@cdb1> select * from hr.orders;

        ID     AMOUNT
---------- ----------
         1       1000

- 갱신이 필요하므로 다시 읽기 쓰기로 전환
SYS@cdb1> alter tablespace hist_data read write;

Tablespace altered.

SYS@cdb1> update hr.orders set amount = amount * 1.1;

1 row updated.

SYS@cdb1> commit;

Commit complete.

======================================================================
[3단계] 테이블스페이스 이름 변경
======================================================================

SYS@cdb1> alter tablespace hist_data rename to hist_arch;

Tablespace altered.

SYS@cdb1> select tablespace_name from dba_tablespaces
  2  where tablespace_name like 'HIST%';

TABLESPACE_NAME
------------------------------
HIST_ARCH

======================================================================
[4단계] 테이블스페이스 삭제 (INCLUDING CONTENTS / AND DATAFILES)
======================================================================

- 삭제 전 물리 데이터 파일 경로를 기록해 둔다 (삭제 후 확인용)
SYS@cdb1> select file_name from dba_data_files
  2  where tablespace_name = 'HIST_ARCH';

FILE_NAME
------------------------------------------------------------
/u01/app/oracle/oradata/CDB1/pdb1/hist_data01.dbf

- (실수) 세그먼트가 있는데 절 없이 삭제 시도 -> 거부
SYS@cdb1> drop tablespace hist_arch;
drop tablespace hist_arch
*
ERROR at line 1:
ORA-01549: tablespace not empty, use INCLUDING CONTENTS option

- 원인: 안에 테이블(세그먼트)이 있음. 객체와 물리 파일까지 함께 삭제하도록 수정
SYS@cdb1> drop tablespace hist_arch including contents and datafiles;

Tablespace dropped.

- 딕셔너리에서 사라졌는지 확인
SYS@cdb1> select tablespace_name from dba_tablespaces
  2  where tablespace_name = 'HIST_ARCH';

no rows selected

- OS에서도 물리 파일이 제거되었는지 확인 (AND DATAFILES 덕분에 삭제됨)
SYS@cdb1> host ls -l /u01/app/oracle/oradata/CDB1/pdb1/hist_data01.dbf
ls: cannot access '/u01/app/oracle/oradata/CDB1/pdb1/hist_data01.dbf': No such file or directory

- [정리]
-   1) OFFLINE/ONLINE, READ ONLY/READ WRITE 전환은 ALTER TABLESPACE로 수행
-   2) 오프라인/읽기전용 상태의 접근 제한 오류(ORA-00376/ORA-00372) 확인
-   3) RENAME TO로 이름 변경
-   4) DROP은 세그먼트가 있으면 INCLUDING CONTENTS, 파일까지 지우려면 AND DATAFILES
