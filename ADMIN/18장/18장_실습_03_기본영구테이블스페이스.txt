======================================================================
[1단계] 현재 기본 영구 테이블스페이스 확인
======================================================================

- DATABASE_PROPERTIES 뷰에서 기본 영구/임시 테이블스페이스 값 조회
SYS@cdb1> select property_name, property_value
  2  from   database_properties
  3  where  property_name in ('DEFAULT_PERMANENT_TABLESPACE',
  4                           'DEFAULT_TEMP_TABLESPACE');

PROPERTY_NAME                    PROPERTY_VALUE
-------------------------------- --------------------
DEFAULT_PERMANENT_TABLESPACE     USERS
DEFAULT_TEMP_TABLESPACE          TEMP

======================================================================
[2단계] 기본값 미지정 사용자의 default_tablespace 확인
======================================================================

- 테이블스페이스를 지정하지 않고 사용자 생성
SYS@cdb1> create user dev01 identified by oracle_1;

User created.

- 명시하지 않았지만 기본 영구 테이블스페이스(USERS)가 적용됨
SYS@cdb1> select username, default_tablespace, temporary_tablespace
  2  from   dba_users where username = 'DEV01';

USERNAME   DEFAULT_TABLESPACE   TEMPORARY_TABLESPACE
---------- -------------------- --------------------
DEV01      USERS                TEMP

======================================================================
[3단계] 기본 영구 테이블스페이스를 app_data로 변경
======================================================================

- 먼저 대상 테이블스페이스가 존재하는지 확인 (실습_02에서 생성한 app_data)
SYS@cdb1> select tablespace_name from dba_tablespaces
  2  where tablespace_name = 'APP_DATA';

TABLESPACE_NAME
------------------------------
APP_DATA

- (실수) 존재하지 않는 테이블스페이스를 기본값으로 지정하려다 실패
SYS@cdb1> alter database default tablespace app_datax;
alter database default tablespace app_datax
*
ERROR at line 1:
ORA-00959: tablespace 'APP_DATAX' does not exist

- 원인: 이름 오타(app_datax). 존재하는 app_data로 다시 지정
SYS@cdb1> alter database default tablespace app_data;

Database altered.

- 변경 결과 확인
SYS@cdb1> select property_value from database_properties
  2  where property_name = 'DEFAULT_PERMANENT_TABLESPACE';

PROPERTY_VALUE
--------------------
APP_DATA

======================================================================
[4단계] 변경 후 새 사용자의 기본 테이블스페이스 확인
======================================================================

SYS@cdb1> create user dev02 identified by oracle_1;

User created.

- 이제 미지정 사용자는 app_data를 기본 테이블스페이스로 가진다
SYS@cdb1> select username, default_tablespace from dba_users
  2  where username = 'DEV02';

USERNAME   DEFAULT_TABLESPACE
---------- --------------------
DEV02      APP_DATA

======================================================================
[5단계] 기본 테이블스페이스로 지정된 것은 삭제할 수 없음
======================================================================

- (실수) 현재 기본 영구 테이블스페이스인 app_data를 삭제 시도 -> 거부
SYS@cdb1> drop tablespace app_data including contents and datafiles;
drop tablespace app_data including contents and datafiles
*
ERROR at line 1:
ORA-12919: Cannot drop the default permanent tablespace

- 원인: app_data가 기본 영구 테이블스페이스로 지정되어 있음.
-   삭제하려면 먼저 다른 테이블스페이스를 기본값으로 지정해야 한다.
SYS@cdb1> alter database default tablespace users;

Database altered.

- 이제 기본값이 users로 바뀌었으므로 app_data는 필요 시 삭제 가능해진다.
-   (본 실습에서는 이후 실습에서 사용하므로 삭제하지 않고 유지)
SYS@cdb1> select property_value from database_properties
  2  where property_name = 'DEFAULT_PERMANENT_TABLESPACE';

PROPERTY_VALUE
--------------------
USERS

- 정리용 테스트 사용자 제거
SYS@cdb1> drop user dev01;

User dropped.

SYS@cdb1> drop user dev02;

User dropped.

- [정리]
-   1) 기본 영구 테이블스페이스는 DEFAULT TABLESPACE 미지정 사용자에게 적용
-   2) ALTER DATABASE DEFAULT TABLESPACE로 변경, DATABASE_PROPERTIES로 확인
-   3) 기본값으로 지정된 테이블스페이스는 교체 전까지 삭제 불가(ORA-12919)
-   4) SYSTEM 보호를 위해 데이터베이스/PDB 생성 직후 반드시 지정
