-- 7장 실습_04: PDB SAVE STATE / DISCARD STATE로 자동 오픈 구성 실습
-- 목표: CDB 재기동 전후로 PDB 오픈 상태가 어떻게 유지/복귀되는지 직접 확인한다.

[oracle@dbsvr ~]$ sqlplus / as sysdba

SQL*Plus: Release 19.0.0.0.0 - Production on Mon Jul 27 13:20:55 2026
Version 19.3.0.0.0

Connected to:
Oracle Database 19c Enterprise Edition Release 19.0.0.0.0 - Production
Version 19.3.0.0.0

SQL> set sqlprompt "_user'@'_connect_identifier> "
SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

======================================================================
[문제 재현] SAVE STATE 없이 CDB를 재기동하면 PDB는 MOUNTED로 복귀
======================================================================

- HRPDB를 열어 둔다
SYS@cdb1> alter pluggable database hrpdb open;

Pluggable database altered.

SYS@cdb1> select name, open_mode from v$pdbs where name='HRPDB';

NAME                           OPEN_MODE
------------------------------ ----------
HRPDB                          READ WRITE

- 저장하지 않은 채 CDB를 재기동
SYS@cdb1> shutdown immediate
Database closed.
Database dismounted.
ORACLE instance shut down.
SYS@cdb1> startup
ORACLE instance started.
Database mounted.
Database opened.

- 재기동 후 확인: HRPDB가 다시 MOUNTED로 돌아갔다 (자동으로 열리지 않음)
SYS@cdb1> select name, open_mode from v$pdbs where name='HRPDB';

NAME                           OPEN_MODE
------------------------------ ----------
HRPDB                          MOUNTED

======================================================================
[해결] SAVE STATE로 오픈 상태를 저장 -> 재기동 시 자동 복원
======================================================================

- (실수) HRPDB가 닫힌(MOUNTED) 상태에서 SAVE STATE를 먼저 실행
-   SAVE STATE는 '현재 상태'를 저장하므로 이렇게 하면 MOUNTED가 저장된다!
SYS@cdb1> alter pluggable database hrpdb save state;

Pluggable database altered.

- 저장된 상태 확인: STATE 컬럼이 무엇으로 저장되었는지 본다
SYS@cdb1> select con_name, instance_name, state from dba_pdb_saved_states;

CON_NAME     INSTANCE_NAME    STATE
------------ ---------------- -----------
HRPDB        cdb1             CLOSE

- 원인: 닫힌 상태에서 저장했더니 STATE=CLOSE로 저장됨.
-   자동으로 '열리게' 하려면 먼저 READ WRITE로 연 뒤 SAVE STATE 해야 한다.
- 올바르게 다시: 먼저 열고 -> 저장
SYS@cdb1> alter pluggable database hrpdb open;

Pluggable database altered.

SYS@cdb1> alter pluggable database hrpdb save state;

Pluggable database altered.

- 이제 STATE=OPEN 으로 저장되었음을 확인
SYS@cdb1> select con_name, instance_name, state from dba_pdb_saved_states;

CON_NAME     INSTANCE_NAME    STATE
------------ ---------------- -----------
HRPDB        cdb1             OPEN

======================================================================
[검증] CDB 재기동 후 HRPDB가 자동으로 READ WRITE로 열리는지 확인
======================================================================

SYS@cdb1> shutdown immediate
Database closed.
Database dismounted.
ORACLE instance shut down.
SYS@cdb1> startup
ORACLE instance started.
Database mounted.
Database opened.

- 재기동 후: 이번에는 HRPDB가 자동으로 READ WRITE로 열렸다
SYS@cdb1> select name, open_mode from v$pdbs where name='HRPDB';

NAME                           OPEN_MODE
------------------------------ ----------
HRPDB                          READ WRITE

======================================================================
[취소] DISCARD STATE로 자동 오픈 구성 폐기 -> 기본 동작(MOUNTED)으로 복귀
======================================================================

- 저장된 상태를 폐기
SYS@cdb1> alter pluggable database hrpdb discard state;

Pluggable database altered.

- 폐기 후 dba_pdb_saved_states에서 해당 행이 사라진다
SYS@cdb1> select con_name, state from dba_pdb_saved_states where con_name='HRPDB';

no rows selected

- 재기동하여 기본 동작(MOUNTED)으로 돌아가는지 확인
SYS@cdb1> shutdown immediate
Database closed.
Database dismounted.
ORACLE instance shut down.
SYS@cdb1> startup
ORACLE instance started.
Database mounted.
Database opened.

SYS@cdb1> select name, open_mode from v$pdbs where name='HRPDB';

NAME                           OPEN_MODE
------------------------------ ----------
HRPDB                          MOUNTED

- [정리] SAVE STATE는 '실행 시점의 오픈 모드'를 저장한다.
-   자동 오픈을 원하면 반드시 READ WRITE로 연 뒤 SAVE STATE 하고,
-   DBA_PDB_SAVED_STATES에서 STATE=OPEN을 확인하는 습관을 들인다.
-   DISCARD STATE는 저장을 폐기해 기본값(MOUNTED)으로 되돌린다.
