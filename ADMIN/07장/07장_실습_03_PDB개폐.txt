-- 7장 실습_03: ALTER PLUGGABLE DATABASE로 PDB OPEN/CLOSE 실습
-- 목표: PDB의 네 가지 오픈 모드 전환을 ALTER PLUGGABLE DATABASE와 STARTUP/SHUTDOWN으로 실습한다.

[oracle@dbsvr ~]$ sqlplus / as sysdba

SQL*Plus: Release 19.0.0.0.0 - Production on Mon Jul 27 11:03:10 2026
Version 19.3.0.0.0

Connected to:
Oracle Database 19c Enterprise Edition Release 19.0.0.0.0 - Production
Version 19.3.0.0.0

SQL> set sqlprompt "_user'@'_connect_identifier> "
SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

======================================================================
[출발점] CDB는 OPEN이지만 사용자 PDB는 MOUNTED 상태
======================================================================

- 현재 PDB들의 오픈 모드 확인. CDB를 열어도 PDB는 기본 MOUNTED
SYS@cdb1> select con_id, name, open_mode, restricted from v$pdbs order by con_id;

    CON_ID NAME                           OPEN_MODE  RES
---------- ------------------------------ ---------- ---
         2 PDB$SEED                       READ ONLY
         3 SALESPDB                       MOUNTED
         4 HRPDB                          MOUNTED

======================================================================
[1] MOUNTED -> READ WRITE : ALTER PLUGGABLE DATABASE ... OPEN
======================================================================

- HRPDB를 연다 (기본적으로 READ WRITE로 열림)
SYS@cdb1> alter pluggable database hrpdb open;

Pluggable database altered.

SYS@cdb1> select name, open_mode from v$pdbs where name='HRPDB';

NAME                           OPEN_MODE
------------------------------ ----------
HRPDB                          READ WRITE

======================================================================
[2] READ WRITE -> READ ONLY : 재시작 없이 강제 전환하려면 FORCE 필요
======================================================================

- (실수) 이미 열린 PDB를 READ ONLY로 바꾸려다 FORCE 없이 시도
SYS@cdb1> alter pluggable database hrpdb open read only;
alter pluggable database hrpdb open read only
*
ERROR at line 1:
ORA-65019: pluggable database HRPDB already open

- 원인: 이미 열린 PDB의 모드 변경에는 FORCE가 필요하다
SYS@cdb1> alter pluggable database hrpdb open read only force;

Pluggable database altered.

SYS@cdb1> select name, open_mode from v$pdbs where name='HRPDB';

NAME                           OPEN_MODE
------------------------------ ----------
HRPDB                          READ ONLY

- READ ONLY 상태에서는 변경이 거부됨을 확인 (PDB에 접속해 테스트)
SYS@cdb1> alter session set container=hrpdb;

Session altered.

SYS@hrpdb> create table t_test(id number);
create table t_test(id number)
*
ERROR at line 1:
ORA-16000: database or pluggable database open for read-only access

- 원인: READ ONLY 모드는 조회만 가능. 루트로 돌아가 READ WRITE로 다시 연다
SYS@hrpdb> alter session set container=cdb$root;

Session altered.

SYS@cdb1> alter pluggable database hrpdb open read write force;

Pluggable database altered.

======================================================================
[3] READ WRITE -> MOUNTED : ALTER PLUGGABLE DATABASE ... CLOSE
======================================================================

- HRPDB를 닫는다 (MOUNTED 상태로 되돌림)
SYS@cdb1> alter pluggable database hrpdb close;

Pluggable database altered.

SYS@cdb1> select name, open_mode from v$pdbs where name='HRPDB';

NAME                           OPEN_MODE
------------------------------ ----------
HRPDB                          MOUNTED

======================================================================
[4] 여러 PDB 일괄 처리 : ALL / ALL EXCEPT
======================================================================

- SALESPDB만 제외하고 나머지 모든 PDB 열기
SYS@cdb1> alter pluggable database all except salespdb open;

Pluggable database altered.

SYS@cdb1> select con_id, name, open_mode from v$pdbs order by con_id;

    CON_ID NAME                           OPEN_MODE
---------- ------------------------------ ----------
         2 PDB$SEED                       READ ONLY
         3 SALESPDB                       MOUNTED
         4 HRPDB                          READ WRITE

- 모든 PDB를 한 번에 닫기
SYS@cdb1> alter pluggable database all close;

Pluggable database altered.

======================================================================
[5] STARTUP/SHUTDOWN으로 PDB 개폐 (PDB에 접속 후, MOUNTED 필요)
======================================================================

- HRPDB에 접속 후 STARTUP으로 열기
SYS@cdb1> alter session set container=hrpdb;

Session altered.

SYS@hrpdb> select open_mode from v$pdbs;    -- 현재 MOUNTED

OPEN_MODE
----------
MOUNTED

SYS@hrpdb> startup
Pluggable Database opened.

SYS@hrpdb> select open_mode from v$pdbs;

OPEN_MODE
----------
READ WRITE

- SHUTDOWN으로 닫기 (MOUNTED로 되돌림)
SYS@hrpdb> shutdown immediate
Pluggable Database closed.

SYS@hrpdb> select open_mode from v$pdbs;

OPEN_MODE
----------
MOUNTED

- [정리] PDB 오픈 모드: READ WRITE / READ ONLY / MIGRATE / MOUNTED.
-   ALTER PLUGGABLE DATABASE는 어떤 모드에서든 다른 모드로 전환 가능(FORCE로 재시작 없이).
-   STARTUP은 대상 PDB가 MOUNTED 상태일 때 사용한다.
SYS@hrpdb> exit
Disconnected from Oracle Database 19c Enterprise Edition Release 19.0.0.0.0 - Production
Version 19.3.0.0.0
