-- 10장 실습_02: Local Naming(tnsnames.ora) 구성 및 접속 실습
--   목표: tnsnames.ora에 넷 서비스 이름(별칭)을 정의하고 TNS_ADMIN을 지정한 뒤,
--         tnsping과 별칭 접속으로 검증한다. 괄호/철자 오류 -> 수정 흐름 포함.

======================================================================
[1단계] TNS_ADMIN 디렉터리 준비 및 구성 파일 백업
======================================================================

- 구성 파일을 둘 별도 디렉터리를 만들고 TNS_ADMIN으로 지정 (표준 경로 대신 사용 가능)
[oracle@dbsvr ~]$ mkdir -p /u01/app/oracle/net_config
[oracle@dbsvr ~]$ export TNS_ADMIN=/u01/app/oracle/net_config
[oracle@dbsvr ~]$ echo $TNS_ADMIN
/u01/app/oracle/net_config

- 기존 표준 위치의 tnsnames.ora가 있으면 참고용으로 복사(없으면 새로 만든다)
[oracle@dbsvr ~]$ cp $ORACLE_HOME/network/admin/tnsnames.ora $TNS_ADMIN/ 2>/dev/null; echo done
done

- 편집 전 항상 백업하는 습관
[oracle@dbsvr ~]$ cp $TNS_ADMIN/tnsnames.ora $TNS_ADMIN/tnsnames.ora.bak 2>/dev/null; echo backed-up
backed-up

======================================================================
[2단계] (실수) tnsnames.ora에 별칭 정의 - 괄호 짝이 맞지 않음
======================================================================

- 넷 서비스 이름 sales 를 정의 (편의상 cat + here-doc으로 작성; 실무에선 vi 사용)
-   (실수) 마지막 닫는 괄호를 하나 빠뜨림
[oracle@dbsvr ~]$ cat > $TNS_ADMIN/tnsnames.ora <<'EOF'
sales =
  (DESCRIPTION =
    (ADDRESS = (PROTOCOL = TCP)(HOST = dbsvr.us.oracle.com)(PORT = 1521))
    (CONNECT_DATA =
      (SERVER = DEDICATED)
      (SERVICE_NAME = salespdb.us.oracle.com)
EOF

- 별칭이 제대로 해석되는지 tnsping으로 점검
[oracle@dbsvr ~]$ tnsping sales

TNS Ping Utility for Linux: Version 19.0.0.0.0 - Production

Used parameter files:
/u01/app/oracle/net_config/sqlnet.ora
TNS-03505: Failed to resolve name

- 원인: 괄호 짝 불일치로 별칭 정의가 올바른 연결 기술자로 파싱되지 못함(이름 해석 실패)
-   닫는 괄호를 보강하여 다시 작성
[oracle@dbsvr ~]$ cat > $TNS_ADMIN/tnsnames.ora <<'EOF'
sales =
  (DESCRIPTION =
    (ADDRESS = (PROTOCOL = TCP)(HOST = dbsvr.us.oracle.com)(PORT = 1521))
    (CONNECT_DATA =
      (SERVER = DEDICATED)
      (SERVICE_NAME = salespdb.us.oracle.com)))
EOF

======================================================================
[3단계] tnsping으로 이름 해석 및 리스너 도달 확인
======================================================================

[oracle@dbsvr ~]$ tnsping sales

TNS Ping Utility for Linux: Version 19.0.0.0.0 - Production

Used parameter files:
/u01/app/oracle/net_config/sqlnet.ora
Used TNSNAMES adapter to resolve the alias
Attempting to contact (DESCRIPTION = (ADDRESS = (PROTOCOL = TCP)(HOST =
dbsvr.us.oracle.com)(PORT = 1521)) (CONNECT_DATA = (SERVER = DEDICATED)
(SERVICE_NAME = salespdb.us.oracle.com)))
OK (0 msec)

- 'Used TNSNAMES adapter to resolve the alias' -> 로컬 네이밍으로 해석되었음을 확인

======================================================================
[4단계] 짧은 별칭으로 접속 (긴 연결 문자열 대신 sales 한 단어)
======================================================================

[oracle@dbsvr ~]$ sqlplus system@sales

SQL*Plus: Release 19.0.0.0.0 - Production on Wed Jul 22 10:20:03 2026
Enter password:
Connected to:
Oracle Database 19c Enterprise Edition Release 19.0.0.0.0 - Production

- 프롬프트 설정 후 실제 접속 서비스/컨테이너 확인
SQL> set sqlprompt "_user'@'_connect_identifier> "
SYSTEM@sales> show con_name

CON_NAME
------------------------------
SALESPDB

SYSTEM@sales> select sys_context('USERENV','SERVICE_NAME') svc from dual;

SVC
------------------------------
salespdb.us.oracle.com

======================================================================
[5단계] (실수) 정의하지 않은 별칭으로 접속 -> ORA-12154
======================================================================

SYSTEM@sales> exit

- (실수) tnsnames.ora에 없는 별칭 saels(오타)로 접속
[oracle@dbsvr ~]$ sqlplus system@saels
Enter password:
ERROR:
ORA-12154: TNS:could not resolve the connect identifier specified

- 원인: 로컬 네이밍은 별칭을 tnsnames.ora의 로컬 목록과 대조하는데 saels 항목이 없어 해석 실패.
-   ORA-12154(이름 해석 실패)는 ORA-12514(서비스 미등록)와 다름에 주의. 올바른 별칭 sales로 재접속.
[oracle@dbsvr ~]$ sqlplus system@sales
Enter password:
Connected to:
Oracle Database 19c Enterprise Edition Release 19.0.0.0.0 - Production

SQL> select 'ok' from dual;

'O
--
ok

- [정리]
-   로컬 네이밍 = 클라이언트 tnsnames.ora에 별칭->연결 기술자 매핑 저장, 모든 프로토콜/고급 옵션 지원
-   TNS_ADMIN으로 구성 파일 위치를 표준 경로가 아닌 곳으로 지정 가능
-   ORA-12154 = 별칭을 못 찾음(로컬 목록에 없음) / ORA-12514 = 서비스 미등록. 원인이 다르다.
-   편집 전 백업, 편집 후 tnsping으로 반드시 검증
SQL> exit
Disconnected from Oracle Database 19c Enterprise Edition Release 19.0.0.0.0 - Production
[oracle@dbsvr ~]$
