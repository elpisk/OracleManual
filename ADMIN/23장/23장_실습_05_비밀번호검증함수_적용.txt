-- 23장 실습_05: Oracle 제공 비밀번호 검증 함수 적용 (ora12c_verify_function, ORA-28003)

- 루트 컨테이너로 SYSDBA 접속된 상태 확인
SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

SYS@cdb1> alter session set container = pdb1;

Session altered.

======================================================================
[1단계] (오류 -> 원인 -> 수정) 미설치 함수 지정 시도
======================================================================

- 검증 함수를 프로파일에 연결하려 한다. (실수) 아직 설치하지 않은 상태에서 지정.
SYS@cdb1> create profile pw_prof limit
  2    password_verify_function ora12c_verify_function;
  password_verify_function ora12c_verify_function
                           *
ERROR at line 1:
ORA-07443: function ORA12C_VERIFY_FUNCTION not found

- 원인: 제공 검증 함수가 아직 설치되어 있지 않다.
- 수정: SYS 로 utlpwdmg.sql 스크립트를 실행해 표준 검증 함수를 설치한다.
SYS@cdb1> @?/rdbms/admin/utlpwdmg.sql

Function created.

Profile altered.

- 설치 확인: SYS 스키마에 검증 함수가 생성되었다.
SYS@cdb1> select object_name from dba_objects
  2  where  object_name like 'ORA12C%VERIFY_FUNCTION' and owner = 'SYS'
  3  order  by object_name;

OBJECT_NAME
------------------------------
ORA12C_STIG_VERIFY_FUNCTION
ORA12C_STRONG_VERIFY_FUNCTION
ORA12C_VERIFY_FUNCTION

======================================================================
[2단계] 프로파일에 검증 함수 연결
======================================================================

SYS@cdb1> create profile pw_prof limit
  2    password_verify_function ora12c_verify_function;

Profile created.

- 실습용 사용자 생성 및 프로파일 할당
SYS@cdb1> create user pwuser identified by StrongPw1 profile pw_prof;
User created.
SYS@cdb1> grant create session to pwuser;
Grant succeeded.

======================================================================
[3단계] (오류 -> 원인 -> 수정) 약한 비밀번호 거부
======================================================================

SYS@cdb1> connect pwuser/StrongPw1@pdb1
Connected.

- (실수) 너무 짧고 숫자 없는 비밀번호로 변경 시도
PWUSER@pdb1> alter user pwuser identified by abc;
alter user pwuser identified by abc
*
ERROR at line 1:
ORA-28003: password verification for the specified password failed
ORA-20001: Password length less than 8

- 원인: ora12c_verify_function 은 최소 8자, 문자·숫자 혼합을 요구한다. abc 는 미달.
- (실수2) 길이는 채웠지만 사용자 이름과 유사한 비밀번호로 시도
PWUSER@pdb1> alter user pwuser identified by pwuser123;
alter user pwuser identified by pwuser123
*
ERROR at line 1:
ORA-28003: password verification for the specified password failed
ORA-20002: Password same as or similar to user

- 원인: 비밀번호가 사용자 이름과 너무 유사하다.
- 수정: 8자 이상, 문자·숫자 혼합, 사용자 이름과 다른 비밀번호로 변경한다.
PWUSER@pdb1> alter user pwuser identified by Welcome2Ora;

User altered.

======================================================================
[4단계] 검증 함수 해제
======================================================================

- 특정 프로파일에서 복잡도 검사를 끄려면 함수를 NULL 로 지정한다.
PWUSER@pdb1> connect sys@pdb1 as sysdba
Enter password:
Connected.
SYS@cdb1> alter profile pw_prof limit password_verify_function null;

Profile altered.

- 확인: 이제 pw_prof 사용자는 약한 비밀번호도 허용된다(정책상 권장하지 않음).
SYS@cdb1> select limit from dba_profiles
  2  where  profile='PW_PROF' and resource_name='PASSWORD_VERIFY_FUNCTION';

LIMIT
--------------------
NULL

- [정리] 미설치 함수 지정=ORA-07443 -> utlpwdmg.sql 로 설치,
-   복잡도 위반=ORA-28003, 해제는 PASSWORD_VERIFY_FUNCTION NULL(또는 DEFAULT).
SYS@cdb1> exit
Disconnected from Oracle Database 19c Enterprise Edition Release 19.0.0.0.0 - Production
