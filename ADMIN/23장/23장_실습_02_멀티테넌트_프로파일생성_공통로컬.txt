-- 23장 실습_02: 멀티테넌트 아키텍처에서 프로파일 생성 (공통 C##/로컬, CONTAINER=ALL)

- 루트 컨테이너로 SYSDBA 접속된 상태 확인
SYS@cdb1> show con_name

CON_NAME
------------------------------
CDB$ROOT

======================================================================
[1단계] (오류 -> 원인 -> 수정) 공통 프로파일 이름 규칙 위반
======================================================================

- 루트에서 공통 프로파일을 만들려 한다. (실수) 접두사 없이 corp_prof 로 시도.
SYS@cdb1> create profile corp_prof limit
  2    failed_login_attempts 5
  3    password_life_time 90
  4    container = all;
create profile corp_prof limit
*
ERROR at line 1:
ORA-65140: invalid common profile name

- 원인: 공통 프로파일 이름은 반드시 공통 접두사 C## 로 시작해야 한다.
- 수정: 이름을 c##corp_prof 로 바꿔 다시 생성한다.
SYS@cdb1> create profile c##corp_prof limit
  2    failed_login_attempts 5
  3    password_life_time 90
  4    container = all;

Profile created.

======================================================================
[2단계] (오류 -> 원인 -> 수정) 이미 존재하는 이름으로 재생성
======================================================================

- (실수) 값을 바꾸려고 같은 이름으로 다시 CREATE PROFILE 실행.
SYS@cdb1> create profile c##corp_prof limit failed_login_attempts 3;
create profile c##corp_prof limit failed_login_attempts 3
*
ERROR at line 1:
ORA-02380: profile C##CORP_PROF already exists

- 원인: 동일 이름으로 CREATE 하면 중복 오류. 재정의는 ALTER PROFILE 을 쓴다.
- 수정: ALTER PROFILE 로 해당 파라미터만 변경한다.
SYS@cdb1> alter profile c##corp_prof limit failed_login_attempts 3;

Profile altered.

======================================================================
[3단계] PDB 에서 로컬 프로파일 생성
======================================================================

- 특정 PDB 로 이동한다.
SYS@cdb1> alter session set container = pdb1;

Session altered.

- 로컬 프로파일은 C## 접두사 없이, CONTAINER 절 생략(기본값 CURRENT)으로 생성.
SYS@cdb1> create profile app_local limit
  2    sessions_per_user 8
  3    idle_time 20;

Profile created.

- (참고) 로컬 프로파일에 C## 접두사를 붙이면 오류가 난다.
SYS@cdb1> create profile c##bad_local limit sessions_per_user 3;
create profile c##bad_local limit sessions_per_user 3
*
ERROR at line 1:
ORA-65140: invalid common profile name

- 원인: PDB 안에서 만드는 로컬 프로파일에 C## 를 붙였기 때문. 접두사를 제거한다.
SYS@cdb1> create profile good_local limit sessions_per_user 3;

Profile created.

======================================================================
[4단계] 공통/로컬 프로파일 확인 (COMMON, CON_ID)
======================================================================

- 루트로 돌아가 CDB_PROFILES 로 컨테이너별 모습을 확인한다.
SYS@cdb1> alter session set container = cdb$root;

Session altered.

SYS@cdb1> select distinct profile, common, con_id
  2  from   cdb_profiles
  3  where  profile in ('C##CORP_PROF','APP_LOCAL')
  4  order  by profile, con_id;

PROFILE        COMMON CON_ID
-------------- ------ ------
APP_LOCAL      NO          3
C##CORP_PROF   YES         1
C##CORP_PROF   YES         3

- 공통 프로파일(C##CORP_PROF)은 루트(CON_ID 1)와 PDB(3)에 모두 COMMON=YES 로 나타난다.
- 로컬 프로파일(APP_LOCAL)은 자신의 PDB(3)에만 COMMON=NO 로 나타난다.

- [정리] 공통=루트에서 C## + CONTAINER=ALL, 로컬=PDB에서 접두사 없이 생성.
-   이름 규칙 위반은 ORA-65140, 동일 이름 재생성은 ORA-02380.
SYS@cdb1> exit
