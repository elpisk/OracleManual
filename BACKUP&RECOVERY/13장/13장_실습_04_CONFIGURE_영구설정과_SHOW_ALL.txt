================================================================================
 실습 13-4 : CONFIGURE 영구 설정과 SHOW ALL 확인
 과정      : Oracle Database 19c Backup & Recovery
 환경      : Oracle 19.3.0 / Oracle Linux 7 / non-CDB ORCL + RCAT
 소요 시간 : 약 25분
================================================================================

--------------------------------------------------------------------------------
[1] 시나리오 개요
--------------------------------------------------------------------------------
-- 운영 표준에 맞춰 RMAN 영구 설정을 적용한다.
-- 자동 백업, 보존 정책, 채널 FORMAT, 병렬도를 설정한다.
-- 설정 전후를 SHOW ALL로 비교한다.
-- CLEAR로 되돌리는 절차와 설정을 파일로 남기는 방법을 확인한다.
-- 작업 유형 : 환경 구성(장애 복구 아님)

--------------------------------------------------------------------------------
[2] 사전 조건
--------------------------------------------------------------------------------
-- 실습 13-3까지 완료되어 카탈로그 등록이 끝나 있어야 한다.
-- 백업 위치 디렉터리가 만들어져 있어야 한다.

[oracle@oel7v9r1 ~]$ df -h /home/oracle | tail -1

-- << 원인 파악 >>
-- 메시지는 컨트롤파일 백업 실패로 나오지만 실제 원인은 다른 곳에 있다.

-- 스냅샷 컨트롤파일을 만들 디렉터리가 없다.
-- RMAN은 백업 중 일관된 컨트롤파일 사본이 필요한데 그것을 만들지 못한 것이다.

[8] 검증 및 실무 포인트
--------------------------------------------------------------------------------
RMAN> SHOW ALL;

CONFIGURE RETENTION POLICY TO RECOVERY WINDOW OF 7 DAYS;
CONFIGURE CONTROLFILE AUTOBACKUP ON;
CONFIGURE CONTROLFILE AUTOBACKUP FORMAT FOR DEVICE TYPE DISK TO
 '/home/oracle/rmanbk/cf_%F';
CONFIGURE DEVICE TYPE DISK PARALLELISM 2 BACKUP TYPE TO BACKUPSET;
CONFIGURE CHANNEL DEVICE TYPE DISK FORMAT
 '/home/oracle/rmanbk/%d_%T_%s_%p.bkp';
CONFIGURE ARCHIVELOG DELETION POLICY TO BACKED UP 1 TIMES TO DISK;

RMAN> EXIT

-- 설정을 파일로 남긴다.

[oracle@oel7v9r1 ~]$ rman target / log=/home/oracle/rman/showall_20250514.txt <<EOF
SHOW ALL;
EXIT;
EOF

[oracle@oel7v9r1 ~]$ grep -c 'CONFIGURE' /home/oracle/rman/showall_20250514.txt
9

-- 출력이 그대로 실행 가능한 CONFIGURE 문 목록이다.
-- 컨트롤파일을 재생성하면 설정이 초기화되므로 이 파일이 복원 근거가 된다.

[oracle@oel7v9r1 ~]$ sqlplus -s / as sysdba <<< \
> "SHOW PARAMETER control_file_record_keep_time"

NAME                            TYPE        VALUE
------------------------------- ----------- -----
control_file_record_keep_time   integer     31

-- 실무 포인트
-- 1) CONFIGURE 설정은 컨트롤파일과 카탈로그에 저장되어 접속을 넘어 유지된다.
--    RUN 블록 안의 설정은 블록이 끝나면 사라진다. 둘을 혼동하지 않는다.
--
-- 2) 자동 백업은 반드시 켜고 FORMAT에 %F 를 포함한다.
--    파일명에 DBID가 들어가야 컨트롤파일을 모두 잃어도 찾을 수 있다.
--    백업이 끝나면 자동 백업이 이어서 수행되는 것을 로그로 확인할 수 있다.
--
-- 3) 기록 수명은 보존 정책보다 크게 잡는다.
--    보존 7일에 기록 수명 31일이면 여유가 충분하다.
--    반대로 되어 있으면 삭제 대상을 찾지 못해 백업 파일만 쌓인다.
--
-- 4) 설정 값은 저장 시 검증되지 않는다.
--    없는 경로를 지정해도 그대로 저장되며 백업 시점에 실패한다.
--    설정 후 반드시 시험 백업으로 확인한다.
--
-- 5) ORA-00245는 스냅샷 컨트롤파일 경로 문제다.
--    메시지만 보면 컨트롤파일 백업 문제로 보이지만 원인은 경로나 권한이다.
--    RAC에서는 이 경로가 공유 위치여야 한다.
--
-- 6) SHOW ALL 출력을 파일로 저장해 형상 관리에 포함한다.
--    컨트롤파일 재생성 후 같은 설정을 다시 넣어야 스크립트가 그대로 동작한다.
