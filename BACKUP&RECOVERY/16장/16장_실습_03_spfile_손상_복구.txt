================================================================================
 실습 16-3 : spfile 손상 복구 — 자동 백업에서 RESTORE SPFILE
 과정      : Oracle Database 19c Backup & Recovery
 환경      : Oracle 19.3.0 / Oracle Linux 7 / non-CDB ORCL / ARCHIVELOG
 소요 시간 : 약 25분
================================================================================

--------------------------------------------------------------------------------
[1] 시나리오 개요
--------------------------------------------------------------------------------
-- spfile과 pfile이 모두 사라져 인스턴스를 정상 기동할 수 없다.
-- 19c 의 RMAN 은 파라미터 파일 없이도 최소 인스턴스를 스스로 띄운다.
-- SET DBID 후 자동 백업에서 spfile을 복원한다.
-- 자동 백업 위치가 기본값이 아니면 FORMAT도 알려 주어야 한다.
-- 복구 유형 : 파라미터 파일 복구, 전면 중단

--------------------------------------------------------------------------------
[2] 사전 조건
--------------------------------------------------------------------------------
-- 컨트롤파일 자동 백업이 켜져 있어야 한다.

[oracle@oel7v9 ~]$ rman target / catalog rcatowner@rcat

RMAN> SHOW CONTROLFILE AUTOBACKUP;

RMAN configuration parameters for database with db_unique_name ORCL are:
CONFIGURE CONTROLFILE AUTOBACKUP ON;

RMAN> BACKUP DATABASE TAG 'BASE_163' PLUS ARCHIVELOG;

Finished Control File and SPFILE Autobackup at 18-MAY-25

RMAN> EXIT

-- 자동 백업 조각에는 컨트롤파일과 함께 spfile 이 들어 있다.

-- 판정
--   ① spfile과 pfile 모두 부재 → 정상 기동 불가
--   ② 자동 백업 있음, DBID는 파일명에서 확인 가능
--   ③ 순서 : RMAN 이 최소 인스턴스 기동 → SET DBID → RESTORE SPFILE
--   → 전면 중단이며 몇 분이면 복구된다.

-- 실무 포인트
-- 1) spfile과 pfile이 모두 없으면 정상 기동할 수 없다.
--    ORA-01078과 LRM-00109가 그 신호이며 찾는 순서는
--    spfile<SID>.ora → spfile.ora → init<SID>.ora 다.
--
-- 2) 19c 의 RMAN 은 파라미터 파일 없이도 최소 인스턴스를 스스로 띄운다.
--    'starting Oracle instance without parameter file for retrieval of spfile' 다.
--    옛 버전에서 db_name 한 줄짜리 임시 pfile 을 만들던 단계가 사라졌다.
--
-- 3) SET DBID가 필요하다.
--    자동 백업 파일명이 c-DBID-YYYYMMDD-NN 형식이기 때문이다.
--    DBID 는 평소에 기록해 두거나 자동 백업 파일명에서 읽는다.
--
-- 4) 자동 백업 위치가 기본값이 아니면 FORMAT도 지정한다.
--    그 위치는 spfile·컨트롤파일에 저장된 CONFIGURE 값이라 지금은 알 수 없다.
--    기본 위치만 뒤지다 RMAN-06172로 실패한다.
--    SET CONTROLFILE AUTOBACKUP FORMAT 으로 알려 준다.
--
-- 5) 복원본은 자동 백업 시점의 내용이다.
--    그 이후 파라미터를 바꿨다면 그 변경은 사라진다.
--    v$parameter 로 isdefault='FALSE' 목록을 확인해 비교한다.
--
-- 6) pfile 사본이 있었다면 이 모든 절차가 한 줄로 끝났다.
--    STARTUP PFILE='...' 로 기동한 뒤 CREATE SPFILE 하면 된다.
--    파라미터를 바꿀 때마다 사본을 남기는 습관이 가장 단순한 대비책이다.
