[1] 시나리오 개요
--------------------------------------------------------------------------------
-- 컨트롤파일이 모두 손상되었다.
-- 카탈로그를 사용해 복원하는 경로를 먼저 수행한다.
-- 이어서 카탈로그 없이 자동 백업에서 복원하는 경로를 수행한다.

-- 복구 유형 : 완전 복구, 전면 중단, RESETLOGS 강제

RMAN-03002: failure of restore command at 05/16/2025 17:02:11
RMAN-06172: no AUTOBACKUP found or specified handle is not a valid copy or piece

-- << 원인 파악 >>
-- 자동 백업 파일명은 c-DBID-YYYYMMDD-NN 형식이다.
-- 컨트롤파일이 없으므로 RMAN이 DBID를 알 수 없어 파일명을 만들지 못한다.
-- 또한 기본 위치에서만 찾으므로 실제 경로도 알려 주어야 한다.

-- << 수정 >>

RMAN> SET DBID 1200530011;

executing command: SET DBID

RMAN> SET CONTROLFILE AUTOBACKUP FORMAT FOR DEVICE TYPE DISK
  2>   TO '/home/oracle/rmanbk/cf_%F';

executing command: SET CONTROLFILE AUTOBACKUP FORMAT

RMAN> RESTORE CONTROLFILE FROM AUTOBACKUP;

channel ORA_DISK_1: AUTOBACKUP found: /home/oracle/rmanbk/cf_c-1200530011-20250516-06
channel ORA_DISK_1: control file restore from AUTOBACKUP complete
output file name=/u01/app/oracle/oradata/ORCL/control01.ctl
output file name=/u01/app/oracle/oradata/ORCL/control02.ctl
output file name=/u02/oradata/ORCL/control03.ctl

RMAN> ALTER DATABASE MOUNT;

RMAN> CATALOG START WITH '/home/oracle/rmanbk/';

searching for all files that match the pattern /home/oracle/rmanbk/
cataloging files...
cataloging done

-- 복원한 컨트롤파일이 모르는 백업을 등록한다.

RMAN> CROSSCHECK BACKUP;
RMAN> RECOVER DATABASE;
RMAN> ALTER DATABASE OPEN RESETLOGS;

Statement processed

RMAN> EXIT

[oracle@oel7v9r1 ~]$ rman target / catalog rcatowner@rcat
RMAN> RESYNC CATALOG;
RMAN> BACKUP DATABASE PLUS ARCHIVELOG TAG 'AFTER_CF';
RMAN> LIST INCARNATION;
RMAN> EXIT

-- 실무 포인트
-- 1) 컨트롤파일은 CONTROL_FILES의 모든 경로에 자동으로 복원된다.
--    6장에서 경로마다 복사하고 하나를 빠뜨려 ORA-00205를 다시 만나던 일이 사라진다.
--
-- 2) 카탈로그가 있으면 RESTORE CONTROLFILE 한 줄로 끝난다.
--    카탈로그가 대상 정보를 알고 있기 때문이다.
--
-- 3) 카탈로그가 없으면 DBID가 반드시 필요하다.
--    자동 백업 파일명이 c-DBID-YYYYMMDD-NN 형식이기 때문이다.
--    DBID 없이 시도하면 RMAN-06172로 실패한다.
--
-- 4) 자동 백업 위치가 기본값이 아니면 경로도 알려 주어야 한다.
--    SET CONTROLFILE AUTOBACKUP FORMAT 으로 지정한다.
--
-- 5) 복원한 컨트롤파일은 그 이후의 백업을 모른다.
--    CATALOG START WITH 로 백업 디렉터리를 등록하고 CROSSCHECK 를 수행한다.
--    카탈로그를 쓰면 이 단계가 자동으로 처리된다.
--
-- 6) 백업 컨트롤파일을 썼으므로 RESETLOGS가 강제된다.
--    인카네이션이 올라가므로 즉시 전체 백업을 받고 RESYNC CATALOG 를 수행한다.
