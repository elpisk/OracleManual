--------------------------------------------------------------------------------
[7] 오류 발생 → 원인 파악 → 수정
--------------------------------------------------------------------------------
-- NETWORK_LINK에 덤프 파일을 함께 지정해 본다.

[oracle@oel7v9r1 ~]$ impdp system/oracle_4U directory=dp_dir \
>   network_link=src_link dumpfile=net.dmp schemas=net19 \
>   remap_schema=net19:net19b logfile=net2.log

Import: Release 19.0.0.0.0 - Production on Wed May 21 17:15:02 2025

ORA-39002: invalid operation
ORA-39053: Parameter DUMPFILE is incompatible with NETWORK_LINK parameter

-- << 원인 파악 >>
-- NETWORK_LINK는 원본에서 읽어 대상에 바로 넣는 방식이다.
-- 중간 파일을 만들지 않으므로 DUMPFILE이라는 개념 자체가 없다.
-- 두 파라미터는 서로 다른 동작 방식을 지시하므로 함께 쓸 수 없다.
-- 덤프 파일이 필요하면 NETWORK_LINK를 쓰지 않고 expdp로 만든다.

-- << 수정 >> DUMPFILE을 뺀다.

[oracle@oel7v9r1 ~]$ impdp system/oracle_4U directory=dp_dir \
>   network_link=src_link schemas=net19 \
>   remap_schema=net19:net19b table_exists_action=truncate \
>   logfile=net2.log

. . imported "NET19B"."SRC"                            20000 rows
Job "SYSTEM"."SYS_IMPORT_SCHEMA_01" completed with 1 error(s) at 17:17:30

-- 상위 버전 덤프를 하위 버전에서 읽는 상황도 확인한다.
-- 12.2 데이터베이스에서 v19.dmp 를 반입하면 다음과 같다.

[oracle@target12 ~]$ impdp system/oracle_4U directory=dp_dir \
>   dumpfile=v19.dmp schemas=net19

ORA-39001: invalid argument value
ORA-39000: bad dump file specification
ORA-39142: incompatible version number 5.1 in dump file
"/u03/dpdump/v19.dmp"

-- 이 경우 대상에서 할 수 있는 일이 없다.
-- 원본에서 version=12.2로 다시 내보내야 한다.

-- 실무 포인트
-- 1) NETWORK_LINK는 덤프 파일을 만들지 않는다.
--    DUMPFILE과 함께 쓰면 ORA-39053으로 거부된다.
--    디스크 여유가 없을 때 유용한 방식이다.
--
-- 2) 재시도가 어렵다는 점이 가장 큰 단점이다.
--    중단되면 남은 것이 없어 처음부터 다시 해야 한다.
--    네트워크가 불안정하거나 대용량이면 덤프 파일 방식이 안전하다.
--
-- 3) 링크의 접속 계정 권한이 그대로 적용된다.
--    원본에서 읽을 권한이 없으면 그 객체가 빠진다.
--    권한 있는 계정으로 링크를 만들되 비밀번호 관리에 유의한다.
--
-- 4) LONG 타입이 있으면 이 방식을 쓸 수 없다.
--    ORA-31696이 발생하며 해당 테이블만 실패한다.
--    그 테이블은 덤프 파일 방식으로 따로 옮긴다.
--
-- 5) VERSION은 내보낼 때 지정한다.
--    반입 시점에 지정하는 것이 아니다.
--    이미 만든 덤프를 하위 버전에 넣을 수는 없고 다시 내보내야 한다.
--
-- 6) 하위에서 상위로는 조치가 필요 없다.
--    19c 덤프를 21c에 넣는 것은 그대로 된다.
--    방향을 혼동하지 않도록 절차서에 명시해 둔다.
