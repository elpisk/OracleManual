--------------------------------------------------------------------------------
[1] 시나리오 개요
--------------------------------------------------------------------------------
-- 정상 종료 후 컨트롤파일 사본이 모두 유실되었다.
-- Binary 백업본으로 복원하고 USING BACKUP CONTROLFILE 로 복구한다.
-- 아카이브가 자동 적용되고 마지막 구간은 온라인 리두를 지정한다.
-- 데이터 손실은 없지만 RESETLOGS가 강제된다.
-- 복구 유형 : 완전 복구(RESETLOGS 강제)

[7] 복구 절차 : 오류 발생 → 원인 파악 → 수정
--------------------------------------------------------------------------------
SYS@orcl> SHUTDOWN ABORT
SYS@orcl> !cp -p /home/oracle/backup/control_115.bkp \
                 /u01/app/oracle/oradata/ORCL/control01.ctl

                 /u01/app/oracle/oradata/ORCL/control02.ctl

SYS@orcl> STARTUP MOUNT
ORACLE instance started.
Database mounted.

-- 복구 절을 빠뜨리고 시도한다.

SYS@orcl> SET AUTORECOVERY ON
SYS@orcl> RECOVER DATABASE;
ORA-00283: recovery session canceled due to errors
ORA-01610: recovery using the BACKUP CONTROLFILE option must be done

-- << 원인 파악 >>
-- 복원한 컨트롤파일은 백업 시점의 SCN을 담고 있다.
-- 현재 데이터파일보다 뒤처져 있어 복구 목표가 잘못 잡힌다.
-- Oracle은 그것을 알고 USING BACKUP CONTROLFILE 절을 요구한다.
-- 이 절은 컨트롤파일 대신 데이터파일 헤더의 SCN을 기준으로 삼으라는 지시다.

SYS@orcl> ALTER DATABASE BACKUP CONTROLFILE TO
  2    '/home/oracle/backup/control_after_115.bkp';
SYS@orcl> ALTER DATABASE BACKUP CONTROLFILE TO TRACE
  2    AS '/home/oracle/backup/cf_after_115.sql';
Database altered.

-- 실무 포인트
-- 1) 백업 컨트롤파일은 CONTROL_FILES의 모든 경로에 복사한다.
--    하나만 복사하면 같은 ORA-00205가 반복된다.
--
-- 2) USING BACKUP CONTROLFILE 절을 빠뜨리면 ORA-01610이 나온다.
--    오류 메시지가 필요한 절을 그대로 알려 주므로 읽고 다시 수행하면 된다.
--
-- 3) ARCHIVELOG 환경에서는 아카이브가 자동 적용된다.
--    SET AUTORECOVERY ON 으로 대부분의 구간이 프롬프트 없이 처리된다.
--    NOARCHIVELOG에서 온라인 리두를 하나씩 입력하던 것과 대비된다.
--
-- 4) 마지막 구간은 온라인 리두를 직접 지정한다.
--    CURRENT 그룹의 리두는 아직 아카이브되지 않아 ORA-00308로 멈춘다.
--    AUTORECOVERY를 끄고 그 그룹의 멤버 경로를 입력하면 끝까지 적용된다.
--
-- 5) 데이터 손실은 없지만 RESETLOGS가 강제된다.
--    컨트롤파일이 리두 적용 이력을 모르기 때문이며 인카네이션이 올라간다.
--    trace 백업이 있었다면 NORESETLOGS 형식으로 인카네이션을 유지할 수 있었다.
--
-- 6) Binary 백업본에는 TEMP 정보가 포함되어 있다.
--    trace 재생성과 달리 TEMP 추가 작업이 필요 없다는 점이 다르다.

SYS@orcl> EXIT
