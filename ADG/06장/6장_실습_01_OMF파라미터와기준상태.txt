--------------------------------------------------------------------------------
 [2] 오류 재현 — 없는 경로를 설정하려 하면
--------------------------------------------------------------------------------

-- OMF 를 켜기 전에 이 파라미터가 어떤 성격인지 확인해 둔다.
-- 존재하지 않는 경로를 주고 설정해 본다.

SYS@chicago> ALTER SYSTEM SET db_create_file_dest='/u03/nosuchdir' SCOPE=MEMORY;

alter system set db_create_file_dest='/u03/nosuchdir' scope=memory
*
ERROR at line 1:
ORA-02097: parameter cannot be modified because specified value is invalid
ORA-01261: Parameter db_create_file_dest destination string cannot be translated
ORA-01262: Stat failed on a file destination directory
Linux-x86_64 Error: 2: No such file or directory

>>> 원인 파악
    오류가 네 줄이다. 아래에서 위로 읽는다.

      Linux-x86_64 Error: 2   운영체제가 돌려준 errno. ENOENT — 그런 경로가 없다
      ORA-01262               목적지 디렉터리에 stat() 이 실패했다
      ORA-01261               따라서 값을 경로로 해석할 수 없다
      ORA-02097               그러므로 파라미터를 바꿀 수 없다

    ★ 핵심은 `Linux-x86_64 Error: 2` 다.
      운영체제 오류 번호가 그대로 노출된다.
        2  (ENOENT)  경로가 없다      ← 지금
        13 (EACCES)  권한이 없다
      두 원인이 이 숫자 하나로 갈린다.

    ★ 그리고 더 중요한 사실.
      **오라클이 이 경로를 실제로 확인한다.**
      단순히 문자열을 저장하는 것이 아니라 stat() 시스템 콜로
      디렉터리의 존재를 검사한다.

      5장의 db_file_name_convert 와 대조해 본다.
      그쪽은 문자열 치환 규칙일 뿐이라 검사할 대상이 없었다.
      그래서 잘못된 경로를 주어도 설정은 성공했고,
      파일 전송 도중에야 ORA-19505 로 실패했다.

>>> 조치
    존재하는 경로를 준다. 6장 실습에서는 /u03/app/oracle/oradata 를 쓴다.
    이 디렉터리는 이미 있다.

[oracle@boston-srv ~]$ ls -ld /u03/app/oracle/oradata
drwxrwxr-x. 3 oracle oinstall 20 Aug 27 10:07 /u03/app/oracle/oradata

>>> 재확인
    설정이 거부됐으므로 파라미터는 그대로 비어 있다.
    아무것도 바뀌지 않았다.

SYS@chicago> SHOW PARAMETER db_create_file_dest

NAME                                 TYPE        VALUE
------------------------------------ ----------- ------------------------------
db_create_file_dest                  string

    빈 값 그대로다. 원복할 것이 없다.
    ★ 실패한 설정은 아무것도 남기지 않는다는 점도 확인해 둔다.

 [6] 정리 — 이 실습에서 확인한 것
--------------------------------------------------------------------------------

  · 현재 구성은 OMF 가 아니다 (db_create_file_dest 비어 있음)
  · FRA 만 15GB 로 설정되어 있다
  · db_create_file_dest 는 설정 시점에 경로를 실제로 검사한다
  · 없는 경로 → ORA-02097 + ORA-01261 + ORA-01262 + Linux Error 2
  · 5장 구성: Boston/ 아래, 사람이 읽는 파일 이름, PDB 이름 디렉터리, 로그 7행
