--------------------------------------------------------------------------------
 [5] 오류 재현 — 새 PDB 를 조회하려 하면
--------------------------------------------------------------------------------

-- Standby 에서 새 PDB 의 데이터를 조회해 본다.

SYS@boston> ALTER SESSION SET CONTAINER=dgpdb;

Session altered.

SYS@boston> SELECT COUNT(*) FROM dba_tables;

select count(*) from dba_tables
                     *
ERROR at line 1:
ORA-01219: database or pluggable database not open: queries allowed on fixed
           tables or views only

>>> 원인 파악
    새 PDB 의 OPEN_MODE 가 MOUNTED 이기 때문이다.

    ★ 메시지의 뒷부분이 정확하다 — "고정 테이블이나 뷰만 조회할 수 있다."
      즉 컨테이너 안으로 들어가는 것(ALTER SESSION SET CONTAINER)은 되지만,
      데이터 딕셔너리 조회는 되지 않는다.
      V$ 로 시작하는 고정 뷰는 조회할 수 있다.

SYS@boston> SELECT open_mode FROM v$database;

OPEN_MODE
--------------------
READ ONLY WITH APPLY

      CDB 는 열려 있다. 열리지 않은 것은 이 PDB 뿐이다.

    ★ 1장과 5장에서 확인한 규칙이 그대로다.
      **CDB 를 READ ONLY 로 열어도 PDB 는 따로 열어야 한다.**
      새로 추가된 PDB 도 예외가 아니다.

    ★ 오히려 더 주의해야 한다.
      기존 PDB 는 구축 시점에 한 번 열어 두었지만,
      **새로 추가된 PDB 는 아무도 열어 주지 않는다.**
      Primary 에서 열었다고 Standby 에서도 열리는 것이 아니다.

>>> 조치

SYS@boston> ALTER SESSION SET CONTAINER=CDB$ROOT;
SYS@boston> ALTER PLUGGABLE DATABASE dgpdb OPEN READ ONLY;

Pluggable database altered.

>>> 재확인

SYS@boston> SELECT con_id, name, open_mode FROM v$pdbs ORDER BY con_id;

    CON_ID NAME           OPEN_MODE
---------- -------------- ----------
         2 PDB$SEED       READ ONLY
         3 CHICAGO_PDB1   READ ONLY
         4 DGPDB          READ ONLY

3 rows selected.

    세 PDB 모두 READ ONLY 다. 이제 조회할 수 있다.

-- ★ 실무 팁 — 재기동 때마다 반복되는 일이다.
--   Standby 를 재기동하면 PDB 는 다시 MOUNTED 로 돌아간다.
--   기동 스크립트에 다음을 넣어 두면 잊지 않는다.
--
--     ALTER PLUGGABLE DATABASE ALL OPEN READ ONLY;
--
--   PDB 개수가 늘어나도 스크립트를 고칠 필요가 없다.

-- ★ **rmdir 을 쓴다. rm -rf 를 쓰지 않는다.**
--   rmdir 은 비어 있지 않으면 실패한다.
--   그 실패가 "살아 있는 PDB 의 디렉터리를 지우려 한다"는 경고가 된다.
--   rm -rf 에는 그 보호가 없다.
--
--   8장 실습 07 의 사고가 정확히 이 원칙을 어겨서 일어났다.

--------------------------------------------------------------------------------
 [8] 정리
--------------------------------------------------------------------------------

  · PDB 추가는 완전 자동이다. GUID 디렉터리와 datafile 디렉터리까지 만들어진다
  · GUID 는 Primary 와 Standby 가 동일하다 (6장에서 확인한 성질)
  · 새 PDB 는 Standby 에서 MOUNTED 다. 따로 열어야 한다 — 안 열면 ORA-01109
  · 기동 스크립트에 ALTER PLUGGABLE DATABASE ALL OPEN READ ONLY 를 넣어 둔다
  · 삭제는 Standby 를 먼저 닫고 Primary 에서 지운다
  · 삭제 후 파일은 사라지지만 **빈 GUID 디렉터리는 남는다**
  · 정리는 V$PDBS.GUID 와 대조해 rmdir 로 한다. rm -rf 를 쓰지 않는다
